# Jack商业启蒙——Sell Put

商业启蒙——Sell Put❤️我(Jack)最爱的策略之一

这种思维方式价值几千万



你是不是总希望“稳赚不赔”可现实世界不存在这样的机会？

但你可以选择只承担自己愿意承担的风险



Sell Put 的核心思想其实很简单：如果价格一直没有跌到我的目标，我就赚一笔权利金；如果真的跌到了，我也愿意按照这个价格长期买入。也就是说，无论哪种结果，都在我一开始的计划里。



很多人之所以焦虑，是因为总想控制结果。而我思考的是：如果事情朝两个方向发展，我是不是都能接受？



人生也是如此，找工作，有没有想过最坏的结果是什么？创业，有没有准备好失败后的成本？做自媒体，如果半年都没人看，还愿不愿意继续？如果答案是愿意，那你就已经比很多人更有优势。



真正让人痛苦的，不是结果不好，而是结果超出了自己的承担范围



我也不是每次都赢，只是从不把自己放进“一次输就出局”局面当最坏的结果你都能接受，剩下的事情，就交给时间和概念🎲
