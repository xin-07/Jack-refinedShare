# Jack商业启蒙——《广场协议》

看懂了也许你能抓到这波机会

1986年美日本等五国签署了著名的《广场协议》，推动美元贬、日元升。这件事对日本经济产生了非常深远的影响

我（Jack）先举一个例子，假设一家日本公司出口一台机器，，售价一万美元。
原本1美元＝240日元，这台机器卖出去，可以换回240万日元

后来日元大幅升值，1美元只能兑换120日元。同样一台机器，还是卖一万美元，换回日本却只有120万日元

如果生产成本没变，你说日本出口企业亏多少？但换个角度，日元升值也意味着，日本人突然变得更有购买力了。以前需要240亿日元才能买到的一栋美国写字楼，现在可能只需要140亿日元。一下子便宜了100亿日元！
