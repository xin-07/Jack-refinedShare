# Jack商业启蒙——数据中心

AI不是只有英伟达芯片，还要内存和存储

上周讲了存储

今天我们继续往下看一层

这些AI芯片、内存、存储，最后都要放在哪里运行？

答案是：数据中心

你可以把数据中心理解成AI时代的新工厂。过去的工厂里，是机器、流水线和工人；今天的数据中心里，是服务器、芯片、网络和冷却系统

但是不管技术多先进，它们都离不开一个最底层的东西：电

AI服务器非常耗电。模型越大，计算越多，需要的芯片越多，消耗的电力也越大。而且服务器发热以后，还需要大量冷却系统继续用电

所以AI时代真正的瓶颈，不只是芯片够不够，也包括电够不够、土地够不够、变压器够不够、数据中心建设速度够不够

这是商业里很重要的一条规律

越是站在台前的风口，背后越需要庞大的基础设施支撑

很多人只想要结果，却不愿意建设基础设施怎么行。

积累阅读，才能出口成章。不断试错才能拿到结果！

看到这知道要发生什么了吗

（该干正事了👍）

<br />

**AI不是凭空运行的。芯片提供算力，内存和存储提供数据能力，而数据中心把这些东西组织起来；数据中心再往下，离不开电力、土地、网络和冷却。**

**AI最终是一场对现实世界基础设施的大规模需求。**

这也是这篇最值得我们学的思维方式——**看到一个风口，不要只看台上的明星，要顺着产业链往幕后找。**
