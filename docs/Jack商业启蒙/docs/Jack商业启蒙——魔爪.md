# Jack商业启蒙——魔爪

一罐能量饮料如此赚钱

Jack商业启蒙：魔爪

上周讲了可口可乐，这周讲他儿子。很多人可能喝过魔爪但你有没有想过，为什么一罐成本并不高的饮料，能做成几十亿美元的生意？

魔爪厉害的地方是它找准了一群人。可口可乐希望全世界男女老少都喝，魔爪却把自己和赛车、极限运动、电竞、年轻人的生活方式联系起来

它卖的是一种充满力量、刺激、挑战极限的感觉

魔爪还和可口可乐建立了合作关系，借助可口可乐庞大的装瓶和分销网络，把饮料送进世界各地的超市、便利店和加油站

魔爪负责让消费者想买，可口可乐的渠道帮助它让消费者随时买得到

这就是商业中很重要的两个能力：创造需求和满足需求

很多人做内容、做生意，总希望所有人都喜欢自己。但魔爪告诉我们，你不需讨好世界

先找到一群真正需要且认同你的人，长期提供价值，再借助成熟的平台和渠道扩大影响力

商业成功不一定来自服务所有人，也可以来自把一群人的需求做到极致！



**产品解决功能需求，品牌还可以满足情感需求。**

**一罐饮料赚的钱可能有限，但一个能够长期、反复卖出产品的商业系统，价值可以非常大。**

**商业成功，不一定来自服务所有人，而是先找到一群人，理解他们的需求，建立他们愿意认同的品牌，再用成熟的系统把价值交付给他们。**

可口可乐告诉我们，如何把一种普通饮料变成全球性的日常消费品；魔爪则进一步提醒我们，即使在成熟的饮料市场中，也可以通过清晰的品牌定位和独特的消费者认同，建立自己的竞争优势。

**先做深，再做广；先创造价值，再扩大影响力。**
