# Jack分析公司——SpaceX

Jack商业启蒙SpaceX



一听到这，就觉得火箭、宇宙、马斯克，离普通人很远。但性感的地方不是把火箭送上天，而是重新思考了一个行业最底层的问题：为什么火箭只能用一次？



以前人类射火箭，很像做一次飞机就把飞机扔掉。成本极高，普通公司玩不起。SpaceX把火箭做成可重复使用。它不是在旧规则里努力省钱，而是直接改变规则本身。



这就是商业世界里非常重要的能力：不要只问“我怎么更努力”，还要问“这个系统本身有没有问题”



SpaceX的商业逻辑也很清楚。先通过可复用火箭降低发射成本，再用更低成本把卫星送上天，最后用卫星互联网服务更多用户。它不是单点突破，而是一层一层搭系统：火箭是基础设施，卫星是网络，用户连接收入。AI部分下回再说 现在八字还没一撇！

好多人这个项目做完，下个项目又从零开始。但我会想办法建立可复用的能力。你的表达沟通能力、信用、认知、方法论，都是你人生里的可复用火箭🚀
