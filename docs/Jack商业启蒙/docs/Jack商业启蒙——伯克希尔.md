# Jack商业启蒙——伯克希尔

为什么慢慢变富才是最优解

Jack商业启蒙——伯克希尔

一提到伯克希尔，就想到巴菲特，想到价值投资，想到长期持有

但如果你只把它理解成一家买股表的公司，就把它看小了。伯克希尔像一个巨大的商业收藏馆。它有保险公司、铁路公司、能源公司、制造业、零售公司、也持有很多优秀上市公司的股票

它不追热点，不会今天人工智能火了就冲进去，每天新能源火了又换方向，它核心的逻辑是找到能长期赚钱、现金流稳定、管理层靠谱的好生意，然后长期持有

其中保险业务非常关键。保险公司先收到保费，未来再慢慢赔付，中间这笔钱就可以被伯克希尔拿去投资。只要风险控制得好，这就像源源不断地资金水库

很多人想一夜暴富，什么火就追什么。但真正的富人不是靠一次爆发，而是长期积累

让大家存钱，要有耐心，才等得起好价格。提升判断力，就拿得住好资产，在别人被迫卖出的时候，有能力买入，只需要时间慢慢复利，你就能肉眼可见的看到自己变好🎉



可以把伯克希尔理解为一个拥有多种赚钱机器的商业集团。
**核心不是押中某一只股票，而是拥有一组能够长期创造价值的资产。**

保险业务可以持续产生浮存金，而投资可以让这部分资金在承担相应风险的同时创造收益。

**不要为了追求快速致富，而牺牲长期积累财富的能力。**
**复利不仅需要时间，也需要本金、正向回报和持续留在市场中的能力。**

**储蓄是在购买未来的选择权。**

**真正的富有，不是某一次赚到了多少钱，而是你建立了一套系统，让自己能够持续创造价值、积累资产，并且有底气等待好机会。**
