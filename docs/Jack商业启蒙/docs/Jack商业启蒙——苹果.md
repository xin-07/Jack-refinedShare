# Jack商业启蒙——苹果

苹果-Jack商业启蒙



苹果是一家卖手机的公司？

















认真看它，会发现苹果卖出一台iPhone，就让一个人进入她的系统



你买了手机，可能接着买耳机手表平板加电脑，然后用iCloud、App Store、Apple Music、Apple Pay。慢慢你会发现，你进入了一套生活方式，再也无法离开



它把硬件、软件、服务、审美和信任，全部连在一起



普通公司卖产品，卖完就结束了。苹果产品用户不容易更换品牌，因为数据、照片、习惯、设备连接，全都在这个系统里



所以苹果不是靠一次成交赚钱，而是靠长期关系赚钱



一个人厉害，不是只会做一件事，而是能把自己的能力连接成系统。你的表达、信用、审美、学习能力、判断力、人脉，如果都是孤立的，就很容易被替代。但如果它们组合起来，别人想到某件事就会想到你，你就有了自己的“人生生态”



最强的竞争力，不是单个产品，而是一整套让别人离不开你的系统🦌







苹果真正成功的秘诀，不是造出了一部优秀的手机，而是建立了一个完整的生态系统。



对于企业来说，竞争的终点，不是谁的单个产品最好，而是谁能建立一个让用户愿意长期留下来的系统。



对于个人来说也是一样。



**未来最强的竞争力，不是拥有一项能力，而是把阅读、学习、表达、信用、审美、人脉和行动连接成一个不断增强的个人生态系统。** 当这些能力互相促进时，你的价值就不再来自某一个技能，而来自整个系统，这也是这篇"Jack商业启蒙——苹果"最值得思考的地方。
