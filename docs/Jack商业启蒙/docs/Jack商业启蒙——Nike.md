# Jack分析公司——Nike

这周商业启蒙Nike



我(Jack)年轻是想买耐克，买不起。想买不是因为鞋子舒服，而是因为它代表一种身份。九几年谁脚上穿一双耐克，大家会羡慕万分。那时候他不是一双鞋，而是一种更先进、更洋气、更有力量感的生活方式。



Nike把普通产品变成了情绪、身份和想象。



但最近几年财报也体现出再强的品牌也不是永远安全。耐克最近增长遇到压力，中国市场下滑，库存和折扣问题也需要处理。更重要的是，鞋服行业没有什么强制绑定。你今天穿耐克，明天也可以换Hoka、On、阿迪或者lululemon。



所以品牌不是靠过去的辉煌吃一辈子，而是要不断重新赢得年轻人。



我们何尝不是如此，你过去很厉害，不代表以后别人还会选择你。真正的护城河，不是别人记得你曾经多强，而是你今天依然能提供价值，依然能让别人相信你、需要你、愿意选择你。



记下来，未来有用！



20-45岁就是打造品牌的黄金时期，45-65就是持续维护和更新自己的品牌🦌
