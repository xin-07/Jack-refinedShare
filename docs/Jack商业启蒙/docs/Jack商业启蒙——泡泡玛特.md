# Jack分析公司——泡泡玛特🧸

Jack商业启蒙——泡泡玛特🧸

粉丝：我真的看不懂泡泡玛特，一娃娃卖几百，好贵，但店里都有好多人。其实这正是商业世界最有意思的地方。



如果只看材料，一个娃就是塑料、毛绒、包装，不值几百。但消费者买的从来不只是材料。星巴克一杯咖啡的成本也不高，但有人买的是环境、品牌和生活方式；苹果手机也不只是零件，而是审美、效率和身份认同。

泡泡玛特卖的，本质是年轻人的情绪价值。

有人买不是家里缺一个娃娃，而是它可爱、特别、能晒图、能收藏、能带来惊喜。



盲盒机制又放大了这种心理：你不知道会抽到哪一个，所以购买过程想一场小型游戏。再加上限量、排队、社交媒体传播，它就从普通商品变成了“情绪资产”



大家记住：商业里最值钱的，不一定是最有用的东西，而是最能打动人心的东西。但我们要清醒：喜欢可以买，别上头，欣赏商业模式，不等于盲目消费。真正值得学的是，泡泡玛特把一娃做成了IP、情绪、社交、收藏和全球化生意👍
