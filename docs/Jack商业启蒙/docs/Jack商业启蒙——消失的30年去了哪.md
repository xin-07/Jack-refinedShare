# Jack商业启蒙——消失的30年去了哪

看懂了也许你能抓到这波机会

1986年美日本等五国签署了著名的《广场协议》，推动美元贬、日元升。这件事对日本经济产生了非常深远的影响

我（Jack）先举一个例子，假设一家日本公司出口一台机器，，售价一万美元。

原本1美元＝240日元，这台机器卖出去，可以换回240万日元

后来日元大幅升值，1美元只能兑换120日元。同样一台机器，还是卖一万美元，换回日本却只有120万日元

如果生产成本没变，你说日本出口企业亏多少？但换个角度，日元升值也意味着，日本人突然变得更有购买力了。以前需要240亿日元才能买到的一栋美国写字楼，现在可能只需要140亿日元。一下子便宜了100亿日元！

这时候，大量日本企业开始去美国购买房地产、酒店和其他资产。

其中最著名的案例，就是1989年三菱地产收购纽约洛克菲勒中心的控股权益。

当时很多日本人觉得，自己的货币越来越值钱，美国的资产相对越来越便宜，这不是天大的好机会吗？

但接下来发生的事情，就非常值得我们思考了。

我们继续举个假设的例子。一家日本公司在1989年花1亿美元买下一栋美国写字楼，当时汇率是1美元兑换140日元，相当于花了140亿日元。

后来美国房地产市场低迷，这栋楼跌到了6000万美元。

更麻烦的是，日元又升值了，1美元只能兑换80日元。

现在日本公司决定卖掉写字楼，把美元换回日元。

6000万美元乘以80，最后只剩48亿日元。

大家算一下！

当初投入140亿日元，最后只收回48亿日元，整整亏了92亿日元，本金缩水将近66%！

当然，这是假设案例，还没有计算租金、税费和融资成本。

但是它揭示了一个非常重要的规律。

**你买海外资产的时候，实际上同时承担了两种风险：资产价格变化，以及汇率变化。**

更有意思的是什么？

当年那些在高位卖掉美国房地产的人，提前拿到了真金白银。而一些日本买家，因为日元升值觉得美国资产很便宜，反而愿意出高价接手。

后来市场反转，资产跌了，汇率又朝着不利于日本买家的方向变化。

所以从结果来看，一些日本企业不仅没占到便宜，反而帮助美国资产的原持有人在高位完成了套现。

当然，这不代表所有日本投资都亏损，更不能简单理解成谁提前设计好了一场收割。

真正的问题在于：日本买家太关注日元升值带来的购买力，却可能忽略了美国资产本身是不是已经太贵。

**一件事情，对一群人是利好，对另一群人可能就是利空；今天看起来占了便宜，放到整个交易周期里，可能反而吃了大亏。**

所以以后看到某个国家货币升值，不要急着判断这个国家赚了还是亏了。

你要继续往下想：出口会怎样？进口会怎样？海外资产会怎样？企业利润会怎样？最后钱又流向了哪里？

当你能够把这些事情串起来思考，才是真正开始看懂世界是怎么运转的。
