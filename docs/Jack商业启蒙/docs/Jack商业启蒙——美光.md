# Jack分析公司——美光

Jack商业启蒙——美光



很多人一听美光，可能觉得离自己很远。它不想苹果、特斯拉那样天天被讨论，也不像麦当劳、开市客一样我们经常能看到。但美光主要做内存和存储。手机要运行，电脑要保存资料，数据中心要训练AI，智能汽车要处理信息，背后都离不开这些东西。你可以把它理解成：机器想要运转、读取、记忆，都需要美光这类公司的产品



这几年AI很火，大家都在讨论大模型、算力、机器人。但很多人忽略了一个问题：AI不只是计算，还需要存储和调用海量数据。数据越多，模型越大，对内存和存储的需求就越高。美光赚的，就是这个趋势背后的钱



你们是不是也总想站在舞台中央，做最显眼的崽🐮但商业世界里，很多真正长期的机会，来自成为别人离不开的基础设施。淘金热里，不一定是淘金的人最稳定，买、卖铲子、卖工具的人也可能赚到大钱



好好想想，如果给你一次淘金热的机会，你会做什么？
