# Jack商业启蒙——HBM、DRAM、NAND

这次我们讲三个最近很火的词：HBM、DRAM、NAND

先别被英文吓住，我(Jack)手机和电脑给大家解释

你买手机的时候，经常会看到两个数字，比如：16GB内存，512GB存储

这里的“16GB内存”，主要对于的就是DRAM。它像手机和电脑的临时工作台。你打开微信、抖音、游戏、浏览器，这些正在运行的软件，都需要放在内存里。内存越大，同时打开的东西越多，机器越不容易卡

而“512GB存储”，主要对应的就是NAND。它像长期仓库。你的照片、视频、文件、APP，关机以后还在，靠的就是存储。电脑里的固态硬盘，手机里的存储空间，本质上都和NAND有关。

那HBM是什么？

HBM可以理解成更高级、更贵、更快的内存。普通电脑跑软件，用DRAM就够了；但AI服务器训练大模型，就像几万个学生同时做题，需要疯狂读取数据。如果数据送的太慢，再贵的AI芯片也会在那里等

所以HBM就像AI芯片旁边的超级高速通道，专门负责吧数据快速送过去。

为什么它们下周这么火？

因为AI时代，不只是需要会计算的芯片，也需要大量内存和存储。模型越大，数据越多，对DRAM、NAND、HBM的需求就越高。

我希望大家的启发是不要只盯着台前最亮的明星，比如AI模型和英伟达。懂商业的人，还会看它背后的基础设施

淘金热里，不一定只有淘金的人赚钱。卖铲子、修路、建仓库的人，也可能赚到大钱

HBM、DRAM、NAND说明市场越火，越要看清楚谁在背后提供必需品
