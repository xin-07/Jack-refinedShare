# Jack商业启蒙——台积电

台积电，站在巨头背后的巨头？

Jack商业启蒙

这周我们拆解的公司是台积电

一提到科技公司，第一反应是苹果、英伟达、特斯拉、微软。因为这些公司站在台前，产品我们看得见，新闻也天天刷到

继续往后看一层：这些最先进的芯片，到底是谁制造出来的？

答案之一，就是台积电

台积电很特别。它不卖手机，不买电脑，也不卖显卡。它做的是帮助别的公司制造芯片。苹果设计自己的芯片，英伟达设计人工智能芯片，很多公司都有自己的芯片设计，但真正把这些设计变成现实，需要极高的制造能力。

这就是台积电的位置，它不像台前明星一样被普通消费者天天看到，但它站在整个科技产业最关键的环节上

台积电长期坚持一个原则：我只帮客户制造芯片，我不和客户抢生意。所以苹果、英伟达、超微半导体这些公司，才愿意把重要订单交给它。因为它们知道，台积电不是竞争对手，而是最重要的合作伙伴

所以最强的人不必站在舞台中央，而是所有人都需要你



英伟达负责画出极其复杂的建筑图纸，台积电负责拥有一座能够把这张图纸真正建出来的超级工厂。

**“会设计芯片”和“能把芯片稳定、大规模、高良率地制造出来”，是两件完全不同的事情。**

台积电长期强调自己的角色是：
**我负责制造，不直接和客户做同类芯片产品竞争。**
这形成了一种非常重要的信任关系

**与其成为某一个赢家，不如成为很多赢家共同需要的基础设施。**

所以以后你看一家公司的时候，可以多问一个问题：
**“这家公司到底是在卖一个产品，还是在占据一个别人离不开的位置？”**
