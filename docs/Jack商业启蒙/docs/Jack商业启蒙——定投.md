# Jack商业启蒙——定投

定投——朴实有性感的策略 商业启蒙

很多人觉得，投资最重要的是预测什么时候涨，什么时候跌

今天分享一个被数学验证的模型——定投

<br />

假设你有12万

第一种人，今天一次性全部买进去

第二种人，把12万分成12份，每个月投1万

如果刚买完市场就跌了30%，第一种人会非常痛苦，因为所有资金都买在了高位

而第二种人会开心，因为后面每个月都能用更便宜的价格买到更多份额。当市场重新上涨时，他的平均持仓成本已经被拉低了

这就是定投的价值：它不需要你猜市场，而是让市场波动为你服务

很多人希望一天读完十本书，一个月练成八块腹肌，一年就实现财务自由。但真正改变人生的，往往不是一次拼命，而是每天坚持一点

定投不仅是一种投资方法，更是一种人生思维

我们不用每一次都做出最完美的决定，只需要不断做正确的决定

时间，会奖励那些愿意长期坚持的人👍

<br />

**定投的性感，不在于它能让你一夜暴富，而在于它承认人很难预测未来，却依然给普通人一条可以长期执行的道路。**
