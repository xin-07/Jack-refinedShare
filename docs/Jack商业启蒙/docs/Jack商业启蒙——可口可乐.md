# Jack商业启蒙——可口可乐

为什么一瓶普通糖水，能成为百年生意？

这周分享个几乎所有人都认识的公司——可口可乐

先问大家你这辈子喝过多少瓶可口可乐？有没有想过，这家成立于1886年的公司，为什么能持续赚钱一百多年?

其实可口可乐的产品并不复杂，主要就是水、糖、香料等原料。但它建立了一套全球性的商业系统。

首先是品牌。你走进任何一家超市，看到红色包装，几乎不用思考就知道是什么。消费者对它的熟悉和信任，让它拥有一定的定价能力

其次是渠道。可口可乐不需要在全世界每个地方都自己建厂、送货。它主要通过销售浓缩液、糖浆等产品，结合全球装瓶合作伙伴，把饮料送进餐厅、超市、便利店

最后是消费习惯。一瓶饮料喝完了，下次还会买。一个消费者可能从十几岁喝到七八十岁

这也是巴菲特长期喜欢这家公司的原因之一。它不需要每年发明一个新产品，也能依靠品牌、渠道和持续消费创造现金流

分享个我（Jack）选公司的秘密㊙️

为什么一瓶普通糖水，能成为百年生意？

可口可乐的商业模式对普通人有什么启发？

很多人总想寻找下一个风口，今天做这个，明天做那个。但真正值得思考的是有没有一件事情，你可以持续做十年、二十年，越做越有优势？

你的信用、表达能力、专业知识、个人品牌，如果能够长期积累，也可能像可口可乐一样，形成别人很难复制的竞争力

其实真正强大的商业模式，不一定依靠不断创新，也可以依靠把一件普通的事情，做到全世界都需要、都认识、都愿意反复选择。

分享个我选公司的秘密㊙️



以后看一个公司是不是好公司就 看三条

1.为世界创造了什么价值

2.别人为什么做不了他做的

3.收入增加的时候是不是成本也必须同比例增加



**可口可乐的三道护城河**

1. **品牌：让消费者不用重新做选择**

2. **渠道：让产品出现在消费者需要的地方**

   商业设计：**企业不一定要亲自完成每一步，而是要设计一套能让各方共同创造价值的系统。**

3. **消费习惯：让一次交易变成长期关系**



**好生意和好价格是两回事。即使企业优秀，如果买入价格过高，投资回报也可能不理想。**

**不同公司可以采用完全不同的商业模式，但优秀的生意往往都能回答三个问题：创造价值、建立优势、有效扩大规模。**



以后研究一家企业，可以先问：

1. 它为谁解决了什么问题？

2. 为什么消费者持续选择它，而不是竞争对手？

3. 当它不断扩大规模时，能否让已有的能力发挥更大的作用？



**真正要拿走的东西：不要只想着做成一件事，而要思考怎样建立一个能够持续创造价值、不断积累优势、并且越做越有效率的系统。**
