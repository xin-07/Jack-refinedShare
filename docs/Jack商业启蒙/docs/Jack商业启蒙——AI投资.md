# Jack商业启蒙——AI投资

为什么美国正在全面被拉进了AI投资？

Jack商业启蒙，聊一个最近的现象，AI已经不只是科技公司的事情了

讲AI，想到的是模型、芯片、英伟达、微软、谷歌。
但现在你会发现，美国越来越多公司和资源，都在被拉进这场AI建设。

科技巨头要建设数据中心，所以要买芯片、买服务器、买内存、买土地、买电力、建冷却系统。数据中心公司要扩张，就需要寻找长期资金、绑定合作方、签下长期订单。电力公司要配合，就要升级电网、建变电站、签长期供电合同。

芯片公司、内存公司、设备公司、建设公司、也都被卷进来。最后你会发现，AI不再只是一个软件故事，而变成了一场巨大的基础设施建设。

这就像当年修铁路、修高速、建互联网一样。真正的大趋势一旦出现，最先火的是台前的产品，但最后被改变的是整个产业链。

当然，这里面一定有 Risk

因为大家都在投入，就容易出现过热；大家都相信未来，就容易提前把未来的钱花掉。

所以我们不能简单说AI一定会成功，也不能简单说AI只是炒作。我们要去观察这些巨额投入，未来能不能变成足够多的收入和利润。

对我们的生活启示也是如此

时代机会来的时候，不要只订着最热闹的那个人。你要往后看：谁在供电？谁在建路？谁在卖工具？谁在提供关键资源？谁成为别人离不开的基础设施？

看懂这一层，你才就不是追热点，而是在看世界怎么重新分配 资源。

我们一起持续关注着AI的发展，哪怕不做任何投资，哪怕从中悟到一些做人做事的哲学也很棒了🎉





**AI的最大商业问题已经逐渐从“能不能做出来”，变成“能不能赚回来”。**

这篇内容里最值得你拿走的东西：

**真正的大趋势，不会只改变一个行业**。
**它会重新分配整个社会的资源。**
所以当你看到一个巨大风口时，不要只盯着站在聚光灯下的人。
**往后看三层：谁给他提供工具？谁给他提供资源？谁让整个系统能够运转？**
**看懂这一层，你看到的就不再只是热点，而是一场真正的产业变迁。**
