# Jack商业启蒙——特斯拉

商业启蒙 特斯拉

这不是一家卖电动车的公司，而是重新定义了汽车这个产品

传统汽车像一台机械设备，买回家以后，功能就固定了。但特斯拉更像一台带轮子的电脑。它有软件系统，可以远程更新，可以不断优化体验。你买的是一台还会继续进化的机器

这就是特斯拉改变行业的地方，它让汽车从硬件生意，慢慢变成硬件加软件加数据加能源的系统生意

再往深一层看，特斯拉做电池、充电网络、能源存储、自动驾驶，甚至还在探索机器人。它想做的是一整套未来能源和智能机器的生态

当然，特斯拉也有很多争议。价格波动大，竞争对手越来越多，自动驾驶落地也需要时间。但正因为这样，它才值得研究

因为真正改变世界的公司是最敢重新定义问题的公司

很多人做事，只是在旧规则里更努力。别人怎么做，我也怎么做；别人卖什么，我也卖什么

但我（Jack）希望你能思考：这件事能不能被重新设计，真正的创新，不是把马车做得更快，而是让车可以换一种形态存在

<br />

以后遇到任何一个行业，都可以问自己三个问题：

**① 大家现在是怎么做的？**

**② 为什么一定要这样做？**

**③ 如果从零开始设计，会不会完全不一样？**

特斯拉真正值得学习的，不只是电动车，而是它背后的思维方式：

**不要只想着把别人正在做的事情做得更好，有时候真正的创新，是重新问一遍——这个问题为什么一定要这样解决？**
