# Jack商业启蒙——亚马逊

Jack商业启蒙-亚马逊，不是靠卖货！

这篇会写成上下两篇

上

说到亚马逊，是不是第一反应就是卖货的网站？

其实他的正在价值在于如何从电商长出了AWS-云计算

很多人以为亚马逊是一家电商公司，后来突然做了云计算？

AWS不是凭空出现的，它是亚马逊电商业务倒逼出来的能力。

想象一下，亚马逊每天有海量用户访问网站，几亿件商品要展示，订单、支付、库存、物流、推荐系统都要实时运转。尤其到了节假日大促，流量突然暴涨，如果系统崩了，损失就非常巨大。

所以亚马逊为了服务自己的电商业务，必须建立非常强大的服务器、数据库、存储、计算和工程能力

后来它发现，世界上很多公司也有同样的问题。

创业公司要做网站，要做App，要存数据，要处理订单，但自己买服务器、招工程师、建系统，成本太高，速度太慢

于是亚马逊把自己内部已经验证过的技术能力，包装成服务卖给别人

这就是AWS！

下

所以AWS本质上不是一个孤立业务，而是亚马逊多年电商经验沉淀出来的基础设施能力。AWS赚钱之后，又反过来支持亚马逊继续投资物流、会员、AI和数据中心

这对大家也有启发

这就像一个人一开始为了做内容，逼自己学会写作、表达、剪辑、运营。后来发现，这些能力不仅能服务自己的内容，还可以变成课程、咨询、社群、服务卖给别人

很多人做一件事，只看到眼前结果。但我(Jack)会把做事过程中练出来的能力，提炼出来，再卖给更多人

你做内容，会练出表达能力；做社群，会练出运营能力；做生意，会练出成交能力。这些能力如果能产品化，就可能变成你的“人生AWS”

我希望从这篇关于亚马逊的商业启蒙，让大家意识到，智慧的人，不只是完成一件事，而是把完成这件事练出来的能力，变成可以长期复用的系统！

<br />

**亚马逊最厉害的地方，不是卖了多少商品，而是它在卖货的过程中，练出了别人也愿意付钱购买的能力。**

**一个人也是一样。**

**不要只问自己今天做成了什么，要问：我为了做成这件事，练出了什么？**

**因为真正有复利的，不是你完成过多少事情，而是你在一次次做事中，沉淀出了多少可以重复使用的能力。**

**这就是我理解的——人生AWS。**
