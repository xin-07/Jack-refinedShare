有人问我：“仅靠阅读？是否能够真正提升认知？” 



我的看法是：可以，但并不充分。 



阅读能够帮助一个人看到更广阔的世界。但真正改变人的，并不是懂得了多少道理，而是是否能够将这些认知落实到现实生活之中。 



当我读到“名人传记”时，我开始坚持学习；读到“长期主义”时，我开始建立储蓄与投资的习惯； 读到“自律”时，我坚持健身二十余年；读到“现金流”与“资产”时， 我开始思考如何让财富持续创造价值 。



后来来到美国，无论语言适应、职业发展，还是投资实践，很多事情都是在不断摸索中逐步完成的。书籍未必能够直接帮助一个人获得财富，但它能够提升判断能力，帮助我们减少试错与踩坑的成本。



我始终认为：阅读更像是一张地图，而实践才是真正的行走。



真正的认知提升，来自阅读、思考、实践与复盘，并最终形成属于自己的认知体系。
