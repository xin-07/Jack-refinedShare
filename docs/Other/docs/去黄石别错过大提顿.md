# 去黄石别错过大提顿

以后大家去黄石国家公园旅行的时候，可以顺路去看看大提顿。

那里有雪山、湖泊、森林和山谷，远远看过去，真的像一幅安静的画。很多美景之所以今天还能被我们看见，其实都离不开前人一点一点的珍惜和守护。

我很喜欢这个地方背后一个故事。



当年有一位很有影响力的人来到了怀俄明的 Jackson Hole，被眼前的山川湖泊深深打动。他没有把这里当成眼前的风景，而是觉得：这么美的地方，应该让更多人、也让更久以后的人都能看到。



于是后来，他用很低调的方式，帮助这篇区域被更好地保留下来。



这个故事让我挺感动的。



一个人真正厉害的地方，不只是自己过得好，也在于他有没有愿望，把一些美好的东西留给别人。



这也让我想到，我们每个人都可以留下点什么。



可能是一段经历，可能是一种思考，可能是一句鼓励，也可能是一套让别人少走弯路的方法。



我也想问问大家：如果未来你有机会，你最想留下些什么？
