# 第18篇 已发

算ming未必是在预测未来，更像是在观察一个人的行为习惯与人生趋势。



一个人如果长期熬夜、抱怨、逃避现实、消费无度、情绪不稳定，身边又充斥着不断消耗他的人际关系，即使不依赖任何“推算”，也大概能够判断其几年后的状态不会太理想。



相反，如果一个人坚持学习、锻炼，自律存储，定期复盘，主动远离负面环境，并持续提升自己的表达能力与认知水平，那么，即便当下十分普通，未来大概率也会越来越好。



所谓“运”，很多时候是性格、习惯、环境与选择，在长期重复之后所形成的人生轨迹。



我(Jack)过去并非优秀。小时候贪玩，也不喜欢学习。如一直沿着当时的惯性继续生活，如今人生定会截然不同。后来我在人生某个阶段受到触动，开始主动改变自己，人生才逐渐发生转变。



我不完全否定xuan学的存在，但我更相信真正能够改变命运的，是行动力、认知能力，以及长期坚持的力量。



当你认真经营好每一天，所谓的运气往往也会随之慢慢改善。🦌
