# 收入不低却存不下钱？30天带你读懂普通人的“经济学常识”

朋友们，我(Jack)想问一下，大家想不想在专属会员里多了解一点经济学方面的知识？🤙



不是那种很复杂、很学术的经济学，而是普通人真的用得上的东西。比如：为什么钱会越来越不值钱？💰通货膨胀到底怎么影响我们的生活？利率上涨和下降，对房子、股票、工作机会会有什么影响？为什么有的人收入不低却一直存不下钱什么是现金流？什么是资产和负债？为什么经济有周期，普通人又该怎么在周期里保护自己m



我觉得年轻人越早看懂这些底层规律，人生就越不容易被情绪、消费和环境牵着走。你会慢慢知道，钱是怎么来的，怎么流走的，怎么留下来的🎊



所以我想用最简单的语言，把世界运行的规则一点点讲明白。



下周开始，我准备每天带大家解读一本书的一部分，争取用三十天读完一本书。第一本我已经想好了，叫《小岛经济学》。



这本书特别适合普通人入门经济学，因为它不是一上来讲各种复杂概念，而是用一个小岛的故事，讲清楚储蓄、生产、消费、货币、通胀、经济周期这些最基本的问题。



所以做切片的朋友，也可以提前准备起来。到时候你们可以找这本书挂上，会员们如果想买实体书，也可以从你们店铺。



我希望跟着我一起做内容、一起坚持、一起成长的人，也能从这个过程中得到回报。



这一次，我们就把读书、成长、内容结合起来
