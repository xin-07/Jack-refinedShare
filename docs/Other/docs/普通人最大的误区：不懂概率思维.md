# 普通人最大的误区，不是失败，而是不懂"概率思维"

Jack和一个粉丝聊天，他说最近摆摊生意很差想放弃。我问摆了几天？他：一个星期



我说，一个星期就判断太早了



然后我和他讲了一个关于概率在他生意里的运用



比如你卖烤肠，第一天卖出去十根，你不能马上说废了。你要复盘：是不是位置太偏是不是招牌不够明显是不是价格没写清楚是不是你站在那里太安静是不是别人买一根，你也没有提醒他朋友也带一根



第二天换个位置。第三天把招牌写大一点。第四天试试买两根便宜一块。第五天观察哪个时间段人最多。第六天拍个视频。第七天主动和路过的人打招呼。



我(Jack)做事喜欢一眼看穿这事情的期望概率，比如投硬币，不管前面多少次正面，我知道只要次数足够多 最后正反面必然一样。这的确很需要阅历和智慧。但这能力完全可以培养和提高



我们都会失败，但每失败一次，都能能多看懂一点规律。别失败一次就说运行不好 或者自己不行



其实做自媒体也是一样的。



很多人刚开始发视频，发了三天没人看，发了一个星期有几十个播放，就开始怀疑自己：是不是我不适合做自媒体？是不是我长得不行？是不是我表达太差？是不是这个赛道已经没有机会了？



真正重要的不是第一条视频有没有爆，而是你有没有在提高下一条视频被人看到、被人喜欢、被人转发的概率。



比如你今天发了一条没人看，那你就复盘：开头是不是太慢？标题是不是不够清楚？封面是不是没有吸引力？你讲的是不是太散？有没有一句话能让别人记住？评论区有没有提出问题？同类型做得好的人，他们前五秒时怎么说的？



第二条，你把开头改短一点。第三条，你把标题写得更直接。第四条，你尝试将一个自己的故事。第五条，你看完评论区再选题。第六条，你学会把一句话讲得更有力量。



最后总结一下：



普通人做一次失败一次，我希望大家是失败一次复盘一次，改进后然后再试一次，失败了不断重复上一个步骤，最终必然成功🏆



这是我几十年发现的秘密：大多事情长期坚持做，不断复盘改进，就能提高成功🥇的概率，记住 概率 概率 概率！不是说你下次就一定成功！概率的体现必须建立在大量的样本下，所以？



你们来续写所以之后的话，能写出来🙏代表你获得了这条价值千万的秘密
