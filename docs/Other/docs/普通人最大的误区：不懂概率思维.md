# 美光、闪迪大涨，很多人却看不懂？揭开AI背后隐藏的“真金白银”

今天美光和闪迪都大上，很多人第一反应是这是啥玩意？



美光、闪迪、光模块、AI服务器、存储、算力、数据中心……这些名字听起来很专业，但它们背后其实都是同一个大趋势：AI不是一个软件故事，而是一个巨大的产业链重构。



未来很多改变世界的公司，不一定是你每天听到的那些AI应用公司，而可能是藏在后面的硬件、存储、网络、能源、散热、芯片、设备公司。



有人觉得它们只是短期周期景气，收入不可持续；

也有人认为这是未来二十年最重要的基础设施升级。



不管大家是否做投资，我都建议你们开始理解这个产业链。因为看懂这些公司，就看懂未来世界的钱、技术和机会往哪里流。
