# 第7篇

海明威在Key West生活时，清晨天还没完全亮，就会起床写作。那时没有现代空调南男佛罗里达潮湿闷热，所以他必须趁一天最安静、最凉爽的时候，把脑子里最清醒的部分交给作品。



他每天写得不算多，常常几百字，但极其认真。写完以后，他会出海钓鱼、喝酒、聊天、观察渔民、拳击手、水手和旅人。别人把这些当生活，他把这些变成小说。



后来，他成了世界级作家，拥有房子、船、版权和可观财富。据公开资料，他去世后遗产约140万美元，在当时已经是非常成功的作家。



这给我最大的启发是：



真正厉害的人，不是每天做惊天动地的大事，而是在最清醒的时间，持续做重要的事。



每天几百字，看起来很少；

但写十年，就是命运的复利。



普通人经历生活，只留下情绪。

高手经历生活，留下作品、资产和影响力。
