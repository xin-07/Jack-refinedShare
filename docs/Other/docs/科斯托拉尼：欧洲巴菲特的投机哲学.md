# 第14篇 已发

看了昨天一些公司财报，突然想介绍一位tou机大师，被称为“欧洲巴菲特”——科斯托拉尼。我直播的时候说过他的一句名言：经济像主人，股市像狗，狗一会跑到前面，一会儿落在后面，但最终还是围着主人走。



他1906生于布达佩斯，原本学哲学，后被父亲送到巴黎学证券交易。1929经历大萧条靠市场赚过钱。二战时期，法国被德国占领，他逃到纽约；战后回到欧洲，参与德国复兴，并在之后经济增长中积累到财富。1999年去世，93岁。

他的tou机哲学值得一看，尤其是在现在这样的环境下。



我总结三条他的tou机哲学：

第一，不要在人声鼎沸的时候失去理性。

所有人都说某个东西稳赚，往往已经很危险。



第二，不要在最悲观的时候失去勇气。

真正便宜的资产，通常出现在大家都不想看的时候。



第三，不要用借来的钱du自己的判断。

市场可以长期不按你的逻辑走如果你没有现金流，没有耐心、没有安全垫，就算方向对，也可能先被市场淘汰。
