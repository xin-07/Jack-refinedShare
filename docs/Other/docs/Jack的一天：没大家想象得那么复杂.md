# Jack的一天

很多粉丝问Jack一天是怎么安排



没大家想象得那么复杂，也没什么神秘的方法



我每天最重要的事情只有五件



第一，锻炼身体——每天1h力量 0.5h有氧



第二，阅读和思考——我每天都会花大量时间看历史、商业、科技、投资这些内容 平均每天2-4h



第三，创造价值——参加活动、写作、直播、写专属会员和大家交流，把自己学到的东西分享出去 平均每天3h



第四，投资——研究优秀公司的商业模式，vix（恐慌指数）突破25才通过sell put出手 每天1h



第五，陪伴家人——陪孩子训练，和家人吃饭聊天，陪嫂子看片。每天2h



每天晚上睡8h 下午锻炼回来1h 晚饭前困的话再睡1h



我35岁之后所有事情都是围绕以下目标：身体好，脑子好，情绪稳，家庭和谐，财富自动增长，社会资源丰富，且自己的价值还能分享给更多人🎉
