古埃及方尖碑是怎么建造出来的？



先问大家几个问题



四千五百年前，没有钢铁切割机，没有吊车，没有卡车，没有电，没有发动机，他们怎么从整块花岗岩上凿下一根几百吨重的石柱？又怎么把它运到几百公里外，再稳稳地立起来？



当我看完之后，我脑子里一直在想另一件事



对于当时的一名普通工匠来说，他可能一辈子都在做同一件事：每天挥动石锤一下、又一下。他也许看不到方尖碑最终竖立的那一天，更不知道几千年后还有人会研究他的作品



这件事好像毫无意义。但对他们来说，这就是一生，就是使命



今天的我们，拥有互联网、AI、汽车、起重机和各种工具，完成事情的效率比古人高了百倍，却常常因为一点困难就放弃，因为几个月没有结果就怀疑自己



因为我们的耐心不够🙏



当你知道四千多年前的人类能完成这样的壮举，你会更珍惜今天拥有的一切，也会更相信：长期坚持，本身就是一种能够创造奇迹的力量👍
