前天直播讲扔硬币爆火的切片值得写下来

假设Jack是老师

让全班同学，每人拿一枚硬币，连续抛100次，把每一次的结果记录下来，第二天交给我



有人嫌麻烦，不抛硬币，自己编一份答案交上来

当收到了所有人的作业时，我只看纸上的100次结果，就能大概判断出，哪些人是真的抛了硬币，哪些人是自己编的



大家猜，我是怎么看出来的？









很多人第一反应是看正反面的数量

其实不是❌



真正暴露他们的，是连续出现相同结果的次数



自己编答案的人，总觉得随机应该很均匀，所以会下意识写成：正、反、正、反……或者最多连续三四个正面



因为他们觉得，连续七八个正面太假了

可真正的随机，恰恰不是这样。



如果你真的抛100次硬币，连续出现六七个，甚至八个正面，都是完全可能发生的事情



真正随机的世界，往往看起来一点都不随机

而人脑编出来的随机，反而整整齐齐



送大家一句我们精算秘密

随机最大的特点，就是它看起来不像随机
