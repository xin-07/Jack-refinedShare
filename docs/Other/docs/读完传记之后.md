# 第11篇 已发

早上好



读完传记之后



可以开始读自律和习惯类，如时间管理、习惯养成、长期主义。因为光有榜样不够，还要把热血变成每天的行动。



表达和沟通类的书也值得看。20多岁很多机会不是你没能力，而是你不会表达，不会沟通，不会让别人看见你的价值。



进入社会后，早点理解钱、资产、现金流、复利和商业规则。



开始社交后，你会遇到焦虑、比较、失败、嫉妒、拖延和关系问题。学点人性，才能少内耗。



30岁开始读历史和社会规则类。因为这时候不能只看自己，还要看懂时代、制度、周期和世界怎么运转。



其实这些书不需要全部看完。一年认真读两三本真正有价值的书，十几年下来，就足够让一个人的认知系统和大多数人拉开差距。



我（Jack）做专属会员的目标，就是把这些厚重的、零散、难消化的内容，拆成每天都能看懂、能思考、能吸收的一小块。哪怕你暂时没时间读很多书，只要每天习惯性看看这里，也能慢慢打开眼界，建立高认知系统🎊
