# 第32篇 已发 真正厉害的沟通：不是展现自己多厉害，而是让别人听懂你

上次聊了表达能力，今天说说沟通能力



这是一种连接人的能力。不同于表达，沟通不是展现自己多厉害，而是让别人听懂你，让误解减少，让信任增加，让不同立场的人愿意一起把事情做成。



老师要和家长和学生沟通。一个老板要和员工讲清目标，和客户讲清价值，和合作伙伴讲清规则。一个产品经理要协调研发、设计、运营和市场团队；一个销售要理解客户需求、推动合作落地；运营要和用户建立连接、把内容价值传递清楚。无论你是职场新人还团队负责人，沟通能力都会直接影响你的发展空间。



所有沟通不是嘴巴的能力，而是脑子的能力、情绪的能力、结构的能力。



怎么练？

我(Jack)的经验：每天练习三件事：

第一，把复杂事情讲简单，这个和表达能力重合

第二，遇到冲突时先复述对方的意思，不要急着反驳

第三，写任何消息、邮件、通知，都做到清楚、礼貌、可执行



一个人会沟通，人生会少很多内耗。因为很多问题，本来不是能力问题，而是没说清楚🦌
