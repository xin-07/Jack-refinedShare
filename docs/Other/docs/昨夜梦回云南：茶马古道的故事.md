# 昨夜梦回云南🏔️总有人想看看山那边到底是什么

昨天做梦回到了云南。想到了茶马古道



茶马古道最核心的是“以茶易马”云南盛产茶叶而青藏高原长期以牛羊肉和奶制品为主，茶能帮助消食，藏区对茶需求很大。与此同时，中原有需要高原马匹，于是形成了长期的茶马贸易。



真正支撑这条古道的，是一代代马帮人🐎他们常常赶着马队翻雪山、过峡谷，一走就是几个月，途中可能遭遇塌方、雪崩、土匪，甚至葬身江谷。但为了养家糊口，很多人仍不得不上路。



今天云南许多古城、驿站和石板路，其实都留下了茶马古道的痕迹。



在没有现代交通的年代，人们仅靠马匹、双脚和勇气，就把大山⛰走成了通向世界的路。



这也让我想到丝绸之路、大航海时代、真缅公路



推动世界前进的，不只是有了地图。
