# 第2篇 已发

中国普通人拉开差距，其实有一条很现实的规律。



20岁想进同龄人前20%，如果已经出来工作，年收入大概6万到12万就不差了。这个阶段靠的是醒悟早、肯吃苦、高强度执行。别人还在迷茫，你已经开始赚钱、存钱、积累社会经验。



30岁想进前20%，年收入大概要18万到30万。这个阶段靠的不只是努力，而是选对行业。科技、金融、医疗、工程、销售、创业这些赛道，才能把一个人的努力放大。



但到了40岁，真正拉开差距的，往往不只是工资，而是你有没有把收入变成资产。很多家庭的财富不在现金里，而是在房子、理财、股权、生意和长期积累里。



年轻时赚得多很重要，但如果赚多少花多少，十年后还是空的。真正改变命运的人，是把工资变成存款，把存款变成资产，把资产变成现金流，最后让系统替自己赚钱。



所以普通人不要只羡慕别人收入高，更要问自己：我现在的努力，有没有沉淀成能力、信用、资产和影响力？



六年之约核心是什么？





——Jack要加油
