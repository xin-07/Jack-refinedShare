# 第35篇 已发 除了祝你好成绩，我更想和你聊聊高考后的这几年🎓

高考结束的同学们，除了祝福好成绩！

我(Jack)也把一些陪伴我成长的智慧分享给你们。



高考结束后是你人生快速成长的开始。真正拉开人与人差距的，往往不是高考，而是高考之后的几年。



先让自己的心沉下来，玩几天。别把书给扔咯



我见过太多人，一进大学就开始放纵：熬夜、🦌、游戏、刷视频、攀比消费、谈一段消耗自己的感情。四年过去，学历有了，能力没有；年龄大了，心智没长。等毕业面对社会，才发现自己并没有真正准备好。



这些年我越来越相信，一个人想走得远，先要学会克制诱惑，保持专注。才华不是天生的，而是在日复一日的学习中积累出来的；你一定要尽早问自己：我到底想成为什么样的人？我想靠什么能力在社会上立足？我现在每天做的事，是在靠近那个未来，还是在逃避那个未来？



我当年也不是一路顺风的人。一路走来，我发现真正改变命运的，不是某一次考试，而是后来长期的自律、学习、思考和行动。很多时候，当别人沉迷娱乐的时候，我选择积累；当别人抱怨环境的时候，我选择提升自己。时间久了，差距自然就出现了。

所以从今天开始，不要急着放飞自己。每天读一点书，练一点表达，学一点商业和科技，锻炼身体，远离烂人烂事。你越早建立属于自己的人生系统，未来就越不会被命运推着走。



最后分享给所有年轻人一句话：人生是一场长跑，高考知识其中一个路标。

愿你们保持清醒，保持学习，保持成长，在未来的某一天，感谢今天命运虚度光阴的自己。
