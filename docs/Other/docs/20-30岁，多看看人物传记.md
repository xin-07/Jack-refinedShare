# 第9篇 已发

我(Jack)觉得20-30岁的人，真的可以多看看人物传记。



这个阶段最容易迷茫：刚进社会，不知道自己适合什么；赚钱了，却不懂钱怎么赚得更长久；看到别人发展很快，又容易焦虑和怀疑自己。



人物传记最有价值的地方，不是让你崇拜谁，而是让你看到一个人完整的成长过程：他如何选择、经历失败、被现实打击，又怎样抓住机会，慢慢建立自己的体系。



比如读富兰克林，你会发现普通人也能靠自律和表达能力改变人生；读洛克菲勒，会明白财富背后更重要的是纪律和长期思维；读乔布斯，会感受到创造力和极致追求的力量；读巴菲特，则能理解真正的复利不仅是财富，还有认知和耐心。



20-30岁最怕的不是起点低，而是没有参考样本，只能不断和身边人比较。看传记会让你知道，很多厉害的人一开始也很菜，都是在一次次选择和坚持里慢慢走出来的。



所以这个年纪读传记，本质上是在给自己找“精神导师”。当你焦虑、迷茫时，他们会提醒你：别着急，Jack爱你
