今天看《安妮日记》，有一段让我(Jack)一下子想到自己二十岁出头的时候。



我发现，年轻的时候最难受的，不是没钱，而是没人真正理解你。



你开始思考人生是为了什么，开始怀疑很多以前觉得理所当然的事情。你想努力改变自己，想成为更好的人，可现实总会不断打击你。今天觉得找到答案了，明天有发现好像不是这么回事。



更难的是，很多大人都会告诉你：“等你长大就知道了。”“以后你就明白了。”可他们不知道，当时的那些迷茫、孤独和焦虑，对我们来说都是真的，不是一句“以后就好了”就能过去。



我记得自己那时候特别喜欢看书，不是因为喜欢考试，而是总觉得这个世界一定有人已经思考过我遇到的问题。我想找到一个答案，一个能让我坚定走下去的答案。



现在回头看，我才明白，年轻并不是没有答案，而是在不断寻找答案的路上。



不知道你们十几岁、二十岁的时候，有没有这种感觉？
