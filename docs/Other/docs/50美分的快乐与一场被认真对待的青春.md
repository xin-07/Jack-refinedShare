# 50美分的快乐与一场被认真对待的青春

今天参加活动认识一大叔，说起他年轻的时候

那是1960的周六晚上



天还没黑，大家已经换好衣服，三三两两往同一个地方走去。那里没有这么多电子设备，也没有短视频，只有一间普通的大厅、几盏灯、一台唱片机，还有一群愿意在一起跳舞、聊天、欢笑的年轻人。



门票只要五十美分。有人负责收票，有人负责卖可乐、薯片和糖果，还有人负责结束后一起打扫。那时候的快乐很简单，一首歌响起，害羞的人鼓起勇气邀请喜欢的人跳舞，朋友们站在旁边起哄



一年冬天，一个本地乐队原本要来表演，结果因为大雪迟到了。年轻人们有些失望，但乐队后来专门回来补上了那场演出，他们唱歌、跳舞，和大家一起度过了一个难忘的夜晚。很多年以后，人们可能早已忘记那天穿了什么衣服，却还记得那种被认真对待的感觉



舞会结束后，年纪小一点的孩子会去吃汉堡薯条，年纪大一点、已经会开车的孩子会去吃披萨。



人们在这里长大、相遇、告别
