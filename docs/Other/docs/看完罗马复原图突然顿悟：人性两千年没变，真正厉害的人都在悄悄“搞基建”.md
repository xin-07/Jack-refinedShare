# 第28篇 已发 看完罗马复原图突然顿悟：人性两千年没变，真正厉害的人都在悄悄“搞基建”

今天看罗马诚中心的复原图，我突然大脑性感了。



两千年前的罗马市中心，就像今天的华盛顿、纽约、华尔街、国会山和大型体育场全部集中在一起。那里有养老院，有寺庙，有市场，有法院，有斗兽场，有公共浴场。政治、商业、信仰、娱乐和日常生活，全都在同一个城市系统里运转。



两千年前的人和今天的人，没有那么不同。他们也要赚钱，也要政权，也要社交，也要娱乐，也会焦虑，也会追求荣耀。只是他们没有手机，没有互联网，但人性几乎没有变。



古罗马征服了不少土地，它把道路、法律、税收、军队、市场、城市供水、公共建筑和社会秩序组合成了一个巨大的系统。一个文明真正强大，不是靠某一个英雄，而是靠无数看不见的制度和基础设施持续运转。



很多人总是逆袭，发财，被看见。但真正稳定的成长，和一座城市一样，都是一点点建设出来的。每天学习一点，存下一点，锻炼一次，提升一点表达，修正一个习惯，几年后你的人生系统就会不同，大家觉得呢🦌
