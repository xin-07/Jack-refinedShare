# 第5篇 已发

每次开车穿过美国西部平原，或者坐飞机从高空往下看，我都会被眼前的景象震撼。



大地像一床巨大的被子，有的是方块，有的是圆形。方块是被道路和农田切开的土地，圆形多半是灌溉系统转出来的痕迹。



单这片整齐的土地，曾经不是这样的。



大平原曾经是野牛、草原和印第安人的世界。后来灌溉技术、农业机械、铁路和y民进入这里，草原被犁开，农场取代了原始生态。



文明的进步从来不是免费的。我们的成长，又何尝不是呢？



一个新系统的崛起，往往意味着一个旧世界的退场。真正有智慧的人，不只是赞美发展，也会看见代价。



人生也是一样。



每一次成长，都意味着你要放弃一些旧习惯、旧圈子、旧认知。你想变成一个新的人，就必须允许过去那个自己慢慢退场。



六年之约里，你准备让哪个新习惯，替代你身上的一个坏习惯？
