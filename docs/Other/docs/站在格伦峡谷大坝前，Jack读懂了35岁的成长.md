# 第36篇 已发 站在格伦峡谷大坝前，Jack读懂了35岁的成长

去年，我(Jack)去过格伦峡谷大坝和鲍威尔湖。💦



当时站在大坝上玩下看。一边是巨大的混凝土，一边是被拦住的蓝色湖水，远处是红色砂岩和一望无际的沙漠。🏜



那种感觉很奇妙：你会同时被人类的能力震撼，也会隐隐觉得，这一切一定有代价。



鲍威尔湖不是天然湖，而是科罗拉多河被格伦峡谷大坝拦住以后形成的。



它让沙漠里面有了水面、游船🛶、钓鱼、度假，也提供了电力和蓄水。但与此同时，原来的格伦峡谷被水淹没，河流的自然节奏也被改变。



当时我就在想，技术发展常常不是简单的“好”或“坏”。人类每获得一种便利，背后可能都牺牲了某种原始的东西。



人生也是一样。想要新的生活，就要牺牲旧的习惯。想获得更大的自由，就要承担更大的责任。



35岁以后，不只赞美宏伟建设，也不只盯着代价，而是能看见和接受复杂性



世界从来不是单选题，成长也不是，不是做一个非黑即白的人
