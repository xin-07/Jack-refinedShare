# 第23篇 已发 戏剧《小镇》的一段拆解

希望看完以下内容让你平和



我早上看的剧本《小镇》，表面上写的是美guo一个普通小镇。



最打动我的是第三幕。女主角艾米丽去世后，获得一次机会，回到自己12岁生日那天，重新看一遍曾经的生活。



她看到妈妈在厨房忙碌，爸爸回家，家人说着很普通的话，阳光照进屋子，早餐摆在桌上。可她突然崩溃了，因为她发现：这些当年觉得无聊、普通、理所当然的瞬间，原来都是最珍贵的人生。



她最后说的大意是：人活着的时候，真的意识到自己正在活着吗？



我在三十多岁的时候逐渐意识到人生不是只有成功、财富、远方、掌声才值得珍惜。🙏很多最幸福的东西，早就藏在普通的一天里。家人还在，身体还好，能吃一顿饭，能晒到太阳，能和爱的人说几句话，这些看起来平凡的瞬间，可能才是后来最想回去的地方。



你有过这种幸福的瞬间吗。评论区点赞留言吧🎊
