# 第21篇 已发 清晨六点，一杯咖啡，和几十年前的新英格兰

早上六点起来，屋子里还很安静。



我拉开窗帘，外面是蓝天白云，阳光一点点落进房间。那一刻，突然觉得生活其实不需要太复杂。



下楼，给自己做了一杯咖啡。咖啡香慢慢升起来，整个早餐也跟着醒了。



我(Jack)坐在靠窗的沙发上，手里拿着一个几十年前的剧本——桑顿·怀尔德的戏剧《小镇》。



这部剧1938年上演，也曾经来到我现在居住的麻州，在波士顿演出。想到这一点，突然有一种奇妙的感觉：几十年前，有人也在这片新英格兰的土地上，坐在剧场里，看着舞台上的小镇、家庭、清晨、婚礼、离别和死亡。



而今天，我坐在窗边，喝着咖啡，读着同一个故事。



窗外是今天的蓝色，手里是几十年前的人生。很多年前的人，也曾经认真观察生活，认真写下他们眼里的世界、爱情、命运和时间。



大家如果感兴趣，等会儿我把剧本里最让我有感触的一段，拆给大家听。
