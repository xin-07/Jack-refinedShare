# 第31篇 已发 致所有被低估的女孩：请像她一样，绝不降低你的人生高度

今天想借阿梅莉亚·埃尔哈特(Amelia Earhart)的故事，专门感谢一下我(Jack)的女粉丝。



她是上个世纪最著名的女飞行员之一。那个年代，飞行本来就很危险，很多人甚至觉得女人不该开飞机，更不该去挑战天空。但她偏偏不信这个。1932年，她成为第一位独自飞越大西洋的女性。后来，她又去挑战环球飞行，虽然最后在太平洋上神秘失踪，但她留下的不是失败，而是一种精神：女人也可以勇敢、自由、坚定地去探索自己的世界。



我知道很多关注我(Jack)的女性，也经常过不被理解、被否定、被打压，甚至一边受伤一边努力生活。



但我真的想告诉你们：你们身上那种柔软里带着坚强、脆弱里还愿意向前走的力量，特别珍贵。



不要因为别人的眼光，就把自己的人生飞行高度降下来。



愿你们都像她一样，哪怕世界曾经说“不行”，你也依然敢抬头看天空，敢去寻找属于自己的远方。
