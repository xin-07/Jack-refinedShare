# 《Valkyrie》：当整个时代犯错，一个人还能坚持自己的良知吗？

这周推荐大家看一部电影，英文名叫Valkyrie，

2008年上映 帅哥阿汤哥主演🥰



这部电影讲的是：在一个巨大的时代漩涡里，一群身处系统内部的人，终于意识到继续沉默会把国家和无数普通人推向更深的灾难，于是决定冒着生命危险，做一次几乎不可能成功的行动。



看的话拿好🧻，反正我(Jack)是真的哭了几次😭



里面剧情很刺激 但是需要一点点历史知识，未来再讲那段(比较敏感)



主要看点：人的选择！



很多时候，一个人不是一开始就清醒的，而是在看到代价越来越大之后，才开始问自己：我应不应该听内心的良知？



看完后大家思考一个问题：当大环境错了，普通人还能不能保留自己的判断力和勇气❤️





Jack其实想借这部电影提醒大家：



历史虽然离我们很远，但人性的考验一直都存在。



未来无论是AI时代、商业社会，还是个人成长，

真正重要的能力不仅是知识，更是：

保持独立思考，不盲从；

保持良知，不因为环境而放弃原则；

在关键时刻，做出自己认为正确的选择，并承担相应的责任。



这也是为什么他说："人的选择"，才是这部电影最值得看的地方。
