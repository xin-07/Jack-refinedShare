# 第3篇 已发

很多人以为要等有了钱生活变好了，状态才会变好；但真正改变命运的人是先把自己的状态调起来，再去改变生活。



我特别有感触。因为我以前也不是一个天生自信、天生优秀的人。小时候我学习不好，也被老师否定过。那时候如果我一直沉浸在“我不行”的状态里，我的人生可能真的就被那句话定义了。



但后来我心里憋着一口气。我开始逼自己坐下来学习，开始告诉自己：我不能永远这样。状态一变，行为就变了；行为一变，结果也慢慢变了。后来我考到全校第一，再后来出国、找工作、奋斗、创业、投资、财富自由，回头看，命运不是突然改变的，而是从我不再接受低能量的自己开始的。



所以你现在焦虑、迷茫、痛苦，都没有关系。先别急着证明自己，先把状态调回来：睡好觉，动起来，吃干净一点，每天做一件让自己变好的小事。



人不是有希望才行动，而是行动之后，才重新看见希望。



大家每天睡好觉，运动十分钟，吃的健康一点，看二十分钟书！那就留言告诉我吧





——Jack要加油
