# 未来最值钱的能力，不是会用AI，而是专注力

我（Jack）再次强调未来最值钱的能力，不是会不会用AI，而是专注力



未来，AI会帮你做一切流程化事情。但有一样东西，AI替代不了——你愿不愿意关掉手机，静下心去做真正重要的事。



这也是为什么，我创造了这个方法。



如果你刷到我的视频，就先点赞，然后留言一句：“Jack，我现在要去做__ ，预计__分钟。”

留言之后，马上退出抖音，去完成它。等做完了，再回来刷。如果又刷到我的视频，就再留言一次，再去做一件正事
