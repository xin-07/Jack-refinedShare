# 20-30岁到底应该读什么？

上一篇很多人问我：20-30岁到底应该读什么？



我说这个年龄，其实特别适合多看看人物传记。今天就应大家要求，给大家推荐几个我自己觉得很值得了解的人。



看富兰克林，不是只看他多厉害，而是看他怎么靠阅读、写作、自律、社交和信用，从一个普通人一步步变成影响时代的人。



看洛克菲勒，重点不是看他多有钱，而是看他怎么记账、节俭、控制成本、长期思考，最后建立自己的财富系统。尤其可以看看他写给子女的信。



看巴菲特，要看他为什么能几十年保持耐心，不追热点，不乱出手，靠复利和理性慢慢变富。时间多的话，也可以顺便了解一下他的好基友查理芒格。



看乔布斯，不只是看苹果多成功，而是看他对产品、审美、用户体验和极致标准的追求。尤其是他早期产品卖得不好、后来又被自己公司赶出去那段低谷，很值得看。



看苏东坡，重点看他被贬、失意、人生低谷的时候，为什么还能活得那么幽默、豁达、有才华。顺便品一下性感👄美文
