# 2周50篇文章20000字的积累

恭喜大家！这2周，你一共阅读了我(Jack)50篇文章，共计20000字！慢慢积累起来，是一件很可怕的事情。



一年下来，几乎就是60万字，相当于3到4本书。关键是培养了每天阅读的习惯。



但重点还不是字数，而是这些内容背后的收获。



这一周，我们聊了消费观、表达能力、人物传记、金钱认知、长期主义，以及未来哪些东西会贬值。你每天看一点，可能当下觉得只是几分钟，但一年之后，你接触到的就是一整套人生认知系统。



读书最难的地方，不是买书，而是坚持读、理解、消化，并运用到生活里。



我做这些内容，就是希望把厚书、难书、复杂的道理，拆成你每天都能看懂、能吸收、能行动的一小块。



你每天看一点，一年之后，改变的可能不是知识量，而是你看世界的眼光。



我希望大家在年轻的时候保持阅读习惯，广泛了解一切知识，深入一个领域产出作品！ 



我(Jack)也会为此努力的，让这里变成我们的秘密家园🎉
