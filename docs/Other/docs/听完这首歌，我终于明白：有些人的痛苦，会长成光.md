# 第42篇 听完这首歌，我终于明白：有些人的痛苦，会长成光

今天一个朋友车里放了一首歌，我觉得好听，回去搜了一下



没想到一搜，背后这么多故事，她叫比莉·哈乐黛。

不是音乐特别完美、技巧特别炫的人，但她唱歌特别有感觉。她的人生其实非常苦，从小生活就很动荡，经历过贫穷、伤害、歧视和很多底层生活的痛苦



她唱歌不是在表演悲伤，而是自己人生里的那些难过唱出来



她最有名的一首歌《Strange Fruit》，讲的是美国黑人被私刑吊si的历史。这已经不是普通音乐了，更是一种控诉



有的歌唱得很准，但你听完没感觉，有些声音不一定完美，但你能听到她人生里真的有过痛苦、挣扎和灵魂



每一次和大家连线，我(Jack)就会发现，好多孩子其实都经历过原生家庭的问题、校园霸凌、自卑、否定



痛苦如果没有毁掉你。反而会变成你表达世界、理解别人、影响他人的力量



所以不要因为自己的过去，觉得低人一等。很多未来特别有力量的人，都是从那些不被理解、不被看见的日子里，一点一点长出来的
