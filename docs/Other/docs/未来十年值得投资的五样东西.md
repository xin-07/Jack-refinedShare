# 第13篇 已发

未来十年，我们要分清：哪些会越来越不值钱，哪些才是真正值得投资的。我总结了五样



一，重复性的工作会越来越不值钱。所以，不要只花钱买短暂的快乐，也要投资自己的技能、表达能力和学习能力，让自己变得不容易被替代。



二，普通信息越来越不值钱。值钱的不是谁知道得多，而是谁有判断能力、有真实经历、有自己的观点。所以，与其乱买一堆没用的东西，不如多买几本好书，多出去见见世面。



三，学历的光环会变弱。不是学历没用，而是光有学历已经不够了 。重要的是沟通、解决问题，以及适应变化的能力。



四，私家车会越来越像电子产品，更新快、贬值快。车可以买，但别为了面子而过度消费。



五，维护成本高的高层住宅也可能不再稀缺。稀缺的是好地段、好现金流，以及高质量的生活。



所以花钱的时候问问自己，这笔花费是让我变得更强，还是只是让我看起来更分光

我最愿意投资的东西：健康、认知、判断力、长期主义，以及那个不可替代的自己🦌
