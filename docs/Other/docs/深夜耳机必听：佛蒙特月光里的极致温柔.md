# 深夜耳机必听：佛蒙特月光里的极致温柔

推荐在晚上🌃戴上耳机听《Moonlight in Vermont》



这是一首美国经典流行歌曲 / 爵士标准曲。



中文可译为：《佛蒙特月光》或《月光下的佛蒙特》



作曲：Karl Suessdorf

作词：John Blackburn

首次发表：1944年左右



这首歌写的是美国东北部 Vermont 佛蒙特州 的宁静风景：月光、秋叶、雪景、牧场、山谷，非常温柔、怀旧、浪漫。



歌词很多句子像一副副画面，不是完整叙事，而是意象叠加，比如：



“Pennies in a stream“

溪流里的铜币般闪光



”Falling leaves“

飘落的叶子



”Moonlight in Vermont“

佛蒙特的月光
