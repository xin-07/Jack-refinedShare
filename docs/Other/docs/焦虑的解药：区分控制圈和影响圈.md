# 第27篇 已发 焦虑的解药：区分控制圈和影响圈

受不了饿了！😝



憋不住想和大家分享一个两千年前的人。马克·奥勒留



古罗马皇帝，也是《沉思录》的作者。



很多人认为他是人类历史上最伟大的统治者之一。



白天，他要管理横跨欧亚非三大洲的帝国；晚上，他却会独自写下对人生的思考。



《沉思录》里面有一句话特别触动我：



“你无法控制外界发生什么，但你可以控制自己如何回应。”



这句话看似简单，却藏着改变命运的力量。



我们人生中很多痛苦，其实来自试图控制无法控制的事情。房价涨跌、别人对你的评价、市场波动、孩子未来的发展、运气什么时候来......这些都不完全由我们决定。但很多人吧精力全部消耗在这些事情上，于是越来越焦虑。



而我Jack认为人生只有两类事情：



第一类，你能控制的。

比如学习、储蓄、锻炼身体、提升认知、管理情绪。



第二类，你无法控制的。

比如经济周期、他人的选择、意外事件、命运的波动。



聪明的你。



请把全部注意力放在第一类事情上🦌
