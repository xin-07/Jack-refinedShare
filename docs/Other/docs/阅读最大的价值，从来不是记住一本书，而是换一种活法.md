# 阅读最大的价值，从来不是记住一本书，而是换一种活法

为什么一直让大家阅读🤫



看到股市下跌 你想到什么



过去的你只会想到完了



学过概率后会想到期望值，甚至QQQ、Sell Put



学过经济学的人，会想到周期、利率、现金流。学过心理学的人，会想到损失厌恶、确认偏误



阅读最大的价值，从来不是记住一本书讲了什么，而是让你的大脑多一种理解世界的方法



很多时候，我们明明觉得自己知道，却怎么也说不出来。其实不是没有想法，而是脑子里还缺少能够表达它的语言和概念。



当你学会一共新概念，比如复利、机会成本、贝叶斯、系统思维，它就像给你的大脑增加了一个新的坐标轴。从此以后，你会发现，以前毫不相关的事情，突然能够连在一起了



这也是为什么，我一直鼓励大家不仅要阅读，还要尝试写出来、讲出来、录出来



因为真正属于你的知识，不是你看过的，而是能够用自己的语言讲给别人听的



大家加入专属会员这一个月是否发现世界没有变，但你看到的世界已经变了👍
