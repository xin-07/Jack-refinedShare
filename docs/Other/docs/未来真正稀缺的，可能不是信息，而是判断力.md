# 未来真正稀缺的，可能不是信息，而是判断力

说个有趣的事情，今天下午和一个百岁老人聊天，他说1938年有一天晚上听到电台里说：火星人来了，怪物降落在新泽西🤣



他说那时候很多人真的慌了。有人冲出家门，有人打911，有人开始祈祷。后来大家才知道，那是一档广播剧，是科幻故事改编的，那是第一次这么刺激的故事通过一本正经的广播播放😖



我不惊想到，现在各种自媒体不也一样的尿性。



尤其现在ai视频以假乱真，未来更是真假难辨。



所以 ai泛滥的未来，我们更需要培养一种超能力：明辨是非 独立思考



点赞👍留言你有没有遇到过类似情况，一开始以为真的 后来发现全是假的





个人感受：

以前是"耳听为实"，后来变成"眼见为实"，而未来可能连眼见都未必为实。



未来真正稀缺的，可能不是信息，而是判断力。



过去，我们害怕没有信息；未来，我们更应该害怕没有判断力。信息越来越便宜，独立思考越来越昂贵，而这恰恰会成为AI时代最重要的竞争力。



每一次媒介革命，都会放大谣言；而每一次时代进步，都更需要拥有独立思考能力的人。
