上场直播和大家聊的同一天生日问题专门写一篇：一个房间有23个人，至少两个人生日同月同日的概率是多少？



50%、10%、20%，1%？ 大家先猜猜看 往下翻















































但真正答案是：50.73%。



为什么？



因为数学里有一个很重要的思维：遇到难算的问题，就换个角度。



直接计算”至少两个人生日相同”非常复杂，所以数学家反过来算：“23个人生日全部不同”。



第一个人生日是哪一天都可以，所以概率是1。



第二个人不能和第一个重复，所以是364/365。



第三个人不能和前两个人重复，所以是363/365。



一直乘到第23个人，就是：



1×364/365×363/365×……×343/365≈49.27%。



那么至少两个人生日相同，就是：



1－49.27%=50.73%



很多伟大的数学发现，都不是因为计算能力更强，而是因为换了一个角度思考🦌
