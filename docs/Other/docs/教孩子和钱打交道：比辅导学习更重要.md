送给所有有孩子的会员❤️



很多父母都希望孩子以后过得好，所以会花很多时间辅导学习，却很少有人认真教孩子怎么和钱打交道



其实，对钱的学习不用等长大👍



孩子小时候，你就可以准备三个透明罐子，分别写上：消费、储蓄、分享。每次收到零花钱或压岁钱，都让他自己决定放进哪个罐子。当他亲眼看到储蓄越来越多、消费越来越少的时候，他学到的不只是数字，而是延迟满足和选择



等到九岁、十岁左右，可以让孩子通过额外做家务、完成任务赚一点零花钱。重点不是赚钱，而是让他明白：收入来自创造价值，而不是伸手就有🤫



到了高中，就开始学习做预算，知道每个月的钱花到哪里；真正开始工作以后，再养成一个最重要的习惯：先存钱，再消费



一个人的财富，很少是输在能力，而是输在习惯



说到底 理财培养的不是数学能力，而是自信，每一次存下一笔钱，做出个正确决定 完成一个目标都会让孩子觉得“我能管理好自己的生活”🦌
