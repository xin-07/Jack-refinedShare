# 第16篇 已发

表达不是天生的，可以慢慢练出来。



第一步，别急着一上来就拼命说，先让脑子里有东西。平时多看看人物传记、历史故事、商业案例或者留意生活里的小细节。慢慢地，你就会有故事可讲、有观点可说。



第二步，观点一定要明确，越直接越好。别模棱两可，也别说空话套话。很多人讲话听着没毛病，但别人听完一点印象都没有，就是因为没重点、没态！先把观点抛出来，再解释原因。比如别说“这个事可能有很多因素”，直接说“我觉得最核心的问题就是执行力不够”。观点越清楚，别人越容易被你说服。



第三步，给自己的观点找几个支撑点就够了，别一下子想太多。三点足以！



第四步，每一个论据都要真实案例或者数据。尤其是自己的经历，会特别有说服力。



第五步，每天练习短表达。哪怕每天随手写几句，时间久了都会有变化。



学会在方法，然后就是每天自己练，和周围人聊天就当作是练习机会。拿起抖音吧👍每天就拿专属会员内容来发表你的看法✌
