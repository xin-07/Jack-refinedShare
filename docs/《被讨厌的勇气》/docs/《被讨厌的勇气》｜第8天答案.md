# 《被讨厌的勇气》｜第8天答案

学被讨厌的勇气，不是让别人讨厌你，而是获得一种勇气

《被讨厌的勇气》第8天答案

这本书不是教你故意得罪别人。也不是我想干什么就干什么，谁都别管我

而是如果你想按照自己的价值观生活，就必须接受一定有人不喜欢你的选择

你选择努力，有人觉得你太卷。你选择轻松一点，有人觉得你不上进。你节省，有人觉得你小气。你花钱享受，有人有觉得你浪费

你表达观点，有人说你太强势。你什么都不说，又有人觉得你有没有态度，无论你怎么活，都很难让所有人满意。

既然如此，我们真正应该追求的就不是怎样才能让所有人喜欢我？

而是我愿意成为什么样的人？

当然，这绝不代表不听别人意见。别人指出你的问题，该改就改。伤害了别人，该道歉就道歉。做错事情，该承担就承担责任

所有“被讨厌的勇气”真正的重点，从来不是被讨厌，而是勇气

即使有人不认可我的选择，我依然可以认真听完，然后为自己的人生负责的勇气

<br />

**被讨厌不是目的，勇气才是。**

而这份勇气具体就是：

**即使有人不认可我的选择，我依然可以认真听完，然后为自己的人生负责。**
