# 《被讨厌的勇气》｜第3天

自卑，到底是在阻碍你，还是在保护你？

《被讨厌的勇气》第3天思考

假设有一个年轻人，一直想做自媒体。他看了很多视频，也想过很多次，但每次准备开始的时候，他都会告诉自己我长得不好看，我说话也没有别人厉害，我没什么特别的经历，就算发了，也不会有人看

所以两年过去了，他一条视频都没有发。

有一天他和我（Jack）连线，我问那你为什么不先发一条试试？

他说因为我还不够好

听起来很合理，对不对

但你是否把不够好当作不用开始的理由，因为只要不开始，就不会失败。

不参加比赛就不会输。不去表白就不会被拒绝。不发作品就永远不用知道别人到底喜不喜欢。

于是不够好就是安全的借口

所以今天大家思考：很多事情你没做，到底是因为自卑，所以不敢行动？

还是有些时候，在利用自卑，让自己不用面对行动之后那个不确定的结果？

晚上我们继续聊

<br />

**“我不够好”虽然让你失去了很多机会，但同时也保护你免受失败、拒绝和评价。**

真正打破循环的方式：

**“先做一个小行动，让现实告诉我到底哪里需要改。”**

**现实没有发生之前，我们其实无法完全知道答案。**

**信心有时候不是行动的前提，而是行动之后的结果。**

**不开始，确实可以保护你不失败、不被拒绝、不被评价。**

**但同时，它也让你永远不知道自己到底能不能做到。**

**我一直说“等我准备好了再开始”的那件事情，到底是真的还没准备好，还是我只是害怕知道结果？**
