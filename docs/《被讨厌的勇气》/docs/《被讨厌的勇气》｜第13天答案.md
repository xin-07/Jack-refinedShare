# 《被讨厌的勇气》｜第13天答案

真想帮别人，千万别把善缘做成了恶果

《被讨厌的勇气》第13天答案

我（Jack）赢书里一个点开篇：他者贡献

就是通过自己的行动，让别人生活得更好，并且从中感受到自己与他人的联系

但帮助别人，不等于别人从此欠你一笔债。比如你帮朋友搬家。
你花了一整天时间，很辛苦。如果你是因为珍惜折断友谊，愿意帮助朋友，那这一天本身就有意义

但如果你心里想的是我今天帮了你，以后你必须帮我。那么这件事就不是帮助了，而是变成了一笔没有提前说清楚的交易。

交易没错 朋友之间互相帮助、讲究公平，也正常。但容易产生问题的是你明明没有告诉对方自己的期待，却要求对方必须按照这个期待回报你。

当然，是否帮一个人需要巨大的智慧，我可以分享下我的思维模型就是问三点
一，我愿不愿意帮你？二，我有没有能力帮你？三，如果你没有回报，我能不能接受？四，我帮你对你长期是有益的吗？

真正的善意，不能以失去自己为代价！你觉得呢



他者贡献：就是**通过自己的行动，让别人的生活变得更好，并从中感受到自己与他人的联系。**

**他者贡献，不是要求你牺牲自己去满足所有人的需要，更不是要求你通过不断付出来证明自己是一个有价值的人。**

第13天的核心 takeaway：
**帮助别人之前，先看清自己的意愿、能力和期待。**
**不要用牺牲自己来证明善良，也不要用过去的付出来控制别人。**
**真正的善意，是我愿意帮助你，但不要求你因此欠我一笔人情债；我希望你变得更好，也不会为了帮助你，而让自己失去生活的边界。**
**你可以对世界保持善意，但不必把自己交出去。**
