# 《被讨厌的勇气》｜第15天

如果你当自己的父母，希望如何培养自己

《被讨厌的勇气》第15天思考

一个孩子正在学骑自行车。刚开始，他掌握不好平衡。爸爸怕他摔倒，一直扶着车座

孩子往左歪，爸爸赶紧往右扶。孩子速度慢了，爸爸就在后面推。每次快要摔倒，爸爸都会提前帮他稳住

结果练了好几天，孩子还是不敢自己骑

他已经习惯只要爸爸一松手，肯定会摔倒

后来爸爸换了一种方法。他先给孩子戴好头盔，选择一块安全的空地。然后告诉孩子我就在旁边，你可以试着自己骑一小段

孩子摔了几次，也慢慢找到了平衡。最后终于能够独立骑车

生活中父母替孩子解决所有困难。管理员替员工做所有决定。
朋友遇到问题，我们总是迫不及待给出答案。我们所谓自己是在帮助别人

但有没有可能，有些帮助，反而让对方失去了相信自己的机会

今天大家想想真正的帮助，到底是替别人解决问题，还是让别人相信自己有能力解决问题？我为什么说最大的贵人其实就是经常鼓励自己的你！



**表扬容易让人关注自己有没有得到认可；鼓励则可以帮助人逐渐建立对自身能力的信任。**

**真正的自我鼓励，是既承认不足，也承认进步。**

**不要只做那个不断要求自己进步的人，也要学会成为那个能够支持自己进步的人。**

第15天的核心 takeaway：
**真正的帮助，不是替别人走完所有的路，而是让他逐渐相信自己能够走下去。**
**真正的鼓励，不是告诉自己永远不会失败，而是在失败之后，依然愿意相信自己、改善自己，并继续行动。**
**如果你是自己的父母，请不要只做那个不断要求自己优秀的人，也要做那个在自己遇到困难时，愿意理解自己、支持自己继续成长的人。**
**最大的贵人，不一定是永远替你解决问题的人，而是帮助你逐渐拥有解决问题能力的人。对自己，也是如此。**
