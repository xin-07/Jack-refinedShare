# 《被讨厌的勇气》｜第5天

如果你不喜欢现在的自己，为什么一直没有改变？

《被讨厌的勇气》第五天思考

假设有一个人，一直说自己特别内向。不喜欢参加聚会。不敢主动认识陌生人。开会的时候，即便有想法，也很少主动表达。

他经常羡慕那些特别外向的人，然后说：我要是天生也是这种性格就好了

有一天朋友问他：那你为什么不试着主动和陌生人聊一次？

他说：没用，我从下就是这样

如果和我连线 我会继续追问：如果你真的这么讨厌现在的状态，为什么这么多年，你还是一直选择维持它？

因为改变有一个很多人不愿意承认的成本：不确定

我不主动和别人说话，就不会拒绝。我不换工作，就不用面对新环境。

我不开始做那件一直想做的事，就永远不用知道自己到底行不行。

现在的生活可能并不满意。但是至少——我熟悉它。

所以今天大家想想：一个人一直没有改变，到底是因为我就是这样的人

还是因为在某些时候，保持现在的自己，比改变自己更加安全？

<br />

值得思考的是：

**我是不是把“改变很难”，变成了“我根本无法改变”？**

**你现在是什么样，可以解释你的现状；但不能直接决定你的未来。**

**“我就是这样”有时候不是答案，而是保护自己不改变的理由。**

**我真的不喜欢现在的生活，还是我只是害怕改变之后的不确定？**

进一步问：

**如果我知道改变一定不会失败，我会不会马上去做？**

**熟悉的生活不一定是你想要的生活，只是你已经习惯的生活。**

**改变需要勇气，不是因为你不知道怎么改变，而是因为你必须接受：改变以后，结果可能不会按照你的预期发生。**
