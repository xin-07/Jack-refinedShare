# 《被讨厌的勇气》｜第9天

为什么你是为他好，他却不领情？

《被讨厌的勇气》第9天思考

假设有一位妈妈，特别重视孩子的学习。每天放学以后，他都会提醒孩子写作业，检查错题，安排阅读

孩子成绩不好，她比孩子还着急。孩子考试进步了，她比孩子还开心

有一天，孩子终于忍不住说妈妈，你能不能别管我了？

妈妈特别委屈。我每天这么辛苦，还不都是为了你好？

但孩子却觉得你根本不在乎我想什么

于是一个很奇怪的情况出现了。一个人觉得自己付出了很多，另一个人却觉得自己承受了很多

这种事情其实不只发生在父母和孩子之间，夫妻之间也有，朋友之间也有。

你觉得对方应该换一份工作。应该少玩手机。应该早点睡觉。应该按照你的建议做决定

你越想帮助他，他越想反抗。最后你甚至开始怀疑难道我对他好，还有错吗？

今天思考为什么我们明明是。出于好意，却经常让别人感到压力？到底什么时候，我们是在帮助别人？又是什么时候，我们已经开始试图替别人决定人生？

<br />

**帮助，是把选择权留给对方；控制，是把选择权拿过来。**

**真正的自由，不只是“我不让别人控制我”。**

**还包括“我也不去控制别人”。**

**我可以关心你，但我不能替你活。**

**我可以给你建议，但不能替你做决定。**

**我可以希望你好，但你的人生，最终还是你的课题。**
