# 《被讨厌的勇气》｜第20天答案

如何自由自在的生活

《被讨厌的勇气》第20天答案

过去20天，我们讨论了为什么会自卑？为什么总觉得想得到别人的认可？为什么害怕被讨厌？为什么喜欢控制别人，又害怕让别人失望？

其实这些都有一个共同点。我们太容易把自己的人生，交给别人的评价来决定

比如你明明喜欢画画，却因为别人觉得画画赚不到钱，最后放弃了。明明已经拥有不错的生活，看到别人赚的更多，就觉得自己很失败。还有一些父母，希望孩子幸福，却总忍不住拿孩子和别人比较因为我们觉得，只有得到外界认可，才算成功

这样会让自己陷入内耗的困境

所以我（Jack）觉得一个比较理想的生活状态，是同时做到三件事

第一，做自己感兴趣的事情
第二，让自己的行动对别人产生积极的价值
第三，在这个过程中，自己也能够不断学习和成长

最后，我想用一句话结束这本书

真正的自由，不是想做什么就做什么，而是你有勇气按照自己认可的价值生活，同时愿意为自己的选择承担责任



内耗的一个重要来源：**你不仅要处理生活本身的问题，还要不断应付自己想象中的评价。**

**自由不是没有约束，而是你知道自己为什么做出选择，并且愿意承担选择带来的后果。**

**自由不一定是一下子改变整个人生，也可能是从一件小事开始，不再仅仅因为害怕别人的评价而行动。**

**人生不是一场必须得到所有人认可的考试。你真正需要做的，是认真生活、持续成长，并逐渐找到自己愿意为之付出的人生方向。**
