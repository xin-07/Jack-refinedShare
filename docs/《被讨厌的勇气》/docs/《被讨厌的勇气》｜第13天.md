# 《被讨厌的勇气》｜第13天

为什么你对别人越好，越容易失望

《被讨厌的勇气》第13天思考

假设有个人，特喜欢帮朋友。朋友搬家，他第一个过去帮，朋友遇到困难，他主动借钱。朋友心情不好，他愿意花几个小时陪聊

但有一天，他遇到困难，给朋友电话，对方说不好意思，我今天真没时间

他一下子怒了。心想我以前帮你那么多次，现在我需要你，你居然不帮我？甚至开始后悔过去所有的付出

其实这种事情生活中很常见。父母觉得自己为孩子牺牲了那么多，孩子就应该听话。夫妻觉得自己为家庭付出了那么多，另一半就应该理解自己

朋友之间也一样。我们嘴上说不求回报，但心里可能早就给每一份付出标好了价格

所以今天我（Jack）想问大家如果你帮助一个人，最后他没有感谢你，也没有在你需要的时候回报你，那你当初的帮助还有价值吗？

更重要的是我们到底应该怎么帮助别人，才不会让善意慢慢变成委屈？

晚上直播和大家好好聊聊❤️



**你到底是在帮助这个人，还是在用自己的付出，期待对方将来以某种方式回报你？**

这一天最值得思考的，不是以后帮助别人时什么都不要期待，而是学会区分：**真心付出、合理期待，以及要求别人按照自己的期待回报，是三件不同的事情。**

第13天的核心 takeaway：
**你可以真心对别人好，但不要把自己的付出，变成要求别人回报的筹码。**
**善意需要边界，关系需要沟通。你可以期待别人珍惜你，但不要靠牺牲自己，换取别人必须按照你的期待回应。**
**真正成熟的帮助，是我愿意在自己能力范围内帮助你，也尊重你有自己的选择；我珍惜这段关系，但不会用过去的付出，控制你今天的决定。**
