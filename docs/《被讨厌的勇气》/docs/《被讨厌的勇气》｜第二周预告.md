# 《被讨厌的勇气》｜第二周预告

如果这个世界上没有任何人评价你，你现在的人生还会这样过吗？

《被讨厌的勇气》第二周预告

第一周，我们讲过去、自卑、愤怒和改变

第二周，我们开始聊更透彻的话题：为什么我们这么在意别人怎么看自己？

小时候考了100分，希望父母表扬。长大以后努力工作，希望老板认可。

买房、买车、赚钱、健身，甚至发一条朋友圈，有时候我们都会偷偷观察：别人觉得我怎么样？

如果一个人所有努力的动力，都是为了得到别人的认可，那么他看起来是在过自己的人生，实际上人生的方向盘可能一直握在别人手里。

别人夸你，你开心。别人否定你，你怀疑自己。别人拥有的东西比你好，你开始焦虑。于是我们越来越努力，却不一定越来越自由。

所以下周，我们会聊自卑、比较、竞争、认可欲望和人际关系。

最后睡前想一下，希望别人喜欢我，但如果必须牺牲自己的人生才能换，还要不要？

真正值得思考的是：
**这个选择到底是我想要的，还是我想让别人觉得我很好？**
**我可以喜欢别人的认可，但我能不能不依赖别人的认可来决定自己的人生？**

<br />

**“即使别人不认可我，我依然敢为自己的人生负责。”**

**我可以在乎别人的看法，但我不能把人生的方向盘交给别人的看法。**
