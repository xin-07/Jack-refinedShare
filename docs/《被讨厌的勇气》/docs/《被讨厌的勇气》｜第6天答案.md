# 《被讨厌的勇气》｜第6天答案

一直需要别人认可，你的人生方向盘就在别人手里

《被讨厌的勇气》第6天答案

我们都喜欢被认可，被夸谁都会开心

书里并非说不要在乎任何人的感受。而是不要把“别人认可我”，变成我做一件事情的必要条件

因为一旦这样，下一次没有表扬，我还愿不愿意做？

如果我选择一种生活，是为了让别人羡慕，那么有一天别人不羡慕了，这种生活对我还有没有意义？而且别人喜欢什么，是会变的。今天你这样做，他们说你勇敢。明天同样一件事，可能有人说你自私。

你永远没有办法控制所有人的评价。所以如果人生的标准是我要让大家满意

你实际上接下了一个永远完成不了的任务

当然，这不代表别人的意见不重要，别人指出你的错误，你应该听。家人的感受，你应该考虑。专业人士的建议，更应该认真对待

真正的区别是：听取别人的意见，和把决定权交给别人，是两回事

你可以听所有人的声音。最后依然由自己决定：我想成为谁🎉

<br />

**认可可以是奖励，但不能成为方向盘。**

**真正的勇气不是让所有人都喜欢你。**

而是：

**即使有人不喜欢你，你依然敢为自己的选择负责。**

**过去不能拿走你的选择权，自卑不能拿走，情绪不能拿走，比较不能拿走，害怕改变不能拿走——现在，别人的认可，也不能拿走。**
