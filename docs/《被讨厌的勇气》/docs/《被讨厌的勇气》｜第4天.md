# 《被讨厌的勇气》｜第4天

为什么你已经过得不错了却还是觉得自己不够好？

《被讨厌的勇气》第4天思考

有一个30岁的年轻人。五年前，他最大的愿望是工资能达到两万，有自己的房子，每年可以出去旅行

五年以后，他真的做到了。按理说，他应该很满足。

但他发现自己反而比以前更焦虑

因为以前月薪一万的时候，他和月薪两万的自己比较。现在月薪两万了，他开始看到月薪五万的人。

买了第一套房以后，它开始注意别人住什么房子。买了一辆不错的车，又发现朋友换了更好的。

甚至出去旅行，第一反应都是别人去了哪里？

慢慢地，他发现一件很奇怪的事情，自己明明一直在进步，却很少真正觉得自己赢过。

为什么？因为比赛的对手永远在 变。

所以今天大家想想：如果你判断自己过得好不好的标准，永远是别人过得怎么样，那这场比赛到底什么时候才能结束？

也祝大家节日快乐🎉国庆节好好休整 也别忘了每天要干正事哦

<br />

**不要把人生建立在别人的评价之上。**

**比较别人，是为了获得信息；比较自己，是为了判断成长。**

**如果你永远用别人来衡量自己，你永远都不会觉得自己够好。**

**真正值得比较的，不是“我有没有超过别人”，而是“我有没有成为比过去更好的自己”。**

**如果没有任何人知道我的收入、房子、车、工作和生活，我自己还会觉得现在的生活不够好吗？**
