# 《被讨厌的勇气》｜第2天答案

愤怒不是原因，而是工具



《被讨厌的勇气》第2天答案



我们太习惯说他把我惹火了



我控制不住😡了，好像对方按下了一个按钮，我们就只能爆炸



但在你愤怒的时候 能不能想一下，愤怒本身能帮你做什么？



比如孩子不听话，父母开始大喊。为什么？

因为正常讲话没有效果。声音提高以后，孩子马上停下来

于是你就明白愤怒可以让我更快控制局面



夫妻吵架也是一样。一个人突然声音特别大，并不只是因为情绪出现了，而是发现这样做能让另外一个人闭嘴



所以“愤怒是工具”这个理论不是告诉你不应该生气，人当然会有真实的愤怒，身体也会有真实的感受



但当情绪出现以后，可以再思考下，我现在有这种方式表达愤怒，是为了什么？



是真的想解决问题，还是想让对方害怕？还是真的想让他理解我还是只想赢？



今天作业



下一次你快要发火的时候，想！我现在发这个脾气，是想让对方做什么，有没有更好的方法达到目的，相信我，练几次，会不同





“愤怒是工具”是什么意思：

**我不是单纯地被愤怒推着走，我的愤怒表达方式，有时候也在帮助我实现某个目的。**



第2天真正要拿走的东西



**愤怒是真的，但愤怒不是唯一的选择。**

**你可以承认自己真的生气了，但在表达之前，先问自己：**

**“我现在发这个脾气，是想让对方做什么？”**

**如果有更好的方法达到同样的目的，我能不能换一种方式？**



从“他把我惹生气了”，变成“我生气之后，准备怎么选择？”
