# 《被讨厌的勇气》｜第3天答案

自卑本身并可怕

《被讨厌的勇气》第3天答案

当我发现现在还不够好，我告诉自己这正是进步的开始

我跑的不够快，所以我训练。英语不够好，所有我练习。不会表达，所以我一次一次去说。

自卑感最后变成了一股力量：因为我还不够好，所以我要往前走

真正需要警惕的是 我不够好，慢慢变成，所以我不能做

我不够漂亮，所以我不能拍视频。我没有钱，所以我不能创业

我性格内向，所以我不能表达。我以前失败过，所以我不适合做这件事

这时候，自卑已经不只是感受了。它开始变成了给自己写的一张免战牌。

因为只有我认定我就是这样的人，我就不需要承担改变的风险

“我不够好”和“我不能开始”，其实是两句话。很多我们今天看到厉害的人，并不是等到“不自卑”以后才开始的

而是在自己还不够好的时候，就已经开始了

所以当你的脑子里再次出现：我不够好

然后再加一句：但是，这和我今天能不能开始，有什么关系？

<br />

真正需要警惕的是：

**我们把“现阶段的不足”，偷偷变成了“永远不能行动”。**

**很多看起来是在描述自己的话，实际上也可能在保护自己不去行动。**

**先开始 → 获得反馈 → 做得越来越好 → 慢慢建立自信。**

所以：

**自信有时候不是行动的前提，而是行动之后产生的结果。**

**自卑不是问题，把自卑变成“不行动的理由”才是问题。**

**你不需要等到足够好，才有资格开始。**

很多时候，**开始本身，就是变好的第一步。**
