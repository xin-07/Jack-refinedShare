# 《被讨厌的勇气》｜第11天答案

《被讨厌的勇气》第11天答案

我们平时习惯用高低来理解人与人之间的关系。老板比员工高。老师比学生高。父母比孩子高

所以会默认我比你懂得多，所以我有资格决定你应该怎么做

我（Jack）希望你试试另一种思考方式。一个人可以比另一个人经验更多、能力更强、承担更多责任。但这不代表他在人格上就比另一个人更高

比如孩子做的不好，妈妈可以说，但不一定非要靠居高临下。你可以告诉孩子哪里做的不好，为什么不对，需要承担什么后果。

然后让他参与思考下次我们怎样避免这些事情？

这和简单的说你怎么这么不听话效果完全不同，我们依旧要规则，也不是让所有人都拥有相同的决定权，而是我们可以在履行这些责任的时候，始终尊重对方

今天留给大家一个练习。下一次你想批评、命令或者教育一个人的时候，先想想我是要证明我比他正确，还是想帮助我们把问题解决？



**指出一个人的行为有问题，不等于认定这个人本身有问题。**

**规则可以明确，责任可以严格，但没有必要通过羞辱和居高临下，来证明自己拥有权威。**

**提供帮助是我们的选择，如何回应帮助是对方的选择。**

**你不必站在别人的对面，才能帮助他变好。**
**你可以指出错误，但不必否定一个人；你可以坚持规则，但不必用居高临下的方式证明权威。**
**真正的教育，不是让别人越来越听你的，而是让他逐渐学会自己判断、自己选择，并为自己的选择负责。**
