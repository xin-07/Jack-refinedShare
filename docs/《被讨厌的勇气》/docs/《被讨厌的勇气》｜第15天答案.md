# 《被讨厌的勇气》｜第15天答案

真正的鼓励，是让你相信自己有能力

《被讨厌的勇气》第15天答案

我当时取名叫Jack要加油，是因为我从小就会鼓励自己，我母亲经常告诉我即使我现在做的不好，我也 有能力面对问题，继续尝试

孩子做数学题。父母看到孩子不会，第一反应就是赶紧教，甚至直接把答案告诉他。这样解决了眼前的问题。但孩子没有机会经历从不会到会的过程。

下一次遇到难题，他还是会习惯性的等待别人帮助。如果换一种方式呢？

我会问他决定这道题应该从哪里开始？如孩子想不出来，再给一点提示。让他自己尝试，自己发现错误，最后自己完成

这时候，他得到的不只是一个正确答案。他得到了一次证明自己能解决问题的经历

大家慢慢长大，甚至未来当了父母，请记得这篇，因为最好的鼓励，不是让他永远需要你的帮助，而是他有一天能够自信的告诉你这次我想自己试试

今天想想，哪些人，，哪些事情让你越来越肚里，敢于去试错，并且相信自己也有成长的能力！



**真正的鼓励，不是让一个人觉得自己很优秀，而是让他相信：即使现在不会，即使可能失败，我也有能力面对问题，并且可以通过尝试慢慢学会。**

**帮助的目标，不只是让事情完成，更是让人逐渐拥有独立完成事情的能力。**

**你可以接受别人的帮助，但不要因此失去对自己能力的信任。你也可以帮助别人，但不要因为想保护他，就替他走完所有的路。**

真正的鼓励，是让一个人逐渐相信：
**“我现在可能还不会，但我可以学习；我可能会犯错，但我能够调整；即使没有人替我解决所有问题，我也有能力一步一步找到自己的答案。”**
