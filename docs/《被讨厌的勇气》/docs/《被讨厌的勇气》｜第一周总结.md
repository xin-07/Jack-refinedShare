《被讨厌的勇气》第一周总结

第一天我们讲过去解释你为什么走到这里，却不能解决你下一步往哪里走

第二天我们讲了愤怒，以前我们总觉得别人把我惹生气的

但如果换个角度看，有些时候，愤怒。也在帮我们达到某个目的

让别人闭嘴。让别人重视。让事情按照自己的意思走

我现在用愤怒，想得到什么？

第三天讲自卑本身不可怕，发现自己还不够好，反而可能成为进步的开始

第四天我们讲很多人其实已经过得越来越好了，却还是越来越焦虑。因为判断自己的标准，不再是自己有没有进步，而是别人是不是比我更好

只要人生变成一场排名赛，这场比赛就几乎永远没有终点

最后一天，我们回答了这一周最重要的思考：人到底。能不能改变？

答案当然是可以，我们不能选择所有发生在自己身上的事情。但我们可以慢慢选择自己。准备怎样回应这些事情

晚上发下周预告 大家可以好好复习一下😄

<br />

**过去发生了什么、别人怎么看你、你现在是什么状态，都可以影响你，但它们都不能自动替你决定下一步。**

真正需要练习的，是： **事情发生之后，我还能不能保留一点选择的空间？**

**我们不能选择所有发生在自己身上的事情，但我们可以慢慢选择，自己准备怎样回应这些事情。**

**真正决定你往哪走的，是你今天怎么理解自己，以及你愿不愿意做出一个不同的选择。**

> 遇到“过去”时：我是在理解过去，还是被过去定义？
>
> 遇到“情绪”时：我是真的失控，还是正在选择一种表达方式？
>
> 遇到“自卑”时：我是真的不够，还是拿“不够好”阻止自己开始？
>
> 遇到“比较”时：我是在获取信息，还是在给自己排名？
>
> 遇到“改变”时：我是真的不能改变，还是害怕改变之后的结果

| 遇到的问题 | 不要只问           | 改成问自己                               |
| ---------- | ------------------ | ---------------------------------------- |
| 过去       | 为什么会这样？     | **过去无法改变，我今天能选择什么？**     |
| 愤怒       | 他为什么惹我？     | **我现在这样表达，是想达到什么目的？**   |
| 自卑       | 我是不是不够好？   | **不够好，和我今天开始有什么关系？**     |
| 比较       | 我是不是不如别人？ | **我和过去的自己相比，有没有进步？**     |
| 改变       | 我是不是改不了？   | **我是在做不到，还是害怕改变后的结果？** |
| 所有问题   | 我为什么只能这样？ | **我现在还有什么选择？**                 |
