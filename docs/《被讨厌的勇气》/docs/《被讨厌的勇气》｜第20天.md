# 《被讨厌的勇气》｜第20天

你到底为什么要努力？

被讨厌的勇气第20天思考

有一天，你突然发现，身边所有人都不再评价你了。你赚多少钱，没人关心。开什么车、住多大的房子，没人羡慕

你读了多少书、获得多少奖项，也没有人夸奖。甚至你做了一件很了不起的事情，也不会有人给你点赞

那你还会像现在一样努力吗？你还会每天运动、读书、工作，努力让自己变得更好吗？

还是说，当所有人的目光都消失以后，你突然发现，很多以前特别想做的事情，其实根本没有那么想做？

我觉得大家可以思考思考。因为我们这一生，很多选择看起来是自己做的，但背后可能藏着别人对我们的期待。

小时候希望父母满意。上学希望老师认可。工作以后希望老板赏识。赚了钱，希望别人觉得自己成功。我们不断努力，却很少停下来想下：如果没有人看见，我还愿意这样生活吗

讲了20天，最后一天我们一起看看真正的自由和幸福，到底是什么?

晚上我们用最后一篇，结束这本书



**贡献不是为了换取别人的感谢，而是你知道，自己的行动能够给生活带来一些积极的东西。**

**你不是不再追求成就，而是不再需要靠成就证明自己值得。**

**努力，不是为了让所有人都觉得你很优秀，而是为了让自己拥有能力，选择想过的生活。**
**你可以享受掌声，但不必依赖掌声；你可以追求成功，但不必用成功证明自己的价值。**

当别人不再看着你的时候，你依然愿意认真生活——那时，你的努力才真正有了属于自己的理由。
