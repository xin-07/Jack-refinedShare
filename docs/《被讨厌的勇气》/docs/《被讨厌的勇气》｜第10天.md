# 《被讨厌的勇气》｜第10天

别人讨厌你，怎么办



《被讨厌的勇气》第10天思考



假设你有一个特别好的朋友。有一天，他邀请你周末出去吃饭。但你已经答应陪家人了，于是告诉他不好意思，这周末我有安排，下次我们再约



结果朋友不高兴了，他觉得你不重视这段友谊。甚至接下来几天，都没有主动联系你



你开始焦虑。是不是应该取消家里的安排？是不是应该解释的更详细一点？是不是应该买个礼物，让他重新开心起来？



原本只是一件很简单的事情。最后却变成了你必须想办法，让另一个人不再生气



但麻烦来了。你已经礼貌地拒绝了。也没有故意伤害他。那么他最后能不能接受你的决定，到底应该由谁负责？



书里有一概念：课题分离



他提出一种判断方法：一件事情最后的结果，主要由谁承担？



比如你真诚的对待朋友，是你的课题。朋友最后喜不喜欢你，是朋友的课题



所以今天需要思考：如果别人不喜欢你的选择，你到底应该努力改变他的想法，还是学会接受他的想法不由你控制





**课题分离不是把责任推给别人，而是不替别人承担他的人生，也不逃避自己应该承担的责任。**



**我愿意认真检查自己的行为，但不会仅仅因为别人不满意，就认定自己必须改变。**



**对自己的行为负责。** 如果做错了，就承认和改正。

**尊重别人的感受。** 对方可以失望，可以不同意，也可以不喜欢你。

**接受自己无法控制的结果。** 不必为了消除所有人的不满，而不断牺牲自己的选择。



**我可以努力不伤害别人，但不能保证所有人都不讨厌我。**

**我可以认真对待每一段关系，但不能把让所有人满意，当成自己的人生责任。**
