# 《被讨厌的勇气》｜第5天答案

改变最难的地方是不知道改变以后会发生

《被讨厌的勇气》第5天答案

很多人没有改变的勇气，因为现在的自己虽然有很多问题，但你已经会使用这个自己了

你知道什么事情应该逃避。什么情况下应该沉默。怎样和身边的人相处。甚至知道失败以后应该用什么理由安慰自己

这一切可能并不完美。但它最大的优点是熟悉

而改变意味着什么？不知道

你开始主动表达，可能有人不喜欢你。你开始做自己的事情，可能失败。你离开熟悉的环境，可能发现外面的世界并没有想象中那么好。

所以我们宁愿忍受一种熟悉的不满意，也不愿意承担一种未知的可能性。

这也是为什么很多人说了十年我要减肥、换工作、改变自己的性格，但每一年过去，生活机会还是一样

不是因为他们不知道应该做什么，而是改变意味着：我必须放弃现在这个虽然不完美、但至少是熟悉的自己

所以真正的改变，就是从我也可以做一次和以前不同的选择开始

试试看，今天就做一点不同

<br />

**熟悉的不满意，有时候比未知的可能性更容易让人接受。**

真正的“勇气”不是：

**相信改变一定成功。**

而是：

**我知道改变可能失败，但我依然愿意为自己想要的生活，尝试一次。**

**改变最难的地方，不是你不知道怎么改变，而是你必须离开那个虽然不完美、但你已经非常熟悉的自己。**

**你不需要先知道改变以后会发生什么，才有资格开始改变。**

**有时候，只有你真正迈出第一步以后，才会知道下一步应该往哪里走。**
