# 《被讨厌的勇气》｜第6天

如果没人看见，你还愿意做这件事吗？

《被讨厌的勇气》第6天思考

一个孩子考了100分。回家以后，爸爸妈妈特别高兴孩子也特别开心。下一次考试，他又想考199分。但慢慢的，一件很微妙的事情可能发生。他从我想学会变成我想被表扬

长大以后，这套逻辑可能还在继续。努力工作，希望老板认可。买了一辆喜欢的车，会想别人觉得怎么样。发一条视频，第一件事就是看多少人点赞。甚至做一件好事，也希望有人知道。

于是有一天，我们已经分不清这件事到底是我真的想做，还是我希望别人觉得我是一个很好的人？

所以今天思考下假设从明天开始，你做的很多事情都不会被任何人知道。没有朋友圈。没有点赞。没有人羡慕。也没有人夸你。

你还会不会健身？还会不会读书？还会不会努力工作？还会不会买现在想买的东西？

甚至——你还会不会选择现在正在过的人生？

晚上我们聊书里一个非常主要的概念：认可欲望

<br />

**别人怎么看我，究竟是一个参考意见，还是人生的最终裁判？**

**不要把获得别人的认可作为自己行动的目标。**

**“即使有人不喜欢我，我还能不能继续过我认为正确的人生？”**

这才是“被讨厌的勇气”。

真正的意思应该是：

**我听见你的看法，但我不把你的看法当成人生判决书。**

**你可以喜欢别人的认可，但不要靠别人的认可证明自己的价值。**

**别人可以给你建议，但不能替你决定人生。**

**你可以在乎别人怎么看你，但人生的方向盘，必须一直在自己手里。**

最重要的一句话是：

**如果一个选择只是为了让别人觉得我很好，那么我得到的可能不是自己想要的人生，而是别人眼中的“好人生”。**
