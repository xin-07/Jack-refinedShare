# 《被讨厌的勇气》｜第18天答案

爱自己才成功

《被讨厌的勇气》第18天答案

人生不是一条通往终点的直线，而是一连串的点。很多人习惯把人生看成爬山。小时候读书，为了考上好大学。考上大学，是为了找到好工作。找到好工作，是为了赚更多钱。

赚够了钱，是为了退休以后享受生活。这样看起来很合理

如果你始终认为幸福只存在于山顶，那么爬山的几十年，就好像都只是准备阶段。可如果你爬到一半，因为某种原因再也无法继续呢？

难道前面几十年的人生就没有意义了吗？

人生的意义，不一定需要等到实现某个目标以后才能获得。

比如你喜欢读书。当然希望通过读书增长知识，未来变得更优秀。

但今天读到一个特别有意思的观点，突然理解了一个以前想不通的事情。那一瞬间的快乐，难道不是真实的吗？

分享个方法，对你认真想做好的事情说两句话

第一，我会当下就认真努力，也会为未来认真做准备
第二，我不要因为未来尚未到来，就否定今天的幸福



**不要因为未来尚未到来，就否定今天的幸福。**

人生当然需要目标，但人生的意义不只存在于目标实现的那一刻。

你今天学到的知识、解决的问题、付出的努力，以及与重要的人共同度过的时光，都可以成为人生的一部分，而不只是通往未来的工具。

你不必等到足够成功，才允许自己满意；不必等到财务自由，才开始珍惜生活；也不必等到成为理想中的自己，才觉得现在的自己值得被善待。

**认真为未来努力，也认真过好今天。未来值得期待，而今天不需要为未来让路。**
