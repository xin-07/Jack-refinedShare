# 《被讨厌的勇气》｜第1天

你的过去，真的决定了今天的你吗？

《被讨厌的勇气》第一天提问

我（Jack）想问一个会让你不舒服的事：你今天变成这样，真的是因为过去发生的那些事情吗？

假设有两个孩子，小时候都经常被父母批评。长大以后，第一个人变得特别害怕表达自己。开会不敢说话。遇到喜欢的人不敢主动。有机会摆在面前，也总觉得算了，我肯定不行

他觉得因为小时候总被批评，所以我现在没有自信

但第二个人长大以后，却完全不同。他特别喜欢证明自己。别人越觉得他不行，他越想试。甚至觉得正是因为小时候总被否定我才这么想证明自己

如果同样的过去，可以产生完全不同的人生，那过去真的是今天唯一的原因吗？

我（Jack）为什么喜欢这本书，因为阿德勒的思想和我是完全一致的，我不喜欢说因为过去发生了A，所以今天的你一定变成B

我更相信，今天的你，怎样理解和使用自己的过去？才决定了未来的你！

今日思考：我还要不要继续让过去，替未来的我做决定？

<br />

**不能简单地把过去发生的事情，当成今天行为的唯一决定因素。**

**发生的事情可能一样，但一个人如何理解这件事情，可以不同。**

**过去不能被修改，但你对过去的解释，以及你今天的选择，可以改变。**

**我不能重新写过去，但我可以重新决定过去对我的意义。**

**过去发生的事情，你无法改变；但你如何理解过去，以及今天选择怎么行动，仍然属于你。**
