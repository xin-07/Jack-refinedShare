# 《被讨厌的勇气》｜第19天

看完这篇 你会重新看待人生

《被讨厌的勇气》第19天思考

有两个孩子，都在学习钢琴。第一个孩子每天练琴，心里想的是将来一定要考到最高级，参加比赛，拿到奖牌

第二个孩子也每天练琴，但他更喜欢的是弹出一首自己喜欢的曲子，或者发现自己今天又学会了一段新的旋律

十年以后，第一个孩子可能拿到了很多奖项，第二个孩子可能没有参加过什么比赛

你觉得谁的这十年更有价值？

很多人第一反应可能是，第一个孩子更成功。因为他有证书、有奖牌、有可以证明自己努力的成绩
但第一个孩子在这十年里一直觉得练琴很痛苦，拿到奖牌以后也没有真正开心多久。而第二个孩子每天都很享受弹琴，十年以后依然愿坐在钢琴前面呢

你的答案还会一样吗？

人生像跳舞。跳舞和跑步区别是跑步有终点，你希望尽快到达。但跳舞，你并不是为了跳到某个地方。跳舞的过程，本身就是你想做的事情

那如果跳舞这样没有明确的终点，那该怎样保持努力和进步呢？



**真正的问题是：我们是不是只看得见最终的结果，却看不见一个人在追求结果的过程中，究竟是怎样生活的？**
**你不是只有在成功的那一天，才算真正活过自己的人生。你今天正在做的事情，也构成了你的人生**
**没有唯一的终点，不等于没有方向；不把结果当成唯一价值，也不等于不在乎结果。**

**人生不是为了抵达某个终点，才值得认真生活。努力的意义，不只在于你最终得到了什么，也在于你如何度过追求目标的每一天。**

你可以争取奖牌，但不要让奖牌成为你唯一的快乐来源。
你可以追求成功，但不要等到成功以后，才允许自己享受生活。
你可以不断进步，但不必把每一天都变成证明自己价值的考试。

人生像跳舞，不代表我们不再努力，而是我们开始明白：努力不只是为了抵达未来的某个地方，也可以让今天的自己活得更充实、更清醒。

**不要只顾着问自己什么时候才能到达终点，也要问问自己：我正在走的这条路，是不是我愿意认真走下去的路？**
