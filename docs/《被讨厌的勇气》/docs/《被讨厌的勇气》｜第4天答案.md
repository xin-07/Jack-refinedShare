# 《被讨厌的勇气》｜第4天答案

比较最可怕的地方，是它没有终点

《被讨厌的勇气》第4天答案

看到一个比自己优秀的人，你会怎么想

我们很容易偷偷把人生变成一场排名赛

我赚多少，不重要。重要的是有没有比你多

我的孩子表现怎么样，不重要。重要的是有没有比别人家的孩子强

我的生活好不好，也不再由自己的感受决定。洱海要看别人有没有比我更好

你永远找得到比你厉害的人，其实就是选择了一场几乎不可能真正结果的比赛

今天开始不要把别人看成赛道上的对手，真正值得比较的，可能是昨天的自己

我去年不会的东西，今年会不会了？以前不敢做的事情，现在敢不敢了？以前遇到一句批评就难受三天，现在能不能三个小时以后继续生活？

这样一来，人生的方向就变了

以前你总想我有没有赢过别人？

现在你开始想我有没有继续往前走？

这两个想法看起来很像，最后带来的生活状态却完全不同

<br />

**幸福是即使别人走得比你快，你依然知道自己为什么要往前走🎉**

**比较最可怕的地方，是它没有终点。**

**所以，不要把人生变成一场“超过别人”的比赛。**

真正值得问自己的，是：

**去年不会的东西，今年会不会了？**

**以前不敢做的事情，现在敢不敢了？**

**以前很容易被影响的事情，现在是不是能够更快地走出来？**

**幸福不是一定要走得比别人快，而是即使别人走得比你快，你依然知道自己为什么要往前走。**

**换一把尺子。**

**不要用别人的位置，衡量自己的人生；用自己的方向，判断自己有没有继续前进。**
