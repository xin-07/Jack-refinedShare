# 《被讨厌的勇气》｜第18天

怎么样活 算幸福？

《被讨厌的勇气》第18天思考

一个年轻人，刚毕业的时候告诉自己等找到一份好工作，生活就轻松了

几年以后，他真的找到了好工作。但他又开始想：等买了房子，就可以安心生活了

后来房子也买了，他又觉得等赚够一笔钱，实现财务自由，就可以真正享受人生了

结果等到四十岁，他已经拥有了很多曾经梦想的东西，却发现自己还是习惯每天想着下一个目标。他总觉得，现在还不是享受生活的时候

等孩子长大了。等事业稳定了。等自己退休了。到那时候，才是真正幸福的时候

如果一个人总是把幸福安排在未来，那他今天的生活到底算什么？难道我们人生中的前几十年，都只是为了最后那几年做准备？

人生不是一条通往终点的直线，而是一连串的点！

所以今天大家想想：我们到底应该为了未来的目标而活，还是应该认真享受今天？

如果只享受今天，会不会变得没有追求？
如果只追求未来，我们又会不会错过整个人生？

晚上直播聊



幸福到底是什么？
**1. 幸福不是拥有所有想要的东西，而是学会看见自己已经拥有的东西**
**2. 幸福不一定要等到所有问题解决之后才开始**
**3. 幸福也可以来自正在做的事情**

**人生不是为了抵达某个终点，才值得认真度过。今天本身，就是你的人生。**

你不需要在“追求未来”和“享受当下”之间二选一。
你可以一边为未来积累，一边认真对待今天；一边承认自己还有不足，一边珍惜已经走过的路。

**不要把人生过成一场漫长的等待。未来值得期待，但今天也值得生活。**
