# 《被讨厌的勇气》｜第12天答案

你的价值到底来自哪？

《被讨厌的勇气》第12天答案

为什么你已经努力，却始终觉得自己不好？

因为从小就形成了一种习惯：只有我表现得足够好，才值得被认可。小时候，考了第一名才值得表扬。长大以后，赚了很多钱才值得尊重。

等到自己有了孩子，又不知不觉把同样的标准交给下一代
但一个人的价值，只建立在他的表现和成就上吗？

比如孩子考试考砸了。你可以帮他分析原因，找改进方法。但不应该让他觉得，成绩不好就不值得被爱

你工作二十年，突然失业。收入会减少，生活需要调整，但这代表你过去的努力、积累的经验，以及作为一个人的价值，全部消失了？

不，一个人暂时没有能力工作、赚钱或者帮助别人，他依然值得被善待，你也不能让这些成为衡量自己全部价值的唯一标准

人生会有顺利，也会有不顺利，幸福是当你发现自己内心的价值

所以大家想想除了收入、成绩、身份和别人对你的评价，你还能说出自己身上哪三个值得珍惜的地方



**当你把自己的价值完全交给外界评价时，你的人生就容易变成一场永远不能输的比赛。**

**发现自己的价值，不是给自己找理由，而是即使看见自己的不足，也依然愿意面对它、改善它。**



第12天的核心 takeaway：
**你的成绩决定不了你整个人的价值，你的收入也不能衡量你全部的人生。**
**你可以努力变得更好，但不必靠不断变好，来证明自己值得被尊重。**
**真正值得建立的，是一种更稳定的自我认可：我知道自己还有不足，也愿意继续成长，但我不必等到成功以后，才允许自己觉得自己是一个值得被善待的人。**
