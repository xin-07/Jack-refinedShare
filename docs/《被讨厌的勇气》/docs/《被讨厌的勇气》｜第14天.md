# 《被讨厌的勇气》｜第14天

你是不是总觉得别人对你有意见？

《被讨厌的勇气》第14天思考

你走进办公室，主动和一个打招呼。结果对方只点了点头没有像平时一样热情。你心里马上开始琢磨他是不是对我有意见，是不是我昨天说错什么话了？

接下来一整天，你都在观察他，他和别人聊天，你觉得他在故意冷落你。他开会没有赞同你的观点，你觉得他在针对你。甚至他下班没有和你告别，你都觉得是在表达不满

但实际上呢？

可能他昨天晚上没睡好。可能他家里出了点事情。也可能他今天根本没有注意到你。

你花了一整天研究别人是不是讨厌你，而别人可能根本没有在想你

今天大家思考下：为什么有时候，我们越在意别人怎么看自己，就越容易觉得整个世界都在针对自己，有没有一种办法，让我们不再把别人的每个表情、每句话，都理解成对自己的评价？



**别人的行为是事实，你对别人行为的解释，却不一定是事实。**

**你可以在意别人对你的看法，但不必把别人的每一种反应，都理解成对你的评价。**

**不要用自己的猜测，替别人决定他怎么看你。**

第14天的核心 takeaway：
**别人的表情，不是对你的判决；别人的沉默，也不等于对你的否定。**
**你可以听取别人的评价，但不必替别人猜测；你可以认真对待关系，但不必靠每一个人的反应，证明自己的价值。**
**把注意力从“别人是不是不喜欢我”，转回“我想怎样做好自己能做的事”。你不需要读懂每个人的心思，才能安心地生活。**
