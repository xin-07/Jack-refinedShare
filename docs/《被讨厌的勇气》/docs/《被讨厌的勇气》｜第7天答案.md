# 《被讨厌的勇气》｜第7天答案

困住你的不是他的那句话，而是你给了他多大的权力

《被讨厌的勇气》第七天答案

别人评价我们，这件事永远避免不了。有人喜欢你。有人不喜欢你。有人理解你。有人误解你

这些评价一定会出现。而你，准备把多大的决定权交给了它们呢

如果别人说你不行，你马上开始怀疑自己。别人说你做得好，你才觉得自己有价值

那你的情绪，其实就一直被外界遥控，你内心的评价系统其实一直掌握在别人手里

书里一直强调人际关系中的很多烦恼，都来自我们太想控制别人怎么看自己

可这件事根本控制不了！

你把事情做好 问心无愧，别人怎么理解你，是他的事情

这不是冷漠。而是边界

反馈能帮助你成长。评价只是别人站在自己的角度，看了你一眼

分享给大家一个智慧：**真正的自由，不是再也听不到不同的声音**

<br />

**而是有一天你听见了，想过了，然后依然知道自己是谁**

别人可以评价你，但不代表别人有资格定义你！

**别人可以评价你，但不能替你定义你是谁。**

**你可以听见所有人的声音，但不要把自己的价值，交给其中任何一个人的一句话。**

**评价可以是信息，但不能成为判决书。**
