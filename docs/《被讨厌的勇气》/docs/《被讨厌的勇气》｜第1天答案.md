# 《被讨厌的勇气》｜第1天答案

过去会影响你，但如何解读过去会决定你

《被讨厌的勇气》第一天答案

我们平时特别习惯用“原因”解释自己。我为什么不敢上台？因为小时候被嘲笑过

我为什么不愿意相信别人？因为以前被伤害过

我为什么脾气这么大？因为我的家庭就是这样

这些解释是一种选择，就像过去会影响我们

但现在，除了问过去发生了什么，能不能想一下，我们现在的这种行为，在帮我达到什么目的？

比如你不敢参加比赛。会因为失败过，所以我害怕

如果只停在这里，故事结束了，过去已经发生，我们改变不了。

但我会继续问不参加比赛，我能达到什么目的？可能是不需要再次面对失败。不需要被别人评价。也不用验证自己到底行不行

这样一来，一切都变了

以前你会想现在为什么还需要用这种方式保护自己？

这两想法最大的区别，就是第二个把选择权交回给了我们！

永远记住：没人能拿走我们的选择权

<br />

**原因论**容易变成：

**过去发生了什么，所以我只能这样。**

**目的论**关注的是：

**即使过去影响了我，我今天为什么还在维持这种行为？它现在发挥着什么作用？**

**别人可以影响你的处境，但不等于别人自动拥有了替你做人生选择的权力。**

第1天真正要拿走的东西就是：

**过去是经历，不是判决书。**

**你可以承认它影响过你，但不要因此放弃今天的选择权。**
