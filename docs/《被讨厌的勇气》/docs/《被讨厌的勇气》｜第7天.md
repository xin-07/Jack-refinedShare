# 《被讨厌的勇气》｜第7天

别人一句话，如何能毁掉你一天的心情？

《被讨厌的勇气》第7天

假设你今天本来心情很好。早上工作也顺利，中午还和朋友吃了顿饭。结果下午，有个人突然对你说了一句：我觉得你最近状态不太好

就这一句话。你回家的路上开始反复想“他为什么这么说？”

是不是别人也这么觉得？我是不是哪里真的有问题？

原本90%的事情都挺顺利。最后你的注意力却全部被这一句话拿走了

更奇怪的是：如果有十个人夸你，只要有一个人批评你，很多时候，我们记得最清楚的，偏偏就是那一个批评

所以今天大家好好想想

为什么别人一句评价，会拥有这么大的力量？是因为那句话本身真的那么重要，还是因为我们太习惯把别人对自己的看法，变成自己评价自己的标准？

晚上我们继续聊

<br />

**评价可以是信息，但不能成为判决书。**

**别人可以评价你，但不能替你定义你是谁。**

**你可以听见所有人的声音，但不要把自己的价值，交给其中任何一个人的一句话。**

**第6天，是把人生方向盘从别人手里拿回来。**

**第7天，是把“我是谁”的定义权，也慢慢拿回来。**
