# 《被讨厌的勇气》｜第9天答案

帮一个人，但不替他过人生

《被讨厌的勇气》第9天答案

书里有一个我（Jack）认同的点：很多人际关系的烦恼，来自我们分不清自己的事情和别人的事情

比如孩子学习。父母当然有责任提供教育、环境、指导和必要的监督。但孩子最终愿不愿意认真学习，能不能逐渐建立主动性，不可能完全由父母替他完成

夫妻之间也是一样。你可以建议另一半多运动。可以解释运动为什么重要。甚至可以每天陪着一起去。但你不能因为自己认为运动正确，就要求对方必须按照你的方式生活

因为你越想控制，对方可能越想逃离

我希望你好，可你必须按照我认为好的方式生活，是两回事。我给你建议，你不接受，我生气。我为你付出，你没有按照我的期待改变，我委屈

慢慢地，帮助就变成了一种索取：既然我为你付出了这么多，你就应该听我的

但真正的帮助，应该给对方更多选择，而不是让对方越来越依赖我们的决定

大家下次再帮助别人时思考下，你是在提供帮助，还是要去服从？

<br />

**你可以为自己的帮助负责，但不能要求别人用服从来回报你的帮助。**

**帮助，是让一个人拥有更多选择，而不是让他只能服从你的选择。**

**我可以关心你，但不能替你活；我可以给你建议，但不能替你做决定。**

**真正的尊重，是我希望你好，也允许你用自己的方式走完人生。**
