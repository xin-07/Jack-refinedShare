# 《被讨厌的勇气》｜预告

下周一正式开始解读被讨厌的勇气

给你选择的自由，你敢不敢按照自己的想法活？我（Jack）发现，很多人真正缺少的，可能不只是钱。而是勇气

小时候，我们希望父母满意。上学以后，希望老师认可

工作以后，希望老板认可，发一条朋友圈，会在意别人怎么看

做一件自己真正想做的事情，又担心别人觉得自己奇怪

甚至到了三四十岁，我们做很多人生最重要的决定时，脑子里还会想别人会怎么看我？

一个月后，我希望你能清晰明确回复自己

为什么我们这么害怕被别人讨厌

明明知道比较没有意义，我们还是忍不住和别人比较？

有人一句话，就可以影响我们一整天的情绪？

为什么过去发生的事情，会一直影响今天的自己？

父母对孩子的期待，到底是谁的课题？

别人不喜欢你，怎么办

一个人到底什么时候，才算真正开始为自己活？

我想借此书，告诉大家真正的自由，不是让所有人都喜欢你

而是有人不喜欢你，你依然能够好好生活

<br />

《被讨厌的勇气》会挑战这种非常常见的思考方式：

**过去发生的事情，真的决定了现在的你吗？**

还是说：

**我们正在用过去的经历，解释自己现在的选择？**

这个问题会非常重要，因为它直接关系到：

**一个人到底有没有改变自己的可能。**

这本书真正想讨论的自由，更接近：

**我可以尊重你的看法，但我不需要用你的认可来决定我的人生。**
