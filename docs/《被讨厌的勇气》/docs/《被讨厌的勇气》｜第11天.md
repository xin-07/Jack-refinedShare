# 《被讨厌的勇气》｜第11天

为啥你越想教育别人，它越不愿意听？

《被讨厌的勇气》第11天思考

有两个家庭。第一个家庭，孩子考试考了90分。爸爸说：不错，但为什么没有考100分？下次继续努力。孩子考了100分，爸爸又说：很好，这才是你应该有的水平。

第二个家庭，孩子也考了90分。爸爸却问：“你觉得这次哪些地方做的不错？哪些地方可以改进？”孩子开始主动分析自己

两个爸爸都希望孩子进步。但他们之间有一个很大的区别。

书里提出纵向关系和横向关系

纵向关系是习惯用高低、强弱来理解人与人之间的关系

横向关系，则是承认每个人能力、经验和责任不同，但可以平等对话

所以今天大家思考

为什么我们越想通过批评和表扬改变一个人，他越不听我们？如果不靠命令、批评和奖励，我们又应该怎样帮助一个人真正成长呢



**纵向关系：我比你懂，所以你应该听我的**
**横向关系：我们可以平等地交流**

**平等，不等于能力相同；尊重，也不等于放弃指导。**

**尊重对方的选择，不代表你必须赞同他的选择，更不代表你要替他承担后果。**

当你很想纠正一个人的时候，先停下来，想一想：
**我是在帮助他找到自己的答案，还是希望他承认我的答案才是正确的？**

真正有价值的帮助，不是让一个人越来越离不开你的判断，而是让他逐渐拥有独立判断的能力。



**第11天的核心 takeaway：**
**教育不是让别人证明你是对的，而是帮助他逐渐学会自己判断。**
**你可以指出方向，但不能替别人走路；你可以帮助他成长，但不能把服从当成成长。**
