# 《被讨厌的勇气》｜第19天答案

如何每天开心 又能达成长久目标

《被讨厌的勇气》第19天答案

中午我（Jack）说人生就像跳舞。跳的时候，并不是尽快跳到舞台的另一边。我们认真完成每一个动作，感受音乐，享受整个过程。

人生也是一样，比如喜欢读书。当然希望自己未来拥有更多知识。
但如果他每天阅读的时候，都只是为了完成一年读一百本书的目标，那读书变成了一种任务。

读完一本，赶紧下一本。至于书里到底讲了什么，自己有没有真正理解，反而不重要了。

如果读书的时候经常产生新的问题。看到一个有意思的观点，就停下来思考，甚至花一个小时去研究相关知识。最后一年可能只读了二十本书。但每天都觉得很有意思。

你觉得谁的阅读更有价值？所以我们要区分两件事：一种是为了获得结果而行动。另一种是行动本身就有价值。两者可以兼得

人生不是只有赢了才有意义。当你真正投入一件事情的时候，意义就长出来了

今天大家想想，你现在做的事情 如何让两者兼得！



**当我们过分关注目标的完成情况时，很容易忘记自己最初为什么要做这件事。**

**真正可持续的努力，不是每天都靠意志力逼迫自己，而是即使目标还很遥远，你也能从正在做的事情中发现价值。**

**人生不是只有赢了才有意义。当你真正投入一件事情的时候，意义就已经开始产生了。**

**目标让你知道要去哪里，过程让你知道为什么要去。**
