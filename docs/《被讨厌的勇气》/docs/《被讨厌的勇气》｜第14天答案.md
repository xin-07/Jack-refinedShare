# 《被讨厌的勇气》｜第14天答案

大多数人都是嘉豪

《被讨厌的勇气》第14天答案

不要以为大家都在看你！这听起来好像有点奇怪。

我们不应该重视自己吗？

当然应该，但重视自己，和认为别人所有的行为都与你有关，是两回事

比如同事今天没有和你打招呼。这只是一件事实。但你马上解释为他是不是讨厌我

然后你又根据这个解释，产生了很多情绪。焦虑、委屈、生气，甚至开始疏远对方。最后两个人的关系真的变差了。

但最开始，可能什么事情都没有发生。

你有没有发现？真正让你难受的，不是别人做了什么，而是你认定别人做这件事是因为你

事实上别人有自己的生活，并不是每个人的喜怒哀乐，都和你有关系

以后当你觉得别人对你有意见时，问自己

第一，事实是什么？比如他今天没有主动和我说话
第二，我的解释是什么？比如我认为他不喜欢我

如果这段关系对你重要，你可以主动沟通。如果对方就是恶意，那直接拉黑。但没有证据之前，不必急着把最坏的解释当成事实



**你是自己生活的主角，但不意味着你也是别人生活的主角。**
不要高估自己在别人每一个行为中的重要性。

**不要在还没有弄清事实的时候，就先用最坏的解释折磨自己。**

第14天的核心 takeaway：
**别人的行为是事实，你对它的解释不一定是事实。**
**别人有自己的生活，不是每个人的喜怒哀乐都与你有关。**
**当你觉得别人对你有意见时，先问自己：事实是什么？我的解释又是什么？**
**如果关系重要，就主动沟通；如果对方确实有恶意，就设立边界。但在没有证据之前，不必急着把最坏的解释当成事实。**
**你不需要读懂每个人的心思，才能安心地做好自己。**
