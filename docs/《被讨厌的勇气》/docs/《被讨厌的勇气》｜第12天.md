# 《被讨厌的勇气》｜第12天

如果你不再优秀，还会有人喜欢你吗？

假设有一个孩子，从小成绩特别好。每次考第一名，父母都很高兴，老师也会表扬他。慢慢的，他发现了只要我成绩好，大家就喜欢我。

于是他越来越努力。但有一次考试，他只考了第十名。明明这个成绩也不差，他却特别难过，甚至不敢告诉父母

因为在他心理，考试已经不只是考试了。考得好，说明我是一个值得被喜欢的人。考的不好，说明我让所有人失望了

其实成年人也一样。有些人必须不停赚钱，才能觉得自己有价值。有些人必须不断获得别人的认可，才能相信自己足够优秀

还有些人，一旦失业、生病，或者暂时做不出成绩，就开始怀疑自己的人生

所有今天我想问大家

如果有一天，你不再赚钱，不再优秀，也没有任何值得炫耀的成绩，你还会觉得自己是一个有价值的人吗？



**这就是把成绩和自我价值绑在一起的危险：你不仅害怕失败，还开始害怕失败后的自己不再值得被喜欢。**

**当你的价值必须依靠成绩来证明时，你就很难允许自己有一段暂时不优秀的时期。**

我们需要学会区分：**对具体行为的评价，不等于对整个人的价值下判决。**

**真正的自信，不是相信自己永远优秀，而是即使有一天不再优秀，也不因此否定自己。**
**成绩可以证明你某个阶段的表现，收入可以改善你的生活，别人的认可也能带来快乐。**
**但这些东西，不应该成为你允许自己拥有价值的唯一条件。**

**你可以努力成为一个更好的人，但不要把“变得更好”，当成“我才值得被喜欢”的前提。**
