# 《被讨厌的勇气》｜第二周总结

你的人生，到底是谁在做主？

《被讨厌的勇气》第二周总结

不知不觉，我们已经读完了第二周。这一周，我们一直在讨论为什么我们这么在意别人怎么看自己？

第6天，我们讲认可欲望。很多时候，我们努力不是因为自己想做，而是希望得到别人的表扬

第7天，我们讲别人的评价。为什么十个人夸你，一个人批评你，你却可能难受一整天？别人可以评价你，但不代表别人有资格定义你

第8天，我们讲被讨厌的勇气。它不是故意得罪别人，而是接受你不可能让所有人满意

第9天，我们讲关心和控制。真正的帮助，并非让别人越来越听你的话，而是让他有能力为自己负责

第10天，我们讲课题分离。做好自己应该做的事情，但不要视图控制别人所有的想法和选择

所以这一周，我（Jack）总结一句：你可以尊重别人的感受，但不必为了让所有人满意，放弃自己的人生

下周我们将会一起探讨：怎样既保持自己的边界，有和别人建立真正好的关系？



**最值得警惕的，不是别人对你提出了什么要求，而是你为了满足这些要求，逐渐放弃了自己的判断。**

**成熟不是不再在乎别人，而是在乎别人时，依然能够做出自己的判断。**

**你可以尊重别人的感受，但不必为了让所有人满意，放弃自己的人生。**

**别人的看法值得倾听，但你的人生，最终需要由你自己做主。**
