# 《被讨厌的勇气》｜第17天答案

可以百分百信任别人吗

《被讨厌的勇气》第17天答案

书里有个概念，叫他者信赖。就是愿意在没有绝对保证的情况下，给予别人一定程度的信任。担信任别人，不等于相信别人不会犯错

比如夫妻，你可以选择相信另一半。但这不意味着对方永远不会让你失望

朋友之间也是一样。你愿意帮助一个朋友，但不能保证他将来一定回报你

信赖不是毫无原则的相信所有人，但不要因为害怕可能受到伤害，就提前把所有人都当成不值得信任的人

这里又回到了我们前面讲过的课题分离。我是否真诚待人，是我的选择。别人是否珍惜这份信任，是他的选择

如果对方辜负了我，我可以重新判断这段关系，保护自己的边界，但我不需要为了避免任何失望，就试图控制所有人的行为

分享我（Jack）的交友原则，当我遇到陌生人会潜意识告诉自己
1.我愿意相信别人
2.如果信任被辜负，我也有能力面对现实，保护自己

请你也想想，我们能不能接受，人际关系本来就存在一定的不确定性？



**你不需要保证自己永远不会看错人，只需要相信自己在看错人之后，仍然有能力重新作出选择。**

**信任别人，不是因为你确定他永远不会让你失望，而是即使无法保证所有结果，你仍然愿意真诚地对待别人。**

真正值得培养的不是识别所有坏人的能力，也不是让所有人都不会辜负你的能力。
而是这两种能力：
**一方面，愿意相信别人；另一方面，即使信任被辜负，也有勇气面对现实。**

他者信赖
**你可以对世界保持善意，但不必对任何人毫无边界；你可以选择信任别人，也可以保留保护自己的能力。**
