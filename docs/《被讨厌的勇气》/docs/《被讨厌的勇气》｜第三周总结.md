# 《被讨厌的勇气》｜第三周总结

让彼此都能成为自己 是最美好的关系

《被讨厌的勇气》第三周总结

这一周，我们讨论了怎样既保持自己的独立，又和别人建立好的关系？

第11天，我们讲横向关系。父母和孩子、老板和员工，虽然责任和能力不同，但应该平等。尊重他就是一起面对困难

第12天，我们讲个人价值。人的价值，不应取决于收入、成绩和社会地位。你不必因为暂时不够优秀，就否定自己

第13天，讲他者贡献。帮助别人可以带来快乐，但不要把付出变成要求别人回报的筹码。善意不应该以牺牲自己为代价

第14天，聊共同体感觉。别人有自己的生活和烦恼，不是所有人的情绪都与你有关。你是自己人生的主角，但不是别人人生的主角

第15天，我们讲鼓励。好的帮助不是替别人解决所有问题，而是让他逐渐相信自己有能力面对困难

好的关系不是让别人依赖你，也不是让自己依赖别人，而是彼此尊重、互相支持，又都能独立成长

下周也是最后一周，将讨论如何接纳不完美的自己



**真正的尊重，不是放弃指导，而是在帮助别人时，依然把对方当作一个有能力思考和成长的人。**

**善意不应该变成控制别人的筹码，也不应该以失去自己的生活边界为代价。**

**真正的独立，不是我什么都不需要你；真正的亲密，也不是你必须按照我的期待生活。**

第三周核心 takeaway
让彼此都能成为自己，是最美好的关系。

**我尊重你，不代表我要控制你；我帮助你，不代表你必须回报我；我在乎你，不代表我要替你决定人生。**
**同样，你可以帮助我、支持我、给我建议，但我仍然需要为自己的人生负责。**
**好的关系，不是两个人互相捆绑，而是两个人能够互相支持，又各自拥有成长的空间。**
**我可以和你一起走一段路，但不必替你走完你的人生；我可以珍惜我们的关系，也不必为了维持关系而放弃自己。**

这就是“让彼此都能成为自己”的意义。
