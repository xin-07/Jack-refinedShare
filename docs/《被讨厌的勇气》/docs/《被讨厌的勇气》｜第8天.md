# 《被讨厌的勇气》｜第8天

也没有可能，或者也没有这个必要让所有人都喜欢自己？

《被讨厌的勇气》第8天思考

假设你进入一个十个人的新团队。特别希望和大家相处好。

第一个人喜欢你说话直接。第二个人却觉得，说话应该委婉一点。

于是你面对第二个人的时候，开始小心翼翼。

第三个人喜欢有主见的人。

第四个人又觉得，太有主见的人不好相处

第五个人希望你多说话。

第六个人觉得安静一点更成熟。

慢慢的，你开始觉得特别累。因为每遇到一个人，你都在想：我要变成什么样，他才会喜欢我？

最后可能真的很少有人讨厌你。

但有一天你突然发现：问自己到底是什么样的人？

好像已经说不清楚了。

所以今天的死啊空是：如果想让所有人都喜欢自己，就必须不断调整自己去满足不同人的期待，那么所谓所有人都喜欢我，最后需要付出的代价，会不会就是我越来越不敢做自己？

晚上我们直播见❤️

<br />

真正值得追求的不是：

**“所有人都喜欢我。”**

而是：

**“我可以允许有人不喜欢我，同时依然做我认为正确的事情。”**

**你不需要让所有人喜欢你，因为那意味着你必须成为所有人期待的样子。**

真正的自由是：

**允许有人不喜欢你，允许有人误解你，允许有人不同意你，同时你依然知道自己是谁，也依然愿意为自己的选择负责。**

第6天：别把人生方向盘交给别人的认可。

第7天：别把“我是谁”的定义权交给别人的评价。

第8天：别为了让所有人喜欢你，而放弃做自己。
