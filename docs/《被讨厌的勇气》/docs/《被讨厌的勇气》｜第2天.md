# 《被讨厌的勇气》｜第2天

你发脾气的时候，真的是控制不住吗？

《被讨厌的勇气》第2天思考

你去吃饭，服务员不小心把水洒到了你身上，你很生气，大声说你怎么做事的？

旁边的人劝你，他也不是故意的

你可能会说我就睡觉一下子没控制住

听起来很合理。因为我们平时都觉得，愤怒就像一团火。事情发生了，火突然烧起来，我们只是被它推着走

但书中里提出了一个想法，有没有可能，有些时候我们不是“因为生气所以大喊”，而是“为了达到某个目的，所以使用了愤怒”？

比如你把声音提高以后，服务员立刻就紧张了。马上道歉。马上重视你的要求。也就是说，愤怒可以让对方按照你的意思行动。

假设就在你大发脾气的时候，老板突然打电话过来。你接起电话，很可能马上换一个语气：您好，没事，您说

电话挂掉，又继续对服务员生气

如果愤怒真的完全无法控制，为什么有时候我们可以在一秒钟里把它暂停？

大家思考：我控制不住自己的脾气是真的吗？还是对某些人不愿意

<br />

“老板打电话”的例子至少说明了一件非常有意思的事情：

**我们对情绪的表达，并不总是完全失去控制。**

真正值得思考的是：

**“我生气了”和“我一定要用吼叫的方式表达愤怒”，是不是同一件事？**

**把人生的注意力，从“我为什么会这样”，慢慢转向“我现在可以怎么选择”。**

**情绪可以影响你，但不等于它可以替你做决定**。

**你可以承认自己真的生气了，但在表达愤怒之前，先问一句：**

**“我现在这样做，是想达到什么目的？”**

真正思考的问题：

**我所谓的“控制不住脾气”，有多少是真的失控，又有多少是在用情绪让别人按照我的方式行动？**
