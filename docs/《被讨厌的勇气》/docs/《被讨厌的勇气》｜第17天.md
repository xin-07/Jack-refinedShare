# 《被讨厌的勇气》｜第17天

恋爱的时候想看对方手机 总会胡思乱想 怎么办

《被讨厌的勇气》第17天思考

假设两个人谈恋爱。其中一个人特别害怕被欺骗。所以每天都想知道另一半在哪里，和谁在一起，什么时候回家

对方没有及时回复消息，他就开始胡思乱想。如果另一半出去聚会，他还想看看有没有自己不认识的人

他觉得我不是不相信你，我只是害怕受到伤害

但时间长了，另一半却越来越不开心。因为无论自己做什么，都好像需要不断证明清白。

原本两个人是因为喜欢才走到一起。最后却变成了一个人不断检查，另一个人不断解释

生活中类似的事情还有很多。朋友借钱，我们担心他不还。员工负责项目,老板担心他做不好。孩子独自处理事情，父母担心他犯错。

我们总希望先获得百分之百的保证，然后才愿意相信别人

但这个世界上，有没有一种关系，可以保证别人永远不会让你失望？

如果没有，我们到底应该怎样理解信任

晚上我们继续聊



**你可以认真经营一段关系，却无法替另一个人保证这段关系的所有结果。**

信任不是掌握了对方的全部信息，而是在无法掌握一切的情况下，仍然选择如何与对方相处。

**信任一个人，不是因为你有把握他永远不会让你失望，而是你不再试图通过控制他，来消除人生中的所有不确定性。**

我们培养的勇气是：**我愿意认真对待一段关系，但我不要求自己控制它的每一个结果；我愿意信任别人，也有能力在信任被辜负时保护自己。**
