# 《被讨厌的勇气》｜第16天

为什么当你越努力，反而越焦虑

《被讨厌的勇气》第16天思考

假设有一个人，每天都特别努力。他坚持运动，希望身体更好。每天读书，希望自己懂得更多。努力赚钱，希望家人生活得更舒服

但他有一个习惯，就是永远盯着自己还没有做到的地方。今天运动了半小时，他觉得应该运动一小时。今年收入增加了，他觉得别人增长得更多。读完一本书，他又觉得自己还有那么多知识不知道

事实呢？明明每天都在进步，他却很少真正满意

甚至偶尔休息一天，都会觉得自己正在浪费生命

书里有个概念，叫作自我接纳。

但很多人听到这个词，第一反应就是如果我接受现在的自己，是不是就没有动力进步了？

所以今天大家思考下

一个人有没有可能，既对现在的自己感到满意，又始终保持进步的动力？

或者说如果有没有办法让你既愉快的接受自己的不足，又还愿意努力改变提升自己？

晚上我们直播继续聊



**问题在于，他只允许自己追求进步，却不允许自己承认进步。**

**你可以对自己的表现不满意，却不必对自己这个人失望。**

**你到底是在帮助自己成长，还是在用不断否定自己的方式，逼迫自己成长？**

**成长不是每天都要证明自己很优秀，而是每天都能找到一点可以改善的地方。**

**不要因为不满意现在的自己，才允许自己努力；而是因为接纳现在的自己，所以有勇气继续成长。**

今天的核心 takeaway：
你不必等到足够优秀，才允许自己满意。
你可以承认现在的自己还有不足，同时珍惜已经取得的进步。
**接纳现在的自己，不是停止成长，而是不再靠否定自己，才能获得成长的动力。**
