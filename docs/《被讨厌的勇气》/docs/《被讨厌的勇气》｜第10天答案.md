# 《被讨厌的勇气》｜第10天答案

对自己的行为负责，但不对别人的情绪负责

《被讨厌的勇气》第10天答案

书里最值得反复学习的概念之一，就是课题分离。很多人会觉得这是不是自私？

比如朋友生气了，我不管。孩子不学习，我不管？夫妻吵架了，我说这是你的课题？

课题分离不是让你不负责，而是让你分清自己到底应该复制到哪里

比如朋友请你吃饭。你认真考虑他的邀请，礼貌拒绝，解释原因。也可以主动约下一次。这些都是你能做的事情，但你最完以后，对方仍然不高兴

那你就要接受事实：你可以影响别人的感受，但无法完全决定别人的感受

如果你把所有人满意都当成自己的任务，就会发现，这是一份永远做不完的工作，因为每个人都有期待。有些期待甚至互相矛盾

你满足了这个人，可能又让另一个人不高兴。最后你的人生，就会变成不停的处理别人的情绪

所以今天趁周末思考下：从此以后，你能否认真对待每一段关系，但不再试图控制关系里的每一个人呢

<br />

**别人不高兴，不等于你做错了；别人满意，也不一定代表你做得对。**

**对自己的行为负责，但不对别人的所有情绪负责。**

**认真对待每一段关系，但不试图控制关系里的每一个人。**

**我可以努力不伤害别人，但不能保证所有人都不讨厌我。**
