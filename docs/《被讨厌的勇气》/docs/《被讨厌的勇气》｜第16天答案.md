# 《被讨厌的勇气》｜第16天答案

如何接纳自己并且更快乐的成长

《被讨厌的勇气》的16天答案

自我接纳是承认自己真实的样子。比如你想每天阅读一小时。但因为工作忙，只读了10分钟。如果你习惯自我否定，可能会想怎么连这点事情都坚持不了？

然后越想越失望，甚至干脆放弃。但如果你能接纳自己，你会换一种想法：今天确实只读了十分钟，但我已经开始了。明天看看能不能安排的更好

两个人面对的事实完全一样。但一种让人陷入自责，另一种让人继续行动。这就是自我接纳的意义

承认现实，然后从现实出发，分清哪些事情可以改变，哪些事情暂时无法改变

比如你的身高、已经发生的过去，无法改变。但你的生活习惯、学习方法、面对问题的态度，往往还有调整空间

如果你每天都为无法改变的事情痛苦，就没有精力去改变真正能改变的部分

大家想一件最近让你不满意的事，然后说出两句话
第一句：我接受自己现在确实还没有做好
第二句：接下来，我愿意为它做出什么具体改变？



我们需要区分两件事：**接受现实，不等于接受现状永远不变。**

自我接纳不是告诉自己“我已经足够好了，不需要改变”，而是承认：
**我现在确实有不足，但这不代表我没有能力改变。**

**接纳自己，不是为不足找借口，而是不再把不足当成否定自己的理由。**
