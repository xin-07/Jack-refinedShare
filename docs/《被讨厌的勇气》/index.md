# Jack带你读《被讨厌的勇气》

《被讨厌的勇气》（The Courage to Be Disliked）是岸见一郎与古贺史健的代表作。全书采用「青年与哲人对话」的形式，用阿德勒心理学的视角，重新回答一个困扰很多人的问题：**怎样才算真正为自己而活？**

这本书不是教你讨人喜欢，而是帮你卸下「害怕被讨厌」的枷锁。过去为什么一直影响着你？愤怒真的控制不住吗？自卑到底在阻碍你还是保护你？别人怎么看，真的那么重要吗？

通过每天一个思考，跟着Jack一起，把这些困扰讲清楚：

- **目的论**：过去不能替你决定今天，你如何解读和使用过去，才决定了你的未来
- **情绪的目的**：愤怒不一定是失控的火，有时它只是我们为了达到某个目的而使用的工具
- **自卑与勇气**：「我不够好」有时不是起点，而是阻止自己开始的借口
- **与他人比较**：如果幸福的标准永远是「比别人过得好」，这场比赛就永远没有终点
- **课题分离**：别人怎么看你，是别人的课题；你怎么选择，才是你的课题

真正的自由，不是让所有人都喜欢你，而是有人不喜欢你，你依然能够好好生活。
