365天思想实验，第160天：抗生素耐药性

抗生素用来治疗细菌感染。用着用着，效果越来越差了

细菌之间本来就存在差异。当抗生素进入人体，容易被它杀死的细菌大量死亡，但具有耐药能力的细菌可能存活下来，继续繁殖

结果就是你消灭了一大批细菌，却让更难对付细菌有了更多生存机会，这就是自然选择

所以抗生素一定合理使用，不能随便滥用。但我想讲的是背后的规律

有时候，麻烦反复出现，不是因为你不够努力，而是因为环境一直没有改变

想戒掉刷短视频。强迫自己不看手机，但手机放在旁边，通知不断响起。你坚持几天，最后。还是忍不住打开！

如果只消灭眼前的坏结果，却不改变背后的选择环境，麻烦就可能换一种方式继续存在

今天大家找一个生活中反复出现的麻烦，想想
一，什么环境让它容易发生？
二，他发生以后，得到了什么奖励？
三，怎样让更好的替代行为更容易发生？

我想听听大家思考和分析，改变环境改变一切！
