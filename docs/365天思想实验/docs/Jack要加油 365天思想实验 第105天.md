# Jack要加油 365天思想实验 第105天

365天思想实验，第105天



今天搞一个特别适合接下来“行为实验”的概念：承诺装置



很多时候，我们不是不知道什么是对的

我们知道应该运动，应该少刷手机，应该早点睡

等到真正要做的时候，我们又会告诉自己今天算了，明天开始



所以别只相信未来的自己，要提前给未来的自己设一个规则

比如你想每天运动20分钟。不要等到晚上再想今天要不要去



你可以提前跟朋友约好每天六点一起跑步

也可以在群里公开打卡甚至提前把运动服、鞋子都准备好



你是在今天状态好的时候，替明天那个可能偷懒的自己做决定❤️

这事特别重要。因为很多人设计人生的时候，总是假设未来的我一定会更自律



但现实往往是，未来的你还是会累，会拖延，会想偷懒



所以真正好的系统，不是要求自己每一天特别自律而是提前把一些选择做掉



今天选一件一直想做的事，告诉家人，告诉朋友或者在评论区直接写出来。程序中清醒，提前替偷懒的自己，把路铺好。
