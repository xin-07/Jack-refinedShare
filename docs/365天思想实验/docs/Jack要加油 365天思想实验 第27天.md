# Jack要加油 365天思想实验 第27天

6月24日，365天思想实验，第27天。



今天，请主动承认自己的一次进步👍

不是骄傲，不是炫耀。



也不是觉得自己已经很厉害了。

而是认真看见：我确实比过去的自己好了一点



可能你最近少抱怨了，开始存钱了，主动夸过别人了也可能你联系了很久没联系的人，整理了房间、照顾了身体、减少了解释、或是不再乱消费了



这些看起来都不是惊天动地的大事

但你懂得🤙真正的改变，往往就是从这些小事开始的。



很多人为什么坚持不下去？

因为他总是盯着自己还没做到的地方，却从来不肯承认自己已经走了一小步。



人是需要正反馈的，我要让你知道：你正在慢慢变好🎊



今天的任务很简单：写下自己最近一个小小进步。



哪怕只是“我今天忍住了一句抱怨”。

不知不觉27天了，我也要点正反馈
