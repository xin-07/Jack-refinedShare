365天思想实验，第143天

今天讲一个生物学里很有意思的概念：选择性注意

你有没有发现，假设你最近准备买一辆特斯拉，突然就觉得马路上的特斯拉特别多。难道是这几天特斯拉的数量突然增加了吗？

当然不是。而是因为你开始关注它，大脑更容易注意到相关的信息。

其实我们每天接触的信息非常多，不可能全部认真处理，所以大脑会根据当前的目标、兴趣和经验，决定哪些信息值得注意

对大家也是如此，以前你从不研究商业模式，走进一家咖啡店，看到的就是咖啡好不好喝。当你研究商业后会想：这家店一天有多少顾客？房租多少钱？员工工资多少？一杯咖啡到底能赚多少？

同样一家店，看到的世界完全不同

今天给大家一个任务：找一个你也别想了解的领域。每天在生活里寻找三个和它有关的现象，再试着解释背后的原因

我希望当所有人看到别人已经麻木的事情，而你开始有能力看见以前看不见的东西，发现新的机会
