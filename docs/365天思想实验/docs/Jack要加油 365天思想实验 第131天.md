# Jack要加油 365天思想实验 第131天

为什么要有记忆能力



365天思想实验，第131天



几年以后，你可能已经忘掉了一件事90%的细节。当时谁说了什么、在哪个房间、具体是哪一天，可能都想不起来了



但有的事影响你很多年。比如小时候遇到一个真正尊重你的老师。多年以后，你可能已经记不起他当时说过哪句话，却因此更愿意相信自己



一次失败也是一样。事情的细节慢慢模糊了，但你后来遇到困难时，会下意识多准备一步



从神经科学看，这很合理。记忆并不只是给大脑做一个完整的录像备份。学习和记忆会通过神经可塑性，让大脑中的连接发生改变。过去的经验，会参与影响你以后怎么判断、怎么预测、怎么行动



所以一个成功的记忆，不是30年后，你还能把当时发生的事情完整复述出来。而是你早就忘了当时发生过什么，但那次经历已经悄悄改变了后来那个你，过去经历的东西，最重要的作用，就是帮助我们改变未来的行动



今天希望你想一件已经记不清细节、却明显改变过你的经历的事情！
