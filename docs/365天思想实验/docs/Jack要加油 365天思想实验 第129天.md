365天思想实验，第129天



之前讲了牛顿一，今天讲牛顿第三定律



一个物体对另一个物体施加力，另一个物体也会同时给它一个大小相等、方向相反的力



你用手推墙，墙也在推你的手。你往地面向后瞪，地面给你向前的力，你才能往前跑。这两个力作用在不同物体上，所以不是简单互相抵消



你想会的信任，就要先让别人觉得你值得信任。你想认识优秀的人，就要想我能给他创造什么价值？你想让别人认真听你讲话，就要学会认真听别人讲话



你想让自己的内容有人传播，也要先给别人来带一点东西。甚至健身也是。你给身体一个适当的刺激，身体经过恢复以后，会用更强的能力回应你



但付出也不保证一定从同一个人、同一天得到回报。长期来看，你持续释放出去的能力、善意、作品和价值，会改变你周围的人



改变人生的第一步，不是等世界先推你。而是你先伸出手
