# Jack要加油 365天思想实验 第126天

你不弱，只是把力量撒的太开了



365天思想实验，第126天



周末来个刺激的，没错，讲压强：同样大小的力，作用的面积越小，产生的压强越大



为什么针容易进去因为针尖非常小，同样的力量被集中到了一个很小的地方



做事情也是一样，一天其实非常忙，想健身，想学英语，想做副业，想拍视频，想读书，还想学AI。每天都在努力，但一年过去了，好像每件事都只前进了一点点



因为你的力量被分到了太多地方

假设你每天只有两个小时可以真正用来提升自己，同时做五件事，每件事可能只分到二十几分钟



但如果接下来三个月，你把大部分时间集中在一件最重要的事情上，结果会不同。我（Jack）认为人生每个阶段，都应该有一个主攻方向



要清楚最重要的到底是什么。想做自媒体，就把内容做好，想提高身体，就把运动和睡眠稳定下来，想变富，就先解决最影响你的收入或者支出问题



想一下未来90天，只能重点做好一件事，它应该是什么？



然后扎进去！
