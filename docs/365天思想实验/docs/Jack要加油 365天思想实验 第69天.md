# Jack要加油 365天思想实验 第69天

8月10日，365天思想实验，第69天



剧透一个心理学概念——锚定效应

就是一个人先看到一个数字以后，后面的判断，很容易被这个数字带着走



比如一件衣服原价写着2000，现在卖800



你第一反应可能是：便宜这么多，划算啊

但真正应该问的是：这件衣服本身值不值800？



投资里这个问题更明显



一只股票以前100块，现在跌到60块

你会觉得：都跌40%了，应该便宜了吧？

可100块只是你脑子里的一个锚

它以前卖100，不代表它现在就一定值60



反过来也一样



你20块买的股票涨到了40块，你可能觉得已经翻倍了，太贵了



但它未来到底值多少钱，也和你的买入价没有关系



人生里其实到处都是锚



别人30岁买房了，我30岁是不是也必须买？

别人一年赚100万，我是不是也得赚100万？



今天的任务：找一个影响你的数字，然后问问自己，没有之前那个数字，我还会做出同样的判断吗？
