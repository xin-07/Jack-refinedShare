# Jack要加油 365天思想实验 第96天

9月6日，365天思想实验，第96天



今天讲一个越来越重要的能力：反脆弱



有些东西遇到冲击会坏，比如玻璃杯

有些东西遇到冲击能抗住，比如石头

但有一种东西它经历一点波动以后，反而会变得更强



人的肌肉就是最简单的例子

你去训练，本质上是在给身体适当的压力。训练以后恢复，身体为了应付下一次压力，会慢慢变得更强



我觉得人生也应该尽量建立这种系统



比如你做自媒体，一条视频没人看，你不是简单地告诉自己坚持，而是去研究为什么没人看，下一条改标题、改开头、该表达



这次失败给下一次增加了经验



再比如工作中被拒绝一次，你开始学怎么沟通；投资里判断一次，你开始建立规则；第一次上台紧张得说不出话，第二次就知道该怎么准备了



人生总会遇到坏事

很多事情只要没有把我彻底击垮，我就尽量从里面拿走一点东西



今天任务：从自己经常做的事情里运用这个模式

适当得压力+足够的恢复+从中学习
