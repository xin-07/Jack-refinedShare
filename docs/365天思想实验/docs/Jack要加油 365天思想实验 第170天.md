周日说个时间管理理论：排队论

有没有这样的体验，去银行或超市，前面对了几个人，等待时间就突然变得特别长？

假设一家店只有一个收银员，每小时能服务20位顾客。如果每小时10个人，大家不用等，但如果每小时来了19个人呢？

理论上还能处理，但只要有几位顾客结账慢一点，后面就排起长队

因为当系统的使用率接近顶格时，等待时间会快速增加！

你每天有8小时可以工作，就安排整整8小时的任务。时间利用率达到了100%。但突然来一通电话，或者某件事比预计多花半小时，后面的安排就按部就被打乱，然后你开始加班、焦虑...

如果你很努力，结果还是很差，很可能你的系统根本没有留下应对变化的空间，恰恰相反，一定程度的闲置能力，使系统保持稳定和灵活的重要条件

今天周日，别把时间都安排满，主动留出一段没有安排任务的时间吧❤️
