# Jack要加油 365天思想实验 第161天

这几类人值得深交🎉



365天思想实验，第161天。前几天和大家聊过哪几种人应该拉黑。今天聊聊：什么样的朋友必须珍惜？



我总结了四点



一，真心希望你越来越好的人，你成功了他不会嫉妒，而是发自内心的替你高兴。你遇到困难，他不会幸灾乐祸，而是愿意陪你一起想办法，人品好的朋友不需要你过得不好，来证明他自己过得不错！



二，敢于告诉你真话的人，你做错决定，他不会为了讨好你，什么都说对。但他也不会故意打击你，而是私下认真告诉你哪里有错。能让你舒服的人很多，愿意冒着让你不舒服的风险，帮助你成长的人很少！



三，尊重你边界的人。你忙的时候，他不会因为你没有及时回复就生气。你拒绝一个请求，他不会因此道德绑架你。好的友谊是彼此尊重！



四，能够一起成长的人。你们有不同的职业、收入和兴趣，但可以互相分享新的知识、不同的观点。和他聊完天，你会觉得这个世界又大了一点



我（Jack）祝每一位专属会员能拥有这样的好朋友🎁
