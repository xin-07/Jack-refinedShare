# Jack要加油 365天思想实验 第119天

情绪最差的时候，不必想通，而是别乱做决定



365天思想实验，第119天



每个人都会有情绪特别差的时候，可能因为别人一句话或者工作不顺，也可能什么大事都没发生，就是突然觉得烦、累、什么都不想做



很多人这时候会急着把情绪解决掉，不停想我为什么这么难受？是不是哪里出现问题？以后怎么办？自然是越想越难受



其实面对情绪，最重要的是承认它，今天我就是不开心就是生气。没关系，不需要马上变积极



然后把事实和自己脑子里的解释分开



比如别人没有回复你，这是事实



“他看不起我”“所有人都不喜欢我”，这些可能只是情绪替你补出来的故事



人在情绪里，很容易把一个问题想成整个世界都有问题



最后就是让身体恢复



出去走走，运动一下，洗个澡，吃顿饭，睡一觉。以我（Jack）经历很多昨晚觉得天塌下来的事，第二天早上看，根本没有那么严重



下一次情绪来时，想一下现在发生了什么？哪些是事实，哪些只是情绪，感受它 把控它
