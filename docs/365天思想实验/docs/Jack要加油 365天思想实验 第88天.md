# Jack要加油 365天思想实验 第88天

8月29日，365天思想实验，第88天



周末讲一个工程里特别重要的概念——冗余设计



比如一架飞机有两台发动机

正常飞的时候，可能根本用不到备用

但工程师为什么还是要这么设计？



因为要考虑如果有一个东西突然坏了，整个系统还能不能继续运行？



数据中心也一样

重要的服务器要有备用电源

医院都要准备发动机



永远不要相信意外不会发生

而是提前想好如果意外发生以后怎么办



人生特别需要这种思维



很多人总是把生活安排得刚刚好

每个月赚一万，就花一万

每天时间排得满满的，一点空都没有

身体也一直撑到极限

只要什么事情都不发生，好像没问题



但孩子突然生病怎么办？

工作突然没了怎么办？

家里突然需要一笔钱怎么办？



所以一直要有备用方案

存钱

保持身体健康

多学一个技能

都是一种冗余



甚至给自己的时间留一点空，也是冗余



今天任务：找重要的一件事情，想象如果出问题了，你有没有备用方案？
