# Jack要加油 365天思想实验 第148天

失败是什么

365天思想实验，第148天：故障模式与影响分析

这是工程领域的词，听起来复杂，道理简单

假设工程师要设计飞机。不能只考虑正常飞行的时候，还要提前想如果某个零件坏了怎么办？如果传感器提供了错误的信息怎么办？哪些故障最危险？

然后根据发生的可能性、后果的严重程度，以及能不能提前发现，决定优先解决哪些风险。

这种思考方式我（Jack）希望能深刻刻进骨子里。比如创业。很多人就是计算如果生意成功，能赚多少钱。但你想过如果半年没有收入怎么办？如果合伙人退出怎么办？如果投入的钱全部亏掉，会不会影响家人的正常生活？

再比如投资，除了研究它未来能涨多少，是否想过如果自己的判断错了，最多会损失多少？自己能不能承受？

有两种失败。一种是失败了还能重开。另一种是失败一次，就失去重开的机会！
你要不断尝试第一种，一定要避开第二种

问问自己亚欧走的事最坏会发生什么？我能承受吗？现在能做什么来减少损失？
