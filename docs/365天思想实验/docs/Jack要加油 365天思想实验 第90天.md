# Jack要加油 365天思想实验 第90天

8月31日，365天思想实验，第90天



昨天讲竹子为什么遇到大风不容易断，今天讲为什么有些竹子，能突然长得特别快？



竹子前几年几乎不长，一直在地下扎根，等根扎好了以后，突然一天长几十厘米



竹子在你看得见的快速生长之前，地下已经有一套根和地下茎系统，等到温度、水分、营养这些条件合适以后，新的竹笋可以长得非常快



记得年少去宁波山上，惊呼怎么突然长这么高了？



不得不说我们日常大堆事情都是如此

做自媒体，前面发了100条视频都没人看

第101条突然火了



你会觉得运气来了

可那100条没人看的视频，就是根



读了很多年的书，平时好像也没什么用

直到有一天遇到机会，突然能把很多东西串起来

别人有觉得你怎么懂这么多？



记住：很多真正重要的成长，刚开始都是看不见的



今天想一件你愿意认真做三年的事情



然后问问自己如果前半年没人看见、没人夸我、也没有明显结果，我还愿不愿意继续？
