# Jack要加油 365天思想实验 第65天

8月6日，365天思想实验，第65天



今天咱们讲一个心理学概念：标签效应

就是一个人一旦长期给自己贴上一个标签，慢慢就真的会活成那个标签



很多人经常说：我就是不会赚钱

我就是不擅长表达

我就是记性不好

我就是傻炮



你以为这只是随口一说，其实你的大脑会把这些话，当成事实

然后开始寻找各种证据，证明这个标签是对的



相反，如果你把标签换一下



不要说：我就是不会

改成：我只是现在还不会



前一句，是给自己判了死刑

后一句，是告诉自己还有成长的机会



我认识的所有成功的人，他们从来不给自己贴死标签！



不会，就学！

失败，就改！

做不好，就继续练！



你必须相信，今天的自己，不代表一辈子的自己



今天的任务：找一句你最常对自己说的负面标签，留言告诉我，然后把它改掉！
