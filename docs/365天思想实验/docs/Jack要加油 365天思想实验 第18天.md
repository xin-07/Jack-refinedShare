# Jack要加油 365天思想实验 第18天

6月15日 365天思想实验，第18天

今天，请承认一次：我可能是错的😭



不是让你否定自己也不是让你没有立场

而是训练自己拥有一种更高级的能力：允许自己的认知被更新📕



这几天我看大家在评论区讨论，发现一个很有意思的现象

同样一件事情，有人看到的是机会，有人看到的是风险；有人觉得应该坚持，有人觉得应该放下🧘‍♀️



以前我可能会下意识觉得，和我想法不一样的人就是没想明白。很多时候不是别人错了，而是他站的位置和经历的人生，跟我不一样



人最容易犯的错误，就是把“我不喜欢”和“他没价值”混为一谈



很多人的认知提升不了是因为他太害怕承认自己可能错了。一旦别人观点和他不同，他第一反应不是理解，而是反驳🤬



但真正成长很快的人，往往都愿意问自己一句：有没有可能我之前想得太简单了



今天的任务很简单

找一个你曾经非常坚定的观点 



然后认真问自己：它有没有可能不完全对
