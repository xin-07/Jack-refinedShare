# Jack要加油 365天思想实验 第112天

365天思想实验，第112天



今天讲一个特别的概念：遗忘



很多人学习的时候，觉得听懂了，就等于学会了

其实完全不是一回事



你今天听一段很有道理的话，当时觉得特别震撼

第二天还能记得大概



过几天以后，很多细节就开始模糊，再过一段时间，可能只剩下好像以前听过



这其实很正常，人的大脑本来就会遗忘



所以真正有效的学习是不断把重要的东西重新拿出来



这也是为什么我（Jack）最近一直跟大家强调输出



你看完一篇内容，马上用自己的话讲给别人听一次，效果完全不一样，因为当你开始的时候，大脑不是在被动接受，而是在主动寻找：刚才到底讲了什么？为什么是这样？我能不能举个自己的例子？



如果讲不出来，说明你其实还没有真正理解



以后大家看专属内容，看完以后，别马上划走，花一分钟，把里面最重要的东西复述一遍，当天再找机会用一次，过几天遇到类似的事情，再把它想起来一次



今天就试试 看看一周后能不能记住一条
