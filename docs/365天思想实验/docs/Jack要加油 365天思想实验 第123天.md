# Jack要加油 365天思想实验 第123天

有些东西，过一段时间，就少掉一半



365天思想实验，第123天



今天讲个概念：半衰期



一些会衰变的物质，并不是到了某一天突然全部消失，而是经过一个固定时间后，数量减少到原来的一半，再过同样的时间，又剩下一半。



所以它的变化不是“啪一下没了”，而是不断按比例减少



很多人想改变一个坏习惯，总希望从明天开始，我彻底不做了。可现实往往不是这样。你以前刷三个小时手机，先变成一个小时。再慢慢变成四十分钟



以前一星期点五次外卖，先变成三次，再变成一次



情绪也是这样，今天特别生气，你不一定需要逼自己马上想开，出去走一走，睡一觉，过两天再回头看，它可能已经没有当时那么大了。



未开悟时常追求一下成功



如今我（希望）能不能先让这个东西减少一半，坏习惯减一半，无效社交减一半，刷手机的时间减一半。把省下来的空间，再慢慢留给运动、阅读、家人和真正重要的事情



今天找一个想改变的习惯，能不能先把它砍一半？
