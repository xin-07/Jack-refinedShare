# Jack要加油 365天思想实验 第32天

6月30日，365天思想实验，第32天



今天，请把一件正在让你焦虑😖的事情，写下来

不要只在脑子里想一定要写出来，因为很多焦虑，最可怕的地方不是事情本身，而是它一直再脑子里反复打转。



越想越乱越想越怕。越想越觉得自己完了。但当你真的把它写下来，你就会发现，很多问题并没有想象中那么可怕



今天的任务很简单：写下你现在最焦虑的一件事



然后问自己三个问题：



第一，这件事最坏的结果是什么？



第二，我现在能做的最小一步是什么？



第三，如果朋友遇到同样的问题，我会这么劝他？



当我(Jack)遇到焦虑的事情 都会这么三步走🤫
