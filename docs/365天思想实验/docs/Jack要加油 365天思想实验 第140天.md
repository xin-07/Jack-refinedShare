# Jack要加油 365天思想实验 第140天

每天这样用AI，彻底改变你的世界

365天思想实验，第140天

最近两年，我（Jack）每天使用AI的时间越来越长。有时候聊天，研究一些以前根本不会主动了解的事，一聊就几个小时

大多数人以前每天刷两个小时短视频，现在改成和AI聊天两个小时，那只是把时间换了地方

真正我希望大家做到的是让AI创造出你原本没有的好奇心

比如以前你根本不关心电网怎么运行，半导体怎么制造，一家公司到底靠什么赚钱。现在只要有一点好奇，就可以马上问AI。听不懂，让它举个例子；听懂了，再继续追问

一个带出三个，三个又带出十个疑问。不知不觉，你开始对整个世界产生兴趣

我每天专属会员分享不同领域的知识。是希望某个话题，能让你突然产生一个念头：这件事，我想弄明白

当然和AI聊的久不代表真的学到了东西。你还得独立思考，验证答案，并且学会运用

所以今天你用AI的时候观察下自己是在不断增加好奇心 还是只是回答了你的疑问
