# Jack要加油 365天思想实验 第93天

9月3日，365天思想实验，第93天



今天聊一个年轻人越早明白越好的东西：你学的很多东西，最后真正值钱的不是知识本身，而是它训练出来的能力



比如你大学学高等数学

毕业以后，你可能一辈子都用不到微积分



那是不是白学了？

肯定不是

你在学属数学的时候，其实还训练了把一个复杂的问题，茶城一步一步去解决



你学历史也是一样。你可能记不住某一年发生了什么，但是如果你真的学明白了，你会慢慢知道，一件大事发生，背后往往不是一个原因，而是经济、利益、人性很多东西一起推动的



你学写作呢？

未来AI可能一分钟就能帮你写一篇文章



但你真正训练出来的是脑子里有一个很模糊的想法，怎么把它想清楚，再让另一个人听懂

这个能力不会因为AI出现就没用了

反而可能越来越重要



所以我(Jack)希望大家学一个东西的时候问自己一句：它正在训练我的什么能力

因为那些真正长在你身上的能力，

换一个地方，照样能用👍
