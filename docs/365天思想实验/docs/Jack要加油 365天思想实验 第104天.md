# Jack要加油 365天思想实验 第104天

365天思想实验，第104天



今天讲一个特别适合“六年之约”的概念：飞轮效应



你想象一个特别重的铁轮，刚开始推的时候，非常累，推一下，好像根本没动



再推一下，还是很慢



但只要你一直朝同一个方向给它力量，它转起来以后，后面每一下都会比前面轻松



这就是飞轮



生活中到处都能体现



第一次运动20分钟，你可能一直在看时间

第一次读一本书，十页都觉得慢

第一次拍视频，光开口就要练半天



可当你连续做了一段时间以后，会发现昨天做过的事情，会帮助今天的你



你运动以后精神更好，第二天更愿意动

你读的越多，新书越容易看懂

你视频做的越多，表达、剪辑、选题都会越来越快



这时候，你就不再是每天从零开始



所以我(Jack)特别希望大家理解，我们每周做行为实验，不是为了完成7天任务然后结束

而是在找哪些行为值得让它转起来



今天选一件你希望一年以后成为习惯的事情，然后看看能不能今天先推它一下？
