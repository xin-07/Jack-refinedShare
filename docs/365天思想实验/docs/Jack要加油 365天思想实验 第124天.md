今天讲个化学知识：缓冲溶液



有些溶液只要加入一点酸或者碱，酸碱度就会发生很大的变化。但缓冲溶液不一样。当外界加入少量酸或者碱的时候，它内部的成分会帮助“接住”这一部分变化，让整体的酸碱度不至于突然大幅波动



智慧的人都需要自己的“缓冲系统”



比如钱。如果你每个月赚多少就花多少，突然失业、车坏了、家里有急事，整个生活马上被打乱，但如果有一笔应急储备，这钱平时看起来没发挥作用，真正出事的时候，他就在帮你缓冲



睡眠也是。一个长期睡得好、身体状态不错的人，偶尔忙一天，还能扛得住，但如果你本就透支，再来一点事情，马上崩掉



还有家人、朋友、运动、阅读，甚至每天给自己留一点安静的时间，这些东西平时不一定帮你赚钱，却都在提高你的“缓冲能力”
