如何找到一生的使命

365天思想实验，第162天

周末想和大家聊一个特别的事情：如何找到一个真正适合自己、值得长期投入的方向？

分享个秘密，人有三种心理需要：自主感、胜任感和关系感，如果能满足，人就会幸福

一，自主感。这件事情，是你真正愿意做的，还是因为别人觉得有前途，你才去做？比如你已经实现财务自由，却依然每天主动研究学习。因为这件事情本身，就能让你感到快乐

二，胜任感。你在做这件事情的时候，能不能不断感受到自己在进步？比如第一次拍视频，讲得磕磕绊绊。拍到第30条，你发现自己表达得越来越清楚。这种成长

三，关系感。你做的事情，能不能和别人建立联系，甚至帮助别人，比如你研究了一个知识，自己能明白已经很开心。但当你把它讲出来，有帮助别人理解了这个世界，你会获得更深层次得满足
