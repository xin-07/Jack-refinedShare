就是一个人回忆一段经历的时候，往往不会把所有细节都记住。他最容易记住的，是其中感受最强烈的那个时刻，还有最后结束时的感受🎉



比如你出去旅行，前面几天都挺开心，但最后一天吵了一架。回来之后，你一想这趟旅行，可能首先想到的就是那场争吵😡



反过来也一样。一天本来过得很普通，甚至有点累，但晚上家里人跟你好好吃了顿饭，或者有人认真跟你说了一句谢谢，你会觉得这一天其实还不错😌



所以很多关系不一定要靠大事改变，有时候你只需要把结尾做好一点
