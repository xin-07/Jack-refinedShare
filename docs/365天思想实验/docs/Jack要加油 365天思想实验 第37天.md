# Jack要加油 365天思想实验 第37天

7月5日，365天思想实验，第37天。



今天大家做一件相对轻松的事：认真看一部电影



可以是我(Jack)之前推荐过的那部，也可以是任何一部你一直想看、但没静下心看完的电影。



但今天看电影，不是为了打发时间。



而是带着一个问题去看：这不电影里，有没有一个情节、一句话、一个人物，让我想到了自己的人生？



看电影，别看热闹。谁赢了，谁输了，谁被骗了，谁翻身了。



看完一部电影，应该看到人性、选择、命运、时代，还有自己。



一个角色为什么会走到那一步？



他哪一次选择改变人生？



他是被环境推着走，还是自己一步步选出来的？



如果换成我，我会怎么做？



好的电影不是让你逃离生活两个小时，而是让你回来以后，更看懂一点生活。



今天的任务很简单：



找一部电影，认真看完。



晚上告诉我 哪一部🦌
