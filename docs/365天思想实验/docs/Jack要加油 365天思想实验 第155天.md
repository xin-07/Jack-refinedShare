# Jack要加油 365天思想实验 第155天

这几类人越早拉黑越轻松

365天成长计划，第155天

今天想和大家聊聊哪几种人应该远离

第一见不得你好的人。你失业了他安慰你。你升职了他却开始阴阳怪气。你赚钱了，他说你运气好。你买房了，他说你肯定借了不少钱。

一个人只能接受你过得不好，却接受不了你越来越好，他真的是你的朋友吗？

第二只懂索取，从不付出的人

有困难的时候，第一个想到你。借钱、帮忙、介绍资源，什么都来找你。但你需要帮助的时候，他永远有理由拒绝。朋友之间不用每笔账都算清楚，但长期只有一方付出，这不是友谊，而是消耗

第三当面一套，背后一套的人。当着你的面称兄道弟，转过身就传播你的隐私，甚至添油加醋地说你的坏话。这样的人最危险，因为你不知道什么时候，自己就成了他嘴里的故事

第四种，不断突破你底线，你已明确拒绝，他还反复纠缠。你表达了不舒服，他却说你开不起玩笑。尊重你的人，不需要你一遍遍解释自己的边

你身边有这样吗
