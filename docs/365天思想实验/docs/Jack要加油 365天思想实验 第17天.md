# Jack要加油 365天思想实验 第17天

6月14日 365天思想实验，第17天

今天，请从一个你曾经讨厌的人身上，找一个亮点



昨晚我(Jack)和一位大主播连线🎉我们很多观点其实并不一样，甚至有些地方是完全不同的。但我听完以后，反而受益很多。更让我开心的是，大家没有因为观点不同就开始谩骂、攻击、扣帽子，而是愿去倾听、去思考、去包容



一个人成熟的重要标志，不是只能从喜欢的人身上学习，而是能够从自己不认同、不喜欢，甚至曾经讨厌的人身上，依然看到值得学习的地方



这个世界很复杂。 没有一个人是全对的。也没有一个人是全错的。有些人你不喜欢他的表达方式，但他可能很真诚



有些人你不认同他的观点，但他可能很努力。有些人你觉得他身上有很多问题，但他可能也有你没有的勇气、执行力、抗压能力，或者某种生存智慧



如果我们只愿意听让自己舒服的话，最后认知会越来越窄



今天任务：找一个你曾经不喜欢、不同意，甚至讨厌过的人



认真写下他身上的一个亮点🙏
