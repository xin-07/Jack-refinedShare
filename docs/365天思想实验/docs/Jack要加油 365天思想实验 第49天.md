# Jack要加油 365天思想实验 第49天

奖励早起的伙伴学物理学一个定律：熵增定律



简单理解，一个封闭系统如果没有能力输入，会自然从有序走向混乱🤪



房间几天不整理，会越来越乱

身体长期不锻炼，会越来越差

关系长期不维护，会越来越远

钱不管理，也会越来越少

很多人总觉得，只要我什么都不做，生活就会维持原样



其实不会❌



不主动整理，就会变乱。不主动学习，认知就会落后。不主动经营人际，感情就会变淡。不主动管理身体，健康就会慢慢下降



所以自律并不是把自己逼得很苦。只是持续给人生输入能量，让重要的事情保持秩序。



今天的任务很简单：找一个已经开始变乱的地方，把自己重新整理一下。留言告诉我，你的人生什么时候开始变差的🙏
