365天思想实验，第154天：功率和容量

一座大型电池，功率300兆瓦，储电容量1200兆瓦时，这两个数字有什么区别？

功率，决定它一瞬间最多能输出多少电
容量，决定它一共储存了多少电

所以这座电池如果以300兆瓦的功率放点，理论上只能运行4个小时

你可以把它想象成一个水库。功率是出水管有多粗，容量是水库里有多少水。水库很大，出水管太细，水就放不出来那么快。出水管很粗，水库却很小，很快就会放空

人生也一样。能连续直播5小时，说明输出能力不错。但如果让你连续直播一年呢？那就不仅需要表达能力，还需要知识储备，身体健康，选题积累和恢复时间

读过几百本书，知识储备很丰富，也要有把储备转换成实际成果的能力

所以你要更大的水库，还是更粗的出水管？
