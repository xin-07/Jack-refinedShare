# Jack要加油 365天思想实验 第44天

7月14日，365天思想实验，第44天。



今天正好周一，分享个心理学现象：新起点效应（Fresh Start Effect）。



研究发现，人在一些有“新开始”意义的时间点，更容易重新行动。



比如周一每个月第一天、生日、新的一年。



为什么很多人总说明天开始、下周开始、下个月开始？



因为大脑会觉得，这是一个新的阶段。



既然今天是周一，那就别浪费这个机会。



不要想着把人生全部改变。

就改变一件小事。

这周少抱怨一点。

这周每天运动二十分钟。

这周每天早点睡半小时。



不用一次改变全部。



只要让这周，比上一周好一点。



很多人觉得命运是在某一天突然改变的。



其实更多时候，命运只是很多个普通的周一，累计出来的结果。



今天的任务很简单：



写下你这周最想坚持的一件小事。



然后连续做七天。
