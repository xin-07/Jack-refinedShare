# Jack要加油 365天思想实验 第103天

365天思想实验，第103天



今天讲一个物理概念：摩擦力



我们平时一说改变自己，总喜欢讲意志力

要自律一点，逼自己运动，少刷手机

实际上一个习惯能不能坚持，靠的不是意志力，而是摩擦力大小



什么意思？

你想每天运动20分钟

如果运动鞋在地下室，衣服没准备，健身房还要开车20分钟，那你每次开始之前，都要先克服一堆麻烦

这就是摩擦力



可如果你睡觉前把运动服放在床边，跑鞋放门口，第二天就能出去走20分钟，开始这件事就容易很多



反过来也一样

如果你想少刷手机，却每天睡觉都把手机放在枕头旁边，那你实际上是在把刷手机的摩擦力降到最低



所以不要天天跟自己较劲，而是要让想做的事情最低摩擦



不想做的事情就增加摩擦力



想存钱，就设置自动转账

想少吃零食，就别把零食买回来



现在不是每天要运动20分钟吗？



那咱们就试试，把明天运动的摩擦力降到最低

衣服准备好，时间定好，地点想好，如何？
