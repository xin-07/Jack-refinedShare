# Jack要加油 365天思想实验 第66天

8月7日，365天思想实验，第66天



今天咱们讲一个统计学概念，叫均值回归



我(Jack)直播提过就是当一件事情出现特别极端的结果以后，下一次往往更容易回到正常水平





不要因为一次成功，就觉得自己找到财富密码。



也不要因为一次失败，就觉得自己彻底不行。



真正值得关注的，不是一次结果，而是长期平均水平有没有提高。



如果你的平均能力不断提升，那么均值回归回去的，也是一个越来越高的均值。



今日思考：



你最近有没有因为一次特别好的结果而过度自信，或者因为一次特别差的结果而否定自己？真正应该改变的，是一次结果，还是自己的长期能力？
