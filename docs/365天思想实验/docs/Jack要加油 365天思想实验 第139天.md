# Jack要加油 365天思想实验 第139天

你以为自己在做选择，其实只是被习惯推着走



365天思想实验，第139天



今天讲一个心理学特别有意思的现象：默认效应



当人面对选择，如果已经有一个默认选项，就会直接接受它，而不是重新思考



比如你注册一个软件，系统默认勾选了自动续费，你可能根本没注意，就一直付钱



人生里也有很多这样的默认选项。早上醒来，默认先看手机。下班回家，默认躺在沙发上刷短视频。工资到账，默认先消费，月底剩多少再存多少。这些事情你可能从来没有认真决定过，但它们却每天都在发生



你根本没意识到自己还有别的选择！



如果你想改变生活，不一定要每天做很多艰难的决定。而是去重新设计自己的默认选项



比如工资到账，自动把一部分转进储蓄账户。想每天读书，就把书放在床，让拿起书比打开手机更方便。想运动，就把每天固定的20分钟提前安排好



你会发现，原来咬牙坚持的事情，开始变得很自然



今天请你挑一个每天的默认选项，重新设置它
