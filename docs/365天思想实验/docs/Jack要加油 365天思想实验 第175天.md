讲一个诺贝尔经济学奖得主提出的经典理论：柠檬市场



有一个二手车市场。有些车质量很好，有些车却很差。卖车的人知道自己的车怎么样，但买车的人不知道。于是买家担心被骗，只愿意按照一个比较低的平均价格买



那些真正拥有好车的人，觉得价格太低，不愿意卖了。结果市场上留下来的，反而是质量较差的车



买家更加不信任市场，价格进一步下降，好车更不愿意出现。最后，明明有好产品，却可能因为缺乏信任，被坏产品挤出了市场



这就是经济学里的信息不对称和逆向选择



那应该怎么做？很简单，不仅要努力变得优秀，还要让别人能够验证你的优秀。比如长期记录自己的作品，公开真实的成绩，兑现自己的承诺



今天想一想，你有什么真正的能力或者价值，却很难让陌生人相信？



能不能用一个具体的作品、记录或者一次实际行动，把它证明出来？



改命除了积累能力，还要有别人愿意相信你的理由
