# Jack要加油 365天思想实验 第130天

你只看见了他台上的两个小时，我看见了他背后的五十年



365天思想实验，第130天



大家知道，这几天我（Jack）跟一位真正做到顶尖的人（吕思清）在一起，一起开车吃饭彩排甚至换衣



舞台上的灯一亮，掌声响起来，大家看到的是从容、熟练，是一个人已经把事情做到极致的样子



但他说台上的两个小时，背后是五十多年的重复，四岁半至今没停过练习



同一把琴，不知道拉过多少遍。同一个动作，不知道纠正过多少次。一首曲子，台下练了几个月，最后观众可能只听十几分钟



我们都会羡慕别人今天拥有什么，却很少去看他昨天、前年，甚至二十年前每天在做什么



我知道很多年轻人焦虑。拍十条视频没人看，就开始怀疑自己



练三个月琴还弹不好，就觉得没天赋。工作两年没达到理想状态，就觉得自己选错了



可真正做到顶尖的人，很少是突然出现的。他们只是把一件事情，做到了足够久



今天我希望你思考：你现在做的这件事，愿不愿意做十年？
