365天思想实验，第134天



讲一个工程里的概念：信噪比



一个信号传过来，有用的信息叫“信号”，那些干扰它的东西叫“噪声”。噪声越大，你越难听清真正重要的内容



你们不觉得现在生活里噪声太多了吗，手机一打开，新闻、短视频、群消息、评论、热点、别人的观点，全在抢你的注意力。你一天可能看了几百条信息，晚上却想不起来真正学到了什么



未来真正稀缺的能力，是能不能从大量信息里，分辨出什么才是真正重要的信号



比如投资，股价每天在变，是噪声；公司的商业模式、利润、竞争力，才是重要的信号



做自媒体，某条视频突然没流量，不能说明你不行。要看连续几十条以后，什么内容观众更愿意看，什么表达真正有效



生活中别人今天一句评价，只是噪声。你过去三年的进步，才是有效信息



大家思考下，今天接受到这么多信息里，有哪几条是真正的消息，哪些是噪音
