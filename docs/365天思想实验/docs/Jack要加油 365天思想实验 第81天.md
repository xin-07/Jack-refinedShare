# Jack要加油 365天思想实验 第81天

8月22日，365天思想实验，第81天



我（Jack）昨天看我们小镇的报纸，看到一个心理学家出了本新书。他有一句话让我想了很久：**很多人一直在寻找自己身上的力量，却不知道，那些力量可能就藏在过去的痛苦里**



你仔细想想



小时候家里条件不好的人，长大以后特别知道钱意味着什么

小时候经常换环境的人，可能特别会适应陌生地方

被拒绝过很多次的人，后来越来越不怕别人说不

很早就要自己解决问题的人，长大以后比别人更自立



我不是说苦难是好东西

如果能不经历，当然最好不要经历



但问题是，有些事情已经发生

那我们能不能换一个角度



以前你回忆过去，可能总在想：那件事伤害了我



今天想想：为了熬过那件事，我到底训练出了什么？



可能是耐心

观察力或者抗压能力

有时候我们只看见了伤口，却没发现旁边已长出新的肌肉



今天任务：回看不堪的过去，找一件一直让你记忆的事情，并且写下这件事后来训练出了你的什么能力？
