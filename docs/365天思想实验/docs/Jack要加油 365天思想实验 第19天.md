# Jack要加油 365天思想实验 第19天

6月16日 365天思想实验，第19天

今天，请做一件“没有人看见，但对你有用”的事情。



比如读十页书，运动二十分钟，把房间整理一下，认真写一段复盘，学习一个你拖了很久的技能，做一件好事



重点：不要发朋友圈，不要告诉别人，不要期待夸奖。

就安安静静地完成它。



悄悄改变，让它发生在没人看见的时候。

很多人一努力，就想被认可



而我们要练的恰恰相反，就是感受没有反馈



如果你能在没有掌声、没有监督、没有奖励的时候，

依然愿意做正确的事，你的人生就已经开始不一样了



今天的人物很简单：

做一件没人看见，但对未来的自己有用的事情

不是演给别人看的

而是在没人看见的时候，依然不放弃自己
