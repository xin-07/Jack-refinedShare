# Jack要加油 365天思想实验 第165天

一招让你成为万人迷

365天思想实验，第165天

妻子对丈夫说你根本不在乎我

丈夫一听生气了：我不在乎你？我每天这么努力工作，不都是为了你吗？

妻子觉得丈夫根本不理解自己。丈夫又觉得，自己的付出被全盘否定了。于是两个人越吵越厉害

这时候，我们就需要用到这3步

第一，确认事实。最近几天，丈夫回家以后一直在忙工作，两个人很少交流

第二，拆解感受。妻子觉得孤独失落，希望得到更多陪伴

第三，判断解释。妻子认为，丈夫不愿意陪自己，是因为他已经不在乎自己了

前两件是真的，但第三件是推测

关系里最危险的事情，就是把推测 当成已经确定的事实

妻子可以换一种说法：最近几天你回家以后一直在工作，我们很少聊天，我有点失落。希望能用半小时，我们好好说说话。这样既表达了感受，也提出了具体需求❤️

下次大家遇到不开心的事，想想：究竟发生了什么？真正难过的是什么？我对对方的判断，有没有足够证据？
