今天讲一个森林管理里的做法——间伐

一片森林里，树不是越多越好

如果长得太密，大家都要阳光、要水分、要土壤里的养分

结果是每颗树都长不好



所以管理森林的时候，会主动去掉一部分长势不好、位置不合适或者过于拥挤的树

树少了以后，剩下的树反而能得到更多阳光、水分和空间，长得更好



这做法就叫间伐

我们生活中也喜欢不断往自己身上加东西

再学一个技能、认识一些人、做一个项目、再开一个账号或再给自己定几个目标



可你一天只有24小时，注意力、精力也是有限的

必须好好挑选要做的事情
