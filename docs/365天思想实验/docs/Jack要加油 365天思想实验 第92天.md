# Jack要加油 365天思想实验 第92天

9月2日，365天思想实验，第92天



昨天和孩子说起默认效应



我（Jack）她你的选择真的是你自己做的吗

她没法回答



很多时候，人并没有认真做选择，而是会顺着那个默认选项一直走下去。



比如晚上回到家，你想读会儿书，结果往沙发上一坐，手机一拿起来，短视频刷完一条，自动下一条



等你反应过来的时候，一个小时没了



晚上要刷一个小时短视频 这个决定是你做的吗



你只是顺着默认状态走下去了



人生里特别多事情都是这样的

回家默认打开手机

发工资默认先消费

周末默认睡到中午

遇到问题默认先抱怨



以为自己每天都在做决定，其实很多时候，只是重复昨天



你想改变吗？

那就早上起来，默认先读十分钟

工资一到账，默认先存一部分

到了健身时间，不再问今天想不想去，换衣服直接出门

时间长了以后，这些好习惯变成了默认选项



今天任务：给自己重新设置一个默认选项，先做一星期，每天发视频
