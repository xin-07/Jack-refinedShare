# Jack要加油 365天思想实验 第67天

8月8日，365天思想实验，第67天



今天讲一个化学里的概念，化学平衡



很多化学反应进行到一定程度以后，并不是完全停下来了



正向反应还在发生，逆向反应也在发生，只不过两边速度差不多，所以比看起来好像没有变化



我们生活也是如此



你最近明明在读书也在运动，也开始存钱了，为什么感觉自己还是老样子



因为你一边在进步，另一边可能也在消耗

今天读了半小时书，晚上刷三个小时手机

今天运动了一小时，晚上又熬夜到两点

这个月努力存了两千块，转头冲动消费有花掉两千。



最后一看：Jack，我这么努力，怎么一点变化都没有？



不是努力没用



是你前面往前走两步，有往后了两步



所以有时候，想让人生变好，不一定是再给自己增加十个好习惯



反而是先找到那个一直把你往回拉的东西



今天想想：我现在最努力改变的一件事，是什么东西一直耗自己
