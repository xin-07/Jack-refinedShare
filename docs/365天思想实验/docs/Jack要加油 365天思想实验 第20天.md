# Jack要加油 365天思想实验 第20天

6月17日

365天思想实验，第20天。



今天请把一个很大的目标，拆成一个最小动作。



比如你想减肥，今天就先走二十分钟

你想存钱，今天就先记一笔账

你想读书，今天就先读五页

你想提升自媒体，今天就先写一个选题

你想提升表达，今天就先录一分钟(赶紧准备起来，七月份正式开始六年之约激励计划啦🎊)



很多人不是没有目标。

而是目标太大，大到自己根本不敢开始

一想到改变命运，就觉得太难

一想到要坚持几年，就觉得太累

一想到别人已经走了很远，就干脆放弃



真正厉害的人不是每天都做惊天动地的大事

而是每天都能把一件正确的小事做下去



人生不是突然变好的，是从一个小动作开始，慢慢变得有秩序、有方向、有力量



今天的任务很简单：把你现在最想改变的一件事，拆成一个今天就能完成的小动作然后立刻去做



不要等状态

不要等机会

不要等准备好
