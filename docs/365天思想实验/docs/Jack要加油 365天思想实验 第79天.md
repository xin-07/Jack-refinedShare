8月20日，365天思想实验，第79天



今天忍不住了 在ai时代聊电



你回家按，灯亮了

插上充电器，有电了



很正常吗？

仔细想想，特别神奇



发电厂离你家几百公里，电被生产出来，通过输电线路、变电站，一路把电压升高、降低，最后送到你家



电很难像矿泉水一样，先大量生产出来放仓库里慢慢卖

电网必须保持一个平衡：用多少，供多少



你家晚上突然开空调，工厂开始生产，城市里几百万人一起打开电器，整个系统都要跟着调整



所以电网要让无数发电厂、线路、变电站和用户，在同一个系统里不断配合



我们何尝不是？

你总想着多赚钱多学习多接项目多做事情



但你的电网能不能扛得住？

你的时间精力够不够？

身体能不能恢复？

如果所有事情一起开，你是不是马上就跳闸了？



想成功必须要会分配自己的能量



什么时候该全力工作 VS 什么时候该休息



今日任务：想想你现在生活里，有没有一个特别耗你电的东西
