# Jack要加油 365天思想实验 第171天

吃完药病好了，能证明药有效？



365天思想实验，第171天



我（Jack）想带大家了解一个很喜欢的科学方法：随机双盲对照实验



假设一个人感冒，第一天很难受，第二天开始吃一种新药，第四天明显好转，他非常激动：这个药太有效了！



但如果他什么药都不吃，第四天会不会也开始好转？



完全可能，所以科学家设计了一套方法。找来一批符合条件的患者，随机分成两组。一组接受新药，另一组接受安慰剂对照治疗



在双盲设计中，患者不知道自己接受的是哪一种治疗，评估疗愈的研究人员也不知道



因为人的心理预期，甚至研究人员的主观判断，都影响实验结果。科学家想知道的并非是吃药以后有没有好转，而是相比没有接受这种药的人究竟多好了多少



所以背后的启发是：不要把先后发生的两件事情，轻易理解成因果关系



今天大家找一件坚信有效的方法。然后问自己，如果不用这个方法，结果会怎样？有其他原因可以解释结果吗？如何更有信心地证明他真的有效？
