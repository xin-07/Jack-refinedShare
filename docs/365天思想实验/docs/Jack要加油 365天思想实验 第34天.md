# Jack要加油 365天思想实验 第34天

7月2日，365天思想实验，第34天。



昨天，我(Jack)鼓励大家勇敢发出第一条视频。

今天，我想请大家做第一件事：不要急着看有没有播放量？有没有点赞？有没有评论？有没有人关注我？



数据不好，就开始沮丧😦



刚开始做自媒体，最重要的不是数据，而是你有没有从每一次发布里学到东西。



今天的任务很简单：

如果你昨天发了视频，请认真复盘三个问题：



第一，我这条视频讲清楚了吗？

第二，我哪里可以表达得更自然一点？

第三，下一条视频我能不能比这一条进步一点？



专属会员可以继续在评论区打卡：



“我今天发了第几条视频，花了多久拍摄，多久剪辑，复盘发现了上面。”



这不是普通留言。



这是你在给自己建立成长档案，哪怕不发现视频的粉丝，做任何事情都是这样三步走🎉
