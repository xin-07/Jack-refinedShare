# Jack要加油 365天思想实验 第61天

8月2日，365天思想实验，第61天



今天讲一个数学概念：不要追求100%，而要追求提高概率



Jack发现很多人做事情，一开始就在问：这个能保证成功吗？

万一失败了这么办



其实，这个世界几乎没有100%的事情



投资没有、创业没有、做自媒体没有、找工作没有



甚至谈恋爱、教育孩子，都没有



我从来不想：我一定要成功



而是：我怎么把成功的概率，从30%提高到40%，再提高到60%



多读一本书，成功概率高一点

多认识一个优秀的人，成功概率高一点

多复盘一次，成功概率高一点

多坚持一个月，成功概率高一点



我为什么一直让大家学习、行动、存钱、锻炼？

因为这些事情，不一定马上让你成功



但是它们都会默默提高你成功的概率



今天的任务很简单：想一件你特别想完成的事，不要问：我一定能成功吗？



而是问：今天我做什么，能让成功的概率提高1%！
