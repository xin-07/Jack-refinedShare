如何能发现机会

365天思想实验，第150天：探索与利用

假设你搬到一个新城市，附近有20家餐厅。第一天，你随便选了一家，发现味道不错。第二天，你是继续去这家，还是尝试一家新的？

继续去，至少知道不会太差。尝试新的，可能踩雷，但也可能发现一家更好吃的。这就是探索与利用之间的选择

探索，是尝试未知的事情，获得新的信息。利用，是把已经知道有效的方法继续用下去

比如你找到一份收入不错的工作，要不要学习一个完全陌生的领域？你做自媒体，发现某种内容很受欢迎，要不要拿出时间尝试新的方向？你已经有几个熟悉的朋友，还愿不愿意主动认识不同领域的人？

如果永远只做已经证明有效的事情，你会越来越熟练，但也可能错过更大的机会

今天大家回顾最近一个月，做的事情有多少是在重复熟悉的生活，又有多少是在接触未知？

然后给自己安排一次小探索，可以读一本从来没接触过的书，研究一个陌生行业，或者和不同领域人聊聊
