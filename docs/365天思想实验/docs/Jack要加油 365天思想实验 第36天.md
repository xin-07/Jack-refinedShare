# Jack要加油 365天思想实验 第36天

7月4日，365天思想实验，第36天。



今天周末大家做一件事：好好休息一次



但不是躺在床上刷几个小时短视频那种休息



那种不叫休息，那叫把脑子刷废！真正的休息，应该是让你回复能量。



出去走走，晒晒太阳，和家人吃顿饭，睡个好觉，安静看几页书，或者什么都不干，就让自己发会儿呆。



很多人平时已经够累了。



工作累，学习类，带孩子累，赚钱累焦虑也累。好不容易到了周末，结果又用垃圾信息、熬夜、乱刷手机继续消耗自己。



最后休息了一天，比上班还累。



我(Jack)以前也这样，明明想放松一下，结果手机一刷几个小时，放下以后心里更空，脑子更乱，还觉得自己又浪费了一天。



所以今天别这样。



今天给自己一次真正的休息，用一种不消耗自己的方式休息一次。



白天都把正事干了，晚上我推荐个好电影🤫
