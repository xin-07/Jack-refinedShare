# Jack要加油 365天思想实验 第102天

不知不觉，365天思想实验已经来到第102天了



正如我（Jack）昨晚直播里说的，从今天开始，把学的落实到行动中

每周我设计一个行为实验，而且准备做一年。做得好就做六年



六年之约太长，我们就把它拆开。一年52周，一周只改变一件小事



今天的实验非常简单：连续7天，每天运动20分钟，9月11-17号



跑步、快走、力量训练、跳绳、游泳都可以，做什么不重要，重要的是每天拿出20分钟去做



如果你也想顺便开始做自媒体，这七天就是素材



前六天，不比拍的复杂，就记录当天真实的过程一个真实的自己，是怎么慢慢发生变化的



第七天，单独做总结：最开始是什么感觉？

哪一天想放弃？身体和情绪变化？从一开始的排斥，到后来有没有喜欢上？七天结束，还愿不愿意继续？为什么？



我想通过七天，让你观察自己，了解自己，然后看看一个小小的行动，能不能真的进入自己生活改变人生



相信我，这不是心灵鸡汤，而是我曾经摸索路上的光
