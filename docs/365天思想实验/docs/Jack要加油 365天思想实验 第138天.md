# Jack要加油 365天思想实验 第138天

你现在最舒服的选择，正是困住你未来十年的根源

365天思想实验，第138天

今天讲一个计算机里的概念：局部最优和全局最优

假设你在爬山，目标是找最高的山峰。但你只能看到周围。于是你每次往更高的地方走，最后走到了一个山顶。你以为成功了。可如能往天上往下看就会发现，旁边还有一座更高的山

但想爬到那座山，你得先下山。也就是说，有时候想去更高的地方，反而需要先往低处走一段

人生也会遇到这情况。比如工作，工资不错，很稳定，但每天都重复同样的事情。如你只考虑明年的收入，留下来是最好的选择

但考虑未来十年，学习新技能，甚至接受更低的收入
反而可打开更大的空间

我不是鼓励大家辞职。是希望你明白眼前最好的选择，不一定是长期最好

勇敢不是一直往上爬，而是能为了更远的目标，往下走几步

今天找一件你现在做的很舒服、很熟练的事情。然后问自己：我是真的找到了最好的方向，还是只是不愿意离开现在这个山顶？
