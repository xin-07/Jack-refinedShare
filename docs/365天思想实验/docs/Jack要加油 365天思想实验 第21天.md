# Jack要加油 365天思想实验 第21天

6月18日

365天思想实验，第21天



今天，请记录一次自己的情绪变化

不是压抑情绪，也不是批评自己



而是认真观察自己：我为什么突然不开心？我为什么刚才会发火

我为什么听到那句话会难受？我为什么看到别人成功，心里会不舒服？



情绪的背后往往藏着一个人的真实需求



你生气，可能是因为你觉得自己没被尊重

你焦虑，可能是因为你对未来没有掌控。

你嫉妒，可能是因为别人拥有了你也想要的东西

你难过，可能是因为你一直在委屈自己



如果一个人从来不观察自己的情绪，他就会一直被情绪牵着走

别人一句话，就能毁掉他一天

一个小挫折，就能让他怀疑人生



担当你开始看懂自己的情绪，你就慢慢有了掌控感



今天的任务很简单：当你情绪波动的时候，不要立刻反应

先停下来，问自己一句：我现在到底在难受什么



能看懂自己的人，才有机会真正改变自己

命运的改变，很多时候就是从不再被情绪控制开始的
