365天思想实验，第125天



今天讲个概念：限制反应物



化学反应需要几种原料一起参与。如果其中一种原料先用完了，哪怕其他原料还有很多，反应也只能停下来



真正决定最后能生成多少东西的，不是你拥有很多的那个，而是最先不够用的那个



你想把事业做好，可能不是缺时间，而是表达能力不够。你想做自媒体，可能每天都很努力，但真正卡住你的，是不会选题



你想健身，训练已经很多了，但如果长期睡不好，身体恢复跟不上，再加训练量也未必有用。甚至赚钱也是



有人一直想着再多学一个技能，但真正限制他的，可能是从来不敢把自己的能力拿出去卖



这时候最容易犯的错误，就是继续往已经很多的地方加东西。已经每天工作十个小时了，还想着再多工作两个小时，但真正那个限制你结果的东西，一直没有解决



今天的任务找一件你最想推进的事情找一个限制反应



然后这周，就解决它！
