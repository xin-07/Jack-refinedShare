# Jack要加油 365天思想实验 第89天

8月30日，365天思想实验，第89天



今看到周边有竹，想到百年前王阳明格物

我（Jack）也愣那，竹子看起来那么细，遇到大风，却很难折断



我觉得是它会弯



风大的时候，它不会跟风硬顶

会顺着风弯下去

等风过去，再慢慢回来



这不就是人生吗

我们小时候觉得，真正强大的人应该是什么样？

永远坚定、正确？

遇到什么事情都不低头？



后来发现，真正智慧的人才能走很远

区别就是韧性



计划变了会调整

工作出了问题会换方法

投资判断错了会重新判断

以前相信的东西发现不对也敢承认



很多人说这是机会主义或是精致利己

但我认为这恰恰是一种很强的能力

因为这个世界一直在变

如果一个人什么都不愿意改，最后可能不是世界被他说服，而是自己先被折断



当然，能弯不代表没有原则

竹子弯的是身体，根还在土里



根就是你的底线，你珍惜的人，还有你想成为什么样的人



今天的任务：记住风来的时候要弯得下，风过去以后，依然能够站起来
