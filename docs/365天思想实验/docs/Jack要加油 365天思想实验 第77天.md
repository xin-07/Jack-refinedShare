# Jack要加油 365天思想实验 第77天

8月18日，365天思想实验，第77天



今天讲个刺激的：排污系统



你每天洗澡、上厕所、洗衣服，水一冲，东西就消失

其实根本没消失

它只是被系统接走了



地下有大量我们平时根本看不见的管道，把污水送到处理厂，经过沉淀、过滤、处理，最后才能重新排出去



好好想想，你生活里有没有这样一套刺激的系统？

我们每天都在往脑子里装东西



新闻、短视频、工作、赚钱、家庭、别人评价，各种乱七八糟的信息



但很多人只有输入系统，没有排污系统

烦心事一直憋着

没用的信息一直留着

不好的情绪反复想

最后脑子越来越乱



我（Jack）自己的排污系统在十几岁时就有意识建立了

运动一次

出去走走

写几句话

找人聊聊

把房间整理一下

甚至只是安静坐十分钟，把最近烦你的事情想清楚



这些看起来没创造什么价值，其实特别重要！



今天任务：清理一样最近一直在消耗你的东西
