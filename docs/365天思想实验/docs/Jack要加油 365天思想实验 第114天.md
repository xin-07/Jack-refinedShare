# Jack要加油 365天思想实验 第114天

改变命运的五种底层能力



365天思想实验，第114天



第一，先学会做选择

很多时候拉开差距的，不是你做得多努力，而是方向有没有选对。别只看眼前结果，多想一想：这件事如果做三年，会把我带到哪里？



第二，学会独立思考

不要别人说什么就信什么。遇到问题多想：真正原因是什么？如果把表面东西拿掉，核心是什么？



第三，注意力

未来最稀缺的不是信息，而是。专注。谁能在手机、短视频、消息打扰世界里，不断做正事，谁就更有优势



第四，理解金钱

会赚钱当然重要，但更重要的是知道该怎么留、怎么花、怎么让自己慢慢拥有选择权



第五，慎重选择身边的人

朋友、伴侣、合作伙伴，都会一点点改变你。和什么样的人长期待在一起，你很可能就会慢慢变成什么样的人



专属会员要建立的，就是这些不会过时的能力。每天学一点、想一点、输出一点，时间久了，你会发现改变的不只是知识，而是你对待困难、选择和过生活的方式
