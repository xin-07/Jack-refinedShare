# Jack要加油 365天思想实验 第136天

一场大火烧掉了你家的店，千万别让它再烧掉你们一家未来十年的生活

365天思想实验，第136天

昨天看到一位关注我（Jack）两年的粉丝留言。他说家里的店被一场大火烧掉成了废墟，父亲半辈子的心血没了，周围20家商铺也全部烧毁。他年纪还小，看着父母难过，却不知道能做什么

我想用二阶思维回答你。第一阶思维，是看眼前的损失。店没了，货没了，几十年的积蓄可能也没了

但第二阶思维，是继续往后想：这场火已经发生了，接下来怎么做，才能不让损失继续扩大？

照顾好父母的身体和情绪。尤其是你的父亲，千万别让他觉得自己半辈子白干了，先别急着借钱重开。保存证据，了解保险、赔偿和救助渠道，和其他受灾商户一起商量后续怎么办

最后也是我最想告诉你的，父亲失去的是店铺，他的经验、人脉、判断力，这些东西大火烧不掉

你虽年轻，也可以帮父母整理资料、联系人员、分担事情。我不希望你因为这被迫长大，但希望你能成为父母的依靠❤️
