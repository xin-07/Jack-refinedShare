365天思想实验，第164天

有没有发现想认真做一件事情，越来越难？刚读书，手机响了，刚开始工作，又想看看有没有新信息。本来只是打开手机查个事，结果半个小时过去了，自己都忘了最初想查什么

大脑在不同任务之间切换，是有成本的。比如你正在认真思考，突然回复一条消息。虽然只花了3秒，但重新回来时需要很长时间才能找回刚才的思路。真正浪费我们时间的，不是刷手机的那几分钟，还有一次次被打断以后，重新进入状态的成本

那怎么提高专注力？大家可从四件小事开始

一，减少干扰，而不是考验意志力，学习的时候，把手机放在另一个房间

二，每次只做一件事，读书就认真读书，工作就认真工作。突然想别的任务，先写下来，不要立刻切换

三，循序渐进的训练如果你现在只能专注5分钟，就先5分钟开始。慢慢增加到10分钟

四，保证睡眠和休息，不足就会导致注意力
