# Jack要加油 365天思想实验 第64天

8月5日，365天思想实验，第64天



今天讲一个数学概念：大数定律



听来复杂，其实简单

就是一件事情，次数越多，结果越接近它真正的概率



举个简单的例子

抛一次硬币



抛10次，可能7次正面、3次反面

很多人就觉得这枚硬币是不是有问题

但如果抛1000次、10000次，它一定会越来越接近50%



人生也如此



很多人做一件事情，失败一次，就觉得自己不合适



投资亏一次，就觉得投资没用

发几条视频没人看，就觉得自媒体不行

跑步一个星期没瘦，就觉得运动没效果



其实，不是你没用，而是你的样本太少了



智慧的人不会因为一次结果就下结论



他们会不断增加样本不断复盘不断调整



直到真正看见这件事情的规律



今天的任务很简单：想一件你因为失败一两次，就准备放弃的事情。



然后问自己一句：是这件事真的不行，还是我的样本太少了？



很多时候，你以为自己输了



其实只是比赛，才刚刚开始🤫
