# Jack要加油 365天思想实验 第23天

6月20日365天思想实验，第23天。



今天，不要去刻意解释



不是让你冷漠，也不是让你逃避沟通。当你发现对方根本不想理解你，只是想反驳你、消耗你、证明你错的时候，学会停下来。



很多人每天浪费大量能量，不是在做事，而是在解释自己，解释自己为什么这么想，解释自己为什么这么做，解释自己没有恶意，解释自己其实已经很努力了。



你慢慢会发现，有些人不是听不懂而是不想懂。你越解释，他越抓细节。你越着急，他越消耗你😭



最后真正该做的事情没做，情绪却被别人带走了🤣



一个人成熟的重要标志，就是知道什么值得沟通，什么不值得纠缠。真正理解你的人，不需要你反复证明。不想理解你的人，你说再多也没用。



今天的任务很简单：遇到一次没必要的争论时，停下来。不解释。不争辩。不证明。把时间和能量收回来，去做一件真正对自己有用的事。
