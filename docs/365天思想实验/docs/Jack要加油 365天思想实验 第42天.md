7月10日，365天思想实验，第42天。



今天搞个生物学概念：大脑可塑性



就是人的大脑不是固定不变的，你反复做一件事，大脑里的连接就会越来越强。



比如你反复抱怨，大脑就会越来越喜欢抱怨，你反复拖延，大脑就会越来越习惯逃避。



但反过来也一样。你反复运动，大脑会慢慢接受运动。你反复读书，大脑会慢慢适应思考。你反复表达，大脑会慢慢习惯输出，你反复存钱，大脑会慢慢享受掌控感。



很多所谓的“我是这样的人”，其实只是你过去重复太多次以后，大脑形成的旧思路



但旧路线可以被改写，只要你愿意一次又一次走新的路。

你每重复一次新的行为，大脑就在重新布线。



所谓改变人生，很多时候不是突然换一个人生，而是先把自己训练成一个不一样的人。
