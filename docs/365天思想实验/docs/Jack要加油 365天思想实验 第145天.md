# Jack要加油 365天思想实验 第145天

为什么越努力，结果越差——365天思想实验，第145天

今天讲正反馈和负反馈。正和负，不代表好坏，而是两种不同的作用

正反馈，是一个变化发生后，系统会进一步放大这个变化
负反馈，则是系统会抵消一部分变化，让事情保持相对稳定

比如空调。室温高了，空调开始制冷；温度降到了设定值，空调就停止工作，这就是负反馈

但生活中恰恰相反。比如你最近很焦虑，晚上睡不着。第二天精神不好，工作效率下降，事情越积越多。你就越焦虑，晚上更睡不着。这就是不断自我加强的正反馈

那怎么打破它？

很多人第一反应，是更加努力工作，赶紧把事情做完。但这样可能进一步压缩睡眠，让整个循环越来越严重。有效的方法，是先保证睡眠，减少任务，恢复精力

所以当一件事越来越不好的时候，不要只盯眼前，要看看背后有没有一个不断放大的循环

今天大家找一个烦恼的事情想什么引发了它？我的反应有没有让它更严重？能在哪个环节打断这个循环？
