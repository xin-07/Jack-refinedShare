365天思想实验，第117天



为什么这么说？因为很多人一直在等



等我有钱了，我就开始理财

等我瘦了，我就开始喜欢运动

等我粉丝多了，我再认真做内容

等我成功了，我自然就自信了



可如果你一直等结果出现以后，才准备改变自己，那这个结果可能永远不会来



人生真正有效顺序应该反过来：先成为，再去做，最后才拥有



你想拥有一个好身体，就先把自己当成一个重视健康的人

然后想这种人今天会做什么？他可能会运动20分钟，会注意饮食，会早点睡



你想成为一个会管理的人，也不要等有钱以后再学。从今天开始记录支出、控制消费、存钱、学习投资



你想成为优秀的内容创作者，也不要等流量来了才认真。先像一个优秀创作者那样，每天观察、思考、记录、输出



因为一个人的身份，会慢慢决定他的行为，行为重复得足够久，又会一点一点改变结果



㊙️成为你想成为的人，做他会做的事，你才有可能拥有他拥有的
