# Jack要加油 365天思想实验 第132天

成长不是靠多做一点，而是让同一件事越做越便宜



365天思想实验，第132天



今天讲一个经济学和工程里都很重要的概念：学习曲线



很多事情第一次做，特别慢。第一次剪视频，可能两个小时。第一次直播，不知道说什么。第一次做表格、写方案、跑一个流程，到处都要查



可当你做第二次、第五次、第五十次以后，同样一件事，时间会越来越短，错误越来越少



因为你不是简单的重复。你会开始留下模板，经验，方法，甚至形成自己的判断



所以年轻的时候不要太害怕重复，真正可怕的不是重复，而是每一次都从零开始。



你拍了100条视频以后，应该比第1条更知道观众想听什么。你工作五年以后，应该有一些事情别人要两个小时，你半小时就能完成



你读了很多书以后，再遇到一个新问题，也应该更容易把它放进以前的知识体系里



今天的任务是找一些你经常做的事情，想办法让下一次，比这一次快1%，然后每一次都要比上一次做的更好一点
