# Jack要加油 365天思想实验 第47天

7月17日，365天思想实验，第47天



分享最喜欢的经济学概念：边际效应递减



什么意思？😝

就是同样的东西，第一次得到的时候最快乐。第二次，还不错，第三次，感觉就没那么强了



比如你特别饿的时候，第一口饭特别香。第二口也很好吃。但吃到最后，再好吃的东西，你也不想吃了。



你是否觉得：等我有一百万就幸福了。等我买了房就幸福了。等我买了新车就幸福了



可真正拥有以后，你会发现快乐会慢慢变成习惯。



然后又开始追求下一个目标。



所以，一个人如果把幸福全部建立在“拥有更多”上，就很容易一直觉得不满足。



人生要幸福＝不断创造+懂得珍惜



会赚钱很重要，会感受已经拥有的东西，同样重要。



今天的任务：写下三件你已经拥有，但以前特别想得到的东西。



可能是家人、身材、收入、一段感情、也可能只是今天能安安静静吃一顿饭



很多时候，不是生活不幸福。而是你太快习惯了🤫
