今天讲个社会心理学里很有意思的现象：信息瀑布效应



一条街上有两个餐厅，味道差不多，门口都没人。第一个顾客随便走进左边那家，第二顾客看见有人进去了，也就跟着进去了。

第三个顾客来到这里，发现左边已经有两个，心想这家肯定更好，慢慢的越来越多人选择左边



最后，左边排起长队，右边却一个人都没有



最初可能只是一个随机选择，后来的人却把前面人的行为，当成了判断依据。这就是信息瀑布



网上突然流传一个消息，第一个人转发，第二个人评论，第三个人看到这么多人评论，就觉得肯定是真的，最后几十万都相信了，却没人认真查过最初的消息从哪里来



所有人都朝一个方向走的时候，你愿意停下来，想一想为什么吗？



今天找一个大家都在讨论、你也相信的观点。思考三点1.最初的信息来自哪里？2.有没有独立证据支持？3.如果没有人告诉我别人的选择，我会得出同样的结论吗？





**不要因为自己提出了一个看起来合理的解决方案，就认为问题已经被解决。要让实际结果来检验方案。**



一个人遇到问题时，通常有三个层次：



第一层 · 处理结果

**事情发生了，我赶紧把它解决。**

例如：上错菜了，赶紧重新上菜。

第二层 · 分析原因

**为什么会发生？究竟哪个环节出了问题？**

例如：为什么服务员总是看错桌号？

第三层 · 改变系统

**怎样改变流程，让同样的问题更难发生？**

例如：优化点餐系统，增加核对流程。



**真正的进步，不只是让自己越来越擅长处理问题，还应该让自己所在的系统越来越不容易产生问题。**
