# Jack要加油 365天思想实验 第95天

9月5日，365天思想实验，第95天



昨天和孩子谈起学习方法，我(Jack)都是就说了几点，晚上我觉得可以写篇分享给大家



我总结了三点最重要的方法



第一，带着疑问来学习



大家学习往往这个学一点，那个收藏一下，总觉得以后可能用得上，但时间和注意力都有限

所以最高效的方法是遇到要处理的问题，才去学习



比如我要投资赚钱，那就要研究公司，那就去学它的商业模式、行业格局、财务报表



不要为了学习而学习，要为了真正处理问题而学习



第二，学完马上说

你看懂了，和你真的懂了，是两回事

最好的检验方式，就是你能不能把它讲给小白听

像我直播不爱说复杂的东西，都是最简单易懂，这就是我从高二开始训练的能力



说不是学习结束以后做的事情，说本事就是学习



第三，说完马上做

这一点很多人做不到

学了一个道理，觉得特别有启发，然后就没有然后了。过了一个星期，基本忘光



学了谈判，就去谈一次

学历表达，马上录视频



做几十次，知识就成了你的直觉，需要它的时候自然会出来
