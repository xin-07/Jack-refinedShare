# Jack要加油 365天思想实验 第163天

一件小事如何毁掉你一整天

365天思想实验，第163天

周日讲一个很有意思的法则，也就是10/90法则。生活中发生的事情只占10%，另外90%取决于我们如何回应

假设早上出门前，孩子不小心打翻了一杯牛奶，弄脏了你的衣服。你特别生气，责怪孩子。孩子哭了，你又和妻子吵了起来。因为耽误事件，出门遇到堵车，你更烦躁，最后一整天心情不好

但如果换一种反应呢？牛奶打翻了，你换件衣服，收拾干净，提醒孩子下次小心一点，五分钟后继续出门。同样一杯牛奶，为什么会产生完全不同的结果？

因为第一次意外已经发生了，但后面那些不必要的损失，是我们的反应造成的

投资也是一样。本来是正常现象，但你因为恐慌，不断做出没有计划的决定，反而造成更大的损失

智慧是有能力不让一件坏事，变成十件坏事！

下次生气时思考下：这件事我能改变什么？我现在的反应是在解决，还是制造新痛苦？一年以后，我还会如此在意吗？
