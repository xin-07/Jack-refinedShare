# Jack要加油 365天思想实验 第48天

7月18日，365天思想实验，第48天



今天玩个生物学规律：用进废退💣



简单理解，一个能力越用，越容易得到强化；长期不用，就会慢慢退化🌊



肌肉大脑都是这样。



很久不读书，专注力会下降。很久不表达，开口时就会越来越紧张。很久不做决定，就会越来越依赖别人。



甚至勇气也是这样😎



你每逃避一次，下次就更容易逃避。你没主动一次，下次就会更敢一点。



你们总说：我没有表达能力，我不擅长社交，我天生不自律，甚至我是sb😂



但很多能力不是天生有没有，而是你有没有长期使用。你不需要等自己厉害了才去做。恰恰是因为不断去做，你才会慢慢变厉害。



今天的任务很简单：选择一个你正在退化、但又希望拥有的能力，认真使用一次。



想提高表达，就录一分钟自己的想法

想恢复专注，就安静读十页

想变得勇敢就完成一件一直不敢做的小事

想拥有好身体，就运动二十分钟



你长期使用什么，最后就会成为什么样的人🦌
