365天思想实验，第142天

讲一个我特喜欢的概念：全生命周期成本

假设你买车。一辆车卖两万，另一辆卖三万。第一辆更便宜，对吧？

但如果第一辆车油耗很高，修起来很贵，五年下来多花了一万五，那到底哪辆更便宜？

这就是全生命周期成本

成本不只你今天付多少钱，而是从开始使用到最后结束，一共付出了多少

这个道理更适合用来做人生选择

比如你为了省钱，租了套离公司特别远的房子。每个月少付了500房租，看起来一年省了6000。但如果每天上下班多花两个小时，一年工作250天，就是500个小时

这些时间如果用来学习、陪伴家人，甚至只是好好休息，值多少钱？当然，每个人对时间的估值不同，但至少你应该把这些成本算进去

今天想想，你最近准备花钱或者花时间的东西，五年内还会为这个决定付出什么

当你开始计算长期成本，你做出的选择就会完全不同
