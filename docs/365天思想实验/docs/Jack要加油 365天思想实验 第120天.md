# Jack要加油 365天思想实验 第120天

能坚持很多年的人都是状态最差的时候，也有一个最低标准



365天思想实验，第120天



很多人坚持不下去是给自己的标准太高了



规定每天运动一小时，读50页书，必须拍一条视频

状态好的时候当然没问题



但我不可能365天状态都好，你会生病，会忙，会心情不好，也会有一天什么都不想干



很多人一旦今天没有完成一小时运动，就觉得算了，今天已经失败了然后彻底不做



我觉得好习惯，有两个标准。一个叫正常标准。一个叫最低标准



正常情况下运动一小时。特别累的时候，走20分钟也算



正常读30页。今天实在太忙，就读5页



平时认真拍一条视频。今天没状态，至少记下一个选题



这样做最大的好处是：你允许自己做的少，但不允许自己断掉，一个习惯最怕的，不是偶尔做的差。洱海停下来以后，再也没回来



所以以后状态不好的时候想一下，今天最少还能做到多少？



哪怕只有10分，也把这10分钟做掉！
