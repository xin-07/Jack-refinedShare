# Jack要加油 365天思想实验 第137天

有没有一个同样的错误，你犯了很多年的



365天思想实验，第137天



讲一个工程学的概念：容错机制



飞机、服务器、工厂里的很多系统，设计的时候就会考虑如果某个地方出错了，怎么办？



必须要保证出错以后，能够及时发现、减少损失，并且避免同样的问题反复发生



很多人犯错以后，第一反应就是后悔。投资亏了，骂自己太贪心

考试没考好，觉得自己不够聪明。工作出了问题，难过好几天。但后悔本身，让下一次的结果变好了吗？



有一种超能力就是每次犯错，你都能从错误里留下一个新的规则



比如投资亏钱了，想明白以后每次投入多少，最坏情况能不能承受



考试没考好，找到究竟是哪个知识点没掌握，而不是单纯增加学习时间



工作忘了一件重要的事，那就建立一个提醒系统，而不是发誓下次一定记住



错误如果只留下情绪，它就是损失。但留下了方法，它就能变成经验



今天想想有什么事，如果重新发生，你能提前设置规则，避免再次犯错！
