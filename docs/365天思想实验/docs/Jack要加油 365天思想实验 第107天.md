# Jack要加油 365天思想实验 第107天

365天思想实验，第107天



我（Jack）想聊聊大家是用什么心态开始一周的？

很多人醒来的第一反应就是又要上班了



然后开始盼星期五

如果一年有五十多个星期，而你每个星期都拿前四五天去等待周末，那你其实是在等待自己大部分的人生赶紧过去



一周最好的开始就是给自己一点期待



早上，可以先思考下

这周我最想完成的一件事是什么？

这周五最期待的一件事是什么？

到了星期天晚上，我希望自己因为哪件事觉得这周没白过？



可能是完成一个项目、读完一本书、去运动三次、或是约一个很久没见的人吃饭



甚至只是星期三晚上，给自己留两个小时做一件喜欢的事情



人有期待的时候，一周的感觉会完全不一样



你不再只是完成老板交给你的任务，也有一些事情是属于你自己的



过得很累，是因为脑子里同时挂着十几件没有开始的事



所有今天任务：开始做最重要的几件事，相信我，做着做着整个人都会轻松很多，跟着我一起深呼吸🧘一分钟
