# Jack要加油 365天思想实验 第97天

9月7日 365天思想实验，第97天



我先问大家一道特别简单的题



一个池塘里有一种荷叶，每天面积都会翻一倍



如果第99天的时候，荷叶刚好覆盖了半个池塘



请问，什么时候整个池塘会被铺满？





















很多人第一反应可能会觉得，还要很久。

答案其实是第100天

因为第99天已经是一半了，再翻一倍，第二天就是整个池塘

那我再往前问



第98天是多少？

只有四分之一



第97天呢？

八分之一



在最后几天到来之前，它看起来一直都没有那么夸张

这就是指数增长最容易欺骗我们的地方

它前面很慢，慢到你会怀疑这件事情到底有没有用



读了十本书，好像没变聪明

拍了五十条视频，还是没人认识你

学了一年英语，还是说得磕磕绊绊

存了一段时间的钱，账户里的数字看起来也没有多大变化



很多人就是在这个阶段放弃



今天任务：找一件最近想放弃但是你觉得方向对的事情，再想想你愿不愿意再给它100天？
