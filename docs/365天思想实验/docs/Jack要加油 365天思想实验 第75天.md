# Jack要加油 365天思想实验 第75天

8月16日，365天思想实验，第75天



今天讲一个生物学概念，稳态



什么意思呢？

人的身体其实每天都在做一件事，就是想办法把自己拉回一个相对稳定的状态



你热了会出汗，冷了会发抖，缺水了会口渴

身体不是要求自己永远保持完美，而是偏离以后，知道怎么回来



我觉得这个东西放在人生里特别有意思



很多人对自己的要求是：我要每天自律

每天运动读书情绪稳定不能浪费时间

结果有一天没做到，就觉得完了



计划全毁了

然后干脆连续摆烂一个星期

其实拿我（Jack）人生举例，我也会偏离轨道

但偏离以后，回来得特别快

昨天熬夜了，今天早点睡

这周花钱多了，下周重新控制

几天没运动，今天出去走二十分钟



最近状态不好，也别一直骂自己，写下日记反思一下，然后慢慢让生活一点点恢复正常



今天任务不难：

想想最近有没有一件事情，你已经偏离原来的状态了？
