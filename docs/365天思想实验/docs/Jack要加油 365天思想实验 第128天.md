# Jack要加油 365天思想实验 第128天

你每天消耗掉的精力不会凭空回来，所以不必总想着干什么，而是别把能量浪费在没必要的地方



365天思想实验，第128天



今天讲个最基本的规律：能量守恒



在一个封闭系统里，能量不会凭空产生，也不会凭空消失，只会从一种形式转化成另一种形式



比如电能可以变成光和热，汽油里的化学能可以变成汽车运动



当然，人的精力不能完全当成物理学里的能量来计算，但有一点很像：你一天能够投入的注意力和精神状态，确实是有限的



你花两个小时和一个人争论，就少两个小时做自己的事情



你晚上刷三个小时短视频，第二天睡眠不足，消耗掉的不只是昨天三个小时，还有今天的状态



你每天反复纠结一件一件无法改变的事情，这些精力也没有消失，它们只是被转化成了焦虑和疲惫



所以我(Jack)希望大家不只是会努力，而是会想我的能量到底流到哪里去了？



今天直播前好好思考下：每周最消耗我精力的三件事是什么？它们最后分别变成了什么？
