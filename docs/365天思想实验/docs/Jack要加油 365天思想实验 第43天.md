# Jack要加油 365天思想实验 第43天

7月11日，365天思想实验，第43天。



今天学一个很多人听过，但真正做到的人很少的概念：复利效应



简单说，就是一件小事只做一次，几乎看不到结果。



但如果长期重复，后面的变化会越来越大。



存100块钱，看不出什么。



每天读十页书，看不出什么。



每天运动二十分钟，也看不出什么。



所以很多人做了几天后，就觉得没用，然后放弃。



但复利最重要的地方，恰恰就是前期看起来没什么用。



树刚种下去的时候，地面上机会没有变化。



但根正在底线慢慢长。



等到某一天，它开始长高、开花、结果，别人只看到它突然变好了，却没看到前面那段安静积累的时间。



坏习惯其实也有复利。



每天熬夜一点。



每天多花一点。



每天拖延一点。



每天少运动一点。



短期没什么，几年后，差距就出来了。



所以今天的任务很简单：



告诉我，你要选哪一件值得长期复利的小事，认真做十年🦌
