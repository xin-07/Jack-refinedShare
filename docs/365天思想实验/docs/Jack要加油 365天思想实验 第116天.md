# Jack要加油 365天思想实验 第116天

永远不要努力学习，也不要努力工作



365天思想实验，第116天



努力这个词有时候会骗人，如果你每天都在告诉自己：我必须逼自己学习，我必须逼自己上班，我一定要坚持



时间长了以后，大脑很容易把这件事情和痛苦绑在一起，一想到学习就抗拒，一想到上班就烦，最后甚至会产生怨气



解决的秘方就是你要想办法在里面找到一点乐趣



学习的时候，找到自己真正好奇的问题。工作的时候，去研究怎么把一件事做的更快、更漂亮。



运动的时候，不只是想着今天必须完成20分钟，而是去感受身体越来越有力量



当你开始享受这个过程的时候，状态会完全不一样



你不是一边做，一边等它赶紧结束，而是愿意把注意力真正放进去



人在这种状态下，身体是放松的，精神是专注的，就发挥出最好的水平



下次做事情的时候想一下你是在痛苦逼自己完成，还是在困难里面慢慢找到乐趣和成就感？



我（Jack）做事情不靠意志力硬撑，而是把该做的事变成喜欢做的事🤫
