# Jack要加油 365天思想实验 第133天

年轻时候，必须要想办法创造这几种收入



365天思想实验，第133天



一个人的收入分成了8种：工资、副业、生意、租金、版税、资本增值、股息、利息



我（Jack）觉得大家应该早点知道赚钱，不只是“上班拿工资”这一种方式



刚毕业的时候，工资当然最重要。因为你首先要靠自己的能力养活自己。但就像我们上一本书解读的穷爸爸富爸爸里说的，随着年龄增长，如果哪一天我不去上班了，还有没有钱进来？



比如你下班以后做点副业，这是第二种收入



后来你有了自己的生意，收入开始和你的时间慢慢脱钩



买了一套能出租的房子，每个月有租金



写了一本书、做了一首歌、开发了一个产品，可能产生版权



手里的资产长期增值，是资本增值



持有一些能够分红的资产，会有股息



现金、债券或者其他固定收益资产，还可能产生利息



今天大家想想：未来五年，我最有可能增加的下一种收入是什么？



然后拿张纸默写一次这8种收入🎉
