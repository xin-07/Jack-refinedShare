7月15日，365天思想实验，第45天。



分享一个心理学概念：确认偏误👑

就是人都喜欢相信自己愿意相信的东西



当你觉得一个人很好，你会不断寻找证明他好的证据



我发现这不仅发生在看别人身上，也发生在看自己身上



如果你每天告诉自己：我不行❌



你的大脑就会拼命找证据证明你真的不行。一次失败、一次拒绝、一次失误。都会变成你不相信自己的理由。



但如果你告诉自己：我还在成长、我可以学、我只是现在不会



你的大脑又会开始寻找新的证据✅



所以很多时候，不是现实决定了你的想法。而是你的想法，决定了你会看到什么样的现实。



今天的任务很简单：找一句你经常对自己说的负面话。

然后把它改成一句更真实、更积极的话！
