# Jack要加油 365天思想实验 第54天

7月25日，365天思想实验，第54天



讲一个都听过的规律，叫适者生存🔥



很多人一听到这四个字，就觉得是不是最厉害的人才能活下来？



其实不是，真正的意思更接近于：能适应变化的人，更容易活下来。



恐龙够强吧，但最后活下来的，不是最大的，也不是最凶的



而是那些更能适应环境变化的物种🐒



人生也是一样，以前会开车就能找到工作，后来会用电脑的人机会更多，现在，会用AI的人，效率可能又比别人高很多



年轻时最宝贵的就是可以不断学，今天学一点新东西，明天学一点新工具，后天认识一个朋友



一年以后，你就已经和以前完全不一样了💪



今天的任务很简单：学一样你以前不会的东西，或者是Jack专属会员目前为止对你启发最大的内容
