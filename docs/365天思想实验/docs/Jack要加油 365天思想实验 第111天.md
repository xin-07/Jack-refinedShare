# Jack要加油 365天思想实验 第111天

365天思想实验，第111天



今天是周六

很多努力的人最容易忽略的事情：恢复也是进步的一部分



健身的人应该理解，你去训练的时候，肌肉并不是当场变强的。训练只是给身体的一个刺激，真正的恢复和适应，发生在之后



很多人一到周末就有一种负罪感，睡晚一点，觉得自己不自律

出去走走，觉得浪费时间，陪家人吃顿饭，脑子里还想着工作。好像一个人只要没有产出，这几个小时就白过了



如果一台机器365天一天满负荷运行，不保养、不降温，最后会怎么样？



不是效率越来越高，而是更容易出问题，周末的作用是给下一个星期恢复状态



今天可以看个我（Jack）推荐的电影，或者运动，看书，陪孩子，见朋友，也可以说明都不安排，安静地待一会儿



有时候困扰你好几天地问题，反而实在散步、洗澡、开车的时候突然想明白，因为大脑也需要一点空白



今天晚上睡觉以前想想：今天做什么事情，让我的电重新充回来了一点不？
