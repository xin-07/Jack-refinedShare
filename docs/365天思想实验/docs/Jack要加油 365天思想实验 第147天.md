365天思想实验，第147天：影子价格

你今天有两个小时空闲。可以拿去兼职，赚100.也可以陪孩子、运动、读书、或学习一项技能

经济学里，影子价格可以理解为，在一定条件下，多拥有一单位稀缺资源，能够带来多少额外价值

人生最值得计算影子价格的资源，就是时间。比如你为了省20块钱，花一个小时跑去很远的超市。看起来省钱了，但这一个小时，你本来可以做什么？

再比如，有人愿意花钱请人打扫卫生，把节省下来的时间用来学习、工作或者陪伴家人。这不一定是浪费钱，反而可能是很好的资源配置

不是说所有时间都应该拿来赚钱。恰恰相反。休息、陪伴家人、满足好奇心，这些事情虽然不能直接换成收入，却可能比赚钱更有价值

财富真正重要的作用就是让我们拥有更多自由支配时间的能力

大家回顾一下昨天，找出其中一个小时，如果重新安排，这一个小时还能创造什么价值，不一定是钱，也可以是健康、知识、快乐
