周末讲个轻松但深刻的规律：平方和次方

一个正方体，把它的长宽高全扩大两倍。它会变成原来的几倍大？

答案是体积变成8倍，表面积只变成4倍。这说明当一个物体越来越大，体积和表面积不会同比增长

所以大象不是一只放大百倍的老鼠，因为身体变大，重量、骨骼承重、散热等都会发生变化，规模变了，原来有效的方法就不再有效了

这个规律在生活中如何利用呢，比如你做自媒体，只有100个粉丝，每条留言都能回复。但当你有100万粉丝以后，还能用同样的方法吗？

肯定不行，你需要新的工具、团队、管理方式，甚至需要重新设计和粉丝交流的机制

创业也是一样。经营一家小店，什么事都能亲自处理。但如果开了100家店，继续以来老板一个人，整个系统都会崩溃

今天找一件正在做的事问自己：如果它的规模每天扩大十倍，我现在的方法还能不能正常运转？

如果不能，我要做些什么

我（Jack）几十年工作和创业以及投资的经验分享给大家

快速成长，不是让自己做更多事，而是建立一种系统，让规模扩大后，自己不必按照相同比例增加付出🎉

因为一个人能走多远，取决于他能不能在不同阶段，找到合适新规模的生存方式🎁
