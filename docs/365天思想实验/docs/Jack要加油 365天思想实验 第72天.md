# Jack要加油 365天思想实验 第72天

8月13日，365天思想实验，第72天

昨晚直播答应写一篇送给大家的决策方法——37%策略



假设有100个人来相亲，但你必须一个一个见

拒绝了就不能再找回来，而且你最后必须选一个



那怎么选，最容易选到最好的那个？



数学上被证明策略：前37个个人，一个都不要选

你就看，就比较，就学习，记住这37个人里面最好的那个人是什么水平

从第38个人开始，只要出现一个比前37个人里面最好的人还要好的人，就立刻选他



为什么？

因为一开始你根本不知道这个世界的水平在哪里，你需要先拿一部分机会，去建立自己的判断标准



但如果你一直比较、一直等，你又可能把真正好的机会全部错过



找工作、招员工、租房子，甚至很多生活中的选择都可以借鉴这个思路



不要看到第一个不错的就马上决定，也不要永远想着后面是不是还要更好的



先观察，再建立标准，然后果断行动！
