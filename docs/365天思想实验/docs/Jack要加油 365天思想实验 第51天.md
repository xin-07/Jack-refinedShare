# Jack要加油 365天思想实验 第51天

7月22日，365天思想实验，第51天



今天咱们讲一个很多人听过的话题：木桶效应



一个木桶能装多少水，不是看最长的那块木板，而是看最短的那块🪣



这句话放在人生里，你想到啥？



有的人很聪明，也很努力，但是情绪一上来就乱说话，最后机会全被自己干飞了



有的人特别会赚钱，但是完全不会存钱，赚得再多，最后还是没底气



还有的人能力很强，但是身体越来越差，等真有机会的时候，自己肉身已升天



所以很多时候，你不需要什么都变得更厉害



你先找找自己哪里最短😄









别乱想😂



可能健康，情绪，表达，也可能是存钱能力！



今天的任务就一个：



认真找一下，自己现在最明显的短板是什么



别给我搞十个，就找一个



然后问自己，我今天能不能先补它一点点？



坦诚给大家一个秘密㊙️



当你把最短的那块补起来，你整个人生能装下的东西，会三维提升。好好想想 长方体体积公式是什么
