# Jack要加油 365天思想实验 第71天

8月12日，365天思想实验，第71天



再次强调一次的概念，叫损失厌恶



我们最近读的书《思考，快与慢》里最重要的内容之一



假设我今天给你1万，你会挺开心

但如果第二天，我再从你手里拿走1万，你难受的程度，往往会比昨天开心的程度更强



人就是这样

失去一件东西带来的痛苦，通常比得到同样东西带来的快乐更强（损失的情绪是得到的两倍）



这个东西放在投资里，就特别明显



一只股票涨了10%，你会说还行

但如果跌了10%，你会要一天到晚都想着它了

甚至开始反复打开账户，越看越难受

然后很容易做出一个特别奇怪的决定：赚钱的股票，赶紧卖了，怕利润没了

跌的股票，反而死死拿着，因为实在不愿意承认自己亏了



你仔细想想，这其实不是在投资

是在跟自己的情绪较劲



生活里也一样

别人夸你十句话，你可能晚上就忘记了

但有一个人说你一句不好听的话，你能想好几天



今天任务：想想最近有没有一件失去或者亏损的事情，一直影响你？
