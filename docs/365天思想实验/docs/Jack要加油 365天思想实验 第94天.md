# Jack要加油 365天思想实验 第94天

9月4日，365天思想实验，第94天



今天想写给正在读书、选专业的年轻人



如果我（Jack）重新选专业，我会打开招聘网站找：未来十年，社会到底缺什么人？



我替你们找过了

这几个方向值得关注



第一，AI、软件、数据和网络安全。但千万别以为会用AI聊天就够了。未来真正值钱的是“AI+专业”：AI+金融、AI+工程、AI+内容。AI只是工具，你得有一个真正懂的行业



第二，医疗和养老。人口老龄化不会因为AI出现而消失。护士、康复、医疗服务这些需要人与人接触的工作，长期都会有真实需求



第三，能源、电力和基础设施。AI背后是数据中心，数据中心背后是芯片、电力、电网、设施和工程。很多未来机会，可能藏在这些看起来不那么热门的行业里



第四，现实世界里的技术工作。电工、维修、工程施工这些工作，AI可以告诉你怎么做，但最后总得有人到现场把问题解决



明天我会写未来几年必须要培养的几种能力！
