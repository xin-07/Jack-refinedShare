# Jack要加油 365天思想实验 第84天

8月25日，365天思想实验，第84天



今天分享个我（Jack）特喜欢的思考方法

以后准备做一件比较重要的事情，别只想这件事对我有没有好处？



试着多想三层



第一层，叫直接结果

我做了以后，马上能得到什么？



比如你准备每天晚上拿两个小时做副业

第一层很简单：可能多赚一点钱，也可能多学一个技能



但别停在这里



第二层，叫传导路径

你要开始想：这件事还会影响什么？



每天晚上多工作两个小时，你陪家人的时间会不会少？睡觉会不会变晚？第二天工作状态会不会受到影响？



当然也可能反过来

你认识了新的人，学会了新的技能，未来又出现新的机会



一件事情很少只有一个结果

它会像推倒第一块多米诺骨牌一样，一路往后传



最后第三层：

如果我长期这么做，会发生什么？

一天少睡一个小时，没什么

连续三年呢？



每天读半小时书，一天也看不出什么

连续十年呢？
