昨晚解读原则关于做出好的决策，除了书里说的，我（Jack）还有自己的心得

做决定既是一门科学，也是一门艺术。因为我们无法掌握所有信息，更不可能准确预测未来。但依然有方法做出更好的决策

除了昨晚书里说的三点，我补充三点我个人心得

一，尽量获得真实、高质量的信息。比如你要买房，不要只听中介说房价会涨，也不要只听朋友说房价会跌。应该了解当地收入、人口、房屋供应、租金和利率。而且信息不仅有真假，还有权重。有些信息决定结果，有些只是噪音，要挑选

二，用概率思考，而不是只想一种结果。不要只问这件事会不会成功。而要问：成功的可能性有多大？失败的可能性有多大？不同结果分别意味着什么？

三，计算自己能不能接受最坏的结果。比如创业、成功赚到100万，但失败让你失去全部积蓄。如果最坏结果会让家庭陷入困境，即使成功的概率不低，也未必值得冒险🤫
