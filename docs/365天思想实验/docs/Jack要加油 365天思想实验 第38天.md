# Jack要加油 365天思想实验 第38天

7月6日，365天思想实验，第38天。



今天大家做一件事：



把昨天看电影、看书、刷到的一句话，或者最近让你有触动的一件事，写成一段自己的思考。



不用长，关键是不要只是“看懂就算了”。



我们看电影，看短视频，看文章，看新闻，看别人的人生。

看完以后，脑子里热闹一下，很快就过去了。



真正能拉开差距的，不是你看了多少东西，而是你有没有把看到的东西，变成自己的理解。



比如一个电影人物为什么会失败？



一句台词为什么让你难受？



一个故事为什么让你想到自己？



你如果能写下来，就说明你不只是被内容喂了一遍，而是真的开始消化它。



我(Jack)越来越觉得，普通人想提升认知，最简单的方法就是：



每天把一个感受，写成一段话。



不用装深刻，不用怕别人笑，就老老实实写自己真实想到的东西。
