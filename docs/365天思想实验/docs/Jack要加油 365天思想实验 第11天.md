# Jack要加油 365天思想实验 第11天

365天思想实验，第11天。



今天，请记录三件值得感恩的小事。

不需要惊天动地。

也不需要可以寻找。

可能是今天睡了一个好觉》

可能是父母身体健康。

可能是孩子对你笑了一下。

可能是下班路上看到了一次漂亮的晚霞。

可能是银行卡里还有存款。

可能是今天没有人生病。



我(Jack)发现一个很有趣的现象。



同样的人生。

有的人越活越幸福。

有的人越活越痛苦。

差别往往不在于拥有多少。

而在于注意力放在哪里。







如果每天盯着自己没有的东西。

永远都会觉得缺。

缺钱。缺机会。缺运气。缺爱。缺认可。

但如果开始留意自己已经拥有的东西。



你会发现。

原来很多曾经梦寐以求的东西，早就已经在自己的生活里了。



今天的任务：

写下三件值得感恩的小事。

然后认真过好这一天。
