# Jack要加油 365天思想实验 第152天

AI时代学这三样改变命运

365天思想实验，第152天

就像今天直播说的，我觉得要培养三种能力，而且顺序非常重要

一，看清世界的规律。为什么有些经济体越来越富裕？为什么有些公司能持续赚钱？为什么有些人很努力，却改变不了生活？我们要学习物理、经济、历史、商业，尽可能理解背后的原因，而不是只看表面

二，用数学总结规律，比如财务自由到底要多少钱？你不能说我想多赚一点。要算出家里一年花多少钱，有多少储蓄，投资可能获得多少回报。数学的价值就是让模糊的感觉变得可计算和验证

三，用逻辑把工具应用到生活。知道复利就应该思考怎么长期积累资产。知道时间有限，就应该重新安排每天的生活。知道环境影响习惯，就应该主动创造一个容易坚持的环境

我（Jack）希望和大家长期一起这么做：用规律理解世界，用数学量化世界，然后用逻辑做出好选择

所以今天大家思考下最近做的事背后有什么规律？哪些东西可以量化？接下来应该怎么做？
