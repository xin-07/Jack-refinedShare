# Jack要加油 365天思想实验 第118天

每天都要好好保护最清醒的几个小时



365天思想实验，第118天



我们总说，每个人一天都是24小时，所以时间最公，但其实真正不公平的，是每个小时的质量完全不一样



你早上精神最好的一个小时，和晚上已经累得不想思考的一个小时，都叫60分钟，但能做出来的事情可能差很多



很多人就是把自己最清醒的时间拿去回消息、刷手机、处理杂事



等到真正要学习、写东西、最重要决定的时候、脑子已经没电了



所以每天找出状态最好的两个小时



如果你早上最清醒，那就别一醒来先刷半个小时手机，拿这段时间去读书、写作、学习一个重要技能，或者解决最难的问题



那些会邮件、整理东西、处理简单任务的事情，完全可以留到状态没那么好的时候，就像你每天会拿到一笔注意力预算你花掉了，就没了



所以今天的任务很简单观察一下自己，一天里，什么时候脑子最清醒？



然后明天开始，保护其中至少30分钟，不回消息，不刷手机，不做杂事👍
