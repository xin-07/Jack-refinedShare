# Jack要加油 365天思想实验 第22天

6月18日365天思想实验，第22天



今天，把能量用来完成最重要的一件事🪞



不是最着急的事

不是别人催你的事

不是手机里突然跳出来的消息

而是那件对你未来真正有帮助的事



学习一小时

运动一次

写内容

推进一个长期计划

或者只是安静下来，认真思考自己接下来到底要什么🧘‍♂️



很多人每天都很忙

但忙到最后，却没有真正往前走

因为他的一天都被别人安排！

消息一来就回复

短视频一刷就停不下来

别人一催就立刻去做

结果最重要的事情，永远被放在最后



分享个价值百万美金的秘密：所有白手起家的人都会保护自己最宝贵的时间和精力

先做最重要的事，再处理琐碎的事



人生的差距不是一天拉开的

而是每天最清醒的那段时间，你到底用来做了什么



今天的任务很简单：找出今天最重要的一件事🙏

先完成它

再去处理其他事情



当你开始掌控一天的顺序，你就开始掌控自己的人生🦌
