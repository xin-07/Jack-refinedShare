365天思想实验，第146天：种子休眠

有些种子遇到水和适合的温度，也不会发芽。它们需要满足其它条件，比如经历一段低温，或者种皮逐渐发生变化

对植物来说，发芽的时机非常重要。如果秋天刚暖和几天就发芽，接下来遇到寒冬，幼苗根本活不了，所以种子休眠，是植物适应环境的生存机制

这个现象让我（Jack）思考，很多人故事，只要马上有结果。读了本书，发现自己没变化。运动一个月，发现身材没有改善。做自媒体三个月，粉丝还是很少

于是怀疑自己不适合做这件事？

当然不是说坚持就能成功。种子需要合适的条件，人也需要不断检查方法和方向。比如每天读书，有没有把知识用出来？每天运动，有没有逐渐提高训练质量？每天做内容，有没有研究观众真正需要什么？

耐心不是盲目等待，而是在结果出现之前，持续创造让结果发生的条件

今天找一件你正在坚持，却看不到明显回报的事情。
想一想：我还缺少什么条件？
