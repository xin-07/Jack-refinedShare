# Jack要加油 365天思想实验 第159天

分享三个长期成长的重要思考

365天思想实验，第159天

第一，身份认同决定你的日常选择。我一直告诉自己努力读书。但这样想：我是一个热爱学习、对世界充满好奇的人。你会发现，读书不再是需要完成的任务，而是你本来就愿意做的事。自律是成为那个自然而然会做正确事情的人

第二，长期忠于方向，不忠于方法。比如你希望通过分享知识帮助更多人。十年前，你写博客；五年前，你拍视频；今天你可以利用AI。方法一直在变，但方向没有变。长期主义是一直都朝同一个方向前进

第三，数据评价行动，但不能评价你。你今天发了条视频，没人看。说明这条内容的传播效果不理想，却不代表你这个人没有价值。
你今天投资亏了钱，说明这笔投资的结果不好，不能单凭结果证明你没有判断能力

大家想以下三点，留言
1.希望成为什么样的人？
2.未来十年，有什么方向值得一直坚持？
3.如果明天所有成绩都消失了，还愿不愿意继续做这件事？
