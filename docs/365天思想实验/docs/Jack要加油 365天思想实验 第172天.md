今天讲一个经济学里特别有意思的现象：赢家诅咒



假设有一套房子公开拍卖，十个人都想买。每个人都根据自己的经验，估算这套房子到底值多少钱。有人觉得值80万，有人觉得90万，还有人觉得值110万，最后，出价最高的人赢得了拍卖



他为什么能赢？可能因为他眼光最好，但也可能是因为他高估了房子的价值。当大家争夺同一件价值不确定的东西时，最终赢的人往往也是估值最乐观的人之一



这就是赢家诅咒



为了拿下一个项目，不断压低报价。最后竞争对手全部退出，你成功了。但算下来发现，项目利润太低，甚至还要倒贴钱



再比如投资，一家公司所有人都在抢，你不断提高买入价格，最后终于买到了。但你有没有想过，赢得竞争不代表赢得的价值



下次遇到竞争机会，想3条



他对我到底值多少钱？我的判断可能错在哪里？如果为了获胜付出更多代价，这件事还值得吗？
