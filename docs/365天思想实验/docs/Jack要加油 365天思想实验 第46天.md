# Jack要加油 365天思想实验 第46天

7月16日，365天思想实验，第46天



今天学一个认知误区：结果偏见



很多人一辈子，都在犯这个错误，就是只看结果，就判断当初的决定是对还是错



但结果，常常都骗人！



有个粉丝跟我说：Jack，我听了你的建议开始做自媒体，一周了都没人看，所以这个决定是不是错了？我还是放弃吧



我问他：如果回到一周前，在不知道今天结果的情况下，你还会不会发第一条视频



他说：会。因为当时我没有钱、没有技能、没有资源。发视频至少让我练了口才，也学会了剪辑



我说：那你的决定就是对的



因为一个好的决定，不应该只是看一次结果，而应该看当时掌握的信息下，它是不是一个高概率正确的选择



有两个人，一个从不抽烟，但得了肺癌

另一个天天抽烟，活到了100岁

你会因此觉得抽烟对长寿好吗

当然不会



因为我们评价一个选择，不能只看一次结果，而是看它长期能不能提高成功的概率！



长期成功＝尝试次数×成功的概率
