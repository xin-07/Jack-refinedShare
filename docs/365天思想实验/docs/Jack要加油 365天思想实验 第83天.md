# Jack要加油 365天思想实验 第83天

8月24日，365天思想实验，第83天



一个人越往上走，越应该有的能力：向下包容



就是当你比别人多懂一点、多经历一点的时候，不要急着嘲笑别人



比如有人问你一个你觉得特别简单的问题：基金和股票到底有什么区别？



你别来一句：这你都不知道？



我会说：很正常，我以前刚开始的时候也搞不清楚，我给你举个最简单的例子



再比如一个年轻人跟你说：我一个月才赚5000块，怎么可能存得下钱？



你别马上喷他：500块都存不下来，磙

我会问他：你每个月最大的三笔支出是什么？咱们先看看有没有100块能留下来



做父母的粉丝，你们孩子做错一道你觉得特别简单的题



别说：我讲三遍了，你怎么还不会？

换成：你告诉我你是从哪一步开始不明白的？



我一直提醒自己，厉害的人，不会用自己的认知去羞辱别人

我今天觉得简单的东西，只是因为我已经走过那段路了🙏



在十楼，当然看得比在二楼的人远

但不代表二楼的人有错❤️
