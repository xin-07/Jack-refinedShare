# Jack要加油 365天思想实验 第100天

今天是 365天思想实验的第100天



真的感谢大家这100天的信任和认可



昨天发了一条消息，让做切片的粉丝加群

我设置了两个审核问题：你做了多久？为什么做？



很多人想法都很直接：想拿我（Jack）起号，想赚钱

但做着做着，慢慢变成了习惯

有人说每天做切片的时候，也是自己重新听一遍、反思一遍、学习一遍的时候



我看到这个答案，真的开心🥳

因为这是我一直希望大家做到的事情



不要只是看内容，一定要有输出

你今天看了一篇专属内容，觉得挺有道理，可能明天就忘了



但如果看完以后，再讲一遍，哪怕只是跟身边的人说

我今天看到一个特别有意思的东西，我跟你讲讲

讲的时候，你才知道到底有没有真懂

讲不清楚的地方，你会重新想

想明白了，再讲一次



我特别希望每一位专属会员，除了每天看内容，也给自己留一个小小的输出

不一定非常要做切片，你可以写几句话，可以发评论



哪怕每天只输出一分钟，都比看完就忘了强！
