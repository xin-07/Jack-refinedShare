今天咱们讲一个数学概念，叫指数增长



很多人为什么坚持不下去？

因为人更容易理解直线增长，不理解指数增长



每天多赚100块很容易理解，但是如果有一件事情，每天只比昨天进步1%，前面一个月，几乎感觉不到变化



很多人到这里，就放弃了，可神奇的地方就在后面



因为指数增长，前期慢，后期快



这也是为什么，我一直让大家阅读、运动、拍视频、学习AI



这些事情做一个星期，变化很小，做一个月，别人可能还看不出来



但如果坚持一年、三年、五年，你会发现，你和大多数人的差距，不是慢慢拉开的，而是突然拉开的



看到别人成功，就认为是最近一年突然发生的



其实是前面几年那些看不到结果，就怀疑这件事没意义



也许你现在，正处在指数增长最不起眼的那一段！
