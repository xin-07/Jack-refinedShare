# Jack要加油 365天思想实验 第141天

教你一招 验证自己的努力到底有没有用



365天思想实验，第141天



讲个科学思维：控制变量



假设你想知道，每天早起半小时，能不能提高学习效率。如果你同时改变睡眠时间、饮食、运动和学习方法，最后效率真的提高了，你知道到底是哪个原因吗？



不能吧



所以做实验，会尽量让其他条件保持一致，只改变一个关键因素，再观察结果



这个方法也可用来改善生活。比如你觉得每天效率很低，很多人突然决定早起、戒手机、读书两小时，再加运动。坚持三天，累得不行，最后全部放弃



我（Jack）会第一周，只改变一件事：每天起床后一个小时不碰手机。记录这一周，每天完成了多少重要的事情



第二周，再调整工作时间，看看有没有新变化。



当你开始用观察和记录代替凭感觉做决定，真正得成长就开始了



所以今天找一个想改善的事，如睡眠、学习、运动或工作效率，后七天，只调整一个变量，并每天记录结果，希望你不只是努力改变自己，还要学会研究自己
