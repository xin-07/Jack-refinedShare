# Jack要加油 365天思想实验 第24天

6月21日，365天思想实验，第24天。



周末好啊，今天认真想一件事：我现在做的事情，真的在靠近我想要的人生吗？



你也许每天都很努力

努力上班赚钱带孩子

刷信息也很努力

甚至焦虑都很努力💪



但努力不一定代表方向❌

如果方向错了，越努力，可能只是离真正想要的人生越来越远。



我以前也有过这种感觉。每天看起来都很忙，但停下来想一想，好像并没有真正变成自己想成为的人。



后来我发现不能只低头赶路，也要偶尔抬头看方向。🗺️



今天的任务很简单：

找十分钟，不刷手机，不处理消息。

问自己三个问题：



我现在最想要的人生是什么？

我今天做的事情，哪些在靠近它？

哪些其实只是在消耗我？



不用马上有答案。

能开始问自己这个问题，就已经很重要。



因为一个人真正的清醒，不是突然知道所有答案。

而是开始不再糊里糊涂地过每一天🦌
