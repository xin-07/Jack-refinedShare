365天思想实验，第108天



今天讲一个越早懂，人生过得越好的智慧：期望值



假设有一件事，成功的概率20%，但一旦成功，你可能得到100分；失败了，减5分



很多人听成功率只有20%第一反应就是不做

但如果把它做很多次，其实爆赚



真正应该看的，不只是这一次会不会成功，而是

概率 × 结果，长期算下来值不值得！



这就是期望值

人生里很多选择都应该怎么看



比如你主动认识一个人

可能十个人里面，八个最后都没有联系

但只要其中一个人成为你的朋友、老师或者合作伙伴，可能就把前面所有尝试都覆盖了



做自媒体也是一样，不知道哪一条会有人看

但如果拍一条视频的成本很低，而其中某一条可能让成千上万的人认识你，那这件事长期的期望值就很高



读十本书，不可能十本都改变你

可其中一本书里的一句话，也许会影响你后面十年的决定



分享一条我（Jack）的口诀：**如果这样的选择重复100次，最后大概率会把我带到哪？**
