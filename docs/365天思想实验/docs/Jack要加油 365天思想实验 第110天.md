# Jack要加油 365天思想实验 第110天

365天思想实验，第110天



很多人焦虑要赚多少钱，那我（Jack）就算一辈子到底要花多少钱？



根据统计数据，2025年全国居民人均消费支出是3w，城镇居民是3.6w，农村居民是2w



2025年人均预期寿命达到80岁



假设把未来几十年的物价都冻结在今天，也假设一个人一辈子的平均消费水平都差不多



3w × 80，大约是240w



奢侈点就按两倍算大约是480w，平均到每天大约164元

一天164块，好像真的不多



买顿饭，买杯咖啡，打个车，再买点东西，一天可能就过去了

可如果每天但是164块，持续80年



我们总觉得一顿饭几十块一次购物几百块都没什么

每一笔钱都不大，但人生不是一天，人生是接近三万天



今天的任务就是把自己今天所有花的钱加起来，然后问自己如果每天都这样花，80年以后会是多少？



最后祝我的粉丝们稳定赚大钱，更能开心的存下钱，因为存下的才是你的底气❤️
