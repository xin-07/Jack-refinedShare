# Jack要加油 365天思想实验 第52天

7月23日，365天思想实验，第52天。



讲一个无意中聊过的概念，破窗效应



假设一栋楼有一扇窗户破了，一直没人修。慢慢地，别人就会觉得这里没人管，于是第二扇窗也可能被砸，墙上开始有人乱涂，垃圾也越来越多🗑



最后，原本只是坏了一扇窗，整个地方越来越乱我们生活里也一样，房间里先乱一件衣服，你觉得无所谓，后来桌子也乱了，地上也乱了



今天熬一次夜，你觉得没事，接着连续几天都开始晚睡



这个月多花了几百块，你觉得不多，后来消费越来越随意



人生不是突然失控的，而是从这次没关系开始的



当然，破窗效应也可以反过来用✅



你把床铺好，把桌子擦干净，把今天该做的第一件小事完成，整个人就容易慢慢进入状态



所以今天的任务很简单：



找出你生活里的一扇“破窗”，把它修好



让生活重新变好，就是从你不再纵容第一个小混乱开始🦌
