# Jack要加油 365天思想实验 第151天

历史上少了11天

365天思想实验，第151天

一年365天。实际上，地球完成一个季节循环，大约需要365天5小时48分，多出来的这几个小时怎么办？每四年加一天，也就是闰年的2月29日

但四年加一天还不准确，每年会多11分钟。你可能觉得几分钟算什么？可一百年下来，就会差一天。一千多年后，日历和实际季节已明显错位。于是人类必须修改规则

1752年，英国将9月2日的这二天，直接变成了9月14日。11个日期消失，但人们并没有少活了11天。改变的是记录时间的方法

你目标每天读书一小时，每年发布千条视频，或每月存一笔钱。开始都很合理，执行一段时间以后，实际情况可能已发生变化，你却还按照原计划生活

可靠的系统是要不断发现误差、及时校准！

所以今天找一个坚持很久的目标。看看最初计划和最近的实际情况到底查了多少。如果继续第一年，偏差会有多大？然后是应该改进方法，还是继续调整目标？
