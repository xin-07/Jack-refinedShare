365天思想实验，第106天



今天咱们讲个我(Jack)很喜欢的概念：不断校准



飞机从纽约飞到洛杉矶，并不是设定好方向以后，就笔直地飞几个小时，现实里有风，有气流，速度会变化，航向也会产生偏差

发现偏了，然后修回来



我觉得很多人改变自己地时候，就是太追求"不能偏"



比如我们开始每天运动20分钟



第一天做到了，第二天做到了，第三天突然加班，没运动

很多人马上就会像完了，我又没坚持下来

然后第四天干脆也不做了



其实完全没必要

真正稳定的系统，从来不是永远不出现偏差，而是出现偏差以后，能够很快回到原来的方向



减肥的时候多吃了一顿，下一顿正常吃就行

昨天刷手机刷到凌晨，今天早点睡

一天没读书，第二天继续翻开



不要因为一次偏航，就把整架飞机掉头回机场所以我们接下来做每周行为实验，不希望大家把它变成另外一种压力



哪怕不想动，哪天偷懒了，记录下来就行，然后下一天继续做就是成功🥇
