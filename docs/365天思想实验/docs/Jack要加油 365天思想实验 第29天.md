# Jack要加油 365天思想实验 第29天

6月26日，365天思想实验，第29天。



今天，请主动减少一次“无意义的消耗”



少看一条让你焦虑的消息，不参与一次没结果的争论，不反复揣摩别人一句话，不去刷让自己更空虚的视频，也可能是不再把时间浪费在一个根本不值得人身上🗑



很多人的命运不是被大事毁掉的，而是每天被很多小事消耗慢慢掏空的。



你本来可以学习，但脑力刷手机刷没了

本来可以运动，但情绪内耗消耗掉了



一个人的能量是有限的



你把它给了垃圾信息、烂人烂事、反复焦虑、就很难再有力量去改变自己



今天的任务很简单：发现一次正在消耗你的事情，然后停下来。



不继续看，不继续想。把这份能量收回来，用在真正对自己有帮助的事情上🦌
