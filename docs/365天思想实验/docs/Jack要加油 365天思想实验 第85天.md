# Jack要加油 365天思想实验 第85天

8月26日，365天思想实验，第85天



今天讲一个我(Jack)特喜欢概念——路径依赖



比如像我毕业以后，第一份工作做销售

做了两年，认识的人越来越多，表达能力也越来越强

下一份工作，我还是会选择销售、客户、商业有关的

再过几年，我认识的人更多，经验也更多了

回头一看，我的人生已经沿着这条路走出去很远了



生活也是如此

今天读了一本书，可能认识一个新的概念

因为这个概念，你又去找第二本书

第二本书让你认识一个人

这个人又给你带来了一个新的机会

几年以后你回头看，可能会发现，人生一个很大的变化，最开始竟然只是因为那天随手读了几本书



坏的路径也一样

今天熬夜，明天没精神

没精神就不想运动

不运动状态更差

状态差了又更想刷手机



今天思考：你现在每天重复做的事情，如果继续做五年，会把你带到哪里



送菊花给你们：

人生最重要的，可能不是你现在站在哪里

而是你脚下这条路，正在把你带去哪里
