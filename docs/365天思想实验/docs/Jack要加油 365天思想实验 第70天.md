# Jack要加油 365天思想实验 第70天

8月11日，365天思想实验，第70天



今天讲一个可能听过的概念，叫二八定律



简单理解就是，很多时候，80%的结果，可能来自20%最重要的事情



比如你工作一天，看起来忙了十个小时

回消息、开会、刷新闻、处理各种杂事

晚上觉得自己累得不行



但你认真想想，今天真正推动你人生往前走的，可能就那么一两个小时



投资也是一样

一个人投资很多年，最后真正给他带来大部分收益的，可能就是少数几次重要的选择



人际关系也是一样

你手机里可能有几千个人，但真正遇到事情愿意帮你、能跟你说真话的，也许就那么几个



人生不是做得越多越好，而是要慢慢找到：到底什么事情对我最重要？



今天的任务很简单



晚上睡觉前，把你今天做的事情想一遍

然后问自己：如果今天只能保留20%的事情，我会留下哪一件？
