# Jack要加油 365天思想实验 第153天

到底什么是成功

365天思想实验，第153天：古德哈特定

当一个指标变成必须完成的目标，它就逐渐失去原本的衡量价值
比如学校希望学生真正掌握知识，于是用考试成绩来衡量

如果所有人只追求分数，学生就拼命刷题、背答案，成绩提高了，真正理解的东西没多

再比如做自媒体。你原本希望自己的内容能够帮助更多人，于是用播放量来判断内容好不好。如果你只追求播放量，就可能越来越喜欢制造争议、夸张标题

最后数据越来越漂亮，内容却越来越没有价值

如果我们把衡量成功的工具当成了成功本身，那就出事了

用这个方法想想运动的目的，更懂得定期问问自己：我追求的这个数字，还能代表我真正想要的东西吗？

今天找一个你特别在意的数字。可能是收入、粉丝、体重或者每天学习的时间。然后问自己：如果这个数字提高了，但我真正想要的生活没有变好，那我算成功了吗？
