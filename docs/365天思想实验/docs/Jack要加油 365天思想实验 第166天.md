# Jack要加油 365天思想实验 第166天

特别希望大家去了解的知识——交流电和直流电

365天思想实验，第166天

听说过爱迪生，也听说过特斯拉。他们曾经站在两种不同的电力技术路线背后。爱迪生支持直流电，电流始终朝一个方向流动。特斯拉则是交流电发展的重要推动者。交流电的方向会周期性变化

电往哪个方向走，真的有那么重要吗？太重要了。因为当时人类面临一个烦恼：发电厂造出来的电，怎么才能低成本的送到几十公里、几百公里以外？早期直流输电不容易改变电压，而交流电可以通过变压器方便的升高电压，减少远距离输电的损耗

最终，交流电成为现代电网的主流

但故事还没有结束

100多年后的今天，人类又开始在一些超长距离输电线路上使用高压直流电。因为随着电力电子技术进步，高压直流电在某些输电场景下反而更有优势

一百多年前输掉技术竞争的路线，并没有失去价值，世界上很少有永远正确的方法，更多的是特定条件下更合适的选择，大家试试能否理解交流电原理
