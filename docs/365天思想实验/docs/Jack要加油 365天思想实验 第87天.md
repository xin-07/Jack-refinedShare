# Jack要加油 365天思想实验 第87天

8月28日，365天思想实验，第87天



看着摩天大楼里面，藏着一个几百吨的大球，我（Jack）不禁思考



好好的楼，为什么要挂个球？



别说你不知道这件事🤫

为了让大楼晃的更少😝



摩天大楼太高以后，遇到大风或者地震，本身是会晃的



这个时候，如果楼左右晃，大铁球摆动能产生相反方向的力



工程师再通过阻尼装置，把这些晃动的能量一点点消耗掉。



结果就是，大楼还是会晃，但晃动可以被控制得更小，人待在里面也会舒服很多



这玩意叫调谐质量阻尼器



十多年前第一次理解它的时候，觉得特别有意思



世间万物想要稳定，不是完全没有波动，而是有东西能够对冲波动



工作特别忙的时候，有没有一个东西能把你往回拉



运动？家人？或是阅读？也可能只是晚上出去走半小时



赚钱特别顺的时候，有没有东西提醒你别太骄傲

遇到挫折的时候，又有没有人提醒你坚持下去



现在告诉自己

无论外面的风有多大，都有办法，慢慢稳下来
