今天讲个工程概念：预防性维护

假设你有辆车，可以等发动机坏了，再花几w维修。也可以平时定期换机油、检查轮胎、保养刹车。这些保养看起来是在花钱，而且车开得好好的，为什么还要折腾？

因为工程师知道 很多严重的故障，并不是突然发生的，而是小问题长期积累的结果

很多人只有生病了才开始重视健康，却不愿意每天花20分钟运动。

对于家庭。平时很少交流，等到矛盾爆发才发现彼此已经积累了太多不满

再比如财务。赚钱时觉得一切都好，从来不准备应急资金，知道突然失去收入，才发现根本没有缓冲空间

大智慧是懂得提前减少问题发生的概率。当然，预防不可能消除所有风险，也不是投入越多越好。关键是找到那些成本不高，却能避免重大损失的事情

今天大家检查一下自己的生活，找出一件你一直知道应该做，却因为暂时没出问题而不断拖延的事情
