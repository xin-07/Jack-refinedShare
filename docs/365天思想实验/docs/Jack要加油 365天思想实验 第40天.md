# Jack要加油 365天思想实验 第40天

7月8日，365天思想实验，第40天。



今天我们学一个很简单的物理定律：牛顿第一定律



一个物体，如果没有外力作用，会保持原来的状态

原来静止，就继续静止

原来运动，就继续运动



我(Jack)觉得这条定律放在人生里，也特别有意思



很多人为什么一直没改变？

不是因为他真的不能变

而是因为他一直处在原来的惯性里



以前爱拖延，现在继续拖延

以前乱花钱，现在继续乱花钱

以前不运动，现在继续不运动

以前遇到问题就逃避，现在还是逃避



如果没有一个新的外力，人很容易一直沿着原来的轨道走下去。



所以今天我想让大家思考：你现在的人生惯性是什么？



是越来越清醒，越来越自律，越来越行动？



还是越来越焦虑，越来越懒，越来越逃避？



如果你不主动给自己一个外力，生活大概率不会突然改变。



这个外力可以是一句话。



可以是一本书一个人一次失败🤫
