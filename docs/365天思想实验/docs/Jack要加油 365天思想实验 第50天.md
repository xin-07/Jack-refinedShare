还记得初中化学概念催化剂吗



有些化学反应本来能够发生，但速度很慢。加入催化剂以后，它不会替代反应物，却能降低反应难度，让整个过程更快发生🥺



人生里也有催化剂

好书，可能让你少走几年弯路

好老师，可能一句话就点醒你

积极的朋友，可能在你想放弃时拉你一把

好的环境，也可能让原本很难坚持的事情，突然变得容易很多



很多人改变不了，不一定时因为不够努力，而是一直把自己放在一个不断消耗他的环境



身边的人都在抱怨，你想积极很难

大家都在乱花钱，你想存钱很难

手机里全是垃圾信息，你想专注也很难



今天的任务很简单：给自己增加一个好的催化剂



想读书，就把书放到桌上

想运动，就约一个朋友一起

想早睡，就把手机放到卧室



不要上面都靠意志力硬抗，而是要去找寻你的 催化剂❤️
