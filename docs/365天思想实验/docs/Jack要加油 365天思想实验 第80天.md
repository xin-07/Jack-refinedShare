# Jack要加油 365天思想实验 第80天

8月21日，365天思想实验，第80天



今聊个我（Jack）最近很有感触的事情：爱好！



我把爱好分为两类：创造型 VS 消费型 爱好



看短视频、追剧、逛街、刷新闻、打游戏，这些都是消费型爱好

别人创造东西，你负责消。



那什么叫创造型爱好？

画画、摄影、写东西、弹琴、做饭、木工、种花、拍视频，甚至自己研究一个东西再讲给别人听，都算



能发现区别吗？



消费型爱好结束后，快乐可能也就结束了



而创造型爱好

你做完以后，会留下东西

你画了一幅画

学会了一首曲子

写了一篇文章

拍了一张特别喜欢的片

甚至做了一顿以前不会做的菜

更性感的是，你还多了一点能力



所以我的会员记住：三十五岁前

少追剧、少刷视频、少打游戏



要放松 做什么？创造！



今任务很简单：想一个你愿意培养的创造型爱好

不必能赚钱，也不比要给别人看



今天先花20分钟试一下



记住：

**消费是生存**

**创造是生活！**
