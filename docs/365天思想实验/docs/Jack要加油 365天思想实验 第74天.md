# Jack要加油 365天思想实验 第74天

8月15日，365天思想实验，第74天



今天想跟大家聊三种我（Jack）觉得未来十几年，可能会越来越值钱的能力：阅读、专注、提问



因为AI越来越厉害以后，怎么做这件事会越来越便宜



以前你不会写文章，要学很久

不会做视频，要学剪辑

不会编程，要专门招人



很多事情，你告诉AI一声，它几分钟甚至几秒钟就帮你做了

那人与人以后比什么？



比：你到底知不知道，什么事情值得做

而这背后，其实就是三种能力



第一，阅读

你读得越多，你脑子里的东西越多，你才知道这个世界还有哪些可能



第二，专注

未来最不缺的是信息，最缺的是一个人能不能安安静静，把一件真正重要的事情做几个小时



第三，提问

AI时代，答案会越来越便宜，但好问题会越来越贵



所以今天的任务：找20分钟

别刷短视频，也别回消息

找一篇专属会员，想一个真正和自己未来有关的问题，在拿这个问题去问AI



看看它能不能给你一个以前没想到过的答案
