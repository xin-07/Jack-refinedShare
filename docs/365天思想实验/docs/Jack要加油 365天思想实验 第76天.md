# Jack要加油 365天思想实验 第76天

8月17日，365天思想实验，第76天



上次直播答应写一篇改变人类但没什么技术含量之物——集装箱



别小看这个大铁箱子，它真的改变了全世界的生意

以前一艘船到了港口，人工要把货一箱一袋搬下来，清点、分类，再装到火车或者卡车上

特别慢，特别贵，中间还容易丢东西

后来我们干了一件看起来特别简单的事情：把箱子统一了

不管里面装的是衣服、电视还是玩具，都装进差不多标准的集装箱

轮船、港口、火车、卡车，也全部按照这个标准来



船到了，不用管里面是什么

整个箱子吊起来，直接放到火车或者卡车上就走了



集装箱没有让轮船开得更快

也没有让卡车跑得更快

它真正解决的，是不同环节之间的麻烦



希望对你的启发：很多人想提高效率，第一个想到的是：



我要更努力做得更快。

但真正浪费时间的，有时候根本不是你做得慢，而是你的生活没有标准
