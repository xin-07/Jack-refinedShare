# Jack要加油 365天思想实验 第58天

7月30日，365天思想实验，第58天



今天分享一个耳熟能详的经济学概念：机会成本



很多人以为，花钱才有成本，其实时间也是成本💰



你的每一个选择，都意味着放弃了另外一个选择



比如你今天刷了三个小时短视频，成本不是耗掉了三个小时



真正的成本，是这三个小时，你本来可以读一本书，可以学AI，可以陪家人，可以拍一条视频



这些失去的机会，才是真正的成本🤫



人生也是一样，很多人总觉得自己没有损失什么

其实最大的损失，往往不是做错了，而是一直没有开始



所有Jack为什么一直让大家多阅读、多行动、多拍视频？



因为年轻的时候，最宝贵的不是钱，而是时间



时间一旦过去，再多的钱也买不回来😭



今天的任务很简单：晚上睡觉前，回想一下今天：我今天花时间最多的那件事情，值得吗？
