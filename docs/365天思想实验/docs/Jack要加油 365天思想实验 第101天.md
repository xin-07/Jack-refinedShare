# Jack要加油 365天思想实验 第101天

365天思想实验 第101天



最近看到一封特别鲜为人知的私人电报



1906年12月17日，莱特兄弟给父亲发去信息，大意是：今天上午成功飞了四次，圣诞节回家



人类第一次实现有动力、可控制的持续飞行，给家里报喜，居然就是这么几句话



而第一次飞行，其实只有12秒，大约36米

但就是这12秒，改变了人类的历史



更让我（Jack）感动的是七年后的一个画面



1910年5月25日，父亲米尔顿，第一次坐上了儿子发明的飞机



那时候他已经81岁了，兄弟俩驾驶飞机，父亲坐在旁边



飞机越飞越高，老人不但没有害怕，反而兴奋地对儿子呼喊：再高一点再高一点！



这个画面让我流泪

莱特兄弟原本只是经营自行车店的普通人



他们自己读书、研究、做实验，滑翔机表现不好，就重新研究数据，自己造风洞，测试机翼



他们并不确定能成功，却每天一点一点，把原来不可能的事情，变成了可能



我们呢，何尝不也是一无所有开始的？重要吗
