# Jack要加油 365天思想实验 第28天

6月25日，365天思想实验，第28天。



今天，请把一件事做到“比昨天好一点”

不需要完美也不需要突然做很多❤️



只要比昨天好一点点

昨天刷手机一小时，今天少刷十分钟📱

昨天没有运动，今天走十分钟

昨天乱花钱，今天忍住一次冲动消费💰

昨天情绪失控，今天先停三秒再说话

昨天什么都没学，今天看两页书📕



就如我(Jack)昨天直播说的：改变命运的方式，不是靠某一天突然爆发，而是每天一点点变好



一开始就把目标定得太大必然失败

要一年赚很多钱

要立刻变自律

要马上改变人生

结果三天做不到，就开始否定自己。



但真正长期走出来的人，都不是每天满分的人。

一点点，看起来很慢。

但只要方向对，时间拉长以后，就会变成很大的差距。



今天的任务很简单：选一件你昨天没做好的事，今天把它做的好一点。



借助这个暑假，咱们就能在开学时候显著看到进步🦌
