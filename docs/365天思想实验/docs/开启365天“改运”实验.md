# 命运不是输在能力，而是输在日常：开启365天“改运”实验

刚发关于“运”的文章，大家非常认同。接下来的365天，我(Jack)想做一个专属会员实验。



每天早上，大家起床后，我会发一条当天的“思想浓缩”：可能是一句话、一个提醒、一个小习惯，也可能是我这些年悟出的一点人生规律。



大家当天就按这句话去行动、感受、观察自己。



比如：今天不抱怨，今天夸一个人，今天存一笔钱，今天不刷垃圾信息，今天睡前复盘五分钟，今天把拖延很久的事完成。



我特别想知道，如果一个人连续365天，每天都被积极、清醒、成长型的思想影响，并且真的去实践，一年后运势会不会越来越好？



情绪会不会更稳定？行动力会不会更强？机会会不会更多？身边的人和环境会不会慢慢改变？



很多人的命运不是输在能力，而是每天被焦虑、抱怨、拖延、冲动消费和垃圾信息不断消耗。



如果用365天，一点点把人生扶正，会发生什么？



我想和你们一起做这个实验。参与的小伙伴点个赞，然后每天感受到不同的时候，记得来留言哦。
