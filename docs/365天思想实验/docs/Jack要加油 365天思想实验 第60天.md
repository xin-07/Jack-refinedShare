# Jack要加油 365天思想实验 第60天

8月1日，365天思想实验，第60天



今天讲一个特别重要的投资策略：不要把所有鸡蛋放在一个篮子



很多人第一次听，都觉得是在投资

其实人生也是一样



如果你的快乐，全部来自赚钱

一旦收入下降，你就很痛苦



如果你的价值，全部来自工作

一旦失业，你就开始怀疑人生



如果你的安全感，全部来自一个人

一旦那个人离开，你整个世界都会崩塌



开悟之人，会给自己建立很多篮子



健康是一个、家庭是一个、阅读是一个、赚钱能力是一个朋友是一个、兴趣爱好也是一个篮子



这样就算一个篮子出了问题，其他篮子依然能支撑你



投资是这样

人生更是这样



今天的任务很简单

问自己一个问题：如果我现在失去最依赖的那一样东西，我还剩下什么？



如果答案让你有点不安。

































那就从今天开始，建立第二个篮子🧺



悄悄分享给早起的你：真正的安全感是拥有，无论发生什么都还能重新开始的能力
