# Jack要加油 365天思想实验 第56天

7月28日，365天思想实验，第56天



今天说一个很重要的概念，叫反馈回路

你做一件事，得到一个结果。这个结果，又会影响你下一次怎么做



比如一个孩子，考试考好了，被老师表扬了，他更愿意学习。学得越多，成绩越好；成绩越好，有越愿意学习，Jack高二逆袭就是如此🦌



这就是一个正反馈

反过来也一样



一个人开始熬夜，第二天没精神，不想运动，工作效率下降，晚上压力更大，又继续熬夜

最后就进入了一个越来越差的循环



我为什么一直让大家每天阅读、每天留言、每天去行动？

不是因为一天能改变什么

而是我希望大家尽快进入一个好的反馈回路



你今天读了一篇文章，有一点收获

明天愿意再读一篇

慢慢开始思考，开始分享，开始拍视频

别人给你一个点赞，一个评论，你更有动力继续做



时间一长，这个回路就会推着你往前走



厉害的人，很多时候不是考意志力坚持

而是他们已经进入了一个好的循环，后面的路，会越来越顺🎉
