# Jack要加油 365天思想实验 第78天

8月19日，365天思想实验，第78天



今天分享农业中特古老的智慧——轮种

就是一块地，不要年年只种同一种东西

比如今年中玉米，明年换成大豆，再换其他作物



为什么要这么麻烦？

因为不同植物，从土壤里拿走的东西不一样，有些植物甚至还能帮助土壤恢复一部分养分



如果你永远只种一种作物，短期看起来效率很高，时间长了，土壤里的某些养分越来越少，病虫害的问题也可能越来越严重



我(Jack)也是退休之后自己种地才发现，要长期收获大，不能只想着：今年多收一点

还要想：这块地五年以后还能不能继续种



说到这难道你还没悟嘛！



很多人找到一件有效的事情以后，就会拼命重复

工作有效，就天天工作

拍视频有效，就天天拍

赚钱有效，就把所有时间都拿去赚钱

短期看，你的产量很高



但时间长了人也会像土地一样被耗掉

注意力没了，身体累了，新想法也越来越少，然后焦虑一批



给你们任务：想想最近是否在重复消耗自己某一种能力？
