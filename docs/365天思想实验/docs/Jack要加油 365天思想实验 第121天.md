# Jack要加油 365天思想实验 第121天

做大一件事情不是靠一次特别用力，而是持续在对的节奏上用力



365天思想实验，第121天



今天讲一个物理学的现象：共振



很多物体都有自己的自然振动频率。如果你不断给它一个周期性力量，这个力量的频率刚好接近它的自然频率，哪怕每一次推的不重，振动也可能越来越明显



荡秋千就是最简单的例子，你不需要每次都用尽全力。只要在对的时间，轻轻推一下，在推一下，秋千就会越荡越高



很多人特别喜欢突然努力。星期一熬夜学习五个小时，然后三天不碰。突然运动两小时，然后一个星期不去。突然连续发十条内容，接下来半个月又停了。



其实能走很远就要找到自己的节奏，每天读3页，运动20分钟

每月固定输出几次。力量可能不大，但节奏一直在



时间长了以后，前一次的积累会帮助下一次，你就开始进入自己的共振



今天周一，别想着这一周一开始就把所有事情做完

先给自己找一个节奏



然后。在。对的时间，一次一次推下去❤️
