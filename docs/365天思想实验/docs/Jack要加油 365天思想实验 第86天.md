# Jack要加油 365天思想实验 第86天

8月27日，365天思想实验，第86天



从北瀑布公园出来一路都是电网

大家是否想过为什么远距离输电，要用高压电？



电压越高，是不是电跑得越快？

不是 哈哈

真正的原因，是为了减少损耗



你可以理解成，同样要运送这么多电，如果电压提高，需要的电流就可以变小



而电流越大，电线发热造成的损耗就越大



所以把电压升高以后，就能让电跑几百公里、甚至更远的时候，少浪费很多能量



等电送到城市附近，再通过一个变电站一层层把电压降下来，最后才送到我们家



人生哲学也是如此

想提高结果，不会更努力

每天多工作两个小时

少睡一点

把事情做得更快一点



就像为了输送更多电，拼命增加电流



结果呢？



电送到了，人也快烧坏了



所以不要蛮力，而是想办法提高电压



知识、工具、方法、判断力，还有你调用别人能力的能力就是电压



好好思考再回答我：有没有什么办法，可以用更小的损耗，完成同样的事情
