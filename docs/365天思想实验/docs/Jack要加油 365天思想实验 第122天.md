# Jack要加油 365天思想实验 第122天

你未必不够努力，而是站错了用力的位置



365天思想实验，第122天



今天讲一个物理原理：杠杆



为什么同样一个很重的东西，用手直接抬特别费劲，但换一根足够长的杆子，用在不同的位置，结果可能完全不一样。



有些人特别努力，每天工作十几个小时，但一直在重复别人很容易替代的事情



另外一个人可能没有工作那么久，却花时间学习AI，建立流程、训练表达、积累作品



几年以后，两个人的结果完全不同。不是后面那个人一定更努力。

而是他慢慢找到了自己的“杠杆”



读书、工具、互联网、好的团队都是杠杆

甚至你以前做过的内容、积累的信誉、认识的人，都是！



今天思考：有没有什么东西，可以放大自己，同样花一个小时，你可以重复完成一件事情。也可以用这一个小时，把它做成一个模块，让以后每次都节省半小时
