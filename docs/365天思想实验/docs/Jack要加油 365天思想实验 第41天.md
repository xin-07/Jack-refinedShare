# Jack要加油 365天思想实验 第41天

7月9日，365天思想实验，第41天



昨天搞牛顿今天搞个化学概念：活化能



简单说，就是很多化学反应不是你把材料放在一起，它马上就会发生。



它需要先跨过一个能量门槛，这个门槛，就叫活化能



这个和你是不是一样，不是不想改变，但就是启动不了



知道要存钱，要运动，要读书，要做自媒体，要好好工作，要控制情绪，但就是开始不了。



为什么？



因为改变也有活化能



最难的不是坚持一年，而是今天先开始。



一想到要跑五公里，就不想动了。

一想到要读一本书，就觉得太累了。

一想到要拍视频，就开始害怕别人评论。



所以今天不要给自己定大目标。



只做一件事：把启动成本降到最低



想运动，就先穿上鞋下楼走五分钟

想读书，就先读一页

想存钱，就先记一笔账

想做内容，就先发一句话

想改变关系，就先发一句问候



把它拆到小到不能再小

然后立刻完成第一步🤫
