如何知道自己的能力边界

365天思想实验，第149天

周六大家问的，我（Jack）的答案是两个词：概率和非线性

什么意思？假设你现在最多能做20个引体向上，是不是意味着第21个就做不到？可能今天状态好，你能做22个；明天没睡好，只能做18个

所以能力边界不是一条固定的线，而是随着状态、环境和训练不断变化的，你每天在做的一切决定都会影响边界的概率

再比如你连续发100条视频，都没什么流量，第101条却突然有了几十万播放。难道你的能力一夜之间提高了几十倍？

因为很多事情的结果不是线性的。你的能力、内容质量、平台推荐和观众反应，共同决定了最后的结果

能力影响成功的概率，但不能保证结果。一次成功不代表你具备了稳定的能力，一次失败也不能证明你没能力

我的建议是：不断进行成本可控的小实验，记得过程，分析结果，再调整方法

能力边界不是想象出来的，是在一次次尝试中逐渐发现，又在一次次成长中不断改变！
