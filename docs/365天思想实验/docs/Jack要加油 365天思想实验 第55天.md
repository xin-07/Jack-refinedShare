# Jack要加油 365天思想实验 第55天

7月27日，365天思想实验，第55天



今天讲一个特别容易骗过大脑的思维陷阱，叫幸存者偏差



什么意思呢？

就是我们看到的，往往都是成功的人

看短视频，看到的是爆款

看创业，看到的是上市公司

看投资，看到的是赚了几十倍的人



于是很多人就觉得，成功好像也没那么难

但真正的问题是，那些失败的人，你根本看不到



就像二战的时候，很多战机飞回来以后，机翼上全是弹孔。有人说，把这些地方加厚装甲就行了



后来有个统计学家说，不对

真正应该加厚的，是那些没有弹孔的地方



因为中弹那里还能飞回来，说明问题不大。那些没飞回来的飞机，很可能就是打中了那些没有弹孔的位置



这就是幸存者偏差✈️



所以以后是投资、创业，还是做自媒体，都不要只研究成功更要研究那些失败的人，到底踩了那些坑



今天的任务简单：想一你最近特别羡慕的事

别着急着问什么成功，先问一句那些失败的。人可能失败在哪？



少犯致命错最智慧！
