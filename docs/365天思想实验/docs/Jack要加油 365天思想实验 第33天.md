# Jack要加油 365天思想实验 第33天

7月1日，365天思想实验，第33天



今天，也是我(Jack)正式开始“六年之约”里，鼓励大家勇敢做自媒体的第一天



我想请大家做一件事：勇敢发出你的第一条视频



不要怕自己普通，没人看，怕别人笑话或者怕自己表达不好。



所有大v，都是从第一条很普通的视频开始的🎆



很多普通人总觉得自己还没准备好，觉得别人会评价自己甚至觉得等以后更厉害了再开始。



自媒体这件事，最重要的不是一开始多完美，而是你敢不敢先站出来



从今天开始，我给专属会员一个特别福利🧺

会员可以每天来评论区打卡-比如：我今天发了一个视频 花了多久拍摄 多久编辑 记录下自己的工作强度和投入时间。



这不仅仅是给自己加油，也是在记录自己的成长轨迹



更重要的是，当你每天出现，别人就会慢慢注意到你，会点进你的主页看看。



在专属会员区的评论里，有人会因为一句话、一条视频，开始关注你🦌
