爱上会计学

365天思想实验，第158天

会计学里最基础的公式：资产 ＝ 负债 + 股东权益

资产，就是公司的资源 现金、房子、设备
负债，就是公司欠别人的钱或者需要履行的义务
股东权益，就是资产减去负债，属于股东的部分

直播时候说了复式记账，就是每一笔交易，都要从相互对应的账户记录它的影响

公司借来100万元，现金增加100万元，同时负债也增加100万元

这套思维特别适合用来分析人生。你接受一份高薪工作，收入增加了，但可能也牺牲了陪伴家人的时间

你接了一个新项目，机会增加了，但同时也增加了责任和压力。你获得了更多粉丝，但也需要投入更多时间维护信任。

当然人生不是严格的会计报表，那我们可以借用这种思路

很多人活的越来越累就是因为只计算得到的好处，却没有计算背后的代价

今天大家找一个最近让你特别兴奋的机会，在纸上写两栏
左边写：我能得到什么？右边写：我要付出什么，又会承担哪些风险
