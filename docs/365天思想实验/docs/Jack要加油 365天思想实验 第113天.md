# Jack要加油 365天思想实验 第113天

365天思想实验，第113天



今天讲一个心理现象：目标梯度效应

人里目标越近，往往越有动力



比如一张集10个章就送一杯咖啡的卡，刚盖第一个章的时候，你可能没什么感觉



可当上面已经有8个章了，你会突然特别想把最后两个集完



跑步也一样，跑10公里，刚开始跑2公里的时候觉得还远，到了9公里，你明明已经很累了，反而更愿意坚持一下，就剩最后一公里了



这就是为什么很多长期目标很难的，反而不是最后 而是最开始。因为终点离你太远了



我要坚持六年，我要读200本书，我要做1000条视频



光听这些数字，人就已经累了



所以真正聪明的做法，不是天天盯着六年以后，而是把终点拉近



六年太远，就先看这一年，一年太远，就看这个月，一个月还远，就看这一周



像我们现在的行为实验，不用想我以后是不是一辈子每天运动？



先完成这七天，等七天结束，再决定下一步



因为人需要不断看到我快到了！



开始吧🎉
