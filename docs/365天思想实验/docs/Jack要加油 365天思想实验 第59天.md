# Jack要加油 365天思想实验 第59天

7月31日，365天思想实验，第59天



今天讲一个投资里特别重要的。概念，叫安全边际

假设有一座桥，最多只能承重10吨



你的卡车刚好10吨，你每次过桥都会提心吊胆



但如果你的卡车只有5吨，你是不是轻松很多？



投资一样，智慧的投资者，想的不是能赚多少钱

而是先问自己一句：如果我看错了，我最多亏多少？



市场跌的时候，别人害怕

你却因为提前留好了现金，可以慢慢买



市场波动的时候，别人睡不着

你却因为留足了安全边际，晚上照样睡得很好



今天的任务很简单



想想你的生活里，有没有什么事情，一点安全边际都没有



所以Jack一直跟大家说，要存钱，要有现金流，不要all in，不要杠杆
