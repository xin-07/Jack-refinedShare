# Jack要加油 365天思想实验 第109天

365天思想实验，第109天



今天讲一个很容易忽略的东西：延迟反馈



就是很多事情

今天做了，结果不会今天出现，甚至出现坏结果



你今天运动20分钟，晚上不会突然变瘦

读30页书，不会突然变聪明

拍一条视频，可能只有没人看

但这些事情真正的结果，往往要过一段时间才会慢慢出现



反过来也一样

熬夜一次，好像没什么

连续几天不运动，也感觉不到多大区别

多刷一个小时手机，当下甚至还挺舒服



所以人最容易犯的错误就是用今天的感受，判断一件长期的事情值不值得



好的行为，因为奖励来得太慢，我们容易放弃

坏的行为，因为代价来得太慢，我们又容易继续



一个人想长期做成事情，不能只依靠结果给自己反馈

你得学会给过程反馈！



比如我们这周每天运动20分钟

今天体重没变化没关系，但今天这20分钟，我完成了吗？



生活里很多真正重要得东西，都是先慢慢积累得



我（Jack）的智慧就是 不看短期结果，只记录行动！
