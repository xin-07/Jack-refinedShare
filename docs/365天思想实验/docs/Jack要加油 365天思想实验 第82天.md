上海在长江入海口

纽约天然港湾，又能通过哈德逊河连接内陆

伦敦也是沿着泰晤士河发展起而来



what the H**



因为以前运大量货物，水路通常比陆路便宜得多



但一艘远洋轮船，不可能把货直接送到你家里

船到了港口以后，货得卸下来，放进仓库，然后再换成内河船、火车、卡车，继续往其他地方运



所以这些地方慢慢就聚集了码头、仓库、工人、银行、保险、贸易公司



工作机会来了人也就来了

人来了，餐馆商店住房学校就跟着来了

城市就这样一点点长大了



所以这里面性感的地方是什么？



大城市，不一定长资源最多，而是在资源必经之地！



你悟到什么了吗？



你的价值不在你多努力 而在选择



如今的时代，价值就产生在连接里面

银行连接有钱的人和需要钱的人

平台连接商家和消费者

媒体连接复杂的信息和普通人



我（Jack）每天读商业、历史、科技、制度，然后把复杂的东西重新整理，再用大家听得懂的话讲出来



这其实就是在做一座“认知港口”

所以以后别傻读书



你还可以想想：学到的东西，能不能连接到另外一群需要它的人？



今天的任务：找一条你今天看到的、比较复杂的信息

然后想办法用一个简单的例子，把它讲给家人或者朋友听



如果对方一下就听懂了，你就完成了一次连接



记住：未来特别有价值的人，不一定是什么都知道的人

而是那些能把知识、人和机会连接起来的人
