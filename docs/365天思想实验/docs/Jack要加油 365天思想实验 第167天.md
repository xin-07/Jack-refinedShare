# Jack要加油 365天思想实验 第167天

毁掉你的3个习惯

365天思想实验，第167天

昨天直播说起，今总结如下

1.遇到事第一反应是抱怨。工作顺利怪老板；收入最高怪环境；事情失败怪运气。你仔细想想，抱怨完以后事情解决了吗如果，你永远只研究别人做错了什么，就很难发现自己还能改变什么。

真正有价值反应，不是谁为你的环境负责，而是现在的我还能做些什么？

2.总想着准备好了再开始。想做自媒体，觉得自己表达不好。想学习一项新技能，觉得基础还不够。结果准备了三年，却一次都没行动。有没有想过能力不是准备好了才开始，而是开始以后才慢慢获得的。那些成本可控的尝试，请早点开始

3.把别人的评价当成自己的价值。有人评价两句，就难过好几天。别人夸你几句，又觉得自己特别厉害。如果你的快乐和自我认同，完全取决于别人怎么看你，那你就很难掌握自己的生活

请记住，改变命运，不是从增加多少好习惯开始，而是从停止重复那些伤害自己的行为开始❤️
