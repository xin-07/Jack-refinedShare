# Jack要加油 365天思想实验 第9天

365天思想实验，第9天

今天，请完成一件你拖延了很久的小事。



不要挑最难的。

就挑最简单的那个。

可能是回复一条消息。

可能是整理一个抽屉。

可能是预约一次体检。

可能是看完一本书剩下的十几页。

可能是给家里打一个电话。

可能是把那份一直没开始的计划写下第一行字。



很多人不是输给了困难。而是输给了拖延。

因为每拖延一天，内心就会多一点负担。



拖延一周，会开始焦虑。

拖延一个月，会开始逃避。

拖延一年，甚至会怀疑自己。



最可怕的不是事情本身。

而是那件事一直压在心里，持续消耗你的能量🤫(能量是幸福的秘诀)



很多时候，完成一件事情获得的快乐，远远大于完成这件事情本身的价值。



因为你会重新获得掌控感。

而掌控感，是自信的重要来源。



今天的任务很简单。



完成一件拖延已久的小事。🎊
