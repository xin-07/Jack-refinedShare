# Jack要加油 365天思想实验 第35天

7月3日，365天思想实验，第35天



今天大家做一件很简单的事：让家里人开心一下



不用搞得很隆重，也不用花多少钱✌

给爸妈打个电话，陪孩子玩十分钟，给老婆或者老公倒杯水，主动洗个碗，或者就说一句话：辛苦了



你身边最亲近的人，如果每天都被你冷脸、抱怨、不耐烦对待，你的能量很难真的好起来。

家里天天吵，天天冷战，天天互相消耗，人出门做事也没劲。



家里哪怕普通一点，但大家愿意互相体谅，互相支持，人心里就会稳很多。



当然，我不是说所有家庭关系都能一下子变好，也不是让你去讨好谁。



就是今天先做一件小事，让家里某个人因为你，心情稍微好一点。



你会发现，很多好运不是从外面来的。是你先把身边的关系一点点扶正以后，整个人的状态慢慢变顺的。



想改变命运，想遇到贵人，想运势变好，不妨从身边人爽一下开始🤫
