# Jack要加油 365天思想实验 第127天

不必一个人什么都会，而是越来越多人愿意和你一起把事情做好



365天思想实验，第127天



今天讲个生物学里特别有意思的现象：共生



自然界里，很多生物并不是靠自己单独活得最好，而是在长期相处中，彼此获得好处。比如有些植物的根会和真菌形成合作。植物把光合作用产生的有机物提供给真菌，真菌则帮助植物从土壤里获得更多水分和矿物质



双方做自己擅长的事情，最后都活得更好，年轻的时候，我们觉得什么东西都要自己会就厉害。不会剪视频，就学剪辑，不会设计，就学设计，不会销售，就继续学销售。但一个人时间永远有限



事情做大以后，你必须学会找到那些和你能力互补的人。你擅长表达，有人擅长技术。你擅长想内容，有人擅长把它做成产品



你又流量，别人有服务能力。两个人合作以后，都比原来一个人做得更好，这就是现实世界里的共生



而且好的关系也不是一方永远索取！

今天思考，合作时我从别人这得到什么？我有能给别人什么？
