365天思想实验，第173天



今天我（Jack）在跑步机上突然想到一个行为学现象：现在偏误



假设我问你，今天拿100，还是一年以后拿110？很多人会选今天拿100块



但如果换成十年后拿100块，或者十一年以后拿110块，你可能更愿意多等一年



同样是多等一年，我们对眼前的等待却更加敏感。这就是现在偏误。我们往往高估眼前的快乐，低估未来的收益



生活中很有用，比如你知道运动好，却总觉得明天再开始。你知道存钱会增加未来的自由，却忍不住把钱花在眼前的享受



为什么？因为刷手机的快乐，现在就能得到。但运动、学习和储蓄的回报，可能需要几个月甚至几年才能体现。



那怎么办



我能帮大家的是让你不依赖意志力，而是主动改变奖励系统



所以现在给大家的个人记录的小程序，试着去记录🙏



比如运动以后，记录今天完成的训练，让自己马上看到进步。学习以后，把学到的知识讲给别人，获得及时反馈。



储蓄以后，记录资产的增长，让长期目标变得可以看见。当然，未来也存在不确定性，享受当下也可以，关键是不要让眼前的欲望，永远替未来的自己做决定



今天的任务很简单。找一件你一直想做，却总是拖延的事情。想办法给它设计一个今天就能获得的小奖励💪



我希望大家记住：真正好的个人成长系统是要让今天的自己愿意不断行动。



因为改变命运的关键是你能不能把我说的这些道理，变成今天真正的行动🎁加油
