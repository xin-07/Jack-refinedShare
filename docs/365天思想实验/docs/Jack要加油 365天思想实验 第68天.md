今天咱们讲一个健身概念，叫超量恢复



什么意思呢？



你去健身，练完以后其实不是马上变强的



刚练完的时候，你反而是累的，力量下降了，肌肉也需要恢复



但是你给身体足够的营养和休息，它恢复以后，有机会比原来的状态再好一点



训练，再恢复，再训练，再恢复



慢慢地，人就变强了



很多人有一个误区，觉得努力就是每天把自己逼到极限



学习工作赚钱都不能停



甚至休息一天都会有负罪感



被我说中的点赞👍评论



但强大的人，不是永远不累，而是知道什么时候该努力，什么时候该恢复



休息不是浪费时间。



高质量的休息，本来就是努力的一部分



今天正好是周末



如果你最近真的很累，今天就别逼自己一定要完成多少事情



好好睡一觉，出去走走，陪陪家人，吃顿饭，把手机放下来一会儿
