# Jack要加油 365天思想实验 第73天

8月14日，365天思想实验，第73天



今天聊一个很多人都问过我（Jack）的问题：Jack，到底怎么才能变得自信？



直出答案：自己不是每天对着镜子告诉自己我很棒，我可以

真正的自信，是你做过一些事情以后，慢慢开始相信自己



我今天敢直播，敢表达自己的观点，不是因为我天生自信

而是因为我已经讲过太多次，写过太多东西，也说错过、做错过很多次，然后再一点点改回来



自信来自实力，而实力来自一次次兑现对自己的承诺



你说今天读书30分钟，结果真的读完了

你说这个月存3000块，真的存下来了

你一直不敢拍视频，今天终于把第一条发出去了



每完成一次，你其实都在给自己的大脑增加一个证据：你看，我说到的事情，我真的能做到



那一个人为什么会越来越不自信？

有时候还真不是因为别人打击你，而是你答应自己的事情，一次又一次没做到



今天任务，给自己一个很小的承诺，然后今天一定把它完成
