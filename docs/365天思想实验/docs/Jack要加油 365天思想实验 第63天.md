# Jack要加油 365天思想实验 第63天

8月4日，365天思想实验，第63天



今天讲一个经济学概念：沉没成本



就是已经花出去，而且再也拿不回来的成本



比如你花300块钱买了一张电影票



电影看到一半，发现特别难看



很多人会硬着头皮把它看完



因为觉得：票都买了，不看就亏了



其实，从你坐进电影院那一刻开始，300块钱就已经拿不回来了

真正应该问自己的，不是：我已经付出了多少？



而是：我接下来怎么做，对未来最好？



很多人不愿意离开一份工作，不是因为工作好，而是因为已经干了十年

很多人不愿意结束一段关系，不是因为幸福，而是因为已经付出了太多

很多人投资亏了，不愿意止损，不是因为看好，而是因为已经亏了很多



可过去的成本，不应该决定未来的选择



未来应该由未来决定



今天的任务：想一件你最近一直放不下的事情，然后问自己一句；如果今天是第一天接触它，我还会不会做同样的选择？
