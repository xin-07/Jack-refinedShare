# 《思考，快与慢》｜第四周总结

《思考，快与慢》第四周总结



因为前面我们讲的是怎么想，而这一周讲的是一个更现实的问题：为什么一碰到钱、得失和风险，我们就很难保持理性？



一、损失厌恶

赚1000块的快乐，往往抵不过亏1000块的痛苦。所以很多人赚钱时急着落袋为安，亏钱时反而死扛，因为不愿意承担损失。



二、禀赋效应

一个东西只要变成我的，我们马上就容易高估它。自己的房子觉得更值钱，自己买的股票总能找到更多优点



三、沉没成本

电影已经不好看了，因为票买了还要坚持看完。真正应该问的不是过去投入了多少，而是从今天开始，还值不值得继续？



四、框架效应

救活200个人和400个人挂，本质可能是同一个结果，但不同的表达方式，却会改变我们的选择。所以真正独立思考的人，要学会把一个问题正反面都看



五、心理账户

工资赚了舍不得花，投资赚的却觉得是白来的

其实钱没有颜色，是我们的大脑给它分了不同账户



这一周的五篇，我（Jack）特别希望大家保存下来





**真正的理性，不是让自己变成一个没有情绪的人，而是在情绪最强烈的时候，依然有能力重新问一遍问题。**



亏钱的时候，问：

**“如果今天重新开始，我还会买吗？”**

舍不得卖的时候，问：

**“它是真的有价值，还是因为它是我的？”**

不想放弃的时候，问：

**“如果过去归零，我今天还会继续吗？”**

别人告诉你一个结论的时候，问：

**“如果换一种说法，我还会这么想吗？”**

花钱的时候，问：

**“不管这笔钱从哪里来，它现在是不是仍然属于我的资源？”**



这就是第四周真正想教我们的东西：



**钱不会让人变得不理性，真正让人失去理性的，是我们面对钱时产生的那些“看不见的心理反应”。**



而真正的成熟，不是**没有偏差**。

而是：



**知道自己一定会有偏差，所以在做重要决定之前，主动检查自己的大脑。**
