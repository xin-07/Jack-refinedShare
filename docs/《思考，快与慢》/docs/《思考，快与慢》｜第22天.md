# 《思考，快与慢》｜第22天

《思考，快与慢》

第二十二天：为什么刚赚到钱以后，人反而更敢冒险？



想象一个场景

你带着1000块去玩一个游戏。

第一轮特别顺，你赚了500块，现在手里变成了1500块



接下来有人告诉你：要不要拿刚才赚的500块再试一次？成功了再得500块，失败了这500就没有了



如果这是你出门幸幸苦苦赚来的500块，很多人可能舍不得

但因为这是刚刚赢来的500块，你很容易产生一种感觉：

反正是刚赚的，就算没有了，我也没少什么



于是你愿意承担平时根本不会承担得风险



可大家仔细想想



现在你手里得1500块，是不是已经全部属于你了？



那500块和你原来得1000块，真的有区别吗？



生活里也一样



投资刚有了一笔不错得收益，有些人马上开始提高风险；生意这个月多赚了几万，就觉得可以大胆花一点；甚至打牌刚赢了一些钱，也更容易继续加码



今天思考：为什么刚刚赚到的钱，我们会觉得更敢花





**不要问“这笔钱是怎么来的”，而要问“现在我总共有多少钱？”**

然后再问：



**“如果这些钱今天全部重新交给我，我会怎么配置？”**



**让自己按照真实的财富和未来的风险做决定，而不是按照大脑制造出来的心理故事做决定。**



人并不是简单地“害怕亏钱、喜欢赚钱”。

而是：

**在不同的心理账户、参照点和情绪状态下，会用完全不同的规则评价风险。**
