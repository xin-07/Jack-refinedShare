# 《思考，快与慢》｜第10天

《思考，快与慢》|第十天：为什么事情发生以后，我们总觉得我早就知道?



今天先问大家一个问题。



有没有这样的经历？



世界杯结束以后，很多人说：我早就知道冠军会是他们



股市涨了以后，很多人说：我当时就知道会涨



一家公司成功以后，很多人说：这家公司一看就会成功



可如果把时间拨回事情发生之前，真的有那么多人敢下这个判断吗？



今天的问题来了：为什么一件事情发生以后，我们总觉得它是“必然”的？



我们是真的提前预测到了，还是因为知道了结果，大脑偷偷改了自己的记忆？



想一想，你有没有说过这样一句话：我早就知道会这样。



晚上，Jack来聊聊他的看法❤️







我觉得第10天最大的启发是：



**不要用今天已经知道的结果，去评价过去的自己。**



因为我们已经知道结果。



可站在当时，未来还没有发生，我们拥有的信息有限，也不知道哪一种可能会成为现实。



**所以评价一个决定，不能只看最后结果。**



第10天也提醒我们，要对未来保持一点谦逊。



因为事情发生以后，很多人都会觉得“早就知道”，但未来真正到来之前，往往没有那么确定。



所以，这一天最值得记住的一句话是：



**结果会让过去看起来很简单，但未来发生之前，从来没有那么确定。**



真正成熟的思考，不是事情发生后证明自己早就知道，而是在结果还不确定的时候，承认未知、尊重概率，并持续改进自己的判断。
