# 《思考，快与慢》｜第19天

《思考，快与慢》第十九天：同一件事，换个说法，就能改变你的选择！

做一个选择题

假设有一种病，预计会有600个人挂掉

现在有两种治疗方案：

方案A：确定可以救活200个人

方案B：有1/3的可能600个人全部救活，但也有2/3的可能一个都救不了

如果让你决定，你选哪个？

我(Jack)会选A

因为听到确定救活200个人感觉至少能保住200条生命，比较安心

现在我把同样的问题换一种说法

还是这600个人，还是刚才两个方案：

方案A：最终会有400个人挂了

方案B：有1/3的可能600个人全部救活，但也有2/3的可能一个都救不了

你现在还选A吗？

我会改选B

性感的东西来了：前后两个问题的结果其实完全一样，只是换了一种说法，为什么事实完全没变，只换表达方式，我们的选择就能变？

好好想想：

我们平时做的决定，到底有多少真的是自己想清楚的，又有多少是被人怎么说影响的？

<br />

**事实不会因为换一种说法而改变，但我们的感受和选择，却可能因此改变。**

真正的理性是：

**“我知道自己会受到影响，所以我会主动换几个角度再看一次。”**

**不要只听别人怎么讲，要学会重新定义问题。**

因为很多时候，真正影响我们选择的，并不是：

“事情到底是什么。”

而是：

“事情被放在了什么框架里。”
