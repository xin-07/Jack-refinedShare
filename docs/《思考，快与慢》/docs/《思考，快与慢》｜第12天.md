# 《思考，快与慢》｜第12天

读懂《思考，快与慢》|第十二天：为什么成功的人不一定告诉了你全部真相？

如果有人告诉你：照着我这样做，一年赚了一千万

你会不会很想学习他的方法？

那如果我再告诉你，当时有10000个人都用了同样的方法，最后只有他成功了，另外9999个人失败了。

你还会觉得这个方法靠谱吗？

今天的问题来了：

为什么我们总是看到成功的人，却很少看到失败的人？

那些最后没有成功的人，他们是不是也曾经和成功者一样努力、一样坚持、一样相信自己的方法？

如果我们只研究成功案例，会不会得出完全错误的结论？

大家想一想

你最近学到的一个成功经验，有没有可能只是因为失败的人，没有机会站出来分享？

<br />

第11天讲：

不要用结果判断决策质量。

第12天进一步告诉我们：

不要只看成功结果中的案例。

因为成功案例本身已经经过了一轮筛选。

留下来的，都是赢家。

失败的人已经消失了。

所以：

**成功案例 ≠ 完整真相。**

**不要只研究赢家，也要研究失败者**。

我们可以学习成功者的方法，但不能简单复制成功者的结果。

真正成熟的思考方式应该是：

看到一个成功案例时，不只是问：

“他做对了什么？”

还要问：

“有多少人做了同样的事情却失败了？”

“这个方法成功的概率是多少？”

“如果重新来100次，这个结果还能出现吗？”

**不要只研究成功的人，因为失败的人可能才隐藏着真正的规律。**
