# 《思考，快与慢》｜第10天答案

结果一出来，大脑就会忽悠我们：这一切本来就很明显



《思考，快与慢》第十天答案：这种现象叫做后见之明偏差



事情发生之前，未来充满了各种可能



事情发生之后，大脑会自动把那些失败的可能性删掉，只留下最后发生的那个结果。于是我们就会产生一种错觉：



这不是很明显吗？



但真正的世界，从来不是这样运行的



投资最容易掉进这个坑



看到一家公司后来涨了十倍，我们会觉得："当时买进去多简单"



可如果真的回到那一天，你会发现，当时同样有很多人认为它会失败，也有很多看起来更优秀的公司后来却消失了



所以，一个人真正的能力，不应该只看结果，而应该看做决定的时候，依据是否充分，逻辑是的完整，风险是否考虑到了



这也是我(Jack)做投资一直坚持的一件事



我不会因为一次赚钱，就觉得自己的判断一定正确；也不会因为一次失败，就否定整个方法



一次结果，可能只是运气。长期重复做出高质量决策才是真正的能力！
