# 《思考，快与慢》｜第7天答案

今日答案：大脑不是根据真实概率判断，而是根据想起来有多容易判断



《思考，快与慢》把这种现象叫做可得性偏差

就是越容易想到的事情，我们越觉得它发生概率高



天天报道空事，我们就觉得坐飞机很危险；其实从统计上看，飞机依然是最安全的交通工具之一



短视频天天推豪车、豪宅、创业成功，我们就容易觉得别人都发财了；可平台只是把最吸引眼球的内容不断推到你面前，并不是代表它是整个世界



投资也是一样



牛市的时候，你每天看到的都是赚钱故事，容易觉得赚钱很简单；熊市的时候，你每天看到的都是悲观消息，有容易觉得机会已经没有了



你的情绪，很多时候不是来自现实，而是来自你每天接触的信息



所以Jack一直鼓励大家多读书，少刷无意义的短视频



一本书，会帮助你理解世界的规律；而碎片化的信息，很多时候只会放大你的情绪



你每天看什么，你就会以为世界是什么样子👍
