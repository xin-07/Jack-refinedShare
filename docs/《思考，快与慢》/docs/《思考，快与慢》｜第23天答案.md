# 《思考，快与慢》｜第23天答案

《思考，快与慢》

第二十三天答案：因为系统1最喜欢根据眼前发生的事情，迅速产生情绪和判断

市场越热闹，你每天看到的都是别人赚钱、价格上涨和乐观预测

系统1会立刻告诉你：大家都在赚钱，我是不是错过了什么？

于是害怕错过的情绪越来越强，反过来也一样

市场表现不好 时，坏消息越来越多，大脑最容易想到的都是风险。明明你以前认真研究过的东西，现在也开始觉得哪里都不对

读到这

问问自己，市场最疯狂的时候，你还能不能按照原来的规则做事

我(Jack)喜欢提前制定自己的规则

什么情况下参与、投入多少、什么情况下什么都不做，最好在自己情绪平稳的时候想清楚

因为真正到了所有人都兴奋或者所有人都害怕的时候，再让自己保持理性，几乎不可能

点赞👍留言告诉我 最近你冲动做的一件事 并且复盘一下

<br />

**市场越疯狂的时候，越不能临时要求自己保持理性，而应该提前把规则制定好。**

**真正的理性，不是你在市场疯狂的时候还能告诉自己“我要冷静”。**

而是：

**在自己还冷静的时候，就已经替未来那个可能失控的自己做好决定。**

最终我们追求的不是：

**“我永远不会冲动。”**

而是：

**“我知道自己会冲动，所以我提前给自己装一个刹车。”**
