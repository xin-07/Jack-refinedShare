# 《思考，快与慢》｜第5天

读懂《思考，快与慢》第5天：为什么越熟悉，我们越容易相信？



今天我(Jack)想让大家判断一句话



一天喝八杯水，是每个人都必须做到的。



你觉得是真的吗？



很多人第一反应会觉得是真的，因为这句话我们听过太多次了



可实际上，不同人的体重、运动量、饮食和环境都不同并不存在适用于所有人的“八杯水标准”



今天的问题来了：



为什么一句话，只要重复足够多次，我们就更容易相信它？



它是真的，所以我们相信？



还是因为我们听得太多，大脑就默认它是真的？



想一想，你有没有相信过一些后来被证明是错的观点，只因为它们一直出现在你的生活里？
