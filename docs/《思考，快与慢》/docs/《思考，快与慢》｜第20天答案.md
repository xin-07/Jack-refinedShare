# 《思考，快与慢》｜第20天答案

《思考，快与慢》第二十天答案

没想到大家都知道答案了！

我们的大脑会把不同来源的钱装进不同的账户

理论上，工资赚的1000块和彩票中的1000块没有任何区别。

但大脑不会这么想

我们会给钱贴标签：这是工资、这是奖金、这是投资赚的、这是旅游预算

一旦进入不同的心理账户：我们对钱的态度就变了

投资里特别明显

有人股票赚了1万块，马上敢拿5000块消费，因为觉得反正是赚来的

但问题是：当这1万块已经属于你以后，它和你工资账户里的1万块没有区别

从今天起不要把钱当钱 而是这么想：它们都是我的资源

不管是工资、租金、投资收益还是意外收入，都应该思考：这笔钱放在哪里，对我未来最有价值？

钱不会因为来得容易，就更容易被消费

所以今天记住一句话：当我们开始把所有钱都当成同一种资源，你对消费、储蓄和投资的判断，可能都会发生变化🎉

<br />

**钱不会因为来得辛苦，就更有价值；也不会因为来得容易，就更适合消费。**

真正成熟的财富观不是：

**“这笔钱是怎么来的？”**

而是：

**“我现在拥有多少资源？这些资源怎样配置，才能让我未来拥有更多选择？”**

所以这一天真正想让我们改变的，不只是**花钱方式。**

而是：

**开始把所有的钱，看成同一种资源。**

工资、奖金、投资收益、意外收入——来源不同，但最终都属于你的财富
