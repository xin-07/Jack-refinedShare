# 《思考，快与慢》｜第24天

《思考，快与慢》

第二十四天：怎样强迫自己多想一步？



做一个小实验

假设你正在开车，突然有人从你旁边强行插到你前面

你的第一反应可能是：这人怎么开车的！



甚至马上想按喇叭、骂两句



但如果过几秒，有人告诉你：他车里有个孩子突然受伤了，现在正赶去医院



你的情绪是不是可能马上就变了？



性感的地方就在这！

事情没有变，变的是你知道的信息更多了



第一秒，我们的大脑已经迅速给出了答案：这个人没素质

但多给你几秒，我们可能就会想到：有没有其他可能？



我是不是还不知道全部事实？

我的第一反应一定对吗？



生活中很多错误都是如此

看到一句话，马上生气

看到一个news，马上站队

看到一个机会，马上行动

看到别人一个行为，马上给这个人下结论



今天思考：既然我们知道大脑的第一反应经常不可靠，有没有办法让自己在重要事情上面强制慢下来？



有啥办法，可以让自己在情绪最强的时候，不立刻做决定？







**越重要、越情绪化、越不可逆的事情，越要慢。**



拥有了一种非常重要的能力：

**不让自己的第一反应直接控制自己的行动。**



很多时候，真正改变结果的，不是你多聪明，而是：

**你有没有给自己多几秒钟，看到第一反应之外的另一种可能。**
