# 《思考，快与慢》｜第16天

读懂《思考，快与慢》|第十六天：为什么亏1000块，比赚1000块更难受？

今天我们先做一个选择题

现在桌上放着两个盒子。第一个盒子打开以后，你百分之百拿走500块钱

第二个盒子打开以后，你有50%的概率拿走1000块，50%的概率一分钱都没有

你选哪个？

很多人会选第一个，因为500块已经到手了，不想冒险

现在换一个场景

你已经亏了500块

接下来也有两个选择

第一个，确定再亏500块

第二个，50%的概率一分钱不再亏，50%的概率再亏1000块

这时候，很多人原本不喜欢冒险的人，反而开始愿意选第二个

为什么？

明明面对的金额和概率差不多，为什么一旦变成“亏钱”，我们的性格好像突然变了？

今天的思考：你是否有过

股票赚了20%的时候，赶紧卖掉先落袋为安

可股票亏20%的时候，却开始告诉自己再等等，至少等它回本

以及为什么？

晚上我（Jack）的答案会让你彻底成为投资小能手

<br />

**人不是害怕亏钱本身，而是特别害怕“确认自己亏了”。**

所以我们才会出现一个非常奇怪的投资现象：

**赚20%时，急着落袋为安；亏20%时，却告诉自己再等等。**

而真正成熟的投资者，需要不断提醒自己：

**过去已经发生的盈亏，不应该决定今天的选择。**

今天真正应该问的是：

**“如果重新来一次，我还会做同样的决定吗？”**

这也是第16天真正想教我们的——**不是让我们变得没有情绪，而是在情绪最强烈的时候，重新拿回决策权。**
