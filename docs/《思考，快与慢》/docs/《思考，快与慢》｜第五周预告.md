# 《思考，快与慢》｜第五周预告

下周预告｜知道自己会犯错以后，怎么才能真的改变？



过去四周，我们已经讲了20篇《思考，快与慢》



从系统1和系统2，到锚定效应、确认偏误、幸存者偏差，再到这一周的损失厌恶、沉没成本、框架效应……

所以下周开始，我们要进入我觉得更重要的部分——怎么把这些知识真正用到自己身上。



下周五篇：

我觉得下周会是整个系列一个很重要的转折点🤫



前20天，我们一直在认识自己的大脑

不是知道自己有什么弱点，而是开始给自己的弱点设计一套系统。
