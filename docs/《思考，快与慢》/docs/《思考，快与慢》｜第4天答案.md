# 《思考，快与慢》｜第4天答案

今天答案（特殊原因写成了两篇）：注意力是一笔有限预算，你给了这里，就无法同时给到那里



《思考，快与慢》告诉我们，系统2要工作，就必须消耗注意力



走路、呼吸、看熟悉的东西，系统1可以自动完成。

但计算一道题、理解一段难懂的话、控制自己的情绪，都需要系统2参与



但是，系统2能够使用的注意力非常有限



所以我们不是不会同时做很多事，而是大脑会在不同任务之间快速切换。每切换一次，都要重新进入状态，也会丢失一部分信息



Jack以前总觉得时间最珍贵，后来越来越发现，真正稀缺的不是时间，而是高质量的注意力。一天有十个小时，不代表你真的拥有十个小时。如果其中八个小时都被消息、短视频和情绪打断，真正能够创造价值的时间可能只有几十分钟



这也是Jack为什么提出“刷到我的视频，就立刻去做正事”。就是在帮大家把注意力，从系统1喜欢的即时刺激，重新交还给系统2



你把注意力长期放在哪里，你的人生就会慢慢在哪里开花👍
