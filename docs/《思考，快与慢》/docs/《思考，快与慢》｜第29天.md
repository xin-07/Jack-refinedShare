# 《思考，快与慢》｜第29天

《思考，快与慢》



第29天：为什么改变自己，不需要更强的自律？



这期是我最有感觉的，假设有两个人，都决定晚上睡觉前不刷手机



第一个人把手机放在枕头旁边



每隔几分钟屏幕亮一下，消息来了、视频推送来了



他不断告诉自己：别看，忍住



坚持了二十分钟，最后还是拿起了手机



第二个人



他只是睡觉前把手机放到了另一个房间，床边只留了一本书



结果一个月以后，反而是第二个人坚持得更好



谁更自律？



再比如，你想减肥，家里桌子上每天都放着零食；你想读书，书放在柜子最里面，手机却永远在手边；你想运动，每次都要临时决定什么时候去



你觉得做不到，是因为自己意志力不够



今天大家好好想想：如果一个环境每天都在诱惑你做错误的事，那你能对抗的了吗？



真正厉害的人，是更能忍，还是根本不给自己那么多需要忍的机会？



点赞留言告诉我你的答案





**改变行为最好的方法之一，是改变行为发生的条件。**



**有没有可能，不是我不够自律，而是我的环境一直在诱导我做错的事情？**



真正厉害的人，不是每天都能战胜诱惑，而是知道：

**什么诱惑根本没必要让自己去面对。**



**不要把人生变成一场意志力的战争；能用环境解决的问题，就不要每天靠自律硬扛。**
