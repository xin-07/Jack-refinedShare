# 《思考，快与慢》｜第11天

读懂《思考，快与慢》|第11天：为什么结果好，不代表决策一定对？

如果一个人闭着眼睛过马路，结果刚好没被车撞，你会不会说：他的决定很聪明？

应该不会。

因为我们都知道，结果虽然没出事，但这个行为本身风险很大。

可是在现实生活里，我们却经常这样判断。

一个人重仓买了一只股票，后来涨了很多，大家都觉得他眼光真好。

一个人创业成功了，大家都觉得他当初每一步都走对了。

一个人押中一次机会，大家就开始把他说的每一句话都当成真理。

今天思考：

为什么我们总喜欢用结果，反过来评价一个决定是否正确？

结果好，就说明当时一定对吗？

结果不好，就说明当时一定不对吗？

大家可以想一想：你有没有因为一次赚钱，就觉得自己特别厉害；或者因为一次失败，就全盘否定自己？

<br />

**不要用一次结果，给自己或别人下最终结论。**

一次赚钱，不一定证明自己特别厉害；一次亏损，也不代表自己完全不行。

如果因为一次成功就过度自信，可能会把运气误认为能力；如果因为一次失败就全盘否定自己，也可能错过一个原本正确、只是暂时没有得到好结果的方法。

**成熟不是只看结果，而是愿意回头检查过程。**

**好结果不一定证明决策正确，坏结果也不一定证明决策错误；真正重要的，是在结果出现之前，你有没有做出高质量的判断。**
