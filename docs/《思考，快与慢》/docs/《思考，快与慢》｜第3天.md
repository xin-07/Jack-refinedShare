《思考，快与慢》第3天：第一印象为什么这么可怕？

请大家想象两个人🫂

第一个人：聪明、勤奋、冲动、挑剔、固执✅

第二个人：固执、挑剔、冲动、勤奋、聪明❌

这两个人的性格词完全一样，只是顺序不同😄

可是很多人看到第一个人，会觉得他虽然有缺点，但总体很有能力；看到第二个人，却会觉得他很难相处。

为什么只是把顺序换了一下，我们对一个人的感觉就完全不同了？

今天的问题是：为什么最先出现的信息，会影响我们对后面所有信息的判断？

我们在认识一个人、看一家公司、刷到一个视频时，是先看事实再下结论，还是先产生感觉，再替这个感觉寻找证据？

大家可以回想一下，你有没有因为第一眼喜欢一个人，就觉得他做什么都不错；或者第一眼讨厌一个人，后来他说什么你都觉得不对？

晚上我（Jack）分享我的理解

<br />

我的感受是：

很多时候，我们以为自己是在客观看待事实，其实是在不断证明自己的第一印象。

这一天最大的提醒，不是告诉我们"第一印象一定是错的"，而是提醒我们：

第一印象只是一个起点，不应该成为最后的结论。

以后无论是认识一个人、分析一家公司，还是评价一件事情，我都希望自己能够多问一句：

我现在的判断，是基于完整的事实，还是只是因为第一印象，让我下意识地只相信支持它的证据？
