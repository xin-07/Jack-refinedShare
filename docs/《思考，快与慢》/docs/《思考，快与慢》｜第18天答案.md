# 《思考，快与慢》｜第18天答案

思考快与慢 第十八天答案：过去已经付出的成本，不应该决定你未来的选择



所谓沉没成本，就是已经花出去、拿不回来的钱、时间、精力和情感



最可怕的是，大脑很容易为了证明过去没有白费，继续投入更多东西



电影票已经买了，所以硬着头皮看完



股票已经亏了，所以死等回本



一段关系已经很多年了，所以不敢重新开始



但真正理性的判断应该是：从今天开始，继续做这件事，还值不值得？



我做投资的时候，也经常提醒自己，不要被过去的买入价绑架



你买贵了，市场不会因为你买贵了就补偿你



你投入了很多时间，一个错误项目也不会因为你努力过，就自动变成好项目



智慧的人，不是从来不犯错，而是发现方向错了以后，敢及时止损



所以以后遇到这种情况，不要再问：我以前已经投入了多少？



而要问：如果今天重新开始，我还会不会做同样的选择？
