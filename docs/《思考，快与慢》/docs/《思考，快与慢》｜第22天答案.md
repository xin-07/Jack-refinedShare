# 《思考，快与慢》｜第22天答案

今日答案：因为大脑会把刚赚到的钱，偷偷放进一个特殊的账户

行为经济学里经常把这种现象称为赌场前效应

当一个人刚刚赚到500块，大脑很容易产生一种错觉：这是额外得到的，就算没有了，我也只是回到原点

所以我们对这500块的风险容忍度，会明显提高

但从理性的角度看，钱一旦到了你的手里，就已经是你的财富

刚赚到的500块，和辛苦工作赚到的500块，购买力没有任何区别

这也是为什么我(Jack)觉得，人在特别顺的时候反而要提醒自己

连续几次判断正确，很容易让人把运气当成能力；账户越来越好看，也容易让人不知不觉提高风险

好的系统，不会因为今天特别顺，就突然改变自己的原则

❤️分享一个秘密：

一个人的风险承受能力，不应该由最近赚了多少钱决定，而应该由自己的长期目标、资产情况和最坏结果决定

真正的理性，不是顺的时候敢不敢冲，而是顺的时候，依然记得自己原来的规则

<br />

**人最容易失去理性的时刻，不一定是最倒霉的时候，也可能是最顺的时候。**

亏钱的时候，我们至少知道自己害怕。

但连续赚钱以后，最危险的是：

**我们开始相信自己不会错。**

所以真正成熟的状态不是：

“我最近运气很好，所以我可以冲。”

而是：

**“正因为最近特别顺，所以我更要检查自己的规则有没有改变。”**
