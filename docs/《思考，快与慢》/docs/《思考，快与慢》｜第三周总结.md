# 《思考，快与慢》｜第三周总结

读懂《思考，快与慢》｜第三周总结

这一周的五篇，我觉得特别值得大家反复看，因为它们都在提醒我们：人最容易高估的，就是自己的判断力

第一结果偏见 一次赚钱，不代表决策一定正确；一次亏钱，也不代表当初一定做错，结果里永远混着运气

第二幸存者偏差 我们总能看到那个创业成功、投资翻十倍、做自媒体逆袭的人，却很少看到背后成千上万个用类似方法失败的人

第三基率忽视 一个故事再精彩，也只是一个样本。真正做决定之前，不仅要问有没有人成功，更要问“100个人里面到底有几个能成功

第四小数定律 连续三次赚钱，就觉得自己懂投资；连续五条视频没火，就觉得自己不适合自媒体。样本太少的时候，运气最容易被误认为规律

第五过度自信 知道一点的时候，我们最容易觉得世界很简单；真正知道得越来越多，反而会越来越敬畏不确定性

这周总结一句话：不要急着证明自己是对的，要先想办法降低自己犯错的代价

留言哪篇最有启发

<br />

**少看结果，多看过程。**

**少看个案，多看概率。**

**少凭几次经历，多给自己更多样本。**

**少证明自己正确，多检查自己可能哪里错了。**

而最后才是：

**真正的成熟，不是我越来越相信自己一定是对的，而是我越来越清楚：我可能错在哪里，以及即使错了，我该怎么办。**

这也正好承接第15天的答案——**真正的成长，不是越来越自信，而是越来越清醒。**
