今日记住：**真正有用的方法，不是让自己永远理性，而是给重要决定增加一道程序**

系统1不可能关闭

秘诀就是主动邀请系统2参与

看到别人插车，你还是会生气

看到坏消息，你还是会紧张

遇到特别诱人的机会，你还是会兴奋

真正能改变的，是第一反应出现以后，不要马上行动

大智慧就是给重要决定增加一道程序！

给大家三步：

一、等一等

情绪特别强的时候，能明天决定的事情，今天尽量不决定

二、写下来

为什么要做？最坏结果是什么？什么情况下说明自己判断错了？很多模糊的感觉一写出来，就会发现漏洞

三、找反方

如果我特别想做一件事，我会主动想：什么证据能够证明我可能错了？

我（Jack）大量阅读、写东西，包括每天和大家讨论这些问题，本质上也是在训练自己不要只凭第一感觉生活
