# 《思考，快与慢》｜第4天

《思考，快与慢》第4天：注意力为什么如此珍贵？



大家有没有发现一个很奇怪的现象？



开车在熟悉的路上，听音乐、聊天都没问题。可一旦到了陌生地方，要找一个很难发现的门牌号，很多人会下意识把音乐关小。



音乐变小以后，眼睛也没有看得更清楚，为什么我们还是会这么做？



再比如，你正在心算17×24得时候，旁边有人突然和你说了一段话。等你算完以后，可能根本不知道他刚才说了什么。



今天得问题来了：



为什么我们明明有眼睛、有耳朵，却无法同时认真处理很多事情？



我们平时所谓的“一心多用”，你有没有一边刷手机一边陪孩子、一边开会一边回信息，最后看起来做了很多事，其实什么都没真正做好？



晚上我（Jack）分享我的理解。





**未来最稀缺的能力，可能不是信息获取能力，而是保持注意力的能力。**



现在这个时代，信息太多了。



手机、短视频、消息通知，都在不断争夺我们的注意力。



很多人不是没有时间成长，而是每天的注意力都被切碎了。



这也让我想到Jack之前讲的：

未来最值钱的能力，不是会不会用AI，而是专注力。



因为AI可以帮助我们快速获取信息、完成任务。



但是，如果一个人没有持续思考的能力，没有长时间专注的能力，即使拥有再强的工具，也很难创造真正有价值的东西。



所以第4天给我的启发是：



不要问自己：



“为什么我总是无法集中注意力？”



而应该问：



“我的环境，是不是一直在主动消耗我的注意力？”



真正厉害的人，不一定比别人聪明，而是更懂得保护自己的注意力。



比如：



工作时关闭通知；

阅读时远离手机；

重要事情一次只做一件；

给深度思考留固定时间。



因为注意力在哪里，时间就在哪里。



而时间长期投入在哪里，人生最后就会走向哪里。
