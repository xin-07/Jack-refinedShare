今日答案：第一印象一旦形成，大脑就会自动替它补充证据



《思考，快与慢》里讲到一个非常重要的现象，叫光环效应



当我们先知道一个人聪明、勤奋，后面再看到他固执、挑剔时，大脑会先替他解释：他可能只是有原则、有要求。



可如果我们先知道他固执、挑剔，后面即使看到他聪明、勤奋，也容易觉得：中国人虽然有能力，但太难相处。



事实没有变，变化的是信息出现的顺序。



Jack做自媒体以后，对这一点感受特别深。一个人第一次刷到你的视频，如果觉得你真诚、靠谱，后面会愿意认真听你说什么；如果第一眼就产生反感，哪怕你讲的是对的，他也很难听进去。



所以第一印象会影响别人如何理解后面的全部



同样，我们要经常提醒自己：我现在看到的，真的是完整的事实，还是只是在为最初的感觉找理由？



理性的判断，不是没有第一印象，而是愿意在新证据出现之后，重新认识一个人、重新修改自己的结论🦌
