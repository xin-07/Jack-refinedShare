# 《思考，快与慢》｜第17天

读懂《思考，快与慢》

第十七天：为什么东西一旦属于你，就突然变贵了？



先做个实验



假设我(Jack)给一半的粉丝，每个人发一个价值50块钱的杯子，另外一半人什么都没有



过十分钟，我问拿到杯子的人：多少钱你愿意买这个杯子？



很多人可能会说：60块、80块、甚至100块



然后我再问那些没有杯子的人：多少钱你愿意买这个杯子？



他们可能只愿意出30块、40块

明明是同一个杯子，为什么拥有它的人觉得值80块，没有它的人却只觉得值40块？



杯子没有发生任何变化



唯一改变的，就是两个字：我的



生活中里这种事情更多

一套自己住了十年的房子，总觉得应该比邻居家的值钱；自己买的股票跌了，总觉得市场低估了它；甚至家里一个几年不用的东西，别人真要拿走的时候，又突然舍不得



大家思考下：为什么一样东西只要变成“我的”，我们的大脑就会自动提高它的价值？





**东西一旦属于我们，大脑就会自动给它加价，因为失去它会产生痛苦。**



所以成熟的人会不断提醒自己：



“这是我的，所以我喜欢它；还是因为它真的有价值？”



投资如此。

房产如此。

创业如此。

人生选择也是如此。



真正的理性，不是不拥有任何东西。

而是：

**拥有以后，依然有能力客观看待它。**
