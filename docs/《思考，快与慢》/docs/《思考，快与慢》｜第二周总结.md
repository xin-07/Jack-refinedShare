# 《思考，快与慢》｜第二周总结

《思考，快与慢》|第二周总结



这周认识了自己大脑最容易掉进去的五个陷阱



第一，锚定效应。

很多时候，第一个数字就会影响我们的判断。房价、股票、商场打折......真正重要的不是它以前多少钱，而是它今天到底值多少钱。



第二，可得性偏差

大脑不是根据真实概率判断世界，而是根据什么最容易想起来。短视频刷多了，你会觉得全世界都在发财



第三，代表性偏差

我们总喜欢根据“像不像”下结论，而不是根据概率和实施。一家公司讲AI，不代表它一定值得投资。



第四，确认偏误。

很多时候，我们不是寻找真相，而是在寻找支持自己观点的证据。真正的成长，往往开始于愿意认真听不同的声音。



第五，后见之明偏差

事情发生以后，我们总觉得“我早就知道会这样”。但真正重要的，不是结果，而是当时做决定的逻辑是否合理。



总结：真正限制一个人的，不是知识，而是思维习惯



要愿意听反对自己的声音 要敢于怀疑自己 再寻找事实！







**真正限制一个人的，可能不是知识，而是思维习惯。**



这周真正训练的，不是“记住五个心理学名词”，而是建立一种新的思考习惯：



遇到一个看起来很确定的结论时，多问几句：



**我是不是被第一个信息影响了？**

**我看到的是完整事实，还是平台反复推给我的内容？**

**我是在分析概率，还是只觉得它很像？**

**有没有证据证明我可能错了？**

**如果结果还没有发生，我真的会这么确定吗？**



第二周学到的五个陷阱，最终都指向同一个能力：



**保持开放，尊重事实，承认未知，并在新证据出现后，愿意修改自己的判断。**
