# 《思考，快与慢》｜第23天

《思考，快与慢》

第二十三天：为什么市场越热闹，我们越容易做错决定？

今天想象两个场景

第一个：你关注的一项资产，连续几个月价格不断走高

打开手机，到处都是有人讨论它。有人晒自己赚了多少钱，有人说这可能是十年一次的机会，还有人告诉你：再不上车就来不及了

你本来没打算参与

看了一个星期以后，你开始心痒

看了一个月以后，你终于忍不住加入了

第二个：场景正好相反

市场连续几个月表现不好

新闻越来越悲观，身边的人也开始担心，网上甚至有人说：“这次和以前完全不一样”

原本你觉得很好的资产，现在突然怎么看都不顺眼了

奇怪的是：资产本身可能没有发生那么大的变化，真正变化最大的，却是你的情绪

今天去思考：

为什么价格越高、大家越兴奋的时候，我们反而越想参与

而真正便宜、所有人都害怕的时候，我们又不敢行动？

到底是我们在判断市场，还是市场在控制我们的情绪？

晚上我(Jack)给答案 看完我相信你能理解巴菲特了

<br />

**市场最危险的时候，可能不是你完全不知道发生了什么，而是所有人都在告诉你应该怎么想。**

真正的独立思考，有时候不是找到一个和别人不同的答案

而是：

**即使所有人都在给你答案，你依然愿意停下来，自己重新算一遍。**

正好回到《思考，快与慢》最开始讲的东西：

**系统1喜欢跟随熟悉、快速、明显的答案；真正重要的决定，需要给系统2留一点时间。**

所以第23天我觉得可以留下一个特别简单的提醒：

**市场越热闹，越要问自己：**

**“如果没有人告诉我这是机会，我自己还会觉得它是机会吗？”**
