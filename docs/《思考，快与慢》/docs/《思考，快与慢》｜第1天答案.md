《思考，快与慢》整本书，都围绕一个核心观点展开：人的大脑有两套思考系统

第一套，我把它叫自动驾驶模式

它反应快，不需要思考，看到危险会立刻躲开，刷到短视频会马上点进去，别人夸你会开心，别人骂你会生气😤

第二套，叫深度思考模式

它负责分析、规划、学习和长期决策，但有一个缺点——特别耗能 特别懒🥱

所以很多时候，并不是你不知道什么是对的，而是你的大脑默认会选择最省力、最快速的那条路🤔

未来几周，我们不是要学习更多知识，而是学习如何认识自己的大脑，了解它才能让它舒服有愿意让我们舒服

因为当你知道它为什么会犯错，你才能慢慢减少犯错。

智慧不是从不犯错，而是懂得设计自己的生活，让自己哪怕都用第一套系统都能更容易做出正确的选择🎉

<br />

**很多时候，我们真正要改变的，不是自己，而是自己的环境。**

**真正有效的方法，是让正确的事情变得更容易，让错误的事情变得更困难。**

**高手不是没有人性，而是懂得顺着人性设计自己的生活**
