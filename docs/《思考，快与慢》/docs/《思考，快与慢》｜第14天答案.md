# 《思考，快与慢》｜第14天答案

第十四天《思考，快与慢》答案：小数定律——样本越少，大脑越容易把随机波动误认为规律⚡️



简单说，就是我们总是高估小样本的可信度



明明只发生了几次，大脑却急着总结规律



连续赚钱几次，就觉得自己有投资天赋；连续视频没火，就觉得自己不适合做自媒体；孩子几次考试不好，就觉得孩子没有学习能力



但真实世界不是这样运行的🥰



很多事情短期看，运气成分非常大。尤其是投资、自媒体、创业，这些领域本来就有很多随机性。短期结果不好，不代表方法错；短期结果很好，也不代表你已经掌握了规律



我（Jack）为什么一直让大家做六年之约❤️



因为真正有价值的东西，都不能只看三五天、三五次、三五个月。你要看长期，看重复，看在不同环境下还能不能成立



投资也是一样。一个策略最重要的不是某一次赚了多少钱，而是长期重复下来，能不能控制风险、保住本金、稳定提高胜率



分享一句心里话：智慧的人，会给自己更多样本，也给别人更多时间🙏
