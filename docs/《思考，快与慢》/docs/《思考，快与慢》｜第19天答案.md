# 《思考，快与慢》｜第19天答案

《思考，快与慢》第十九天答案——框架效应



很多时候，我们不是在对事实做决定，而是在对说法做决定



刚才两个问题，本质上完全一样



确定救活200个人，其实就意味着确定有400个人挂

但当我们听到救活200个人时，大脑关注的是得到，所以更愿意选择确定的结果

当我们听到400个人挂时，大脑关注的变成了损失，这时候很多人反而愿意冒险，希望一个人都不要死



事实没变，概率没变，只是换了一个说法，我们的选择就变了



生活里这种事情特别多。



商家说成功率90%，和告诉你失败率10%，感觉不一样；投资里说从最高点已经跌了50%，和说“现在依然是50倍市盈率”，感觉也完全不同



听到能赚多少，就问问最多会亏多少

听到成功率多高，也看看失败率多高



所以要经常提醒自己：遇到重要决定，一定要试着把问题反过来说一遍





**事实不会因为换一种说法而改变，但我们的感受和选择，却可能因此改变。**
