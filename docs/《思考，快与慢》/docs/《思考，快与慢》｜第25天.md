# 《思考，快与慢》｜第25天

《思考，快与慢》

第二十五天：为什么越重要的事情，越不能临场决定？



假设有两个人



第一个人每天早上起床以后再决定：今天要不要运动？今天要不要读书？今天要不要存钱？今天要不要少刷手机？



状态好的时候，它上面都能做到



但累了、忙了、心情不好的时候，就会告诉自己：今天算了，明天再开始



第二个人不一样



她提前规定好：每周固定运动几次，每个月收入进来先留下一部分，每天固定时间阅读，睡觉前手机不放在床边



她每天并没有比第一个人更自律



大家发现区别没：很多事情，更本不需要当天再做决定？



投资也是一样

市场平静的时候，你觉得自己什么都想明白了



可真正所有人都兴奋或者害怕的时候，你还能保证自己按照原来的想法做吗？



今天思考：既然我们已经知道，大脑会偷懒、会冲动、会被情绪影响，那为什么还要把人生中最重要的决定，交给当时那个动物般的自己？







**“我知道未来的自己会累、会懒、会冲动、会害怕、会兴奋，所以我要趁现在冷静的时候，提前帮未来的自己做一些决定。”**



**真正强大的自律，不是每次都战胜当下的自己，而是提前设计一个不容易被当下的自己改变的人生。**



《思考，快与慢》这25天真正开始从：

**“认识大脑”**

走向：

**“设计人生。”**



因为最终我们追求的，从来不是成为一个**永远理性的人**。



而是成为一个：



**即使某一天不理性，也不容易因为一次冲动，把自己长期积累的一切毁掉的人。**
