第2天答案：大脑偷懒，是因为真正的思考非常消耗精力。



昨天我们讲到，大脑有两个系统。系统1反应快、凭直觉、自动运行；系统2负责计算、分析和自我控制，但它启动起来更慢，也更费力。



刚才那道球拍和球的问题，系统1看到“1.1元”“相差1元”，马上就给出了0.1元这个答案。这个答案听起来很顺，大脑便懒得再检查一次。



生活中也是如此。看到一个人穿着体面，我们容易认为他很成功；看到一只股票连续上涨，我们容易认为它还会继续涨；看到一个视频播放量很低，我们容易判断这个内容没有价值。



很多错误不是因为我们笨，而是因为系统1先给出了答案，系统2又懒得审核。



我（Jack）每天阅读、写内容、直播，本质上就是逼自己的系统2工作。很多事情只有写下来、讲出来、反复追问，才会发现原来判断里有多少漏洞。



所以遇到重要决定时，不要只问：“我的感觉是什么？”



再多问一句：这个答案，是我认真想出来的，还是大脑随手递给我的
