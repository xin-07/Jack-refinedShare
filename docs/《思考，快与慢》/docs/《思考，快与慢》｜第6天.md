# 《思考，快与慢》｜第6天

读懂《思考，快与慢》｜第六天：为什么一个数字，会影响你的判断？

今天先回答一个问题。

如果我先问你：

世界最高的红杉树，有1200米高吗？

然后再问你：

那你觉得它真正有多高？

虽然1200米这个数字明显是错的，但很多人猜出来的答案，会比没听过1200米的人高得多。

为什么？

明明知道1200米不对，它为什么还能影响我们的判断？

生活中也是一样。

一件衣服原价999美元，现在299美元，你会不会觉得特别划算？

一套房子挂牌200万美元，现在降到150万美元，你会不会觉得捡了便宜？

一只股票最高涨到300美元，现在跌到140美元，你会不会觉得已经很便宜了？

今天的问题来了：

为什么一个原本毫不相关的数字，会悄悄影响我们的判断？

晚上，我分享《思考，快与慢》里的答案。

<br />

我觉得第6天最大的启发是：

很多时候，真正影响我们决定的，不是事实，而是参照物。

以前我总觉得，自己做决定是经过认真思考的。

但现在发现，很多判断其实早就被第一个数字、第一个价格、第一条信息悄悄影响了。

比如买东西时，我们容易关注"打了几折"，而不是"值不值这个价格"；投资时，我们容易记住历史最高价，而不是分析现在的价值；甚至评价一个人的薪资、房价，也会被最开始听到的数字影响。

所以，我觉得锚定效应最重要的提醒就是：

**不要急着围绕第一个数字做判断，而是先问自己：如果我从来没有见过这个数字，我会怎样评价这件事情？**
