# 《思考，快与慢》｜第13天答案

第13天答案：大脑喜欢故事，但世界遵循概率



《思考，快与慢》里非常重要的概念，叫基率忽视

就是我们特别容易被一个精彩的故事吸引，却忽略了整体的统计概率



比如，一个人买彩票中了五百万，你会觉得买彩票好像很有希望

但真正应该看的，不是这一个中奖的人，而是几千万哥没有中奖的人



投资也是一样



看到一个人买了一只股票赚了十倍，很容易觉得：我也能



但真正应该问的是：



过去十年，有多少人这样做？最后真正赚到钱的比例是多少？



我（Jack）做投资最重视一件事，不是听故事，而是看概率



因为故事能造梦，概率才能保护人



所有，以后别人讲得多精彩，你都记得多问一句：

这是一个故事，还是一个规律



很多人一辈子输就输在，把个例当成规律，把运气当成能力。智慧的人，先看整体，再看个体



大家还记得我直播说过一句话：个体无法预测 但是形成整体后可以被预测🤫
