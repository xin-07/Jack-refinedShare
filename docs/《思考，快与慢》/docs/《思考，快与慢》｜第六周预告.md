# 《思考，快与慢》｜第六周预告

《思考，快与慢》

这周预告｜智慧的人，如何训练判断力？



前几周我们认识了大脑的各种弱点，也学习怎么用规则和系统减少犯错



这周，我们再往前走一步：怎么真正提高自己的判断力？



这周五篇：

一：为什么重要决定不要只听自己的？



二：为什么一定要把决定写下来？



三：为什么做长期决定，要忘掉今天的情绪？



四：为什么改变自己，最有效的方法可能不是自律？



五：怎样建立自己的人生决策清单？



这周我希望大家提前准备一个东西：找一个你最近正在纠结的重要决定，留言告诉我



这周总结的时候跟着这五篇，把它重新拿出来，一步一步重新想一遍



昨晚和大家喜欢的主播连线，不知道大家是否从我们互相交流中看到了判断力的价值



学《思考，快与慢》真正的目的，不是以后能说出多少个心理学名词



希望你和我（Jack）一起学习，潜移默化的慢慢认知提升，看透这个世界只能转的规律



九月一号正式开始解读《穷爸爸富爸爸》





**知道大脑会犯错以后，如何建立一套更好的决策系统**



最终目标是成为一个：

**即使面对不确定，也能不断做出高质量决定的人。**
