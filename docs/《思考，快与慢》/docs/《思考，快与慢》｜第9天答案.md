# 《思考，快与慢》｜第9天答案

今日答案：很多时候，我们不是在寻找真相，而是在保护自己原来的判断



这现象叫确认偏误（上次在365天思想实验也说过，你看🎉猜不到一个月，一个知识点就在两个维度被学到）



当我们先相信一件事，大脑就会自动注意支持它的信息，忽略反对它的信息。即使遇到不同观点，我们也不是认真研究，而是第一时间寻找漏洞



投资里这件事特别危险



买入一只股票以后，很多人会不断看利好消息，却不愿认真研究公司的风险。因为一旦承认自己可能错了，就意味着要面对亏损，也意味着自己的判断并没有想象中那么厉害



生活中也是一样。你一旦认定一个人不好，他做什么都像有错；一旦认定自己不行，别人夸你，你也会觉得只是客气



Jack现在看到和自己不同的观点，会先问一句：有没有一种可能，对方看到了我没看到的东西？



愿意听反对意见，不代表没有立场，而是你更在乎事实，而不是面子。



智慧的人，不是一直正确，而是发现自己错了以后，能够尽快修改答案
