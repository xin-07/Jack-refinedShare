# 《思考，快与慢》｜第14天

读懂《思考，快与慢》|第十四天：为什么三五次成功，就让人以为自己掌握了规律？

假设有一个人，第一次买股票赚钱了

第二次，又赚钱了

第三次，还是赚钱了

这时候，他很容易产生一种感觉：我是巴菲特了

于是他开始加大仓位，开始相信自己的判断，甚至开始给别人讲经验

但问题是，如果把时间拉长一点看呢

也许他只是刚好赶上了牛市。也许他买的几只股票刚好在风口上。也许他的方法换一个市场环境，就完全失效了！

一个人连续发了三条视频爆了，就觉得自己掌握了流量密码；一个销售连续签了三个客户，就觉得自己特别懂人性；一个家长用某种方法教育孩子，刚好孩子听话了几次，就觉得这套方法一定有效。

今天的思考来了：为什么人特别容易根据很少的几次经历，就总结出一个很大的规律？

三次成功，真的能证明一个方法有效吗？

五次失败，真的能说明一个人不行吗？

留言：你有没有因为短期几次结果，就过早相信或者否定过一件事？

<br />

**人不是因为不会思考而犯错，而是因为太着急总结规律。**

我们的大脑非常害怕"不知道"，所以只要看到几个成功或失败的案例，就迫不及待地下结论。

但真正成熟的人，会对少量样本保持警惕。

他们不会因为几次成功就骄傲，也不会因为几次失败就放弃，而是愿意让时间积累更多证据，再判断一个方法到底有没有长期价值。

所以，第14天最值得记住的一句话可以总结为：

**一次、三次、五次，都可能只是巧合；真正的规律，需要大量数据和长期验证。**
