# 《思考，快与慢》｜第17天答案

《思考，快与慢》第十七天答案——禀赋效应



拥有一个东西以后，放弃它会被大脑理解成一种损失



一个杯子还不属于你的时候，你只会想：它到底值多少钱？

可一旦这个杯子属于你，再让你卖掉，大脑想的就变成了：我要失去一个已经属于我的东西



昨天我们讲过，人的大脑特别讨厌损失

所以很多东西一旦拥有，我们就会不知不觉高估它



投资和房产里尤其明显

自己买的房子，总觉得装修好、位置好，应该比市场价更贵；自己持有的股票，也特别 容易不断给它找优点



所以我(Jack)觉得一个特别好的办法就是，经常假装自己今天第一次看到这个资产



忘掉买入价，也忘掉它是不是你的，然后问自己：如果今天我手里只有现金，我还愿意用现在的价格买它吗？



如果答案是否定的，那你舍不得卖的原因，可能不是它真的那么好。

只是因为——它已经是你的了





**人不是因为东西有价值，所以珍惜它；很多时候，是因为它属于自己，所以觉得它有价值。**



真正成熟的人，会经常提醒自己：



“这是我的，所以我喜欢它；还是因为它真的值得拥有？”



真正的成长，不是不拥有，而是在拥有以后，依然保持重新判断的能力。
