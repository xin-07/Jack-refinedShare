读《思考，快与慢》第一天



如果我问你一根问题：为什么很多人知道正确答案，却还是会做错事？



明知道刷短视频浪费时间，却一刷就是几个小时。

明知道应该存钱，却总忍不住买一些并不需要的东西。

明知道健身有好处，却总想着明天再开始。

甚至投资也是一样。涨的时候觉得还能涨，跌的时候有害怕卖在最低点。



很多人觉得，这是因为自己不够自律。

但《思考，快与慢》的作者告诉我们：很多时候，不是你不努力，而是你的大脑本来就是这样设计的。



今天的问题来了：

你有没有一件事，明明知道应该这么做，却总是做不到？



可以留言，也可以自己写下来，晚上我分享我的理解。





**真正困住我们的，很多时候不是不知道，而是误以为"知道"就等于"做到"。**



以前总觉得，一个人做不到，是因为不够努力、不够自律。



但今天的内容提醒了我，大脑天生就更喜欢轻松、更喜欢即时满足，而不是长期回报。



所以，刷短视频、冲动消费、拖延健身，并不是少数人的问题，而是几乎每个人都会面对的人性。



**成长，并不是学会更多知识，而是减少那些重复犯的错误。**
