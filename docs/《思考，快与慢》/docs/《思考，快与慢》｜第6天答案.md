# 《思考，快与慢》｜第6天答案

今日答案：大脑喜欢先找一个参考点，再围绕它做判断。



《思考，快与慢》把这种现象叫做锚定效应



所谓“锚”，就是让你最先接触到的那个数字、价格或者信息。



哪怕这个数字本身没有意义，它依然会成为你后续判断的起点。



这也是为什么商场喜欢先写一个很高的原价，再打折；为什么谈判时，很多人都会先报价；为什么投资者总喜欢说：“这只股票以前300美元，现在180美元，太便宜了。”



可真正应该问的，不是以前多少钱，而是今天到底值多少钱。



Jack做投资时，一直提醒自己不要被价格锚住。



我不会因为它跌了很多就觉得便宜，也不会因为它涨了很多就觉得很贵。我更关系的是：这家公司未来还能创造多少价值？现在的价格，和它的价值相比，是高了还是低了？



记住一句话：市场给你的第一个数字，未必是真相；真正重要的是，你有没有能力自己算出答案。
