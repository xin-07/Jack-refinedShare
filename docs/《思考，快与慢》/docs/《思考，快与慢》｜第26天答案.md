# 《思考，快与慢》｜第26天答案

《思考，快与慢》

第二十六天答案：最大的智慧来源于主动寻找——反对



前面我们讲过确认偏误

当你已经想开餐厅以后，你问别人意见，看起来是在收集信息，其实很可能是在寻找别人的认可



别人支持你，你会觉得他懂你；别人反对你，你反而会开始找理由证明他不懂



所以真正高质量的决策，有时候要故意做一件让自己不舒服的事：主动寻找反方



如果我(Jack)特别看好一个机会，我不会只说好，还会问自己：

什么情况下它会失败？

最反对我的人会怎么说？

出现什么证据，我愿意承认自己错了？



年纪越大 越发现身边有一个敢反驳你的人，特别珍贵！



因为支持你的人给你信心，反对你的人帮你检查盲区



我可以很真诚的分享给你我最近二十年的智慧



**真正的自信是：即使特别相信自己的时候，依然愿意认真寻找：有没有一种可能，我错了？**





把第26天浓缩成一句话，我会这样总结：



**真正的判断力，不是让自己越来越相信自己的判断，而是让自己的判断越来越经得起反对。**



而这也是这一周真正开始训练的东西：



**不是追求“我永远正确”，而是建立一套让自己“错了也能尽快发现”的系统。**
