下周预告 | 我们一起读《思考，快与慢》



过去一个月，我们通过《小岛经济学》理解了财富、储蓄、借贷、通胀、泡沫、经济周期。



下周大家将学到：



如何识别自己的直觉陷阱，避免结果偏见、损失厌恶、锚定效应和从众心理；如何在投资、消费、工作和感情中做出更清醒的决定；也会设计一套系统，减少自己犯错的概率。



大家可以提前准备三件事：



第一，准备一个笔记本，每天记录一个自己做过的错误判断。



第二，回想最近一次冲动消费、追涨杀跌或者与人争吵，想想当时是理性在决定，还是情绪在决定。



第三，有条件的可以买一本《思考，快与慢》，没有书也没有关系，每天跟着我提出的问题思考。



《小岛经济学》让我们看懂钱是如何运转的。



《思考，快与慢》会让我们看懂：自己为什么会被钱、情绪和直觉控制。



周一，我们开始研究世界上最复杂的东西——我们自己的大脑🧠
