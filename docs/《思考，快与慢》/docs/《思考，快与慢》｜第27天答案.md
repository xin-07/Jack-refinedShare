# 《思考，快与慢》｜第27天答案

《思考，快与慢》

第27天答案



前面讲过一个概念：后见之明偏差

事情发生以后，大脑特别喜欢告诉自己：我早就知道会这样



所以想提高判断力，可以建立一个习惯：决策日记



每次遇到真正重要的决定，写下四件事：

第一，我现在准备做什么？

第二，我为什么这么做？

第三，我认为成功的概率是多少？

第四，出现什么情况，说明我的判断可能错了？



然后三个月、半年、一年以后回来重新看



你可能会第一次发现：有些事情你判断对了，但只是运气好

有些事情结果不好，但当时的逻辑其实是没有问题

还有一些事情，你当时信心满满，现在回头看，理由根本站不住脚



所以复盘只能让你知道发生了什么

复盘当时的思考，才能真正提高判断力



秘密分享㊙️把决定写下来，是为了防止未来的自己修改过去

如果想真进步，不能只靠我这次猜对了或者运气好才成功，而是几年以后回头看，自己做高质量决定的比例越来越高，做事情成功的游刃有余！





**真正提升判断力，不是让自己“猜得更准”，而是建立一个系统，让自己知道为什么猜、为什么错。**



**不要只记录人生发生了什么，更要记录当时自己为什么这样判断。因为只有保存过去的自己，未来才能真正知道自己有没有变聪明。**
