# 《思考，快与慢》｜第21天答案

今日答案：很多时候，我们舍不得放手的不是资产，而是舍不得承认过去的判断可能需要调整

100万买的房子，现在市场只认可60万，我们的大脑很容易同时掉进几个陷阱

首先是损失厌恶。一旦卖掉，就意味着接受现在的结果，所以大脑本能的抗拒

然后是锚定效应。100万变成了心理的参考点，总想着什么时候能够重新回到那里

最后还有沉没成本。因为过去已经投入了这么多，所以觉得现在更不能放弃

可真正理性的判断应该是：过去多少钱买的，并不能决定它未来值多少钱。

所以我（Jack）现在判断一项资产要不要继续拥有，会问自己一个特别简单的问题：如果今天我没有它，手里只有等额现金，我还愿不愿意按照今天的价格重新买一次？

如果愿意，那继续拥有有自己的逻辑

如果不愿意，就要认真想想：我现在留下它，究竟是因为未来依然值得期待，还是因为舍不得过去的投入

不要永远证明过去的自己正确，而是永远选择从今天开始更正确的放心🧭

<br />

**重新获得选择权**

决策公式：

**过去的买入价 ≠ 今天的价值**

**过去的投入 ≠ 未来必须继续投入**

**过去的错误 ≠ 今天必须继续坚持**

**“在考虑所有未来收益和风险之后，我现在继续拥有它，是不是最优选择？”**

**“过去发生过什么，我接受；但下一步怎么走，我重新判断。”**
