# 《思考，快与慢》｜第27天

《思考，快与慢》

第27天：为什么重要决定，一定要写下来？



假设你准备做一个新项目



成功概率70%

于是半年后，项目真的成功了



这时候别人问你：你当时是不是就特别有把握？

你很可能会说：对啊，我当时就觉得这事肯定能成



但如果项目最后失败了呢？

你有可能会说：其实我当时就觉得哪里不太对，只是想试试看



你必须想想半年前的你，到底是怎么想的？



很多时候，如果不记录，之后自己都记不清了



因为结果出来以后，大脑会不知不觉修改过去的记忆，让我们觉得：我很早就知道



所以今天大家思考



如果我们永远用今天的结果，去回忆昨天的判断，我们怎么知道自己的判断力到底有没有进步?



有没有一种办法，可以把当时的自己保存下来，半年以后再回来检查？



想明白了 你的认知又会产生一次跳跃🎉





完整的决策系统：

**做决定之前，寻找反对意见。**

**做决定的时候，把自己的判断写下来。**

**结果出来以后，再回头检查当时的判断。**



**不要让今天的结果替你修改昨天的记忆。把当时的判断写下来，未来才能真正知道自己有没有变聪明。**



这也是判断力训练最重要的一步：

**不是只记录结果，而是记录“结果发生之前的自己是怎么想的”。**
