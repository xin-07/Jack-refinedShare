# 《思考，快与慢》｜第20天

《思考，快与慢》| 第二十天：为什么同样100块钱，在我们心里却不一样？

今天先给大家两个场景

一

这个月幸幸苦苦工作，多赚了1000块钱

你拿着这1000块，可能会想：还是存起来吧，赚钱不容易

二

晚上和朋友吃饭，回家路上随手买了一张彩票，结果中了1000块

你会不会突然觉得：这钱本来就是白来的，今天吃顿好的吧！

奇怪的地方来了

同样都是1000块，购买力完全一样

为什么辛苦赚来的1000块，我们舍不得花；意外得到的1000块，却更容易花掉？

再比如，很多人股票赚了5000块，买一个2000块的东西会觉得反正是股市赚的

但如果从工资里拿2000块买，马上又觉得心疼

钱明明没有名字，可我们大脑却会偷偷给每一笔钱贴标签：

工资的钱、投资赚的钱、奖金的钱、捡来的钱、旅游的钱......

今天思考：为什么同样的钱，仅仅因为来源不同，我们花钱的方式就会完全不同？

<br />

**钱没有名字，但我们的大脑会给钱贴标签；真正理性的财务决策，是知道这些标签存在，却不要让标签替自己做决定。**

所以：

工资赚的钱是钱。

股票赚的钱也是钱。

奖金是钱。

意外得到的钱也是钱。

它们的来源不同，

但最终都会进入你的财富。

真正成熟的财富观，不是：

**“这笔钱是怎么来的？”**

而是：

**“我现在拥有多少财富？这笔钱放在哪里，对未来最有价值？”**
