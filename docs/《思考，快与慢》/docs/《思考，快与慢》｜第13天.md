# 《思考，快与慢》｜第13天

读懂《思考，快与慢》|第十三天：为什么一个真实故事，会骗过你的大脑？



假设今天有两个人来找你投资



第一个人说：我朋友三年钱辞职创业，现在公司卖了5000万。我另一个朋友去年开始做AI，现在一个月赚几十万。还有一个朋友做短视频，两年就买了豪宅。所以我准备创业，你要不要一起？



第二个人没有讲故事，而是拿出一份数据



他说：过去五年，全国新成立了100万家公司，其中真正做到盈利的不到三成；能够持续经营五年以上的更少；最后能做到行业头部的，更是极少数



请问，你更容易被谁说服？



大多数人都会被第一个人吸引吧



因为一个真实的故事，远比一堆数字更容易打动我们的大脑



为什么一个栩栩如生的故事，反而比客观数据更能让我们接受



大家可以先想一想，晚上Jack分享《思考，快与慢》里的答案和思考







**故事负责让我们看见可能，数据负责让我们理解现实。**



故事不是没有价值。



一个真实的成功故事，可以给人希望，也可以让我们看到新的机会。



但如果只听故事，不看概率，我们就容易把“别人成功过”，理解成“我也大概率会成功”。



**故事告诉你发生过什么，数据告诉你这种事情有多大概率发生。**
