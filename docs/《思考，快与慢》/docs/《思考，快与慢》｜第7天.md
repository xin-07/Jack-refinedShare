# 《思考，快与慢》｜第7天

《思考，快与慢》|第7天：为什么Bad News总比Good News更容易让人害怕？



问大家，如果连续一个月，你每天都看到这样的画面



“股市暴跌。”

“AI要取代大量工作。”

“房价可能大跌。”

“某地发生重大事件。”



慢慢地，你会不会觉得：



这个世界是不是越来越危险了？



可事实上也许真正发生的大部分事情，都没有出现在你的手机里。



今天的问题来了：



为什么一件发生概率很低的事情，只要不断出现在我们眼前，我们就会觉得它经常发生？



为什么很多人觉得飞机比汽车危险？



为什么看到别人赚钱的视频越来越多，就觉得全世界都发财了？



为什么刷短视频半小时，就会觉得所有人都在过比自己更好的生活？



大家先想一想，晚上我分享答案。







我觉得第7天最大的启发是：



我们的情绪，很多时候不是由现实决定的，而是由我们每天接触的信息决定的。



真正重要的不是每天获取更多信息，而是**主动选择获取什么信息。**



如果每天都沉浸在负面新闻里，你会觉得世界充满危险；如果每天都刷成功案例，你会觉得别人都比自己优秀。



因此，第7天给我的提醒是：



**不要用自己看到的信息，去代表整个世界。**



真正拥有独立判断力的人，不会因为几条新闻、几个视频就轻易改变对世界的看法，而是会主动寻找更多事实、更完整的数据，再做出自己的判断。
