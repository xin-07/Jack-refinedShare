# 《思考，快与慢》｜第25天答案

《思考，快与慢》

第二十五天答案：放弃自律 建构或者参与一个自动让你自律的环境和系统



前25天，我们已经认识了太多大脑的弱点

会被第一印象影响，会害怕失去，会被价格锚定、会因为过去投入太多舍不得停止，也会在所有人兴奋的时候跟着兴奋



既然这些弱点很难消失，那最好的办法之一，就是：提前制定规则



比如我（Jack）一直和大家讲六年之约



它真正的价值，不只是存下一笔钱



而是你提前替未来的自己做了一个决定：收入进来以后，先留下来，而不是每个月重新问自己这次要不要存



运动、学习、投资其实一样



能自动化的就自动化，能固定时间的就固定时间，能提前设定边界的就不要临场决定



因为情绪每天都在变化，规则却可以保持稳定



智慧的人最终拼的不是意志力的，是系统设计能力



务必记住：**当正确的事情越来越不需要自律，你的人生系统才真正开始建立起来**





**既然我知道自己会犯错，那我能不能提前设计一个系统，让我犯错的代价没有那么大，让正确的选择更容易发生？**
