# 《思考，快与慢》｜第四周预告

这周预告



之前我们一直在研究：人的判断为什么会出错



这周开始，我们要进入《思考，快与慢》里我（Jack）特别喜欢的一部分一人到底是怎么面对钱、得失和风险的



而且我觉得，这五篇可能是整本书里，对普通人投资和生活最有用的内容



第一篇：损失厌恶

如果我给你1000块，你会有多开心？如果再从你手里拿走1000块，你又会有多难受？



第二篇：禀赋效应

为什么一个东西一旦属于你，你马上就觉得它更值钱？



第三篇：沉没成本

一场电影已经看了一个小时，难看到不行，因为票都买了，你还要不要继续看？一只股票已经亏了50%，因为亏太多了，所以一定要等它涨回来吗？



第四篇：框架效应

“成功率90%”和“失败率10%”，明明说的是同一件事，为什么听起来感觉完全不同



第五篇：心理账户

为什么工资赚来的1000块舍不得花，股票赚来的1000块却特别容易花掉



留言：大家回想最近一年，你最后悔的一次关于钱的决定是什么





**前三周教我们识别大脑的错误，第四周开始教我们识别大脑在面对“钱和损失”时的错误。**



而这一周最终可能会落到一个非常重要的问题：



**当情绪、得失和利益进入决策以后，我还能不能问自己一句——如果这笔钱不是我的，如果过去的成本不存在，如果换一种说法，我还会做同样的选择吗？**
