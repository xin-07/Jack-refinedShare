# 《思考，快与慢》｜第一周总结

《思考，快与慢》｜第1周总结



如果只用一句话总结前5天，我觉得是：人这一生很多错误，不是因为你不聪明，而是因为你太相信自己的第一反应👍



第一天，我们讲到大脑有两套系统。一个快，一个慢。快的那个负责直觉、情绪、习惯；慢的那个负责分析、计算、长期规划。问题是，快的太勤快，慢的太懒



第二天，我们用球拍和球的问题发现，很多人不是不会算，而是大脑太快给了一个看起来合理的答案，系统2根本没来得及检查



第三天，我们讲第一印象。一个人最先给你的感觉，会影响你后面怎么看他说的话、做的事，所以要论迹不论心🙏



第四天，我们讲注意力。真正稀缺的不是时间，而是高质量注意力



第五天，我们讲熟悉感。一句话重复太多次，大脑就会觉得它更像真的



从今天开始，遇到重要判断时，先停一下，问自己一句：这个想法，是从认真思考后的结论，还是大脑自动塞给我答案？



如果你能养成这个习惯，这本书就已经开始改变你了🎉
