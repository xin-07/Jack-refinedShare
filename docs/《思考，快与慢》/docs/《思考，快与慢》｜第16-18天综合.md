# 为什么人一旦“亏了、拥有了、投入了”，就更难做出理性选择？

《思考，快与慢》这三天，Jack连续讲了三个特别重要的概念：



**损失厌恶、禀赋效应、沉没成本。**



把它们放在一起看，会发现它们其实是一条完整的心理链条。



我们先因为**损失厌恶**，害怕承认自己亏了。



一只股票赚20%，很多人赶紧卖掉；

亏20%，却告诉自己“再等等，至少等它回本”。



接着，**禀赋效应**出现了。



因为这只股票已经属于我，我的大脑会开始自动给它加价：



“这家公司其实还是不错的。”

“市场只是暂时错杀。”

“它以后一定会涨回来。”



最后，**沉没成本**把我们彻底困住。



“我都已经亏这么多了。”

“我都拿这么久了。”

“我都投入这么多时间了。”



于是过去的投入，开始绑架未来的选择。



但问题是：



**过去已经花掉的钱、时间和精力，都已经回不来了。**



所以真正理性的判断，不应该是：



“我以前已经投入了多少？”



而应该是：



**“如果过去的一切都归零，只看今天，我还会不会做同样的选择？”**



投资如此，工作如此，创业如此，甚至人生选择也是如此。



真正成熟的人，不是永远坚持，也不是轻易放弃。



而是在发现方向错了以后，**敢于停止。**



因为：



**及时止损，不是承认失败，而是在保护未来。**



这可能就是这三天给我最大的启发：



**不要让已经失去的，决定你接下来还要失去多少。**
