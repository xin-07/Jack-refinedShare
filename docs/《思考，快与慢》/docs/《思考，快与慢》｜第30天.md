《思考，快与慢》

第30天：为什么越重要的决定，越不能只靠聪明？



大家想象一下，一个飞了20年的机长，准备起飞



天气很好，飞机也没有任何异常，这条航线他甚至已经飞过几百次



他还需要拿着检查清单，一项一项确认吗？



需要！



因为航空业发现经验再丰富的人，也会忘记，也会分心，也会判断错误。

所以要求机长每一次用一张清单，把最重要、最容易出错的事情提前固定下来



那我就在想：飞机起飞需要检查清单，为什么我们人生中很多比坐一次飞机影响更久的决定，却完全凭感觉？



买一套房、做一项投资、换一份工作、选择一个合作伙伴、开始一门生意......



我们是不是也应该有一张自己的人生决策清单？



今天思考：结合整本书学到的内容，如果让你给自己人生中所有重大决定设计5个必须回答的问题，你会写什么？

**越是复杂、重要、重复的任务，越不能把正确完全寄托在人的记忆和临场判断上。**



**决策清单的作用，是强制系统2介入，逐一核对那些容易被系统1忽略的因素。**



**真正厉害的决策者，不是永远相信自己聪明，而是知道自己会犯错，所以提前给重要决定加一道程序。**



**我们无法让自己变成一个永远理性的人，但我们可以建立一个系统，让自己在重要时刻更不容易犯下那些本来可以避免的错误。**
