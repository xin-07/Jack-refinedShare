# 《思考，快与慢》｜第29天答案

《思考，快与慢》

第29天答案



前面学过，系统1喜欢简单、熟悉、马上有反馈的东西

所以手机就在手边，就容易拿起来

零食就在桌上，就更容易吃



而一本书如果藏在柜子里，健身还要开车半小时，我们每多增加一步，大脑就多了一个放弃的理由



当你脑海出现：我要更自律时

先看看自己的环境

想读书，就把书放到伸手就能拿到的地方

想少刷手机，就让手机离自己远一点

想坚持运动，就把固定时间提前流出来

想存钱，就让一部分收入自动留下，而不是月底看看还能剩多少



这也是我们前几天讲“人生系统”的真正意义



不要每天测试自己的意志力

你真正应该设计的，不只是自己，而是自己每天生活的环境



一个好的环境，会让正确的选择越来越顺手；一个坏的环境，却会让你每天都在和自己内耗



今天任务：找出生活中一个你一直想改变的习惯，然后别先改变自己，先改变它周围的环境



秘密㊙️最省力的自律，是让正确的事情变容易，让错误的事情变麻烦





**改变行为最好的方法之一，是改变行为发生的条件。**



**真正的自律，不一定是把自己训练成一个特别能忍的人。**



有时候，更聪明的做法是：



**根本不给自己那么多需要忍的机会。**



所以第29天可以浓缩成一句话：

**最省力的自律，不是让自己变得更强，而是让正确的事情越来越容易，让错误的事情越来越麻烦。**



而这也是“人生系统”真正的意义：

**不要每天靠意志力赢一次，而是设计一个环境，让自己每天都更容易赢。**
