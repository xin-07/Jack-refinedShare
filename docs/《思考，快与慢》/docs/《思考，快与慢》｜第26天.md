# 《思考，快与慢》｜第26天

《思考，快与慢》

第二十六天：为什么重要决定，不能只听自己的？



今天假设你准备花掉自己一半的积蓄，开一家餐厅



于是你问了五个朋友



第一个说：你那么有能力，肯定没问题

第二个说：曾工位置特别好，我觉得能火

第三个说：现在大家都特别喜欢这种餐厅



你越听越兴奋 然后找我（Jack）连线



我直接问你：附近三公里有多少家类似餐厅？

平均一家能活几年？

如果前三个月客流只有你预计的一半怎么办？

如果一年以后还没有达到预期，你准备怎么办？



你突然发现，前面那些让你开心的话，并没有真正帮助你做决定

反而是我这个一直给你泼冷水的人，让你第一次认真想了想风险



今天大家好好想想：为什么我们越喜欢一个想法，越应该主动找人反对自己？



做重要决定的时候，你更需要一个支持你的人，还是一个敢告诉你“你可能错了”的人？





真正好的建议，很多时候不是让你更兴奋，而是让你**少犯一个代价巨大的错误**。



所以第26天可以浓缩成一句话：



**重要决定，不要找一个让你舒服的人证明你是对的；要找一个敢让你不舒服的人，帮你发现自己可能错在哪里。**



这就是第六周真正开始训练的东西——**不是让你更相信自己的判断，而是让你的判断经得起反对。**
