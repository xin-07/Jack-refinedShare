# 《思考，快与慢》｜第30天答案

《思考，快与慢》

第30天答案：如果让我给重大决定设计一张清单，我（Jack）写着五个问题：

一、我为什么要做这件事？

有价值，还是因为别人都在做

二、最坏的结果是什么？

最差结果，能不能承受？

三、我可能错在哪里？

主动找一个最反对自己的理由

四、如果今天重新开始，我还会不会做？

把沉没成本、面子和过去的投入暂时拿掉

五、十年后的我，会希望今天怎么选？

把眼前的情绪拉远一点

十年、二十年里，谁少做几个足以改变命运的大错，谁就走的更远

所以清单真正的意义是在你兴奋、害怕、冲动、自信的时候，替那个理性的自己再次思考：“真的想清楚了吗？”

我这几十年和各种人打交道，发现有的人富了之后又返贫，其实都是飘了然后连续踩几个坑

所以我悄悄在笔记本里写了这句㊙️**真正好的决策系统，不是让你每次都判断正确，而是帮你避开那些本来可以避免的大错**

<br />

以后遇到重大决定，脑海里浮现出这篇，不妨把这5个问题拿出来

**聪明的人追求每次都选对。**

**成熟的人知道自己不可能每次都对，所以提前给自己设置护栏。**

而这五个问题，就是你可以带走的一道护栏：

**我为什么做？**

**最坏会怎样？**

**我可能错在哪里？**

**重新开始我还会做吗？**

**十年后的我希望今天怎么选？**
