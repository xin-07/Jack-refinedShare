# 《思考，快与慢》｜第12天答案

第十二天答案：很多时候，我们看到的不是全部事实，而是幸存下来的结果



《思考，快与慢》里，这种现象视为幸存者偏差



世界每天都有无数人在。创业、投资、拍视频、写书、直播



可最后进入我们视野的，往往只有那些成功的人



于是我们很容易产生一种错觉：原来成功就是这样来的。



但事实上，我们看到的只是最后留下来的那一下部分



这也是为什么Jack一直不喜欢只讲成功故事



Jack更喜欢研究：为什么有的人成功了？为什么更多的人失败了？他们之间到底有什么真正的区别？



投资也是一样



不要只研究过去十倍股为什么涨，更要研究那些曾经人人看好、最后却消失的公司



因为真正提高判断力的方法，不是只看赢家，而是把赢家和输家放在一起比较



成功值得学习，失败更值得研究



当你开始主动寻找那些“没有幸存下来的人”，你的判断力就会比大多数人高一个层次
