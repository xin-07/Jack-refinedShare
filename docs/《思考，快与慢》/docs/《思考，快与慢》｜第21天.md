# 《思考，快与慢》｜第21天

《思考，快与慢》

第二十一天：为什么价格越低，我们反而越舍不得放手？

今天假设你100万买了一套房子

后来市场变化，现在别人只愿意出90万

你想：没事，等回到100万我再卖

后来别人只愿意出80万

你又想：都已经这样了，现在卖太可惜了，再等等

最后市场上类似的房子只值60万

这时候有人问你：如果今天给你60万现金，你还会花60万买这套房子吗？

你想了半天，说：应该不会

反过来想

如果今天你不愿意拿60万买它，为什么你却愿意继续拥有价值60万的它

因为你的脑子里一直有一个数字：100万

你已经不完全是在判断这套房子今天值多少钱，而是在想：什么时候才能重新回到我当初买它的价格？

大家思考下：为什么一个东西价格变化越大，我们反而越舍不得放手？为什么当初付出的价格，会如此影响今天的决定？

晚上我（Jack）分享我的理解

<br />

**重新开始思考。**

人最难做到的事情之一，就是：

**把已经发生过的事情从决策中拿掉。**

因为过去发生过，所以我们天然觉得它重要。

但实际上：

**过去的信息只有在能够帮助我们预测未来的时候才有价值。**

**不要问“什么时候才能回本”，要问“如果今天重新开始，我还会不会选择它？”**

**不是让自己永远不犯错，而是当你发现自己可能错了以后，有能力重新做一次正确的选择。**
