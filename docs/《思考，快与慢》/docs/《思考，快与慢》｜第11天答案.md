# 《思考，快与慢》｜第11天答案

思考，快与慢



十一天答案：结果只能说明发生了什么，不能完全说明当初的决定质量——结果偏见



很多人判断一件事，不看当时的信息、逻辑和风险，只看最后结果



结果赚了，就觉得决策对了；结果亏了，就觉得当初傻了



但现实不是这么简单



投资里尤其明显。你卖put，最后没跌破行权价，赚到了权利金，不代表每一次卖put都是安全的；你买一只好公司，短期下跌，也不代表你的逻辑一定不对



真正要复盘的是：当时有没有控制仓位？有没有预留现金？有没有考虑最坏情况？这个决定能不能长期重复？



Jack做投资最怕的，不是亏一次钱，而是赚到了一次钱以后，以为自己无所不能



因为亏钱会让人害怕，赚钱反而容易让人膨胀



所以以后评价一个决定，不要只问：我这次结果怎么样？



而要问：如果同样的情况重复一百次，这个方法长期看能不能让我活下来、赚到钱、变得更好？



一次结果可能是运气



能长期重复的好决策，才是真正的能力🎉
