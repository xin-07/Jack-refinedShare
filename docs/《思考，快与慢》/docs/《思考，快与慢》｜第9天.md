# 《思考，快与慢》｜第9天

《思考，快与慢》|第9天：我们真的在寻找真相吗



大家想象一下。



你觉得某只股票未来一定会上涨，于是打开手机开始搜资料。



你看到一篇看多的分析，会认真看完，觉得作者很专业；看到一篇看空的分析，却会马上挑毛病，觉得对方根本不懂这家公司。



再比如，你不喜欢一个人，他迟到一次，你会觉得：你看，他果然不靠谱。



但如果是你喜欢的人迟到，你可能会替他解释：他一定是临时遇到了什么事情。



今天的问题来了：



我们寻找信息的时候，是真的想知道事实，还是只想找到支持自己原来观点的证据？



为什么两个人面对同一件事，都觉得证据站在自己这边？



为什么网上很多争论，越讨论越激烈，却很少有人真的改变想法？



大家也可以回想一下：你最近有没有先下结论，然后才开始寻找理由证明自己是对的？



晚上我(Jack)分享我的理解。









我觉得第9天最大的启发是：



**人最难发现的偏见，往往是自己认为自己很客观。**



因为当我们看到支持自己的信息时，很少会觉得自己有偏见，反而会认为：



“我只是看到了事实。”



但真正的问题可能是，我们只看到了愿意看的那部分事实。



这一天提醒我们，独立思考不只是坚持自己的观点，也不是永远和别人唱反调。



真正的独立思考，是愿意主动问自己：



**有没有什么证据，能够证明我可能错了？**



成熟的思考，不是不断证明自己正确，而是始终给自己留下修改观点的可能。
