# 《思考，快与慢》｜第15天

读懂《思考，快与慢》｜第十五天：为什么懂得越少的人，反而越自信？



今天对着雷尼尔山冥想的时候 想到一个特别有意思的现象



假设有两个人



第一个人，刚学了两个月投资。



他开始看财报、学K线、刷各种分析视频。后来连续赚了几次钱，就觉得自己已经看懂了市场。



他会觉得其实投资没有那么难



第二个人，已经投资了二十年



经历过牛市，也经历过熊市；赚过很多钱，也犯过很多错误。



别人问他：你觉得未来股市会怎么走？



他会说：不知道，但我会做好各种准备



奇怪的是，真正经验丰富的人，反而很少把话说满；而刚学一点的人，却常常充满信心。



大家说：为什么人知道得越少，越容易觉得自己什么都懂？而真正懂得越多的人，却越来越谦虚？



就在刚才 一粉丝联系我，聊天记录我发dy了，我晚上要好好写一篇送给每一位想要投资的人！







**真正的成长，不是越来越相信自己的判断，而是越来越知道判断的边界；真正的智慧，不是拥有所有答案，而是在面对未知时，依然保持谦逊，并做好准备。**
