# 《思考，快与慢》｜第5天答案

今日答案：大脑喜欢熟悉感，并且经常把熟悉误认为正确



《思考，快与慢》里有一个很重要的观点：一个观点重复得越多，大脑处理起来就越轻松；处理得越轻松，我们就越容易相信它。



这并不代表它是真的，只代表它很熟悉。



生活中到处都是这样的例子。



一个广告天天看，你会觉得这个品牌更可靠；一个观点不断出现短视频里，你会觉得大家都这么认为；一个谣言传了一万遍，很多人甚至忘了它最开始有没有证据。



所以，大脑判断一件事时，经常不是在问：“它是真的吗？”



而是在问：“我是不是很熟悉它？”



这也是我一直鼓励大家多读书、多思考的原因。



如果你每天接触的都是碎片化的信息，大脑就会不断重复别人想让你相信的东西；而如果你愿意静下心读一本书、研究一个问题，你就会开始建立属于自己的判断。



重复，会塑造记忆；思考，才能接近真相。不要因为一句话听了一百遍，就忘了问一句：它真的对吗
