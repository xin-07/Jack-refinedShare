# 《思考，快与慢》｜第28天答案

《思考，快与慢》

第28天答案



人在不同状态下，对同一件事的判断可能完全不同



特兴奋时，容易高估机会

特害怕时，容易高估风险

特别愤怒的时候，我们又容易低估一段关系、一个工作或者一个选择的长期机会



所以越是影响未来很多年的决定，我（Jack）越觉得不能只说：我现在想不想？

而应该再想一下：三年后的我，会希望今天的我怎么选？



因为当你把时间拉长以后，很多眼前特别重要的情绪，会突然变小



今天一次争吵，十年以后可能根本不重要；今天特想买的东西，三个月以后可能已经忘了；但今天开始存下的钱、坚持的运动、学会的能力，却可能一直跟着你



所以真正的长期主义，不只是坚持很久

更重要的是：不要让短期情绪，拥有决定长期人生的权力。



遇到真正重要的决定，给自己一点时间

等情绪过去，再思考：如果十年后回头看，我希望今天的我做什么



悄悄告诉你一个价值百万的人生智慧：仅仅把时间拉远一点，答案就会完全不一样🤫





**短期情绪往往很强烈，长期价值却不一定和情绪强度成正比。**

今天让你非常难受的事情，可能几年后微不足道。

今天让你觉得“好无聊”的坚持，可能几年后改变人生。



长期思考的一个重要能力就是：

**不要只看今天的感受，要看这个决定在时间里会产生什么结果。**



**时间不是让问题消失，而是让你重新判断什么真正重要。**



**人生很多后悔，并不是因为当时不知道答案，而是因为当时的自己太急着做决定。**
