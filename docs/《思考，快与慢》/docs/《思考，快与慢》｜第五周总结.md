# 《思考，快与慢》｜第五周总结

《思考，快与慢》

第五周总结

这五篇，我觉得是前25天里最值得真正拿去用的

因为我们开始从认识大脑走向管理自己

一，为什么越不顺越舍不得放手？

因为我们讨厌承认损失，又容易被最初的价格锚住。

多问自己：如果今天重新选择，我还会不会拥有它？

二，为什么刚赚到钱以后反而更敢冒险？

因为大脑把意外之钱当成额外的钱。

告诉自己：钱到了你手里就已是你的资源，不应因为来得容易，就承担更大的风险

三，为什么情绪最容易毁掉投资？

所有人兴奋，我们害怕错过；所有人害怕，我们又不敢行动。

所以：重要决定，不要等情绪来了以后再想

四，怎样让系统2真正启动？

重要事情不要急着做决定。

具体方法：等一等、写下来、主动找反方，让理性有时间追上情绪

五，怎样建立自己的决策系统？

答案：提前制定规则，减少需要临场决定的次数

不要只做一个懂很多道理的人

从今天起，把一个你认为正确的道理，变成一条长期执行的规则

<br />

**建立一个即使自己不理性，也不容易犯大错的系统。**

**人不是因为笨才犯错。**

很多时候恰恰是因为：

**大脑太快、情绪太真实、环境太有诱惑，而我们又太相信自己能够临场控制一切。**

前20天：认识大脑。

第21～25天：开始管理大脑。

最终目标不是成为一个永远理性的人，而是成为一个：

**即使某一天不理性，也不容易因为一次错误，把自己长期积累的一切毁掉的人。**

而这句话，可能就是前25天最值得真正带走的一句话：

**改变一个人的，从来不是“我懂了”，而是下一次同样的事情发生时，你真的做出了不一样的选择。**
