# 《思考，快与慢》｜第三周预告

这周预告|成熟的人，不是更相信自己，而是更懂得检查自己



过去两周，其实一直在讲一件事：我们不是被世界骗了，而是被自己的大脑骗了



这周开始，我们会继续将五个特别重要、也特别适合用在投资、成长和人生选择里的思维陷阱



第一篇：结果偏见

现实中，很多好结果可能只是运气，很多坏结果也可能是高质量决策遇到了短期波动



第二篇：幸存者偏差

为什么我们总喜欢研究成功的人，却忘了那些用同样方法失败的人？



第三篇：基率忽视

投资、创业、择业、婚姻，很多判断不能只看个案，还要看整体概率



第四篇：小数定律

为什么很多人看到三五次成功，就以为自己掌握了规律？



第五篇：过度自信

为什么很多人越懂一点，反而越容易高估自己？



《思考，快与慢》读到这里，大家应该会慢慢发现：一个人真正的成长，不是越来越自信，而是越来越清醒



这周，我们继续升级自己的大脑







第三周开始告诉我们：



**即使已经有了经验，大脑仍然可能把运气当能力，把少数案例当规律，把成功当成自己判断正确的证明。**



所以，一个人真正成熟，不一定是越来越自信，而是越来越知道：



世界有很多不确定；

一次成功不能证明能力；

一次失败也不能否定方法；

自己看到的，可能只是全部事实的一小部分。



这周最值得记住的一句话，我认为是：



**真正的自信，不是相信自己永远不会错，而是相信自己发现错误以后，有能力修改判断。**



第三周的五个主题，其实都在训练一种能力：



**少看结果，多看过程；少看个案，多看概率；少凭感觉，多用长期数据检查自己。**
