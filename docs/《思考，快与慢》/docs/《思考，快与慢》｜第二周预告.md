# 《思考，快与慢》｜第二周预告

这周预告｜真正改变人生的，不是知识，而是独立判断力

上一周，我们认识了自己的大脑



这一周，我们要进入《思考，快与慢》最精彩、也是最实用的一部分



你会发现：很多错误，不是因为你笨，而是因为大脑一直“欺骗”你



这周会一起研究五个经典思维陷阱：



第一排篇锚定效应

商场、房价、股票、判断，机会每天都在利用它👍



第二篇：可得性偏差

为什么短视频刷多了，你会觉得全世界都在赚钱🤫



第三篇：代表性偏差

为什么很多人会因为一个人的外表、一家公司的一次成功，就轻易下结论？你的大脑特别喜欢“以偏概全”😎



第四篇：确认偏误

为什么网上那么多人越整越激烈，却没有人真正改变想法🙈



第五篇：后见之明偏差

为什么事情发生之后，我们总觉得：我早知道会这样😖



这五个思维陷阱，我认为每一个都值得学一辈子



它们不仅会改变你对新闻、投资、商业的理解，更会改变你看待自己、看待他人、看待世界的方式🎉
