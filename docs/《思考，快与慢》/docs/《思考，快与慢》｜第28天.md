# 《思考，快与慢》｜第28天

《思考，快与慢》

第28天：今天的你，有资格替十年后的你做决定吗？



假设你刚刚经历了特别糟糕的一天

工作不顺，和别人发生了矛盾，回家后特累



晚上躺在床上，你想哭：我受够了，我明天就辞职



可第二天睡醒，出去走一走，再和家人聊聊天，突然又觉得：

好像也没严重到这个程度



事情只过去了十几个小时



为什么昨天的你和今天的你，像两个人一样？



再比如，特别兴奋的时候，我们容易答应一些未来根本没时间做的事情；特别焦虑的时候，又容易放弃一些原本值得长期坚持的东西。



但很多决定的影响，可能是三年、十年，甚至更久



今天大家思考下：

为什么我们会用几个小时的情绪，替未来很多年的自己做决定？



当你特别开心、愤怒、害怕或者兴奋的时候，你做出的决定，真的是你长期想要的吗？



今晚直播见 很刺激





**人的判断，不仅受到事实影响，也会受到自己当下所处的情绪状态影响。**



我们经常会犯一个错误：

**把“我现在的感觉”，误认为“我长期真正想要的东西”。**



第28天真正要训练的是“延迟决定”：

**“这件事很重要，我现在状态不稳定，所以我要等自己恢复理性以后再决定。”**

变成自己的**规则**：

**情绪特别强烈的时候，可以做记录，但不要立即做重大决定。**



**短期情绪可以很真实，但真实不等于长期正确。**



**不要让几个小时的情绪，替十年后的自己做决定。**
