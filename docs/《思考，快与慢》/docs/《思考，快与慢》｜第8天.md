# 《思考，快与慢》｜第8天

《思考，快与慢》第八天：为什么我们总喜欢以偏概全？

如果有一个人，平时很安静，喜欢读书，不太爱社交，说话也比较谨慎📖

你觉得他更可能是图书管理员，还是销售员？

很多人第一反应是：图书管理员

因为这个描述，太像我们想象中的图书管理员了

但问题是，现实生活中销售员的数量，可能远远多于图书管理员。也就是说，即使这个人看起来想图书管理员，从概率上说，他也可能更大概率是销售员🗣

今天的问题来了：

为什么我们判断一个人、一家公司、一件事时，总喜欢根据“像不像”来判断，而不是根据真实概率来判断？

比如，一个人穿得很体面，我们就觉得他很成功

一家公司名字里带AI，我们就觉得它未来很厉害

一个视频一开始播放量不好，我们就觉得这个内容没价值

这些判断真的可靠吗？

大家可以先想一想：你有没有因为一个人“看起来像某个人”，就提前给他下过结论

晚上Jack分享他的理解

<br />

我觉得第8天最大的启发是：

**很多时候，我们不是在分析事实，而是在给事物贴标签。**

因为按照"像不像"来判断非常快，也很省力，所以系统1特别喜欢这样工作。

但是，现实世界往往比表面复杂得多。

一个人看起来成功，不代表他真的成功；一家企业看起来热门，不代表它真的有价值；一个内容看起来普通，也可能蕴含真正有价值的观点。

因此，第8天最重要的提醒就是：

**不要因为一个人、一家公司或一件事符合你的刻板印象，就急着下结论。**

真正理性的判断，不是看它**像什么**，而是去看**证据是什么**、**概率是多少**、**事实是什么**。

只有学会从"凭感觉判断"转向"依据事实判断"，我们才能减少以偏概全的错误，做出更加客观、更加独立的决策。
