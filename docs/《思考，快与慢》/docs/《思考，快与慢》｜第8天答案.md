# 《思考，快与慢》｜第8天答案

今日答案：大脑喜欢故事感，但世界更看重概率



《思考，快与慢》里把这种现象叫作代表性偏差



简单说，就是我们看到一个人、一家公司、一件事，只要符合我们脑海里的某种模板，我们就会觉得：它大概率就是那样❤️



看起来像成功人士，看起来像好公司，看起来像爆款内容，这都会让你觉得这些是真的



但现实世界不是靠“像不像”运行的，而是靠概率、数据和长期结果运行的🤫



投资里尤其明显。很多人看到一家公司讲AI、讲芯片、讲未来，就觉得它一定有前途。但真正要问的是：它有没有收入？有没有利润？有没有竞争壁垒？价格是不是已经太贵了？



做自媒体也一样。一个视频刚发出去数据不好，不代表它没有价值；一个视频爆了，也不代表你已经掌握了规律。你要看长期反馈，看用户是不是真的被影响、被鼓励、被改变



不要只问它像不像一个好机会，而要问它是不是大概率真的有价值。



成熟的人有直觉，但不会让直觉替自己做全部判断👍
