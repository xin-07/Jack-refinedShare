# 《思考，快与慢》｜第16天答案

《思考，快与慢》第十六天答案——损失厌恶



赚1000块当然开心，但如果第二天再亏掉1000块，那种难受，往往比前一天的开心强的多



所以我们的大脑会天然想避免损失



投资里特别明显



一直股票赚了20%，很多人会想差不多了，赶紧卖

因为已经赚到的钱，我们特别害怕再失去

可一只股票亏了20%，很多人又会想只要我不卖，就不算真的亏



于是原本不喜欢风险的人，到了亏损状态反而越来越失去理智



我（Jack）常提醒自己不要把回本当成判断标准



一只资产值不值得继续持有，和你买入价没有关系



你真正应该问的是：如果今天我手里没有它，我还愿不愿意用现在这个价格重新买一次？



如果答案是否定的，那你继续持有，很多时候只是因为舍不得承认损失



分享一句经常默念的话：真正影响我们投资决定的，很多时候不是未来值多少钱，而是我们有多害怕承认自己已经亏了🎉
