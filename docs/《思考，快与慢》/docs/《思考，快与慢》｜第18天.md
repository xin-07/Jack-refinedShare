# 《思考，快与慢》｜第18天

《思考，快与慢》第十八天：为什么已经错了，我们还舍不得停下来？



今天先想象一个场景



你花69块买了一张电影票，走进电影院，看了半个小时，发现这部电影特别难看



剧情很无聊，演员也不吸引你，你坐在那里已经开始后悔了



第一个，立刻离开，回家休息，或者去做点更有价值的事



第二个，继续坐在那里，不看完不是亏了吗？



可问题是，不管你走不走，那80块都已经花出去了。你继续看完，并不能把钱拿回来，反而还要在浪费一个多小时



生活里这种事情太多了



一只股票已经亏了50%，明明基本面变差了，却还是不愿意卖，因为都亏了这么多了



一段关系已经让你很痛苦，但你舍不得结束，因为我都付出这么多年了



一个项目明明没前途，却还继续投入，因为前面已经花了太多时间



今天思考：为什么明明知道一件事可能已经错了，却还是会因为过去的投入，继续错下去？





**过去投入的钱、时间和精力已经无法回来，它们不应该决定你未来还要投入多少。**



真正成熟的人，不是永远坚持。

也不是轻易放弃。



而是能够在某一个时刻停下来问自己：



**“如果过去的一切都已经归零，只看今天，我还会做同样的选择吗？”**



**停止让过去的错误，继续消耗你的未来。**
