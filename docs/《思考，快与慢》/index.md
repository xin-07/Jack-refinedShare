# Jack带你读《思考，快与慢》

丹尼尔·卡尼曼经典之作，理解人类思维的两套系统。

《思考，快与慢》（Thinking, Fast and Slow）是诺贝尔经济学奖得主丹尼尔·卡尼曼的代表作。他用几十年的研究成果，揭示了人类大脑中两套思维系统的运作方式——**系统1（快思考）和系统2（慢思考）**。

系统1是直觉的、自动化的，帮我们快速做出判断；系统2是理性的、需要刻意调用的，帮我们深入分析。大多数时候我们依赖系统1，但它也容易让我们掉入各种认知陷阱。

这本书会带你认识这些陷阱：

- **锚定效应**：你的第一印象如何悄悄影响了后续判断
- **损失厌恶**：为什么失去100元的痛苦远大于得到100元的快乐
- **结果偏见**：我们如何用结果倒推过程，误把运气当实力
- **从众心理**：群体的力量如何悄然改变你的看法
- **过度自信**：为什么我们总高估自己的判断力

通过每天一个思维实验，跟着Jack一起，识别直觉陷阱，在投资、消费、工作和感情中做出更清醒的决定。
