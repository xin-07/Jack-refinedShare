365天思想实验，第157天

直播和大家聊了一个习惯：写日记
为什么我建议大家写日记？因为人的记忆，其实没有我们想象中可靠

如果你之前就读过我（Jack）写的 思考快与慢 解读，肯定知道我们会不自觉的修改自己的记忆，为什么开心，为什么焦虑，上个月做过什么重要决定，一年以后，你早忘记了

投资赚了钱，觉得自己早就看对了；事情失败了，又觉得自己当初其实有过担心。但如果你当时写下了真实的想法，回头再看，就能知道自己究竟是判断正确，还是运气好

日记最重要的价值是帮助我们认识自己，那怎么写？
我建议每天花五分钟，思考三点

1.今天发生了什么值得记录的事情？不要流水账，只写最重要的一两件

2.我当时是怎么想的？为什么做这个决定尽量记录真实的情绪和判断，而不只是最后的结果

3.今天学到了什么？明天准备改变什么？哪怕只改进一个小细节，也值得写下来

悄悄告诉你日记是今天的你留给未来的礼物
