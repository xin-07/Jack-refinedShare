# Jack：六年之约，不靠鸡血，靠系统改变人生

很多人问我(Jack)六年之约具体如何做 有没有具体方法

我的人生哲学就是一切都要创造为自动运转的系统

所以 我总结为下：

**钱的系统： 存钱、记账、投资常识、现金💰**

**脑子的系统： 阅读、提问、写作、AI使用⚙️**

**行动的系统： 每天专注、做自媒体、练表达、健身🏋️**

**关系的系统： 家庭沟通、朋友筛选、做不同观点的连接器🔗**

我每个月给一个主题，每周一个任务，每天一个小动作

这样你们会真的因为加入会员社区而改变生活

我的使命不只是做一个大家喜欢看的博主，而是要成为一个普通人改变命运的入口💕

💰 第一，钱的系统。 学习存钱、记账、投资常识，建立现金流意识。让钱不再只是花出去，而是开始为你工作。

🧠 第二，脑子的系统。 坚持阅读、学会提问、持续写作、善用AI。不断升级自己的认知，让思考能力成为最大的竞争力。

🏋️ 第三，行动的系统。 每天专注完成最重要的一件事，坚持做自媒体、练表达、健身。成长不是一次爆发，而是每天的一点点积累。

🔗 第四，关系的系统。 经营家庭沟通，筛选真正值得同行的朋友，也学会连接不同观点的人。很多机会，最终都来自人与人的连接。
