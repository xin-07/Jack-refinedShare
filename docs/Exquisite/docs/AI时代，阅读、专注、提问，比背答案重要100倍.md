# Jack：AI时代，阅读、专注、提问，比背答案重要100倍

都在问我(Jack)AI时代，孩子和年轻人最应该培养什么能力。我觉得肯定不是背多少答案，而是三种能力：阅读、专注、提问🤔



细说几句，更多可以直播聊



第一，阅读能力。未来知识越来越便宜，但你要先有理解世界的能力。所以我每天写内容，不是为了让大家看热闹，而是希望你们每天读一点、想一点，慢慢把脑子打开，每天几千字，一年真的相当于好几本书。秒杀全中国平均阅读量了



第二，专注能力。我之前直播说过，以后你只要刷到Jack的视频，就当作老天提醒你：该去做正事了。你可以点赞，然后留言：Jack，我要去学习、健身、写作、工作多少分钟了。然后立刻放下手机去做。



这种戒断短视频的能力，会在你15岁到40岁这段最精华的时间里，帮你省下大量生命。不信的就等着哭吧😭



第三，提问能力。未来答案到处都是，真正拉开差距的是：你会不会提出好问题。



所以别只问怎么成功，要问：我今天读了什么？专注了多久？提出了什么好问题？🦌
