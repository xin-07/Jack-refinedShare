# 未来20年，普通人靠什么翻身？

今天我看了 Anthropic 创始人 Dario Amodei 刚发的一篇博客。看完以后，我(Jack)脑子里一直有一个问题：未来二十年，最重要的能力到底是什么？



是学历吗？是努力吗？是会用 AI 吗？还是会赚钱？



我觉得这个问题非常值得每个人认真想一想。因为时代真的变了。过去很多人拼的是信息差，谁知道得多，谁就更容易领先。但现在 AI 出现以后，知识会越来越便宜，答案会越来越容易获得。那真正拉开人与人差距的，可能就不是“你知道什么”，而是“你如何判断、如何选择、如何行动”。



所以我今天不直接给答案。我希望大家先自己想一想，也可以在评论区写下来：未来二十年，你认为最重要的能力是什么？



明天直播，我会公布我的答案。这个答案不是鸡汤，而是我结合自己从普通家庭孩子一路走到财务自由，再看 AI 时代变化之后，非常认真得出的判断。



如果你未来二十年真的这么做，我相信有一天你肯定会感谢今天的自己。
