# 《穷爸爸富爸爸》｜第6天

《穷爸爸富爸爸》第6天思考



有两个年轻人，都攒下了20万元

第一个买了一辆20万元的车

第二个人用这20万元，买下了一台可以出租的设备

一年以后，第一个人的车还在，每天开着也很方便，但保险、保养、停车都需要花钱



第二个人的设备也还在，每个月有人付钱使用，扣掉维护费用以后，还能留下一部分收入



如果你问他们你们这一年买了什么？



两个人都回答我买了一样价值20万元的东西

但如果你问：这一年，这样东西。给你的。生活带来了什么？

答案可能完全不同



一个主要是在提供使用价值，同时需要持续支出

另一个除了有使用价值，还可能持续带来收入



所以我想分享一个判断方法

不要只看一样东西值多少钱，还要看它会怎样影响你的现金流



今天思考：一辆车、一套房子、一笔存款、一门小生意，到底哪些是资产，哪些是负债？

如果一样东西价值很高，却每个月都需要你拿钱维持，这算什么





**资产，是能够把钱带进你口袋的东西。**



负债最简单的理解就是：

**它需要你不断拿钱出去。**



**不要只看一个东西值多少钱，更要看它会让你的现金流往哪里走。**
