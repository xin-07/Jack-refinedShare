# 《穷爸爸富爸爸》｜第7天答案

《穷爸爸富爸爸》第7天答案



书里关于房子的观点，最容易被误解的，就是很多人把它听成了自己住的房子不是资产



但如果按照正式会计和财富统计的定义，房子当然可以是资产



它有市场价值，可以出售，也可能随着时间增加价值



所以我们不能因为一套房子每个月需要付钱，就说它完全没有资产价值



而我（Jack）想给大家的思考是你拥有的东西，和它每个月能不能替你产生收入，是两回事



比如你自己住的房子它可能给你稳定的生活，减少搬家的麻烦，也可能长期增加价值



这些都是真实的好处

但与此同时，它也可能每个月需要你支付房贷、抵税、保险和维修

所以它是你的资产，却不一定是你的现金流



再比如出租房，很多人听到“每个月收租”，就觉得一定是好资产

你还要扣掉贷款成本、抵税、保险、维修、空置，以及未来可能发生的大额支出，每个月还要掏钱



所以资产和现金流，是两张不同的成绩单，真正成熟的财富判断，是把这两张成绩单都看清楚，分清楚





**高收入不代表高资产，高资产也不代表高现金流。**



**不再只看“我拥有了什么”，而开始看“我拥有的东西，正在怎样影响我的财富”。**
