# 《穷爸爸富爸爸》｜第8天答案

《穷爸爸富爸爸》第8天答案



不知大家怎么看待消费本身



收入增加以后，我们会慢慢把原本可以选择的消费，变成每个月必须承担的固定支出



比如以前没有车，坐地铁也可以

后来买了车，每个月多了保险、停车、保养和贷款



以前住小一点也可以

后来换了更大的房子，房贷、地税、维护费用也跟着增加



这些选择都没错

生活变好，本来就是努力赚钱的意义之一



但如果收入增加的速度，永远赶不上生活成本增加的速度，我们就很难真正积累财富



所以我（Jack）觉得收入提高以后，最值得做的一件事是先给新增收入安排一个顺序



比如以前每个月赚一万，花8000，留下2000，后来收入变成两万，能不能不要马上把生活变成每个月花1.8万



而是先把新增的钱留下来，再决定剩下的钱怎么改善生活，这样你既可以过得越来越好，也可以让自己的资产慢慢增加



所以大家每次收入增加以后思考下：我的生活标准提高了，那我的财务安全感有没有一起提高





**生活变好没有错，但不要让生活升级的速度，超过财富积累的速度。**

真正的财富增长，不是让你永远不消费，而是让你慢慢做到：

**我可以选择更好的生活，而不是为了维持现在的生活，必须不停工作。**
