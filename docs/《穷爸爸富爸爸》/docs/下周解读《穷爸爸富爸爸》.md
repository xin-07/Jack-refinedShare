# 下周解读《穷爸爸富爸爸》

下周预告



我们之前解读的《小岛经济学》，研究世界上的钱是怎么运转的

八月解读的《思考，快与慢》，我们研究自己是怎么做决定的



那下一本，我想继续往前走一步，彻底分析

一个普通人，到底应该怎样理解财富？



下一本，我们一起读——《穷爸爸富爸爸》

为什么有些人一辈子努力工作，却一直在为钱工作？

为什么有些人会想办法，让钱替自己工作？

什么是真正的资产？什么又是你以为的资产? 

为什么收入越来越高，不一定代表越来越富？



还有一个我特别想和大家讨论的问题



如果今天让你从头开始，你会怎样重新建立自己的财富系统？



下一站，我们从大脑，走向财富

希望读完以后，大家不只是更懂钱

而是开始重新思考：自己这一辈子，到底想和钱建立一种什么样的关系



这本书网上的正义非常大恰恰也是筛选认知的一个机会。

 

相信我，这是本好书，但是需要智慧和耐心才能读明白❤️



让我们周一正式开始新书之旅吧
