# 《穷爸爸富爸爸》｜第2天

《穷爸爸富爸爸》

第2天：为什么工资越来越高，却不一定越来越富？



两个年轻人，今天都30岁。

第一个人月收入一万元，每个月花7000，留下3000。

第二个人月收入3万元，但是换了更大的房子，买了更好的车，吃饭、旅游、购物的标准全部提高，每个月最后只剩1000



五年以后，谁更有钱？

第二个人？

真的未必！

我们太容易用一个人的工资，判断一个人有没有钱



很多人每次收入增加，支出也会跟着增加

以前月收入5000，觉得一万元就够了

真的赚到一万，又觉得两万才够

后来赚到三万，生活标准也已经变成了三万元的标准



于是看起来收入越来越高，房子越来越大，车越来越好，但真正能够留下来的东西，却没有同步增加



今天大家思考：一个人的收入到底达到多少，才算真正开始变富？



年收入10万？50万？或更多？



留言告诉我👍







**高收入，只代表你创造现金的能力比较强，不代表你已经积累了财富。**



**真正开始变富，可能不是从“年收入达到多少”开始，而是从“收入增加以后，我终于没有把多出来的钱全部花掉”开始。**



“变富”不是一个绝对的收入数字，而是一个**财富积累过程**。



值得问的是：

**你的收入增长速度，是否超过了你的生活成本增长速度？**



以及：

**你的净资产有没有持续增加？**



再进一步：

**你有没有越来越多不依赖出售时间也能产生价值的资产？**
