# 《穷爸爸富爸爸》｜第三周总结

《穷爸爸富爸爸》第三周总结：如果钱全部没有了，你还剩下什么？

这一周，我们几乎没有讨论应该买什么

而是在讲一个更底层的东西：一个人创造财富的能力

第11天，我们讲了

钱来到你手里以后，你知不知道怎么留下、怎么管理、怎么控制风险，又怎么让一部分继续创造价值

第12天，我们讲了为什么普通人也应该懂一点最基本的财务知识

第13天，我们又往前走了一步：懂钱，还要懂规则

税、合同、保险、公司、债务......

第14天，我们讲了机会到底是怎么出现的

它一直摆在那里，只是以前的自己看不懂

最后一天，我们讲了我(jack)希望大家记住的一件事：不要只为了工资工作，也要为了能力工作

所以如果让我用一个问题总结这一周，我会问大家：

假设今天把你的房子、现金和所有资产暂时拿走，只把你的知识、经验、能力和人脉留下来，你还有没有能力重新开始

总结一句话：**钱是财富的结果之一，创造财富的能力，才是底层的资产**

<br />

**赚钱能力决定钱能不能来到你身边，管钱能力决定钱来了以后能不能留下来。**

**理解规则，在规则允许的范围内做正确的安排。**

**不同知识结构的人，面对同样的信息，会看到完全不同的东西**。

**能力是一个人未来继续创造财富的重要基础之一。**
