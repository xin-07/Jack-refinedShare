# 《穷爸爸富爸爸》｜第16天

《穷爸爸富爸爸》第16天思考

假设有两个人，都读完了这本书

第一个人特别兴奋。他知道什么是资产，什么是现金流

知道存钱，知道复利，也知道应该让钱为自己工作

和朋友聊天的时候，他甚至可以讲得头头是道

但一年以后，他的生活几乎没有变化

收入到账以后还是先消费，月底剩多少算多少

第二个人可能没有记住书里那么多概念

但读完以后，他只做了一件事：每次收入到账，先自动留下10%，第一年，这笔钱并不多，也没有让他突然变得富有

但他坚持了五年、十年，后来收入提高，他留下来的金额也越来越多

再慢慢把这些钱变成能够长期产生价值的资产

十年以后，两个人会拉开差距

为什么我们明明知道应该储蓄、运动、读书、控制消费，却还是经常做不到？到底是因为我们不知道正确答案，还是因为“知道”这件事情，本身根本没有我们想象中那么重要？

那什么才是最重要呢？读到这是不是发现和之前好多篇内容开始有联通之处了🤫

<br />

**真正拉开人与人差距的，往往不是“知道多少”，而是“知道以后，是否真的改变了自己的行为”。**

**知道，是理性的认知；执行，还会受到行为习惯和环境影响。**

**不要只增加自己的财富知识，而要把知识变成长期执行的规则。**

真正的差距，可能不是今天谁赚得更多。

而是：

**十年以后，谁已经拥有了一套会自己持续运行的系统。**
