# 《穷爸爸富爸爸》｜第一周总结

第一周《穷爸爸富爸爸》总结：为什么有些人收入越来越高，却还是不敢停

五天下来，能否回答：如果有一天你停止工作，你现在拥有的一切，还能不能继续支撑你的生活？

第一天，我们讲了穷爸爸和富爸爸最大的区别

区别是他们思考钱的方式不同

一个关心怎样找到更好的工作，提高收入？

另一个还会问除了自己工作，我能不能拥有一些持续产生收入的东西？

第二天，讲了收入高，不等于真正富有

一年赚100万，最后花掉95万和一年赚30万，长期能够留下10万，是完全不同的财富路径

重要的是这些钱经过你的手以后，到底留下了什么？

第三天，我们讲了老鼠赛跑

工资提高，消费升级导致整个生活，必须依赖下一份收入，恶性循环

第四天，我们讲了努力为什么也要有方向

如果今天的努力可以成为明天的生产力，那么时间就没有白花

第五天，我们终于讲到了这本书非常重要的一句话

工作不是终点，而是原始资本的起点、

下周开始讲资产和负债

<br />

第一天其实是在给整个系列换一个思考角度：

**不要只研究“怎么赚更多”，还要研究“赚到以后怎么留下，以及留下以后怎么继续创造价值”。**

**不要只追求今天的回报，也要让今天的努力产生未来的生产力。**

第一周最适合留下的一句话是：

**第一周，我们不是在学习“怎么变有钱”，而是在重新理解“财富到底是怎么积累起来的”。**

**努力工作，是起点。**

**提高收入，是能力。**

**控制支出，是纪律。**

**留下资本，是积累。**

**拥有资产，是开始。**

而真正的目标，是：

**让今天的自己创造的收入，逐渐变成未来可以继续为自己创造价值的东西。**
