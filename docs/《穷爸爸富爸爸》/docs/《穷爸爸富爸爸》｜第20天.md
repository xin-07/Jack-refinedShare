# 《穷爸爸富爸爸》｜第20天

到底拥有多少钱，才算财务自由？

《穷爸爸富爸爸》第20天

假设有两个人，第一个人拥有1000万资产。但他的生活每个月需要20万。房子、车、各种固定支出都很高

只要收入停下来，他很快就会开始焦虑

第二个人只有500万，但他的生活一年只需要20万，而过去积累的资产，每年产生的收入已经基本可以覆盖生活

他依然工作。但他工作已经不完全是因为下个月必须拿到这份工资

如果明天不喜欢这份工作，他可以离开。如果想休息半年，他可以休息

如果想花一年做一件暂时赚不到钱、但自己真正想做的事情，他也有选择

那么这两个人谁更接近财务自由？

我们用了20天讲这本书，最后发现财务自由可能从来都不是一个固定的数字，它更像一种。状态

所以最后一天，大家想想，如果有一天，你不再为了收入做自己不想做的事，那一刻，是不是开始接近财务自由？

晚上，我们用最后一篇，把这20天完整结束

<br />

财务自由可能不是：

“我有1000万了。”

而是有一天你发现：

**我可以工作，也可以不工作。**

**我可以休息一段时间。**

**我可以选择一个暂时赚不到钱，但真正想做的事情。**

**我不喜欢现在的工作，也有离开的底气。**

这时候，钱真正带给你的就不只是消费能力，而是：

**时间、选择和不被迫的自由。**

所以第20天最后这个问题，其实非常值得留给自己：

**如果有一天，我不再为了收入做自己不想做的事——那一刻，我是不是已经开始接近自己理解的“财务自由”了？**
