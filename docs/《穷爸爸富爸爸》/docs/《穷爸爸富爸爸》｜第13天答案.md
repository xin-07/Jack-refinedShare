# 《穷爸爸富爸爸》｜第13天答案

《穷爸爸富爸爸》第13天答案：真正赚钱的人，不只是研究机会，也研究规则

很多人刚开始赚钱的时候，脑子里只想着要高收入

收入从10万变成20万，再变成50万

但随着你拥有的东西越来越多，你会慢慢发现，决定最后结果的已经不只是赚了多少

还有很多以前根本不会注意到的问题。比如税，合同，公司结构，保险，债务等

甚至同样一件事情，用不同的方式去做，承担的责任和最后留下来的结果都可能不同

普通人不需要成为律师、会计师或者税务专家，但你至少要知道什么时候自己已经不懂了，应该去找专业的人

研究税和公司，不等于想办法钻空子，大家先理解规则，然后在规则允许的范围内做正确的安排

财富认知其实是一层一层的，最开始，你学会赚钱，然后学会留下钱，再学会看懂资产和现金流

等拥有的东西越来越多以后，你还必须学会怎样在规则里面保护自己已经积累下来的东西

分享一个小秘密：**赚钱靠能力，留下财富除了能力，还要懂规则**

<br />

**赚钱能力，是财富系统的入口。**\
**财富管理能力，是让财富能够留下来的重要部分。**

**以后遇到财富问题时，不要只问“能赚多少钱”，还要问“这里有什么规则和风险？”**
