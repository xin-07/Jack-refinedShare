# 《穷爸爸富爸爸》｜第7天

《穷爸爸富爸爸》第7天思考：你住的房子，到底是不是资产？



假设有两个人，各自花100万买了一套房子

第一个人自己住

每个月要付房贷、物业费、保险，还要承担维修费用



第二个人把房子租出去

每个月收到租金，扣掉房贷、物业费、保险和维修以后，还能留下2000元



这两套房子，哪一套是资产？



如果第一套房子十年以后价值增加了呢



如果第二套房子虽然有租金，但维修、空置和其他成本很高呢



今天思考：一套房子到底算不算资产，应该看它的市场价值，还是看它每个月产生的现金流？



如果你现在有一套自己住的房子，你会怎样判断它对你的财富到底意味着什么？



晚上根据我(Jack)最真实的经验来分享





我觉得第7天最值得大家建立的，就是这三个维度。

① 市场价值

② 现金流

③ 使用价值



**同样一套房子，不同的人买、不同的用途、不同的资金结构，最终对财富的意义都可能不同。**



**房子是不是资产，不应该只看它是不是很贵，而应该看它在你的财富系统里扮演什么角色。**



一套自住房可以很有价值，但可能持续消耗现金流。

一套出租房可以产生租金，但也可能因为成本、空置和维修最终没有多少净现金流。



所以我们真正要学会的，不是给房子贴一个简单的：

**“资产”或者“负债”标签。**

而是开始看：

**它的价值在哪里？现金流在哪里？成本在哪里？风险在哪里？**
