# 《穷爸爸富爸爸》｜第19天答案

让我（Jack）再次白手起家，我会先把顺序建立起来

穷爸爸富爸爸第19天答案

第一步，我会先提高自己的赚钱能力，因为本金少， 最重要的资产就是自己

每个月只能留下1000元，与其研究如何让1000元获 得更高回报，不如思考怎样把收入从1w提高到1.5w

学技能、做作品、积累经验、提高表达和销售能力让 自己越来越值钱

第二步收入进来以后，先留下一部分，不是月底剩多 少存多少，而是一开始就决定有一部分钱属于未来的 自己,收入提高以后，也不要把所有增长都立刻变成 更高的生活成本。

第三步建立自己的安全垫。让一次失业、一次意外支 出，不至于把过去几年的计划全部打乱

第四步才是慢慢建立自己的资产。而且我不会追求一 开始就找到什么神奇的机会。我更愿意先选择自己真 正理解、能够长期坚持、即使判断错了也不会让自己 无法重新开始的方法

然后不断重复

赚钱-留下钱-建立资产-让资产继续产生价值-再把产 生的价值重新放回系统

<br />

安全垫的作用就是：

**保护你的财富系统不会因为一次意外就被迫重置。**
