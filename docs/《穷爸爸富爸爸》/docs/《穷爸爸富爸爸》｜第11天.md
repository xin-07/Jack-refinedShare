# 《穷爸爸富爸爸》｜第11天

《穷爸爸富爸爸》第11天思考



有两个人，今年都突然多赚了10万元



第一个人特别开心

换了手机，出去旅游，买了很多以前舍不得买的大小，一年以后，10万元基本花完了



第二个人拿到这10万元以后，没有马上决定怎么花

他思考下：这笔钱我要不要留一部分应急？

有没有成本很高的债务需要先处理？

剩下的钱能不能变成长期资产？

如果拿去做一门生意，最坏的结果是什么？

税务上又会产生什么影响？



同样是10万元

一年以后，两个人拥有的可能完全不同



真正不同的可能根本不是这10万元，而是他们处理这10万元的能力



这种能力就是对财富的认知



如果一个人一年收入100万，却不知道自己的钱去了哪里；另一个人收入30万，却懂得储蓄、看懂基本数字、控制风险、积累资产



到底谁更懂钱？



所以今天大家要思考下

一个人很会赚钱，就代表他对财富的认知很高吗





**真正的财富认知，不是让你更会追逐钱，而是让你拿到钱以后，知道应该怎么处理它。**



**会赚钱，让你的收入变高；**

 **懂财富，才让收入真正有机会变成财富。**
