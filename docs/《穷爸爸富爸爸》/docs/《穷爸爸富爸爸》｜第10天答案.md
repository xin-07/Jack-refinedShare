# 《穷爸爸富爸爸》｜第10天答案

《穷爸爸富爸爸》第10天答案：



很多人会说现在钱这么少，买什么才可以变富？

但我（Jack）觉得顺序反了

因为一个人赚1万花1万，那么未来收入变3万，他也会把生活变成3万的标准



所以第一步不要研究买什么

而是先建立规则：收入进来，留下一部分，再安排剩下的钱

这和月底看看还能剩多少完全不同



一个是收入 → 消费 → 剩下多少算多少

另一个是收入 → 先留下 → 剩下的安排生活



第二步，才是让留下来的钱慢慢变成资产

可以长期投资能够产生现金流的东西，也可以先成为一笔安全储备，甚至年轻的时候，钱用来学够提高未来收入的技能



第三步，是让资产产生的收入继续留下来

这时候很重要的东西开始出现了：复利



最开始，你的资产主要靠你自己工作一点点积累

后来，过去留下来的钱也开始参与积累

时间越长，后面那股力量才可能越来越明显



钱少的时候建立习惯，收入提高以后保持比例，时间再替你完成剩下的事情





**延迟消费，把今天的一部分收入交给未来的自己。**



**现在最需要建立的，可能不是选出一个“最牛的投资品”，而是先让自己拥有稳定留下钱、管理钱、积累资产的能力。**



**财富不是从“我有很多钱”开始的，而是从“我赚到的钱，有一部分能够留下来”开始的。**
