# 《穷爸爸富爸爸》｜第3天答案

第3天答案——《穷爸爸富爸爸》



真正困住一个人的，可能不是收入太低，而是生活必须依赖下一份收入



老鼠赛跑不是说上班是不好的



工作当然重要

尤其年轻的时候，工作可以给我们收入、经验、人脉和能力

真正值得思考的是：如果我的收入提高一倍，我的生活成本是不是也必须提高一倍？



如果答案永远是“是”，那无论赚多少钱，我们可能都很难获得真正的选择权



所以 你思考下：如果从明天开始，暂时不工作，你现在的生活能够维持多久？

一个月？半年？三年？



还是即使不工作，过去积累下来的资产产生的现金流，也能够承担一部分生活？



这个数字，其实比工资更能说明一个人的自由程度



所以要脱离“老鼠赛跑”不是辞职，更不是拒绝消费

而是每一次收入增加的时候，不要把增加的部分全部变成新的生活成本



不要让自己永远只能靠下一份工资才能继续生活



真正的财富是给你越来越多说不的权力，和越来越多选择自己怎么生活的自由





**收入增长很重要，但控制生活成本的增长同样重要。**



真正的脱离“老鼠赛跑”方式是：

**在工作的时候，逐渐降低自己对单一工资收入的依赖。**



**工作可以是财富系统的一部分，但不应该永远是财富系统的全部**



**真正的财务自由，不是你赚到了多少钱，而是有一天，你终于不再因为害怕失去下一份工资，而被迫接受自己不想要的人生。**



**努力工作，是为了让今天过得更好；积累资产，是为了让未来拥有更多选择。**



而“老鼠赛跑”真正值得我们警惕的，就是：

**不要让自己的收入越来越高，却让自己越来越不敢停下来。**
