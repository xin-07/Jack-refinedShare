# 《穷爸爸富爸爸》｜第二周预告

《穷爸爸富爸爸》第二周预告：第一周，我们一直在讨论

为什么有些人收入越来越高，却还是不敢停止工作？



第二周，我们要进入这本书最核心、也是争议最大的一部分：



资产和负债



我们会探讨房子到底是不是资产？



为什么有些人收入越来越高，压力反而越来越大？



为什么两个收入差不多的人，十年以后财富差距可能非常大？



还有一个特别重要的概念——现金流。



这一周，我(Jack)希望大家开始学会不再只用赚多少钱判断一个人的财富，而是去看钱从哪里进来，又去了哪里



如果第一周是在学习怎么赚钱

那么第二周，我们开始学习怎么把赚到的钱，慢慢变成真正属于自己的财富



下周，我们一起重新检查自己的“资产栏”





如果第一周让我重新理解的是：

**“赚钱不是财富的终点。”**

那么第二周让我最期待的是：

**开始真正检查自己的财富结构。**



第一周是在改变你看待**工作和收入**的方式。

第二周则开始改变你看待**自己拥有的一切**的方式。



**不要只看自己赚了多少钱，开始看看自己留下了什么，以及这些留下来的东西，未来能不能继续为你创造价值。**
