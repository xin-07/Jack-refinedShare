# 《穷爸爸富爸爸》｜第18天

这本书哪些东西千万不能机械照搬？

《穷爸爸富爸爸》第18天思考：你是不是和我一起读这本书到今天，知道了不要一辈子只为了工资工作，要购买资产，要让钱为自己工作，要学习商业被投资。

你是否想既然工作不能让我财务自由，那稳定工作是不是没意义？

既然现金本身不会帮我创造更多价值，那是不是应该尽量全部拿去投资？

既然买资产这么重要，那是不是只要价格看起来便宜，就应该大胆出手？

甚至看到别人买房、创业、借钱扩大生意，你会觉得是不是胆子越大，最后越容易成功？

但仔细想想，好像哪里不对

因为一本里。正确的道理，如果放到错误而人、错误的时间、错误的条件下，也可能得到完全不同的结果

所以今天大家思考一个可能比。“这本书讲了什么”更重要的事情

如果一本书真的改变了你 我们到底应该复制作者的做法，还是学会作者思考问题的方法？

晚上我们一起聊❤️

<br />

**可以学习别人的地图，但不能直接复制别人的路线。**

**自己分析、自己判断、自己做决定的能力。**

**书告诉我一个思考方向 → 我理解它为什么成立 → 看自己的实际情况 → 判断现在是否适用 → 再决定行动。**
