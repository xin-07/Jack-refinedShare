# 《穷爸爸富爸爸》｜第二周总结

穷爸爸富爸爸第二周总结：赚到的钱，最后到底去了哪里？



这一周，我们讲了最核心的一部分：资产、负债和现金流



如果只能记住一句话，我（Jack）希望大家记住：不要只关心自己赚了多少钱，更要关心赚到的钱，最后变成了什么



这一周第一件事，我们重新认识了资产和负债



资产把钱放进你的口袋，负债把钱从你口袋拿走



当然，这不是严格的会计定义



以后买一样东西，除了它值多少钱？还要想拥有它以后，它会怎样影响我的现金流？



我们还学会了把财富看成两张成绩单：一张看资产价值，一张看现金流



所以如果把这一周五篇浓缩成一条财富路径，就是：

收入 → 留下一部分 → 形成资产 → 产生新的现金流 → 再继续积累资产



这个循环刚开始的时候非常慢，甚至慢到你觉得没有意义



但财富积累本来就不是一场一个月的比赛



所以今天大家想想：如果再给我十年，我希望今天赚到的钱，最后变成什么？
