# 《穷爸爸富爸爸》｜第17天答案

不同的钱，本来就应该有不同的任务

《穷爸爸富爸爸》第17天答案



很多人会把所有的钱看成一样的，其实完全不是



第一层的钱，是让你活下去的钱。房租、吃饭、保险、基本生活

这部分钱最重要的任务 不是获得多高的回报



而是需要的时候，它一定在那里



第二层的钱，是保护你的钱

比如突然没有收入、汽车坏了、家里出现意外支出



它的意义是给你时间，如果完全没有安全垫，一次意外就可能迫使你改变原来的长期计划



第三层，才是长期不用的钱



这部分钱，才更适合考虑怎样长期创造价值。所以一个人的财富系统很像盖房子。很多人一上来就在研究屋顶应该多漂亮



地基稳不稳才最重要



而且这个顺序不是每个人都完全一样，收入特别稳定的人和收入波动很大的人，需要的安全垫可能不同。

有家庭的人和一个人生活的人，也可能不同



所以不要机械的记住必须留几个月，而是思考



如果我的收入突然停止，我需要多少时间，才能不慌不得重新安排生活？
