# 《穷爸爸富爸爸》｜第9天

《穷爸爸富爸爸》第9天思考：为什么有钱人特别重视现金流？



有两个人



第一个人拥有一套价值500万的房子，开着一辆50万的车

但是房子每个月有贷款、税费、保险和维护，车也有各种固定支出

他的工资很高，但每个月收入到账以后，很快就要支付各种账单



第二个人住的房子普通很多，车也很普通

但是他有几项能够持续产生收入的资产

每个月1号，即使他什么都不做，也有一部分钱自动进入账户



如果只看拥有的东西，第一个人看起来明显更有钱

但如果两个人同时一年没有收入，谁会更轻松



这就是我（Jack）这十几年最大价值的思考：现金流



简单说就是钱从哪里流进来，又从哪里流出去



大家好好想想如果一个人拥有1000万的资产，却每个月都需要大量现金维持生活



另一个人只有500万资产，却能够持续产生足够覆盖生活的现金流



到底谁更接近财务自由？这篇看上去最短 实则充满了智慧 晚上我来给答案





工资本质上是：

**用自己的时间和劳动换来的主动收入。**

而现金流关注的是：

**即使我暂时不工作，还有没有钱持续进入我的账户？**



财务自由：**你的非劳动收入，能不能长期覆盖你的生活支出？**



**有钱 = 我拥有的资产，能够持续给我创造选择权。**
