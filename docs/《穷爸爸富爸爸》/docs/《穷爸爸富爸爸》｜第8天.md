# 《穷爸爸富爸爸》｜第8天

《穷爸爸富爸爸》第8天思考



假设一个年轻人，刚工作的时候，每个月收入

8000元

他租一间普通的房子，坐地铁上班，周末偶尔出去吃顿饭

每个月花5000，还能留下3000



后来他升职了，收入变成了2万元

他特别开心，觉得自己终于可以过得好一点了。

于是换了更大的房子，买了车，吃饭、旅游、购物的标准也慢慢提高



几年以后，他每个月收入已经到了3万元

但有一天，他突然发现自己现在每个月必须花掉的钱，已经接近2.8万元



房贷、车贷、保险、孩子的教育、各种固定账单......



以前收入8000的时候，他觉得自己很穷

现在收入3万了，他却发现自己更不敢失去工作



因为以前少赚一个月，可能只是少存一点钱

现在少赚一个月，很多账单就可能付不出来



今天大家思考下

为什么收入提高，本来应该让一个人越来越自由，却可能让他越来越依赖下一份收入？



如果你明年收入增加一倍，你会先提高生活标准，还是会先将可能存钱







赚了更多的钱，让生活过得更好，这当然是收入增长应该带来的好处。

真正需要警惕的是：

**有没有把一次性的消费，慢慢变成自己必须长期承担的固定成本。**



**生活标准一旦上去了，通常很难再降下来。**

**不要让生活升级的速度，超过财富积累的速度。**



**随着收入增长，他能够留下越来越多的钱，积累越来越多的资产，同时让自己必须承担的生活成本不要增长得太快。**
