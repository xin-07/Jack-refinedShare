# 《穷爸爸富爸爸》｜第12天答案

第12天答案

很多人一听到会计马上觉得这是专业人士才学

但以我（Jack）的经历每个人都必须学会会计知识

不需要会做复杂的账，但要看懂基本的数字

比如一门生意，营业额100万，不代表赚了100万

你至少要知道钱从哪里进来？

为了赚这些钱，付出了多少成本？

最后真正留下多少？

为了维持这门生意，还欠别人多少钱？

手里有真正拥有多少有价值的东西？

再比如一个家庭

一年收入50万，看起来不错

但如果一年花掉48万，和一年收入30万、留下10万，完全是两种状态

所以普通人至少应该看懂三张特别简单的表：

第一张：我拥有什么，又欠什么

第二张：一年有多少钱进来，又有多少钱出去

第三张：最后到底有多少现金真正留下来

前两周我们一直讲的资产、负债、现金流和这连起来了

今天思考

你想做的事情成本是多少最后能留下多少？我要承担什么风险？为了得到这些收入，我需要投入多少资金

故事让你兴奋 而数字让你智慧❤️

<br />

**财务知识的第一作用，就是帮你把“看起来很好”和“实际上怎么样”区分开。**

**收入是一个流量概念，资产更像是你已经积累下来的东西。**

**故事可以帮助你发现机会，但数字帮助你判断这个机会到底值不值得。**
