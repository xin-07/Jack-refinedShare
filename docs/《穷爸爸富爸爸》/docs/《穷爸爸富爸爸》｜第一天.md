# 《穷爸爸富爸爸》｜第一天

《穷爸爸富爸爸》

第一天：两个爸爸，最大的区别到底是什么？

这本书一开始，作者讲了两个对他影响很大的爸爸

一个是他的亲生父亲，也就是穷爸爸

他受过很好的教育，工作稳定，也很努力

他告诉孩子好好读书，考个好成绩，找一份稳定的工作

另一个是他朋友的爸爸，也就是书里的富爸爸

他没有那么高的学历，却一直在做生意、买资产、研究钱是怎么流动的

他告诉孩子不要只想着找一份好工作，要学会让钱替你工作

这两个人都很聪明，也都很勤奋

但是面对同一个问题，他们的第一反应完全不同

当一个东西太贵的时候，一个人会说这个我买不起

另一个人却会问我要怎样才能买得起？

一个人结束了思考，另一个人开始了思考

所以今天我（Jack）特别想问你们，如果一个孩子从小听到的都是找稳定工作、好好存钱、不要冒险，另一个孩子从小却在学习资产、现金流、生意和投资，20年以后，他们对钱的理解会有什么不同？

是否应该听取大人的建议？

<br />

财富思维很重要的一步：

**不要只看结果，要开始研究实现结果的路径。**

**稳定很重要，资产也很重要；储蓄很重要，投资也很重要；工作可以创造收入，资产可以创造第二层收入。**

我们真正要解决的是：

**怎样把收入、储蓄、资产、投资、能力和风险管理，组合成属于自己的财富系统。**
