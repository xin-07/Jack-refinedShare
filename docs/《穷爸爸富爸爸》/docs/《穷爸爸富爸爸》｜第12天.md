# 《穷爸爸富爸爸》｜第12天

《穷爸爸富爸爸》第12天思考



假设你的朋友开了一家餐厅，他特别兴奋地告诉你：

我这个月营业额30万！



听起来是不是生意特别好？



但你继续问

食材花了10万

员工工资花了8万

房租3万

水电、平台、保险、广告又花了4万

各种设备维修和其它费用，再花3万

最后真正留下来地，可能只有2万



现在另外一家餐厅，一个月营业额只有15万

但是所有成本加起来只有10万，最后能留下5万

所以到底哪家生意更好？



很多人看公司喜欢看销售额，做生意喜欢 看流水，看一个人喜欢看收入



但我希望大家都培养财务知识

因为数字不会因为你感觉生意很好，就自动变好



今天大家要思考

如果一个人特别会赚钱，却看不懂自己地收入、支出、资产、债务和现金流，他真的算懂钱吗？



为什么有的人赚的越来越多，但对财务知识严重缺乏？



我(Jack)建议大家今天找一家平时一直消费的店。然后拆解他的财务模型，然后判断这个生意的风险和利润如何



晚上留言





**营业额决定了生意有多大，但利润才能告诉你这个生意到底有没有赚钱。**



**不要只看结果，要学会拆解结果背后的财务结构。**
