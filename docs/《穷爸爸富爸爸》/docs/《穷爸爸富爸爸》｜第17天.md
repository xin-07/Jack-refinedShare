# 《穷爸爸富爸爸》｜第17天

有了钱到底应该先存，还是投资？

《穷爸爸富爸爸》第17天思考

两个年轻人，工作几年以后，都终于攒下了10万元

第一个人想：钱放着也是放着，应该赶紧让钱为我工作，于是他把10万元几乎全部拿去做长期投资

结果半年以后，家里突然需要3万元，他手里没有足够的现金，只能临时把原本准备长期持有的资产变现

第二个人却没有急着把钱全部拿出来

他算了一下如果明天突然没有收入，房租、吃饭、保险、交通这些最基本的生活，一个月需要多少钱？

然后先留出一笔备用资金，剩下暂时用不到的钱，再慢慢进入长期资产

几年以后，两个可能都在投资，但他们的系统完全不同

第一个人追求怎样让每一分钱产生回报

第二个人先考虑怎样在发生不好的事时，不会不得已打断自己的长期计划

今天思考：到底先存，还是先投？如一直存，可能错过长期积累

如全部拿出又可能没有安全边际

这两件事情，到底应该怎么排序？晚上我（Jack）分享我的理解

<br />

存钱解决：

**短期安全和流动性**。

投资解决：

**长期增长和资产积累。**

**不要只看收益，还要看资金的用途和时间。**

**现金**提供的是：**流动性 + 安全感 + 选择**权

**现金不一定是为了赚钱，它有时候是为了让你不用在错误的时间卖掉资产。**
