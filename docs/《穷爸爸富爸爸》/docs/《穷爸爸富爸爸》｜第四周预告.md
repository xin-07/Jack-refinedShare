# 《穷爸爸富爸爸》｜第四周预告

《穷爸爸富爸爸》最后一周预告

不知不觉，我们已经一起读了三周

第一周，我们讨论为什么很多人一直在为钱工作

第二周，我们开始理解资产、负债和现金流

第三周，我们又发现，比钱本身更重要的，可能是是一个人创造被管理财富的能力

而最后一周，我（Jack）不想再给大家增加太多新的概念

而是把前面学到的东西，真正放进这几年的人生

知道资产和负债有什么用？

知道现金流有什么用？

知道财富认知、复利、规则、和能力有什么用？

如果看完一本书，第二天的生活还是和以前一模一样，那这本书可能只是给我们增加了一点知识

所有最后一周，我们会开始回答：一个普通人知道这些道理以后，第一步到底应该做什么？

如果现在手里的钱并不多，应该从哪里开始？

我现在在哪里？我想去哪里？未来十年，我准备怎样赚钱、留下钱、积累资产，同时提高自己的能力？

最后五天，我们一起把这本书读完，也把属于自己的财富系统真正开始搭起来

最后五天真正要做的，不是让自己再记住十个财富概念。

而是开始搭建自己的第一版财富系统。

<br />

**哪怕现在钱很少，也可以开始。**

因为真正重要的，可能不是你今天有多少钱，而是：

**从今天开始，你赚到的钱，是否终于开始有一部分属于未来的自己。**
