# 《穷爸爸富爸爸》｜第一天答案

《穷爸爸富爸爸》

第一天答案

我（Jack）觉得两个爸爸最大的区别，不是有钱和没钱，而是他们面对钱的时候，脑海里出现的反应完全不一样

穷爸爸思考的是我怎样获得一份更好的工作，让自己的收入越来越高？

富爸爸思考的是除了工作，我还能拥有什么，让它持续给我带来收入？

这两个问题看起来只差一点，时间久了，人生就不同了

比如你每个月收入一万

第一种思路就是努力工作，争取以后变成两万、三万

这当然没有错

但第二种思路会再多问一步我今天赚到的一万元，有没有一部分能够留下来，变成未来继续给我创造收入的东西？

这就是这本书最值得学习的地方

它不是告诉我们工作没有用，恰恰相反，年轻时认真工作、提高收入非常重要

但如果一个人一辈子只有一种赚钱方式——不断出售自己的时间，那一旦停止工作，收入也跟着停止

所以今天开始，养成一个习惯：每次赚到钱思考一下：我能不能留下一部分，让它变成未来的生产力？

留言九月要存多少

<br />

**当收入增加以后，你有没有把一部分收入从“今天的消费”，转化成“未来的生产力”？**

**钱一到账，就先想“我要留下多少”，而不是月底花剩多少。**

这就是从“消费者思维”向“财富积累思维”的一个非常小、但很重要的改变。

**努力工作，是财富的起点；但如果所有收入都来自出售时间，财富系统就很脆弱。真正重要的是，在提高收入的同时，把一部分今天的收入，慢慢变成未来能够继续创造价值的资产。**
