# 《穷爸爸富爸爸》｜第18天答案

书里这几点非常重要

《穷爸爸富爸爸》第18天答案

第一：不要只看收入，也要看最后留下了什么

收入再高，如果全部变成消费，一个人的财富系统仍然非常脆弱

第二：尽量拥有能够长期创造价值的资产，不要让人生永远只有一条路径：工作一天，获得一天的收入

第三：学会看数字、现金流、风险、规则。钱越多，这些能力越重要

第四，也是对30岁钱孩子最重要的，不只积累钱，也要积累能力

但是这本书也有一些地方，我（Jack）不会简单照搬

比如作者经常用一句非常简单的话区分资产和负债：资产把钱放进口袋，负债把钱拿出口袋

但现实世界比这复杂得多。一个东西可能没有产生现金流，却依然拥有价值，自住房就是最典型的例子

再比如让钱为你工作。这也不代表钱一到账，就应该全部拿出，昨天讲过，安全垫本身就是财富系统的一部分

希望大家理解书里内容，然后回到自己的生活里重新判断，按照自己的年龄、收入、家庭责任、能力、风险承受能力好好想

<br />

**“以后遇到财富问题，我会从收入、资产、现金流、风险、能力等角度去思考。”**
