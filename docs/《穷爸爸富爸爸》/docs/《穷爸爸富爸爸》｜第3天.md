# 《穷爸爸富爸爸》｜第3天

第3天：《穷爸爸富爸爸》



一个年轻人25岁，找到了一份不错的工作

第一个月拿到工资，他特开心

后来收入提高，他买了一辆更好的车

过几年结婚了，换了更大的房子，有了孩子，教育、保险、生活的支出越来越多



与此同时，他的工资也从每个月1万，慢慢变成两万、3万

看起来，他一直在进步

但到了40岁，他突然发现一个问题：自己已经不敢停下来了

房子每个月要付钱，车要付钱，孩子要花钱，一家人的生活标准也已经建立起来



以前月收入1万的时候，他需要1万

现在月收入3万，他发现自己需要的可能也是3万

所以只能继续工作、继续提高收入、继续支付越来越高的生活成本



这就是《穷爸爸富爸爸》里一个特别经典的概念：老鼠赛跑

就像一只老鼠在滚轮上拼命奔跑，它真的非常努力，也跑得越来越快



但跑了很久以后回头一看，自己好像还在原来的轮子里



今日思考：一个人工资越来越高、生活越来越好，为什么反而可能越来越不敢停止工作？





第2天我们说：

**高收入，只代表创造现金的能力比较强，不代表已经积累了财富。**

第3天进一步发现：

**高收入甚至可能让一个人更加依赖自己的工作。**



一个人真正需要警惕的不是“花钱”，而是：

**有没有把越来越多的支出变成自己无法轻易降低的固定成本。**



**努力工作没有问题，但如果收入增加的同时，生活成本也不断增加，让你越来越离不开工作，那么你可能只是跑得更快，而不是越来越自由。**



**真正的财富，是当你越来越努力的时候，也应该让自己的“必须工作”越来越少，让自己的“可以选择”越来越多。**
