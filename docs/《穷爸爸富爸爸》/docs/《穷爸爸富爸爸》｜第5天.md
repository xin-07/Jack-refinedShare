# 《穷爸爸富爸爸》｜第5天

《穷爸爸富爸爸》

第五天思考：到底什么叫让钱为你工作？



假设两个人，各自攒下了10万元



第一个人觉得：我辛苦这么多年，不就是为了享受生活吗？

于是换了一辆更好的车



第二个人也很喜欢这辆车，但他决定暂时不开

他把10万元放进一个能够长期产生收益的地方

假设平均每年能给他带来5000元。

第一年，5000元

第二年，又有新的收益

如果这些钱继续留下来，它还可以继续产生新的收益

最开始的时候，这点钱看起来非常不起眼。



一个月可能连一顿好吃的饭钱都没有

但第二个人发现以前生活里所有的钱，都必须自己出去工作才能赚回来



现在第一次出现了一笔钱——不是他今天工作换来的



我对大家说句心里话：不要一辈子只为钱工作，要学会让钱为你工作



道理这么简单，为什么大多数人都知道钱可以生钱，最后却还是很难做到？



到底拥有多少钱以后，才有资格开始让钱为自己工作？



10万？

100万？

财富积累最有意思的地方就在这里：

**最开始的收益往往很小，小到让你觉得它没有意义。**



**真正的财富，不是你赚到第一笔钱，而是你开始让第一笔钱为未来的自己继续创造价值。**



你不需要等到100万才开始。

**第一笔能够留下来的钱，就是你财富系统真正开始运转的起点。**



而接下来最关键的问题也自然出现了：

**既然我们要把钱变成资产，那么——到底什么东西才是真正的资产？**
