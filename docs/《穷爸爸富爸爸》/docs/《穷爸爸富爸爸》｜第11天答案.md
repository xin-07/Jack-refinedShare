# 《穷爸爸富爸爸》｜第11天答案

《穷爸爸富爸爸》第11天答案



会赚钱，只是财富认知的一部分

因为赚钱以后，你还要面对很多事情

钱怎么留下来？

留下来的钱怎么配置？

一项资产值不值得拥有？

一门生意赚不赚钱？

借钱的成本是多少？

税和规则会怎样影响最后留下来的钱？

风险来了以后，能不能承受？



这些全部加在一起，才慢慢构成一个人处理财富的能力



有些人收入很高，但每个月根本不知道自己花了多少钱

有的人做生意营业额很大，却连最后真正留下来多少都说不清楚

还有人看到别人赚钱，马上跟进去，却从来没有认真算过最坏的结果自己能不能承受



这些都是处理钱的能力还没有跟上赚钱的能力



送大家四句话，每天看看就能提高对钱的理解

1. 看得懂钱从哪里来

2. 知道钱去了哪里

3. 知道怎么让一部分留下来继续创造价值

4. 更知道怎样避免一次错误，把过去很多年的积累全部毁掉



赚钱的能力决定钱能不能来到你身边，管钱能力决定钱来了以后，能不能留下来🎉





**会赚钱，是把钱带进财富系统的能力；**

**会管钱，才是让这些钱真正留下、增长，并且不轻易被一次错误带走的能力。**
