# 《穷爸爸富爸爸》｜第2天答案

《穷爸爸富爸爸》

第2天答案：



其实一个人真正开始变富，并没有一个固定的工资数字

因为收入和财富，本来就是两件事情



收入，是今年有多少钱经过你的手

财富，是这些钱经过你的手以后，最后有多少真正留了下来，并且继续产生价值



请大家六年之约过程中观察是否进入这个循环：

收入提高→支出提高→必须继续提高收入→更不敢停止工作



收入决定你的速度，留下来的东西才决定你最终能走多远



一个人一年赚100万，花掉96万，另一个人一年赚30万，留下10万



第一年看起来，第一个人明显更成功

但如果这种状态持续十年，结果可能完全不同



书里反复提醒我们，很多人收入增加以后，第一件事情不是增加资产，而是升级生活，去买更好的车，更大的房子



慢慢地，他不是越来越自由，而是需要越来越高的收入，才能维持现在的生活



看完这篇，要设定两目标

1.赚得越来越多

2.同时还能存下越来越多



缺一不可





**财富不是看你有多高的收入，而是看你的收入经过你之后，最终留下了什么。**

**高收入是能力，能够把收入转化成长期积累，才是财富。**



财富积累并不是让你永远过苦日子。

而是：

**在享受今天的同时，不要把未来全部消费掉。**



**真正的变富，不是让自己的工资越来越高，而是让每一次收入增长，都有一部分被留下，并逐渐转化成未来可以继续创造价值的资产。**
