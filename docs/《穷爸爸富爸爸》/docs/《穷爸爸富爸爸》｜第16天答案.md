# 《穷爸爸富爸爸》｜第16天答案

真正改变人生的，从来不是你知道什么，而是你重复做什么🤫



《穷爸爸富爸爸》第16天答案





读完一本书以后会出现一个错觉，我懂了，我改变了



其实完全白高兴！你要存钱账户里不会真的留下了钱，你要长期积累，你也未必真的坚持了十年



知识只有进入行为以后，才开始真正产生价值



所以读完一本书不要想着改变十件事情，能真正改变一件事，就已经非常值了



比如读完这篇后，每次收入进来，先留下固定比例



然后把这条规则坚持十年，这比记住书里的100句话更有价值



我（Jack）一直说的建立人生系统，就是不要每天想着自己今天要不要健身 要不要存钱？



因为只要每天重新决定，人就一定会受到情绪影响



把需要意志力的事情，慢慢变成不需要重新思考的规则，最后你会发现：真正拉开人与人差距的，从来都不是特别聪明的选择。



而是一个很普通的动作持续十年！





“复利”不一定只发生在投资账户里

**人的能力、习惯、认知，同样可以产生长期积累。**



**① 我最近学到的东西，究竟改变了什么行为？**

**② 我能不能只选择一个动作？**

**③ 我能不能把它变成规则，而不是靠意志力？**
