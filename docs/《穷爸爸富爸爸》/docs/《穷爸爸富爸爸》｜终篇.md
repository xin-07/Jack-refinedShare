# 《穷爸爸富爸爸》｜终篇

财富最后买到的是选择权

《穷爸爸富爸爸》终篇

读到最后，整本书没有说不要工作。对普通人来说，工作就是建立财富的起点

工作让我们获得收入。收入让我们留下第一笔钱，留下来的钱慢慢形成资产，资产开始产生新的收入

新的收入再继续积累。与此同时，我们继续提高自己的能力。

于是整个系统开始转起来：能力 → 收入 → 留存 → 安全垫 → 资产 → 新的收入 → 更多选择

注意最后两个字：选择

这才是我理解的财务自由

财务自由不是什么都不做也不是让你买更贵的车、更大的房子，或者让别人觉得你很有钱

而是有一天，你可以对不喜欢的事情说不

你甚至不需要等到那一天，才开始感受到自由，当你的安全垫从1个月变成6个月，你自由了一点

当你不再依赖每个月最后一分钱，你又自由了一点，它不是突然来的，它是慢慢增加的

书读完了，但真正的生活才开始，因为从明天起，没有21天了。剩下的，是你自己的几十年

<br />

真正需要改变的是：

**不要让自己永远只有“工作换工资”这一条财富路径。**

这20天最终留下来的，也许不是某一个投资方法，而是一套思维：

**能力 → 收入 → 留存 → 安全垫 → 资产 → 新收入 → 更多选择。**

最后真正积累的，也不只是钱。

而是：

**让自己越来越有能力选择，自己想怎么生活。**

这可能就是这本书读到最后，最值得带走的一件事。
