# 《穷爸爸富爸爸》｜第4天答案

第4天答案——《穷爸爸富爸爸》

努力很重要，但更重要的是，你的努力能不能积累



我（Jack）年轻的时候相信一件事情：只要比别人更努力，就会有结果

但年龄越大发现努力其实分为两种



一种叫重复型努力

今天做一天，得到一天的回报

明天停止，回报也停止



还有一种叫积累型努力

你今天做的事情，明天还能继续产生价值

比如学会一项能力，今天花100小时学会了，以后很多年都能使用



比如做内容，一条内容可能只能被看几天，但几年下来形成的影响力、信任和用户，却可能一直积累



再比如资产，年轻的时候把一部分收入留下来，它未来继续给你产生现金流



所以书里不是“不要努力工作”而是年轻的时候可能更应该努力

但努力的时候，一定要想想：我今天做的事情，是做完结束了，还是能留下什么



不要害怕年轻的时候辛苦。但要想清楚，你今天吃的苦，有没有变成明天可以留下来的东西



努力决定你今天能走多快

积累，才决定十年以后你站在哪里





真正的“积累”必须满足一个条件：

**今天留下来的东西，未来真的有继续创造价值的可能。**



**让过去的时间、过去的收入、过去的努力，开始共同为未来创造价值。**



**努力 × 积累**

努力决定你今天能走多快。

积累决定你走过的路有没有留下东西。
