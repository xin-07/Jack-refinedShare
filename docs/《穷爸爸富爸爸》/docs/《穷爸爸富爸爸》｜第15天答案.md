# 《穷爸爸富爸爸》｜第15天答案

《穷爸爸富爸爸》第15天答案

为了学习而工作，而不只是为了赚钱而工作，我（Jack）不是说工资不重要，而是除了工资，这份工作每个月还在给你留下什么？

假设你工作五年

第一种情况，五年以后你只是把同一件事重复得越来越熟练

第二种情况，五年以后你学会了销售、表达、谈判、管理、财务、技术，甚至知道一门生意到底怎么运转

这五年在简历上可能都是五年工作经验，但留在你身上的东西完全不同

年轻的时候有两种收入

一种是今天发到你账户里的收入。另一种，是未来很多年还能继续使用的能力

第二种收入，当时看不见，但时间越长，它可能越值钱

年轻人不要过早把自己锁死在一个特别窄的能力

懂技术的人，还会表达，他的技术可能更容易被别人看见

会做内容的人，懂商业，他能更清楚内容最后怎样产生价值

分享一句心里话：**年轻的时候，不只让工作购买你的时间，也要让工作投资你的未来，重点培养能力、经验、判断力、作品、信誉**

<br />

**在自己的核心能力之外，再不断增加一些能够产生协同作用的能力。**

**真正重要的，不只是你今天赚了多少钱，而是你有没有不断提高自己未来创造财富的能力。**

**一份工作的价值，不应该只看它今天给我多少钱，也应该看五年以后它让我变成了什么样的人。**

工资是很容易看见的。

但能力、经验、判断力、作品和信誉，是需要时间才能慢慢显现价值的。

所以年轻的时候，工作当然要赚钱，但也不要让自己的五年只剩下一张工资流水。

**让工作给你工资，也让工作给你成长。**

因为工资可能在某一天停止，但真正掌握的能力、积累的经验和判断力，可能会陪你走得更远。
