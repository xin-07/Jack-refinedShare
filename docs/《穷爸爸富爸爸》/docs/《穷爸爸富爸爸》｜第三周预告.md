# 《穷爸爸富爸爸》｜第三周预告

《穷爸爸富爸爸》第三周预告



前两周，我们一直在聊钱



怎么赚钱，怎么留下钱，什么是资产，什么是现金流



但到了第三周，我们聊一个我（Jack）觉得比钱本身更重要的东西



一个人到底应该培养什么能力，才能越来越会赚钱？



对财富的深刻理解



这不是会背多少理财知识，也不是每天研究市场



而是你能不能看懂一门生意怎么赚钱，看懂最基本的数字，理解税和公司的规则，判断风险，发现别人没有注意到的机会



下周会聊



年轻的时候，到底应该为了工资工作，还是为了能力工作？

有些工作今天给你的钱很多，但五年以后什么都没有留下

有些工作今天赚得不多，却可能让你学会销售、表达、管理、投资、谈判，甚至建立一门生意



所以第三周，我希望大家思考：如果今天把我的钱全部拿走，只留下我的能力，我还能不能重新赚回来？



如果答案是可以，那可能才是一个人真正不容易被拿走的资产



下一周，我们开始聊：



钱之外的财富🎉





**钱是结果，能力才是创造结果的底层东西之一。**



**年轻的时候，不要只想着把银行卡里的数字变大，也要想办法让自己的“赚钱能力”不断变强。**
