# 《穷爸爸富爸爸》｜第6天答案

《穷爸爸富爸爸》第6天答案



资产是把钱放进你的口袋，负债把钱从你的口袋拿走



这个说法很有启发性，但我们要注意，它是作者为了教大家理解现金流使用的简化框架，不完全等同于正式会计里的资产和负债



比如一套你自己住的房子

从会计和财富统计的角度，它当然可以是资产，因为它有市场价值



但从现金流的角度，它可能每个月都需要你支付房贷、地税、保险和维护费用



所以不是房子没有价值而是不要因为一样东西很贵，就自动认为它正在让你越来越富



再比如一辆车

它可能让你上班更方便、节省时间、改善生活，这些价值都是真实的



但如果它主要用于个人消费，就不能因为买的时候花了很多钱，便认为它会持续创造收入



反过来，一门小生意、一套出租物业，或者一项能够产生收益的投资，也不能只看收入



今天找一个你想买的东西，思考

一，买完它一年后值多少钱？

二，它每个月是在给我带来钱，还是需要我继续拿钱维持？

三，必须买吗





真正应该记住的不是“资产=进钱，负债=出钱”

**不要只看你拥有多少东西，要看这些东西正在把你的钱带向哪里。**



一辆车、一套房子、一笔存款、一门生意**它们都有价值。**



但如果我们开始从财富的角度思考，就需要进一步问：

**它除了给我今天的价值，还能不能给我未来的现金流和选择权？**
