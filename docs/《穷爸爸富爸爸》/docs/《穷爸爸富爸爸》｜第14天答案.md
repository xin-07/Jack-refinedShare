# 《穷爸爸富爸爸》｜第14天答案

《穷爸爸富爸爸》第14天答案



年轻的时候特别容易误解什么是机会，总觉得是突然认识一个贵人、碰到一门特别赚钱的生意、或是发现一个所有人都不知道的项目



但真正的机会其实一直在那，只是以前的你看不懂



比如一家公司，不懂商业的人看到的是一个品牌，懂一点商业的人开始看它靠什么赚钱

再懂一点的人，会看利润、现金流、竞争优势和未来还能不能继续增长，同一家公司摆在那里，每个人看到的东西完全不同



房子也是一样，有人只看到价格，有人看到地段



有人还能看到租金、税费、维修、土地、法规以及未来可能的用途



所以。拉开差距的不是谁得到的信息更多，而是同样的信息摆在面前，谁能看出更多东西



这也是为什么我觉得学习最大的回报之一，会不断扩大你的“机会识别范围”



你懂商业，就多看懂一种机会。懂财务，有多看懂一种

懂法律、税务、技术、销售，再多看懂一些



所以要冲的时候问自己是真的看懂了，还是只是觉得它听起来很赚钱





**知识不仅帮助你解决问题，也帮助你发现原本根本没有意识到的问题和机会。**



**不是等待机会改变自己的财富，而是不断提升自己的能力，让自己能够看懂更多机会。**



**因为真正属于自己的财富，不只是现在账户里有多少钱，还有未来自己能够看见什么、理解什么、判断什么。**
