# 《穷爸爸富爸爸》｜第10天

《穷爸爸富爸爸》第10天思考



假设两个25岁的年轻人，每个月都是1万元

扣掉生活开支以后，两个人都能剩下2000元

第一个人想：2000块能干什么？等以后工资高了，我再开始理财



于是这个月换个手机，下个月出去旅游，偶尔在买点自己喜欢的东西



钱基本没有留下来



第二个人也觉得2000块很少

但他给自己定了一条规则：不管赚多少，每个月先留下其中一部分

最开始可能只有500块、1000块、2000块

这些钱短期根本改变不了他的生活



一年以后，也没有让他突然变得有钱

但五年、十年以后，两个人之间开始出现一个很重要的区别：一个人每个月仍然只能依靠当月的收入



另一个人身后，已经慢慢积累了一些过去留下来的东西



所以今天大家思考下，建立资产栏，到底应该等有钱以后再开始，还是应该从钱很少的时候就开始？



如果你每个月只能留下500块，它真的有意义吗？



晚上分享普通人资产管理的第一步





**不要等有钱以后才开始建立资产，而要从钱还不多的时候，就让自己拥有“留下钱”的能力。**



因为财富真正拉开差距的，很多时候不是某一次赚了多少钱，而是：

**你从什么时候开始，让今天赚到的钱，变成明天仍然属于你的东西。**
