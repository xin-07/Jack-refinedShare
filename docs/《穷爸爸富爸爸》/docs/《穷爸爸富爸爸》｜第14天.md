# 《穷爸爸富爸爸》｜第14天

《穷爸爸富爸爸》第14天思考

一套房子，正常情况卖100w，但房主急需资金，希望80万尽快卖掉

三个人同时看到这套房子

第一个人说80万也太贵了，没这么多钱然后走了

第二个人说比市场价便宜20万，太划算了马上准备出手

第三个人却没有急着做决定，他先去查附近类似房子的成交价格，再算维修需要多少钱，能租多少钱，税费和持有成本是多少

最后他发现，如果所有数字都成立，80万可能确实有空间

但如果房子需要几十万维修，所谓的便宜20万，可能根本没有想象中的那么便宜

三个人看到的是同一套房子

为什么最后看到的却像三个完全不同的机会？

我（Jack）一直有一个观点就是

机会不只是被发现的，很多时候是靠知识识别出来的

今天思考为什么同样一个机会放在100个人面前可能只有少数人真正看得懂？

到底是他们运气更好，胆子更大，还是因为他们提前拥有了某种别人没有的能力

我（Jack）到底是心灵鸡汤 还是让大家拥有这种能力？

<br />

**不同知识结构的人，面对同样的信息，会提取出完全不同的信息。**

**机会其实一直存在，但不是所有人都能看见。**

**运气可能让两个人同时站在机会面前，知识和能力却会让他们看到完全不同的东西。**

以前希望机会找到我。

现在更希望自己慢慢拥有识别机会的能力。

因为真正属于自己的财富，不只是银行卡里的钱，**还有让自己以后能够看懂机会、判断机会、抓住合理机会的能力。** ❤️
