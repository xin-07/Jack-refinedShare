# 《穷爸爸富爸爸》｜第5天答案

第5天《穷爸爸富爸爸》答案：让钱为你工作，重要的是第一次建立第二种收入来源



很多人听到让钱为你工作，第一反应是要现有很多钱，其实恰恰相反



这件事情最难的阶段，就是钱还很少的时候



假设你只有1w，一年产生几百元的收益，看起来根本改变不了生活



很多人会想这么一点有什么意义？还不如花了



但真正重要的不是这几百

而是从这一刻开始，你建立了一套完全不同的财富逻辑



以前是：

时间→工作→收入→消费

现在中间多了一条路：

时间→工作→收入→留下一部分→资产→新的收入

然后再把新的收入继续放回去



刚开始的时候，你是整个系统里最辛苦的人

绝大部分钱都是你自己赚的

但如果时间足够长，资产越来越多，有一天你可能会发现过去的自己，也开始帮今天的自己赚钱了



我(Jack)觉得真正的财务自由是最开始，100%的生活都要靠今天的自己。



后来，过去积累下来的东西承担10%、20%、50%





**“财务自由”真正发生的那一刻，可能不是你赚到100万**

而是：

**你第一次发现，今天有一部分收入，并不是今天的你赚来的。**



**财务自由不是突然有一天赚了很多钱，而是你一点一点积累，让生活从100%依赖今天的自己，慢慢变成10%、20%、50%甚至更多，可以由过去积累下来的资产和能力共同承担。**



所以不要小看第一笔500元、第一笔1000元的资产收益。



**真正重要的不是它今天有多大，而是从这一刻开始，你的财富系统多了一条路。**



**以前，你只能自己赚钱。**

**后来，你开始让过去的自己帮今天的自己赚钱。**
