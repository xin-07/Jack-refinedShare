# 《穷爸爸富爸爸》｜第19天

如果今天一切清零，你会怎么重新开始？



《穷爸爸富爸爸》第19天



假设你过去积累的钱全部清零，房子没有了，存款没有了，投资没有了



但是你的身体、知识、工作经验和能力全部保留



然后有人给你一份普通的工作，每个月收入10000元，你重新从0开始



这一次，你已经知道了我们前面18天讲过的所有东西



你知道收入高不代表富有，知道要留下钱，知道资产和现金流的重要性也知道要建立安全垫，也知道真正重要的不只是钱，还有赚钱的能力。



那这10000元到账以后，你到底应该先做什么？



是先拼命提高收入？还是先存钱？什么时候开始建立资产？什么时候可以改善生活？如果以后收入从10000变成20000，有该怎么办？



很多人学财富知识的时候，学到的是一个个答案。但现实生活从来不会按照章节出现



所以今天一起思考如果现在让你从0重新开始，你能不能把过去18天学到的东西，变成一套自己可以执行十年的财富系统？





第19天最大的变化是：

**从“书里的财富系统”，开始转向“我的财富系统”。**



第19天真正想让我们思考的，不是：

**“10000元应该怎么投资？”**



而是：

**“如果从今天开始，我决定认真管理自己的钱，我准备建立一套什么样的规则，让它运行10年？”**



创造**属于你自己的系统**
