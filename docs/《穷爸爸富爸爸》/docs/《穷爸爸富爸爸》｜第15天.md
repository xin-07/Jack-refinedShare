# 《穷爸爸富爸爸》｜第15天

《穷爸爸富爸爸》第15天思考：年轻的时候，工资重要，还是学到东西更重要？

一个22岁年轻人，同时拿到两份工作。第一份工作，每个月给他15000元。工作比较固定，每天按照流程完成任务就可以

第二份工作，每个月只有10000元。但他需要不断接触客户，学习销售、谈判、做产品、看财务数据，还能跟着一个很厉害的老板学习怎么经营一家公司

如果只看未来一年，第一份工作明显多赚6万元。但如果把时间拉到十年呢？

假设第二份工作让他真正学会了销售、表达、管理和商业。这些能力以后可能跟着他很多年

那最开始少赚的6万元，到底是损失，还是他为自己交的一笔“学费”？

我认为年轻的时候，不要只为了赚钱而工作，也要为了学习而工作

所以今天的大家思考年轻人选择一份工作，到底应该优先看工资，还是要看这份工作五年以后能给自己留下什么？

<br />

以后看工作可以多问一句：

**“除了工资，这份工作还能在我身上留下什么？”**

因为工资花掉以后就没有了，但真正掌握的能力，有可能陪你很多年。

所以年轻的时候，如果一份工作能够让你接触真实的客户、真实的生意、真实的数字和真实的问题，那么它本身就可能是一所非常好的“学校”。

但我觉得最重要的不是盲目追求低工资的“学习机会”，而是要学会计算：

**我现在放弃了什么，未来又能得到什么。**

**不要只看今天的工资，也看看五年以后，自己手里多了什么。**
