# 《穷爸爸富爸爸》｜第9天答案

《穷爸爸富爸爸》第9天答案：真正决定你能不能停下来休息的，往往不是身价，而是现金流



很多人判断一个人会问你有多少资产

但我建议还应该再多问这些资产每个月在干什么？



假设一个家庭每个月生活需要2万元，工资收入5万元

看起来非常安全，但如果这5万元全部来自工作，一旦停止工作，现金流可能也会明显减少



另外一个家庭每个月同样需要2万元但是过去积累的资产，每个月能够带来1万元净现金流



那意味着即使暂时不工作，过去的积累已经能够替他承担一半生活



如果未来变成1.5万元、2万元、3万元呢



他的选择权正在一点点增加



我（Jack）觉得财务自由可以被理解得非常简单：

非工作产生的稳定现金流，逐渐接近甚至覆盖你的长期生活支出



今天大家算一个数：每个月家庭支出是多少？



如果明天暂时同时工作，现在已经积累的东西，每个月能够替我承担多少？



这个比例，比单纯比较谁的工资高，我觉得更接近一个人的财务自由程度





**高收入解决的是“我现在能赚多少钱”。**

而现金流解决的是：

**“如果我不再持续出售自己的时间，我还能不能继续生活？”**



**财富真正的意义，不只是让你拥有更多东西，而是让你越来越有能力选择自己的时间。**
