# 《穷爸爸富爸爸》｜第4天

第4天思考：《穷爸爸富爸爸》

为什么只靠努力工作，很难获得真正的自由？



有两个人，都特努力

第一个人每天工作10个小时

只要他去上班，一天就能赚1000块，他特别勤奋，今年工作了250天，赚25万



明年想多赚一点怎么办？

最直接的方法就是多工作，可以一天只有24个小时，而且只要哪一天他停止工作，那一天的收入也没了



第二个人一开始可能赚得还没有他多，但每天拿出两个小时，去做一件暂时看不到太多回报的事情



可能是学习一个技能，做自己的内容，建立一门生意，或者慢慢积累能够产生现金流的资产



前几年，第一个人甚至可能一直比第二个人赚得多



但十年以后

第一个人的收入，仍然高度依赖自己的时间

第二个人却可能慢慢拥有了一些——即使今天没有亲自工作，依然能够继续产生价值的东西



所以大家今天思考：如果努力工作真的这么重要，为什么有些人努力了一辈子，依然不敢停下来？





**努力工作可以让你赚到更多钱，但如果收入永远和你的时间绑定，你就很难真正获得自由。**



《穷爸爸富爸爸》提醒我们：

**不要让“出售时间”成为自己一辈子唯一的财富来源。**



真正能够产生复利的东西，往往是：

**今天投入，未来才开始产生回报**



**有些东西短期看没有回报，但长期可能改变你的收入结构。**



**每天拿出一点时间，不再只为今天赚钱，也开始为十年后的自己积累一些东西。**
