# 《穷爸爸富爸爸》｜第13天

《穷爸爸富爸爸》第13天思考：为什么真正懂钱的人，一定会研究规则？



假设两个人今年赚了100万元

第一个人只关心一件事：我怎么才能再多赚20万？



第二个人除了赚钱，还开始研究另外一些问题：我的收入到底属于上面类型？



不同收入在规则上有什么区别？

做生意的时候，哪些是真实地经营成本？

为什么有人用个人名义做事，有人却会成立公司？

合同应该怎么签？保险应该怎么买？

承担风险的时候，怎样把个人和生意分开？



两个人表面上赚的同样的钱。

但十年以后，他们真正留下来的财富、承担的风险，甚至做事情的方式，都可能完全不同



真正的财富认知，不只是会赚钱，还要理解这个世界的规则。



所以今天大家思考下为什么很多人特别愿意花几百个小时研究怎么多赚钱，却不愿意花几个小时研究：赚到钱以后，这个世界到底按照什么规则来处理它？



这期内容大家思考一遍就可以 不必研究和理解，等未来用到了 需要实操几次就会了





**赚钱的时候看收益，做事情的时候同时看责任和风险。**
