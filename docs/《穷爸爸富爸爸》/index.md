# Jack带你读《穷爸爸富爸爸》

《穷爸爸富爸爸》（Rich Dad Poor Dad）是罗伯特·清崎（Robert Kiyosaki）的代表作。作者通过「穷爸爸」和「富爸爸」两个截然不同的人生样本，揭示了普通人与富人在对待金钱、工作和资产上的根本差异。

这本书最重要的不是教你「怎么赚更多钱」，而是帮你重新理解财富的底层逻辑：

- **资产与负债**：什么是真正给你带来现金流的资产，什么只是你以为的资产
- **老鼠赛跑**：为什么收入越来越高，却越来越不敢停下工作
- **让钱为你工作**：如何建立除「出售时间」之外的第二种收入来源
- **财务自由**：不是赚到多少钱，而是当你不工作时，生活还能维持多久

通过每天的思考与讨论，跟着Jack一起，把「赚钱」升级为「积累财富」，把「为钱工作」转化为「让钱为自己工作」。
