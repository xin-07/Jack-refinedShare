# 电影

每周一部电影，用故事理解人生与世界。

好的电影不是消磨时间，而是借别人的一生，提前排练自己的选择。这里是我（Jack）每周推荐给专属会员的电影，每一篇都会聊一个问题：这部电影到底让我们想明白了什么？

**看电影时是故事，看完之后是镜子。** 同一部电影，不同阶段看，答案可能完全不同。希望你在这些文章里，找到一部愿意今晚就打开的片子。
