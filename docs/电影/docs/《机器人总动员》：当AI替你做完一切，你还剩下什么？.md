这周推荐一部电影：《机器人总动员》
不剧透

但我（Jack）写几句

他很孤独，但没有麻木

而人累什么都有了，不用走路，不要思考，不用劳动，吃喝娱乐全部被安排好，结果反而变得越来越弱，越来越迟钝，连真正的生活是什么都快忘了

我看完最大的想法就是对幸福的定义❤️

期待你们的观后感



这部电影真正想表达的不是：
**“科技会毁灭人类。”**
而是：
**如果我们忘记了为什么活着，再先进的科技也不能带来幸福。**

瓦力虽然只是一个机器人，却比很多人更像一个“活着的人”。

因为他还有：
**好奇心。**
**热爱。**
**期待。**
而这三个东西，可能才是幸福最核心的来源。❤️

结合AI、机器人高速发展的当今时代的启发：
**未来不会属于最会重复劳动的人，也不会属于最依赖机器的人，而属于懂得利用机器，同时保持人类独特能力的人。**

**AI会降低普通能力的价值，但会放大真正优秀人的价值。**
