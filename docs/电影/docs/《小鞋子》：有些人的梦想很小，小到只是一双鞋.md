# 《小鞋子》：有些人的梦想很小，小到只是一双鞋

这周推荐一部后劲很大的电影：《小鞋子》

这部电影讲的是一个伊朗小男孩，不小心把妹妹的鞋弄丢了。家里很穷，他不敢告诉父母，他知道，父母很辛苦了，再买一双鞋，对家里来说不是小事

于是兄妹俩想了一个办法：妹妹上午上学穿哥哥的鞋，放学后赶紧跑回来，把鞋交给哥哥，哥哥再穿着同一双鞋去上学

这个剧情特别小，就是一双鞋

一个孩子那么小，却已经懂得替家庭分担，懂得不让父母为难，懂得把自己的委屈藏起来

后来哥哥参加跑步比赛，他不是为了冠军，也不是为了掌声，他只是想拿到第三名，因为第三名的奖品是一双鞋。他拼命跑，拼命追，结果却跑成了第一名。

这一幕特别让人心酸。因为很多时候，穷人的孩子不是没有梦想，而是他们的梦想太具体了，具体到只是一双鞋、一顿饭、一次不让家人难过的机会。

今天我们能好好读书、工作、生活、给孩子买鞋，其实已经是很大的幸福。

也希望大家从这部电影里看到，真正的善良在很小很小的事里



**真正的善良，不一定是做多么伟大的事。很多时候，它只是一个孩子不想让父母为难，一对兄妹愿意互相体谅，一个人在生活不容易的时候，依然愿意为家人着想。**

如果用一句话总结这部电影，我会写：

**《小鞋子》告诉我们：有些人的梦想很小，小到只是一双鞋；但正因为如此，我们才更应该珍惜那些已经拥有、却常常被忽略的幸福。**
