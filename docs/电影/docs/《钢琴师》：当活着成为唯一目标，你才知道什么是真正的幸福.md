# 《钢琴师》：当活着成为唯一目标，你才知道什么是真正的幸福

如果你不想活下去了 推荐大家一部电影：《钢琴师》

这部电影讲的是犹太钢琴家在华沙的经历。他原本是一个体面的人，有音乐、有家人、有自己的生活。可是xx来了以后，一切都被打碎了。家人被带走，城市被摧毁，他从一个受人尊敬的钢琴家，变成一个每天只想着怎么活下去的人

电影里展示着那种一点一点失去人的尊严的过程。不能住原来的地方，不能自已走在街上，不能决定自己的命运，甚至来一口吃的都可能决定生死。

我推荐这部电影，不是为了让大家觉得历史很沉重，而是让大家明白：我们现在能好好吃饭、读书、工作、存钱、思考人生，其实已经是非常大的幸运。



电影提醒我们：**只有在和平、稳定、有秩序的环境里，人才有资格去讨论梦想、成长、投资、阅读和未来。**

能够每天好好工作、陪伴家人、学习知识、规划人生，本身就是一种幸运。

**真正的幸福，不是拥有得越来越多，而是在失去的参照中，重新发现自己已经拥有的一切。**

《钢琴师》最大的价值，不是让人沉浸在历史的悲伤里，而是让人离开电影之后，更珍惜眼前平凡却珍贵的生活。
