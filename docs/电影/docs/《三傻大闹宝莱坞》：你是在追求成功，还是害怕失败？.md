# 《三傻大闹宝莱坞》：你是在追求成功，还是害怕失败？

这周推荐一部印度电影《三傻大闹宝莱坞》

不剧透电影时长很长 留三四个小时看 希望大家喜欢



**不要把一生都用来证明自己没有失败，却忘了问自己究竟想过怎样的人生。**

**真正的成功，不只是你最终得到了什么，更是你有没有在追求成功的过程中，逐渐成为自己想成为的人。**



电影与讲解的《被讨厌的勇气》有很多相似点：

1. **不要为了满足别人的期待而活** —— 课题分离

2. **不要把别人的评价当成人生标准** —— 摆脱他人认可的束缚

3. **不要让恐惧替你做决定** —— 目的论与改变的勇气

4. **人生的价值，不只在于竞争和胜负** —— 共同体感觉与贡献
