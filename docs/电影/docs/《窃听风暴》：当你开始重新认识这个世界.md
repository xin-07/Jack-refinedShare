# 《窃听风暴》：当你开始重新认识这个世界

这周推荐一部讲述东德时期值得思考的电影：《窃听风暴》

不剧透 但是大家过程中对于不了解的背景可以和AI多聊，能了解很多书里没有的历史

我们学习历史和社会运行机制，不要简单的判断谁好谁坏，而是要明白为什么需要独立思考



**一个人最大的变化，有时候不是他获得了新的权力，而是他开始重新审视自己过去坚信的一切。**

**当你真正开始了解一个人，而不是只通过身份、标签和组织给出的评价认识他，你对他的判断可能会发生改变。**

用三句话总结这部电影：

1. **不要让身份代替思考。**
2. **不要让环境限制自己的认知。**
3. **不要失去理解他人的能力。**

**当你开始认真倾听别人的生活，你也许会重新认识这个世界，甚至重新认识自己。**
