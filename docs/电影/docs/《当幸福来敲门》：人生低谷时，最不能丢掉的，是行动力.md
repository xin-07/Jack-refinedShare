# 《当幸福来敲门》：人生低谷时，最不能丢掉的，是行动力

这周推荐：《当幸福来敲门》
送给想做销售或者正在做销售的你

主角的生活已经被逼到死角。他卖医疗仪器，卖不出去，房租交不上，老婆离开他，他还要带着年幼的儿子生活。最难的时候，他连住的地方都没有，只能带孩子睡地铁站的厕所，这一幕带好纸

他一边照顾孩子，一边到处找机会，最后去证券公司争取一个实习机会。问题是，这个实习没有工资，竞争还特别激烈。也就是说，他白天要拼命表现，晚上还要想办法让自己和孩子有地方睡

这才是真正的人生低谷。不是情绪不好，不是暂时不顺，而是现实每天都在追着你要答案，回想我(Jack)的人生其实并没有如此落魄！

但是我们对待生活的态度是一样的，没有等别人来救他，也没有把责任推给时代。我们做一件事：抓住眼前唯一能改变命运的机会，然后死死不放

我推荐这部电影，想提醒大家：人在顺的时候，一定要存钱、学习、积累能力；人在难的时候，一定不要丢掉行动力，只要你不放弃，就没人能打败你❤️



**这不是一篇在讲“幸福”的电影推荐，而是一篇在讲“成年人如何面对现实”的内容。**

而且它其实和 Jack 之前一直讲的很多东西是连着的：

**顺的时候，不要挥霍自己的运气；**
**难的时候，不要挥霍自己的时间；**
**机会来的时候，不要挥霍自己的行动力。**



**真正厉害的人，不是从来没有跌入低谷，而是在低谷里的时候，依然知道自己下一步要做什么。**
