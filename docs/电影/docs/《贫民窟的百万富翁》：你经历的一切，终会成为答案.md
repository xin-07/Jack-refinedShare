# 《贫民窟的百万富翁》：你经历的一切，终会成为答案

这周推荐一部必看的电影：《贫民窟的百万富翁》

记得我第一次看是在网吧通宵实在无聊，随便找了个片子看，没想到不知不觉看完了...

不剧透，大概是一个印度贫民窟长大的男孩，参加电视答题节目，竟然一路答到最后一题。所有人都不相信他因为在他们眼里，一个没读过多少书、从底层长大的孩子，怎么可能知道那么多答案？

介绍给大家是因为我（Jack）也有类似成长经历，贫民窟长大，经历过贫穷、暴力、失去、逃亡，也见过人性的善恶。没有上过最好的学校，没有被系统培养过，但生活本身给他上了一堂又一堂

很多当下觉得痛苦、没用、甚至想忘掉的经历，未来某一天，可能都会变成你人生里的答案🥺

大家看完告诉我你的感受哦



**经历本身没有价值，能够被你重新理解和使用的经历，才会变成资产。**
