# 《原则》｜第18天

为什么有些事，你解决了一百次，却还是一直发生？



原则第18天思考



假设你开了一家餐馆。最近几个月，餐馆经常出现顾客点的菜。总是上错桌。每次出现这种情况，经理都把服务员叫过来说一顿



服务员道歉，重新上菜，事情暂时解决，但过不了几天，同样的事情又发生了



然后经理开始罚款。第一次上错菜罚十元，第二次罚二十元。结果，服务员越来越紧张，出错的情况却没有明显改善



后来，新来了一位经理。他没有急着说任何人，而是在餐馆观察了几天。最后发现，原来餐馆使用的点餐系统，经常把相邻桌号显示的非常相似。尤其在用餐高峰期，服务员很容易看错



于是，他调整点餐界面，又增加了一道上菜前核对桌号的流程。从那以后，上错菜的情况明显减少



生活中类似的事情很多。孩子每天早上起床迟到，父母就每天催促。一个人总存不下钱，就不断提醒自己要节约，但事情从没被解决



所以书中提问：如果一个错事反复出现，说明什么？如何解决？





**反复出现的问题，通常值得从机制和流程中寻找原因。**

**不要只要求自己下一次做得更好，还要让下一次做得更好这件事，更容易发生。**

**真正解决问题，不是每次都能把错误修复，而是逐渐减少错误发生的概率。**
