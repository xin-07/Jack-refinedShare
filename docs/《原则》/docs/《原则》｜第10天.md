# 《原则》｜第10天

要不要做完美的人？

原则第10天思考

有两个人，都准备创业。第一个人特别努力，也特别要强。擅长产品设计，能够发现用户的需求，做出非常受欢迎的产品。但他不擅长财务管理，也不喜欢处理复杂的合同

可他觉得优秀的创业者，就应该什么都会。于是，他每天花大量时间研究财务、法律、招聘和管理，所有重要决定都要自己做

结果，公司规模越来越大，他也越来越忙。原本最擅长的产品研发，反而没有时间做了。

第二个人同样擅长产品设计，也同样不懂财务和法律。但他清楚自己的优势和不足。所以，他把更多精力放在产品上，同时寻找可靠的财务人员和法律顾问，帮助自己处理不擅长的事情

几年以后，两个人的公司可能走向完全不同的结果

今天思考下
一个人究竟应该努力消除自己的所有弱点，还是承认弱点，并建立一套能够弥补弱点的系统？

如果选择后者，会不会变成给自己的不足找借口？

如果有一天你创业了，必然会遇到这个麻烦



**一个人首先要认识自己的知识边界，然后认识自己的能力边界，最后建立一套能够帮助自己持续成长的系统。**

今天最重要的思想是：
**不要把自己培养成一个必须什么都会的人，而要培养成一个知道自己擅长什么、缺少什么，以及如何弥补不足的人。**

**一个人的能力有上限，但一个好的系统可以让不同人的优势组合起来，创造出远超个人能力的结果。**
