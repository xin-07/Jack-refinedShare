# 《原则》｜第11天答案

事实还是观点——原则第11天答案

我们可以把一个人的判断过程分成三个部分。第一层，是事实。第二层，是解释。第三层，是决定

这三层被我们混在一起，但他们其实完全不同。还记得白天那个餐馆的故事吗？一家餐馆最近三个月营业额下降了20%

这是一条事实

第一个管理人员认为，是价格太贵，顾客不愿意来了。第二个人认为，是餐馆缺乏特色，应该提高定位。这是对事实的两种解释

而降价或者涨价，则是根据解释提出的行动方案🤫

但他们都跳过了验证自己的解释，而这是最重要的

验证的最好方式就是进行小规模测试，最终可以不断获得新信息，这也是六年之约里实习的作用

大家以后遇到事情，问自己三句话
一，现在真正知道的事实是什么？
二，如何解释这些事实？有没有其他可能？
三，准备采取什么行动，是建立在已验证的事实之上，还是建立在未验证的猜测之上？

并且要明白我们不可能获得全部信息，有些事情就存在不确定性！



**不要先急着证明自己的方案正确，而是先设计一个能够检验自己方案的实验。**

**不要把猜测当成事实，不要把观点当成答案。**

以后遇到重要问题，可以先问自己三个问题：

1.**现在真正知道的事实是什么？** 把已经确认的信息和自己的主观判断分开。

2.**我如何解释这些事实？有没有其他可能？** 不要只寻找支持自己观点的信息。

3.**准备采取什么行动？这个行动是建立在已验证的事实之上，还是未验证的猜测之上？**



**真正的成长，不是不断积累自己相信的观点，而是不断用现实检验自己的观点。**
