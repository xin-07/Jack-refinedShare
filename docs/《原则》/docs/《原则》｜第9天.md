# 《原则》｜第9天

你会投资谁

原则第9天思考

两个人都准备开餐馆。第一个人特自信。以前做过生意，也赚过不少钱，所以觉得做餐馆没那么复杂

有人提醒他，餐饮行业的成本结构和其他行业不太一样，他觉得自己做过这么多年生意，难道还不懂赚钱吗？

朋友建议他先研究附近的客流量、租金和友商情况，他也觉得没有必要。反正自己有钱、有经验，开起来再说

第二个人却不一样。虽然他也做过生意，但他知道自己没有餐饮经验。所以再签租约之前，他先找了有经验的人聊天。了解食材成本、人工成本附近也没有流量等等

有些建设没用，他就继续研究，寻找实际证据。最后，他可能开餐馆，也可能发现这个项目并不适合自己。

第一个人看起来特别有信心。第二个人却总是问东问西的

但如果让你把自己的钱交给其中一个人去投资，你更愿意选择谁？
为什么？

我（Jack）想好好听听你们的想法。从开餐馆的角度和投资人的角度



**开放心态（Open-Mindedness）**
**愿意承认自己的知识存在局限，愿意听取不同意见，并且根据事实调整自己的判断。**

真正**好的决策过程**应该是：
**收集信息 → 建立判断 → 验证假设 → 承担合理风险 → 根据结果调整。**

**投资一个人，不仅要看他知道什么，还要看他如何面对自己不知道的事情。**
