# 《原则》｜第20天答案

想改掉坏习惯 用以下五步——原则第20天答案



作者在书中提出了一个五步流程：明确目标、发现麻烦、诊断原因、设计方案、执行方案



很多人改变失败是因为直接从目标到了行动。比如减肥，你知道少吃、多运动，但坚持不下来。可能目标定的太高，也可能工作时间不稳定，或者是家里总放着容易让自己吃过量的零食



如果这些事情没有被发现和改变，那下再大的决心，也会失败



所以真正有效的改变，是尽量减少弱点反复影响自己



大家直播总问我（Jack）怎么养成阅读习惯。与其每天提醒自己要努力学习，不如规定每天早上喝咖啡时固定阅读二十分钟，想存钱就每个月收入到账后自动转入储蓄账户



想少刷手机，就把容易分散注意力的应用移出首页，或者在固定时间关闭通知



这些方法的共同点，就是把原本需要反复依靠意志力完成的事情，逐渐变成有明确触发条件的行动流程



所以当你在半途而废或者做事情无法自律的时候，别责怪自己不够努力



今天给大家一个非常实用的练习。选一件你已经下过很多次决心，却始终没有坚持下来的事情



问自己三点



第一，我真正想达到的目标是什么？

第二，过去最经常让我失败的原因是什么？

第三，我能不能设计一个足够简单、即使状态不好也能执行的行动方案？



比如，不要写坚持运动



而是写成每天晚饭后运动二十分钟，如果当天。特别忙，至少完成十分钟



这样，你就把一个模糊的愿望，完成了一条可以执行的规则🎁



今天，我们建立第二十条人生原则：想改变自己，不要只依靠决心。明确目标，找到反复失败的原因，设计具体、可执行、能够持续调整的行动系统



最后送给大家一句话：真正改变人生的，不是某一天突然变得特别努力，而是建立一套即使在普通日子里，也能让自己持续进步的系统🎉





**发现麻烦，就是把笼统的失败，变成具体可观察的问题。**



**真正改变自己，不是反复下决心，而是认真分析为什么过去失败，并建立一套新的行动机制。**



「究竟是什么机制，让我反复在这里失败？我能改变其中的哪一个环节？」

当你能够把反复发生的问题，从情绪和自责中抽离出来，作为一个可以分析、设计、测试和优化的问题去处理，你就开始真正掌握改变自己的方法了。



**真正的成长，不是要求自己永远不犯错，而是让自己越来越能够发现错误、理解错误，并改变产生错误的机制。**
