# 《原则》｜第12天

要不要跟着多数人走

原则 第12天思考

假设你准备买一套房子。你看中了一套价格不错、位置也很好的房子，于是邀请是个朋友一起帮你参考。其中九个人都说：“这房子不错，价格合适，赶紧买吧！

只有一个人提出反对，他说我觉得你应该先检查一下地基，这套房子可能存在结构不对

另外九个人觉得他太谨慎了。“房子看起来这么好，哪有不对？大家都觉得不错，难道我们九个人还不如你一个人懂？”

但有意思的是，这个提出反对意见的人，恰好是一位有二十年经验工程师。另外九个人，虽然是你的好朋友，却没有一个人真正了解房屋结构

如果是你，你会怎么选择？是相信九个人的共同判断，还是认真听取那一个人的提醒？

生活中，这种情况其实非常普遍。一个投资项目，周围所有人都说好，你就觉得应该参与。一个观点的支持者越多，真的就意味着它接近事实吗？

今天思考如果多数人的意见和少数专业人士的意见发生冲突，我们应该信谁



**从众心理（Conformity）**
当我们发现周围大多数人都持有某种观点时，即使自己没有充分证据，也容易倾向于接受这个观点。

**判断一个观点的价值，不应该只看有多少人支持它，而应该看提出观点的人是否真正理解问题，以及他能否拿出可靠的证据。**

当所有人都赞同你的时候，也要保持警惕。
因为有时候，最需要重新审视自己判断的时刻，恰恰是所有人都告诉你「你是对的」的时候。
**真正的独立思考，不是为了反对多数人而反对，而是不因为多数人支持，就放弃自己对事实的判断。**
