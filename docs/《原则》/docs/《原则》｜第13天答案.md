# 《原则》｜第13天答案

有些人很牛，却不值得相信

原则第13天答案

书中的这个概念我特别有感，叫做可信度——应重视那些在相对领域取得过实际结果，并能清楚解释推理过程的人

白天餐馆故事。第一个博主有感染力。说餐饮是刚需，选址好、产品好就能赚钱。但选址好，究竟怎样衡量？产品好，是顾客喜欢还是顾客愿意持续付费？即使营业额很高，扣除房租、人工和食材成本以后，还能剩下多少利润？

第二个经营过15年餐馆，那业绩如何？有没有经历过困难时期？
他能够解释自己做对过什么、做错过什么？如果一个人经营15年都没有找到正确经营方法，那经营年限不足以证明他的判断可靠

第三个经济学教授，擅长分析消费趋势、行业竞争和周期。但具体到某一家餐馆，应该怎样设计菜单安排员工，他未必有实际经营经验的人更了解

所以这三人的价值要综合吸

今天原则：不要只学习那些能够给你答案的人，而是那些能够告诉你答案从哪里来、又可能在哪里出错的人🎁



**不要只听一个人讲自己成功过什么，还要看他能不能讲清楚自己曾经在哪里判断错了。**

第一，**不要被一个人的名气、表达能力和身份迷惑。**
这些东西可能让一个人更容易获得关注，但不能直接证明他的观点可靠。
第二，**不要把经验年限等同于判断能力。**
真正有价值的经验，是经过实践、反思、验证和修正之后积累下来的经验。
第三，**不要寻找一个什么都懂的人。**
重要决策往往涉及多个领域。应该寻找不同问题上真正懂的人，再结合事实和证据，形成自己的判断。

人生原则
**不要只学习那些能够给你答案的人，而要学习那些能够告诉你答案从哪里来，以及答案可能在哪里出错的人。**
**真正的智慧，不是找到一个永远正确的人，而是建立一套能够识别错误、验证观点、修正判断的系统。**
