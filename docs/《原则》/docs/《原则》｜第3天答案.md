# 《原则》｜第3天答案

承认错误

《原则》第3天答案

昨天我们讲到聪明人也会反复犯错，因为知道认错和改变是两回事。今天再往深处想

有时候我们不愿意承认自己需要改变，当别人提出不同意见时，你首先应该关系的，不是怎样证明对方错了，而是对方有没有可能知道一些你不知道的事

比如你买入一直股票，原本以为这家公司未来几年利润会持续增长。后来有人告诉你，这家公司最大的客户正在减少订单。这时候，你又两种选择

第一是反驳对方，寻找各种理由证明自己当初的判断没错

第二种做法并不要求你认错，也不要求你马上卖掉股票。只要你愿意重新检查自己的判断

所以今天我们建立第三条人生原则：当别人提出不同意见时，先寻找其中可能正确的部分，再决定是否坚持自己的判断

我（Jack）的目标不是证明自己正确，而是尽可能接近事实，回想下你和别人发生的争论，到底是追求事实还是情绪争论



**真正成熟的自信，不是相信自己永远正确，而是相信即使自己判断错了，也有能力发现问题、修正判断。**

**当别人提出不同意见时，先寻找其中可能正确的部分，再决定是否坚持自己的判断。**
我不因为别人反对自己，就认定对方错了；也不因为别人反对自己，就立即放弃原来的观点。
我会先理解对方的理由，检查相关证据，并认真考虑自己可能忽略了什么。如果事实证明我的判断存在问题，我愿意修正；如果证据仍然支持原来的判断，我也可以继续坚持。

**我的目标不是证明自己正确，而是尽可能接近事实。**
