# 《原则》｜第11天

为什么同一件事情，会得出完全不同的结论？

原则第11天

假设一家餐馆，最近三个月的营业额下降了20%。老板找来两位经验丰富的管理人员，问他们怎么办

第一个人说肯定是价格太贵了。现在大家都在省钱，我们应该降价，吸引更多顾客

第二个人却说我觉得恰恰相反。我们应该提高价格，把餐馆做得更高端，吸引愿意花钱的顾客

同样一家餐馆，同样下降20%的营业额，两个人都很聪明，也都有经营经验。为什么会得出完全相反的结论？

第一个人说降价可以增加客流量。第二个人说提高价格可以增加每位顾客贡献的利润

如果你是老板，你会相信谁？生活中这样的事情太多了，同样看到房价下降，有人觉得赶紧买入，有人却觉得继续等待

孩子考试成绩下降，有的父母觉得应该增加学习时间，有的父母却觉得应该减轻压力
同样面对一家公司的财报，有人觉得未来前景非常好，有人却觉得风险越来越大

所以我们应该怎样判断谁更接近事实？



**思维模型（Mental Models）**
思维模型就是一个人理解世界、分析问题和做出判断时，脑海中使用的一套认知框架。

达利欧非常重视的一个思想：**不要依赖单一视角，而要通过不同人的观点，尽可能接近真实的答案。**

**不要只相信自己的视角，要通过多角度思考接近事实。**
当别人提出与我不同的观点时，我不急着判断谁对谁错，而是先理解对方的思维方式，分析双方掌握的信息和判断依据。
对于重要决策，我会主动寻找不同领域、有实际经验的人提供意见，并通过事实和证据验证不同的假设。
如果证据证明自己错了，我愿意调整；如果证据支持自己的判断，我也有理由坚持。
行动提醒：下次遇到与自己完全相反的观点时，先问一句：对方看到了什么，而我没有看到？
