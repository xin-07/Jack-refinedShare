# 《原则》｜第6天答案

如何做出更好的决定

原则第6天答案

每个人看世界，都只能通过自己的知识、经验和观察角度。比如有两个人一起经营一家餐馆。一个人负责厨房，另一个人负责接待顾客

厨房的人觉得菜品质量不稳定。接待的人却觉得顾客等待时间太长

两个人都说对了一部分。但如果都认为看到的就是全部事实，那么久很容易吵起来

这就是认知盲点的一个重要来源，我们把自己看到的那部分现实，当成了完整的现实！

那我们怎样才能发现自己的盲点？可以从三个方面开始

一，主动寻找不同的视角。如果你认为某件事是对的，不妨找一个观点和你不同的人，他们理由

二，留意自己反复出现的错误。比如你总追涨杀跌，总和家人沟通时情绪失控，或者总是低估完成任务需要的时间。就值得认真研究自己的判断方式

三，建立反馈机制。比如在做重要决定之前，先写下自己的理由和预期。过一段时间以后，再回头检查

真正的自信，不是永远正确，而是即使错了，也能改！



**真正有价值的讨论，不是证明谁更聪明，而是让双方看到原本看不到的信息。**

**把自己当成一个需要不断改进的系统，而不是一个必须永远正确的人。**

**能够意识到自己的局限，主动寻找不同的观点，并根据现实反馈修正自己的判断。**
