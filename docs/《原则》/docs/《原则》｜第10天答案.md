# 《原则》｜第10天答案

如何让弱点变优点

原则第10天思考

人能力有差异。有人擅长分析，却不擅长沟通。有创造力，却不擅长管理时间。能发现商业机会，却不擅长控制风险

如果总希望自己在所有方面都优秀，会陷入把大量时间花在弥补弱点，却没充分发挥自己的优势

比如创业的例子。擅长产品研发的人，每天都要亲自处理合同、财务和行政事务，那他根本没有时间研究用户需要什么。但如果他找可靠的专业人士合作，就把精力投入最有价值的地方

我（Jack）把弱点分成两类

一是必须改善的弱点，比如反复失信、无法控制冲动、缺乏基本的风险意识，不改会持续影响我们的生活

二是可以通过合作弥补的弱点，比如专业技术。这些事不用亲自掌握，可以通过学习基本知识、寻找专业人士来降低弱点造成的影响

今天大家想3点
一，你最突出的优势是什么？
二，哪些弱点，已经反复影响自己的生活？
三，这些弱点里面，哪些必须改善，哪些可以通过工具合作来弥补？

祝周末愉快



**判断一个弱点应该如何处理，关键是看它是否影响自己的核心责任，以及能不能通过外部系统可靠地控制风险。**

**比较优势（Comparative Advantage）**
就是一个人即使在很多事情上都能做，但仍然应该考虑把时间投入到自己相对更有优势的事情上。

**一个人不应该只追求自己的能力越来越强，还应该追求自己解决问题的系统越来越完善。**

**不要试图把自己变成一个没有弱点的人，而要学会管理自己的弱点。**

**认识弱点，是改变的开始；建立系统，是解决问题的方法；持续检验结果，才是真正的进步。**

**不要把有限的时间用来证明自己什么都会，而要把有限的时间投入到真正能够创造价值的地方。**
