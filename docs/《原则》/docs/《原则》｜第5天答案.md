# 《原则》｜第5天答案

越不顺越值得研究

原则第5天答案

书里提出过通过明确目标、发现错误、诊断原因、设计方案和执行行动，逐步实现想要的结果。

其中诊断错误非常难，很多人遇到困难第一反应就是赶紧采取行动。但行动越快越容易把事情搞砸

比如一个孩子成绩下降了。父母特着急，马上给他报班。每周加三节课，周末还要做很多练习题。结果两个月以后，成绩还是没有提高

父母觉得补习力度还不够。但如果认真研究一下，也许会发现孩子根本不是学习时间不足。而是基础知识没有掌握。也可能是考试时粗心。甚至可能是睡眠不足上课注意力下降

不同的原因，需要完全不同的解决方法，不要只问怎么解决，还要问为什么会出现这个错误，找到原因减少发生概率！

所有今天，我们建立第五条人生原则：遇到反复出现的错误时，不要着急，要先找根本原因，用事实验证，再采取行动

回顾这一周，我们都在研究同一件事情：怎样让自己越来越接近现实，而不是越来越相信自己的想象



**发现问题，不代表理解问题；提出原因，也不代表原因已经被证实。**

可以整理成一条人生原则：
**遇到反复出现的错误时，不要着急，要先找根本原因，用事实验证，再采取行动。**

**不要急着证明自己的判断是对的，要先弄清楚现实究竟发生了什么。**

**不要只做一个努力解决问题的人，还要做一个能够正确发现问题、诊断问题的人。**
