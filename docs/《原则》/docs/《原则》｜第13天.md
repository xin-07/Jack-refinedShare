# 《原则》｜第13天

哪些人不值得你相信

原则第13天思考

你要投资一家餐厅，找了三个人帮忙分析

第一个人非常有名的商业博主。他说话有感染力，分析头头是道，说餐饮是刚需，只要选址好、产品好，赚钱根本不难

第二个人是一位经营了十五年餐馆的老板。他没有那么会表达，但他告诉你，餐标行业有很多看不见的成本。比如食材损耗、员工流动、设备维修，还有淡季现金流压力。他甚至拿出自己过去几年的经营数据，告诉你哪些判断曾经出错

第三个人是经济学教授。他对消费趋势、行业竞争和宏观经济有很深入的研究，但自己没经营过餐馆

大家觉得这三个人，谁更值得相信？

是最会表达的，还是拥有实际经营经验的，还是拥有专业学术知识的人？

实际选择没有那么简单。一个人懂得很多理论不代表他擅长实际经营。有丰富的实际经营。有丰富的实践经验也不代表他的认知和判断都正确

今天大家想想：究竟什么样的人，才值得我们在重要决策中给予更高的信任？实际答案是非常复杂的



**不要寻找一个什么都懂的人，而要学会在不同问题上，找到真正懂这个问题的人。**

当别人向你提出一个观点时，不要急着相信，也不要急着否定。
先问自己：

1. **他真正了解这个领域吗？**

2. **他有过相关的实际经验吗？**

3. **他过去的判断经得起检验吗？**

4. **他能否提供事实和证据？**

5. **如果发现自己错了，他愿不愿意修正？**



**真正的智慧，不是找到一个永远正确的人，而是建立一套能够识别错误、验证观点、修正判断的系统。**
