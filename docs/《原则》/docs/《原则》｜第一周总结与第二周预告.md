# 《原则》｜第一周总结与第二周预告

原则第一周总结与第二周预告

这一周，我们正式开始解读瑞达利欧的《原则》
五天时间，我们讨论了五点

1.为什么有些人越努力，反而离目标越远？因为努力不等于有效，真正重要的是理解现实，找到。事情背后的规律

2.为什么聪明人也会反复犯同样的错误？因为很多时候，我们只想着下次一定要改，却没有改变导致错误反复发生的机制

3.为什么承认错误这么难？因为我们太容易把自己的观点当成自己的一部分。我们应该追求正确答案，而不是一味证明自己正确

4.为什么痛苦不一定带来成长因为如果没有找到真正的原因，再多的努力，也可能只是在解决表面

这周总结一句话：不要只凭感觉理解世界，而要不断用事实判断

学习有价值的不只是知道更多答案，而是可以提出更好的疑问、所以下周我们开始看清自己，面对自己，改变自己并成长



**不要急着相信自己的判断，要学会用事实检验自己的判断。**

一个人真正的成长，不是知道的道理越来越多，而是面对现实的时候，能够不断修正自己的认知。

以前遇到问题，我们可能第一反应就是解释、辩解、抱怨，或者马上采取行动。

现在可以尝试换一种方式：
**先接受事实，再分析原因，最后改变行动。**

这是我理解的《原则》第一周最重要的价值。

**认识现实，是为了更好地认识自己；认识自己，是为了找到真正适合自己的成长路径。**
