# 《原则》｜第19天答案

这么做才真正进步？



原则第19天答案——忙碌和高效 完全不同



书中强调想实现目标就必须识别真正的障碍，并根据重要程度决定解决顺序



比如白天那个你。每天研究设备、学习剪辑、分析算法。这些事情有价值，但如果你想通过创作吸引观众，那最关键的事情是先做出作品，发布出去，再根据真实反馈不断改进



准备工作可以帮助行动，但不能永远代替行动



为什么我们经常把时间花在次要事情上？因为容易完成的任务能够很快带来成就感。整理房间、回复消息、研究工具，做完马上能看到成果



但真正重要的事情都困难，而且结果不确定。比如开始创业、改善家庭关系、学习一项新技能。这些事情可能需要很长时间才能看到回报，还可能面临失败和拒绝



这时我们就想用一些看起来有意义的小事，回避真正困难的选择



今天留个作业，写下你明天准备做的五件事。然后想：如果只能做一件，我会选择哪一件？为什么然后在精力最好的时候做了！



试试🎁





今天的核心 takeaway

**忙碌只能证明你付出了时间，结果才能证明你的行动是否有效。**

**不要用完成了多少事情来衡量一天，也不要因为自己一直在努力，就认为自己一定在进步。**



真正值得关注的是：

**今天，我解决了什么真正影响目标的问题？**



❤️ **今天试着把最重要的那件事，真正放到第一位。 不必把一天安排得满满当当，只要每天持续解决真正重要的问题，时间就会逐渐产生复利。**
