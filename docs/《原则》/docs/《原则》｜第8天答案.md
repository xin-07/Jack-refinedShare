# 《原则》｜第8天答案

用认知放下自我防卫倾向

原则第8天答案

首先我们的天性就是从别人提出不同意见时，就会开始寻找反驳的理由，因为我们希望在别人眼里是聪明正确有能力的

比如中午开车的例子。妻子提醒你变道不安全。讨论的是一次具体的驾驶行为。当你听到以后会觉得她是在怀疑自己的能力

于是你解释自己开车多少年了，经历过多少复杂路况。这些经历，不能证明那一次变道一定安全

过去做对过很多次，不代表这一次就不可能出错

这里分享我（Jack）的认知结构：把自己的行为和自己的身份分开！别人说你这次不对，不代表你是一个失败的人

所以当别人说你的时候，试试这三步

一，不用急着解释，而要把讨论从情绪拉回事实

二，检查对方有没有提供新的信息。比如对方说你变道危险
你可以问是不是后面有车，我没注意到

三，决定是否接受对方的判断

当别人批评我时，先把情绪和事实分开，认真理解对方的依据，再决定接受还是反驳，甚至是感谢🙏



**不要因为不喜欢信息传递的方式，就错过信息本身的价值。**

面对批评的三个步骤

1.**暂停防御**
不急着解释，先把情绪放一放，弄清楚对方在讨论什么。

2.**获取信息**
追问具体问题，检查对方是否提供了自己不知道的事实和证据。

3.**独立判断**
根据事实决定接受、部分接受，还是有依据地反驳。
