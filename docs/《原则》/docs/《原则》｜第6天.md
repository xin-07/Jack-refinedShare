# 《原则》｜第6天

如何知道自己是对还是错

原则第6天思考

假设一个父亲，特别重视孩子的教育。他经常告诉孩子，遇到事情不要找借口，要勇于承认错误。孩子考试没考好，他会说你应该认真分析原因，而不是怪题目太难

但有一天，这位父亲在工作中犯了一个错误。同事提醒他，他却马上解释这不是我的错，是别人没有提前告诉我。回家以后，他还抱怨同事不理解自己

他教给孩子的道理，其实自己也知道。但同样的事情发生在自己身上，他却很难做到。

生活中类似的情况非常多。我们觉得别人太情绪化，却没有发现自己生气时也会失去理智。

我们觉得别人不愿意接受批评，但当有人指出自己的问题时，第一反应也是解释。

书中非常重视一个概念，叫做认知盲点

有意思的是，一个人越相信自己的判断，有时候反而越不容易意识到自己可能存在盲点

今天大家想想如何才能知道自己意识不到的错



**认知盲点，就是我们自己看不到、意识不到，却可能影响我们判断和决策的问题。**

**不要过度相信自己的判断，要通过独立思考和多角度反馈，发现自己看不到的问题。**

1. 主动寻找反对自己的人

2. 区分事实、观点和情绪

3. 用结果检验自己的判断

**一个人最大的认知盲点，可能就是他认为自己没有盲点。**
