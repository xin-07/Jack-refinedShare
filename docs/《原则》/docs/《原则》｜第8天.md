# 《原则》｜第8天

你喜欢反驳吗

原则第8天思考

假设有一天，你正在开车，旁边坐着你的妻子。到一个路口，她突然提醒你刚才那个变道很危险

你的第一反应是什么？

可能马上解释看过后视镜了，根本没事

妻子继续说可是刚才后面那辆车离我们很近

你可能就不高兴了，开车这么多年了，难道还不知道怎么变道吗？

结果两个人只是讨论一次变道，最后却变成了冷战

你有没有发现，妻子最初提出的是：刚才的驾驶行为是否安全？

但你回应却变成了：我到底是不是一个会开车的人？

这其实是两件完全不同的事情

生活中类似的情况特别多。孩子说你不理解他，你马上解释自己为他付出了多少。同事指出工作中的不足，你马上强调自己有多努力。朋友质疑你的投资判断，你第一反应是证明自己比他懂得更多。

很多时候，我们还没得及认真思考对方说得对不对，就已经开始反驳了

今天想想，为什么我们希望自己变得更优秀，却会本能的抗拒那些帮助我们进步的批评？



《原则》中一个非常重要的思想：妨碍我们保持开放心态的两个障碍
**自我障碍（Ego Barrier）**：我们太在意自己的自尊、面子和自我形象。
**盲点障碍（Blind Spot Barrier）**：我们无法意识到自己思维方式中的局限。

**不要把别人对你行为的批评，理解成对你整个人的否定。**
**我们每个人都有自尊，也都希望得到认可。**
**但如果为了维护自己的面子，而拒绝接受有价值的反馈，就可能失去很多成长的机会。**
