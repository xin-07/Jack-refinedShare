# 《原则》｜第16天

为什么你会一直失败



原则第16天思考



假设两个人，都开一家餐馆。第一年，两家餐馆都亏了钱 第一个老板觉得自己运气不好。他觉得今年经济不行，顾客不愿意花钱，附近竞争又太激烈



于是第二年，他继续按照原来的方式经营。结果还是亏钱，第三年，他换了一个位置，重新开了一家餐馆。但没过多久，又不行了



第二个老板也亏了钱。但他做了一件不同的事情。他把过去一年的营业数据全部整理出来，发现自己虽然每天都有不少顾客，但人工成本和食物损耗一直太高。于是，他重新设计菜单，调整员工排班，建立库存管理制度。第二年，他的餐馆开始改善



其实两个人都经历了失败。但第一个人只是经历了失败，但第二个人的却从失败中学到了东西



如果一个人每次失败后只是寻找外部原因，那么即使失败一百次，也未必能够进步



书中强调从痛苦和错误中思考



大家好好想想，最近有什么事情是一直在失败吗。究竟应该怎样做，才能让每一次失败真正产生价值？





**失败本身不会自动带来成长，只有当我们从失败中提取信息，并改变下一次的行动，失败才真正产生价值。**

不要只依赖下一次的决心，而要改变导致问题反复发生的机制。



**不要重复经历，要持续改进**。

经历失败时，不急着抱怨外部环境，也不急着否定自己。

先明确实际结果，分析自己的判断、方法和外部条件，寻找可以验证的原因。

然后把反思转化为下一次具体的行动改变，并通过新的结果检验自己的改进是否有效。

**真正的成长，不是经历了多少事情，而是每次经历之后，你是否变得更有能力解决问题。**
