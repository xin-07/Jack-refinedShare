# 《原则》｜第16天答案

人生最可惜的就是不断犯错，却从不反思改进



原则第16天答案



如果一个人每次遇到事情只是抱怨、后悔，或者责怪别人，那么就是经历很多挫折，也可能始终停留在原地。比如白天那个餐馆的故事。第一个老板连续亏损，却始终认为是经济不好、竞争激烈。这些外部因素可能确实存在，但如果他从来不检查自己的经营方式，就很难知道哪些可以改善



第二个老板则不同。他拆解，发现食材浪费严重、员工排班不合理，于是开始调整经营流程。两个人最大的区别，不是失败的次数，而是有没有把失败转换成下一次行动的改变



我们刚学过，好的决定也可能带来坏结果。所以复盘失败时，首先应该区分：究竟是判断方法不对，还是发生了原本就无法避免的事



所以每次遇到重要失败，都要区分是运气还是决策，寻找可以改善的原因，并把反思转化成下一次能够执行的行动规则



最后送给大家一句话：人生真正可惜的不是犯过多少错误，而是付出了错误的代价，却没有得到相应的经验





**我们要学习的不是每次都赢，而是让自己的决策方法越来越可靠**



工作十年，不一定等于拥有十年的经验，也可能只是把同一年的经验重复了十次。



**人生真正可惜的不是犯过多少错误，而是付出了错误的代价，却没有得到相应的经验。**

**不要害怕犯错，但不要让同一种错误反复发生。**

**每次经历结束后，都问自己：我究竟学到了什么？下一次，我会有什么不一样？**
