原则第17天答案



和大家解读过思考快与慢，里面有个我（Jack）很认同的观点：人的记忆并不可靠。一件事情发生后，我们会根据结果，重新解释当初的想法



比如股票上涨。你会觉得当初早就看出了他的巨大潜力。但如果翻开五年前的记录，你会发现，当初真正看好的业务根本没有发展起来。股价上涨只是因为公司后来进入了一个完全不同的市场。结果是好的，当初的预测是不准确的



直播时也聊过，这种事后觉得自己早就知道结果的倾向，在心理学中叫做后见之明偏差



请大家想做事情前，写这四件事

一，我准备做什么？比如换一份工作

二，把最重要的两三个理由写下来

三，写出具体的预测

四，什么情况会证明我的判断需要重新评估



今天的原则：经验不是经历过什么，而是你能否准确记住当初为什么选择，以及后来究竟发生了什么，最好的方式就是记录一切





**不要只是经历人生，而要学会研究自己的人生。**

**没有记录，经历容易变成记忆；有了记录，经历才有机会变成可以检验的经验。**
