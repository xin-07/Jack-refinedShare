# 《原则》｜第9天答案

人和人差距在于能不能分清自己不知道什么

原则第9天答案

书中反复强调应该保持开放的头脑，主动寻找那些有经验、有可靠判断记录的人，认真听取他们的观点

因为每个人的知识和经验都是有限的。哪怕你在一个领域特别优秀，也不代表你在其他领域同样翻译

一个非常成功的企业家。他可能特别擅长经营公司、管理团队、寻找商业机会。但这不代表他一定懂医术、法律、建筑或者教育。如果他因为过去的成功，就认为自己在所有事情上都正确，反而可能做出很大的错误决定

我（Jack）希望大家听到一个观点，以后不只问自己喜不喜欢，还要问他有没有可靠的证据，问一下

一，我现在真正知道的事实有哪些？
二，哪些只是我的猜测或者个人经验？
三，我可以向谁学习，或者通过什么可靠资料进一步验证？

今天的原则：通过不熟悉的事，敢于承认不知道，主动寻找有经验、有证据支撑的观点，但最终仍然要认真思考、独立判断，真正的无知是你不知道自己其实不知道！

非常经典的心理学概念：**邓宁-克鲁格效应（Dunning-Kruger Effect）**
当一个人对某个领域了解得比较少时，可能因为缺乏判断能力，无法准确认识到自己的不足，从而高估自己的能力。



一个很有意思的现象：
**有时候，知识增长带来的第一个变化，不是让你觉得自己懂得更多，而是让你意识到自己原来知道得这么少。**

**听说一件事，不等于证明一件事。**
**不要只看一个人说了什么，还要看他为什么这样说，以及他有没有能力做出可靠的判断。**

**真正的无知，不是你不知道，而是你不知道自己其实不知道。**
