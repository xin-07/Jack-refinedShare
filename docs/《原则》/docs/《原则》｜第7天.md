# 《原则》｜第7天

为什么总做错事

原则第7天思考

假设你经营着一家非常成功的公司。能力很强，工作努力，对行业也非常了解。过去十年，你做对了很多重要决定，公司规模越来越大

但最近几年，公司开始不行了，有些业务已经不赚钱，你却不愿意关闭，因为这些业务当初都是你亲自建立的

有些员工明显不适合现在的岗位，你也不愿意调整，因为这些人跟了你很多年

甚至当市场发生变化时，你仍然坚持过去成功的方法。你觉得这家公司是我一手做起来的，难道我还不清楚应该怎么办吗？

可是，过去的成功经验，真的能够保证未来的判断仍然正确吗？

生活中也有类似的事情。你会发现，一个人在某个领域能力很强，并不意味着他在所有事情上都能做出正确判断，隔行如隔山，人无完人啊

今天大家想想如果一个人能力很强，但判断方式存在缺陷，他应该继续依靠自己的经验，还是尝试建立一套能够纠正自己的机制？



**过去的成功只能证明你曾经做对过，并不能保证你未来仍然正确。**

不要因为一个决定是自己做的，就必须坚持到底。
不要因为过去投入了很多，就认为未来还应该继续投入。
也不要因为自己在某个领域很优秀，就认为自己在所有领域都能做出正确判断。
真正成熟的人，不是从来不犯错，而是拥有一套能够发现错误、纠正错误、减少重复错误的机制。

**不要把自己当成一个必须永远正确的人，而要把自己当成一个可以不断改进的系统。**
