# 《原则》｜预告

下一本书，我选择了瑞·达利欧的《原则》

过去这段时间，我们一起读了《小岛经济学》《思考，快与慢》《穷爸爸富爸爸》和《被讨厌的勇气》

而这本书的作者达利欧是全球知名投资机构桥水基金的创始人。他把自己几十年来在投资、管理和生活中积累的经验，总结成了一套做事和决策方法

读完这本书能帮助你提升总结规律的能力，这样就能每一次经历中总结规律，让自己下一次做得更好

比如，同样是投资亏钱，有人只会抱怨运气不好，有人却会认真分析自己当初为什么做出那个决定

同样是和别人发生争执，有人只想证明自己是对的，有人却会思考，对方的观点有没有值得自己学习的地方

时间长了，这些不同的思考方式，会让人走向完全不同的人生

我们还是白天一篇引发大家思考；晚上结合书中的观点和生活案例，给出答案

这本书我想多做一步，每天我帮大家总结一条属于自己的原则

这样30天结束，每个人都可以整理出一份自己的《人生原则手册》



《原则》希望培养的能力：**不只经历事情，还要研究事情为什么发生，以及自己下次应该如何做。**
《原则》的精神：**原则不是用来束缚自己的教条，而是帮助自己更好地面对现实的工具。**

**不要让经历只是经历，要让每一次经历都成为下一次行动的依据。**

**真正的成长，不是永远不犯错，而是尽量不让同一种错误一次又一次地发生。**
