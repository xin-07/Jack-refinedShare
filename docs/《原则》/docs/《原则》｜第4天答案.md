# 《原则》｜第4天答案

痛苦 + 反思 ＝ 进步

原则第4天答案

同样一次失败，有人变得成熟，有些人越来越害怕尝试，关键在于，失败以后，我们究竟做了什么

比如投资亏了十万，难过，觉得运气不好，市场太不公平，过了一段时间，情绪平复了，又开始寻找下一只可能暴涨的股票

这样即使亏了很多次，也不能学到了什么！

但亏钱以后认真回顾自己的交易。当初为什么买入？是因为公司基本面发生了变化，还是因为看到股价上涨，害怕错过？买入之前有没有考虑过最坏的情况？如果同样的机会再出现一次，自己应该改变什么？

两个经历的都是亏损，但第二个人把经历变成了可以用于未来的经验

这就是反思的价值：帮助我们找到下一步行动，而不是让我们陷入无休止的自责

所以我们不主动寻找痛苦，但要努力让经历的痛苦变成礼物

今天我们建立第四条人生原则：遇到。挫折允许自己难过，但不陷入情绪里。等平静以后，认真分析原因，把能够改变的部分写下来转化为下一次的行动



**经历过失败，不代表拥有了经验；只有经过反思，并且改变了下一次行动，经历才真正变成经验。**

**亏损是结果，反思是寻找原因，改变行动才是解决问题。**



每次遇到不理想的结果，问自己三个问题：

1. **发生了什么？** 只记录事实，不急着评价自己。

2. **为什么会发生？** 分析自己的判断、方法和外部条件。

3. **下次改变什么？** 找到一个能够实际执行的改进动作。



**不要让自己白白经历痛苦。**

**过去发生的事情无法改变，但我们可以决定，下一次是否还要犯同样的错误。**
