# 《原则》｜第2天

你为啥反复犯同样的错误？

《原则》第2天思考

有一个人，每个月工资一到账，就开始买各种自己喜欢的东西。到了月底，发现钱又花光了。他每次都告诉自己，下个月一定要控制消费

但下个月工资到账以后，还是一样

还有一个人，每天晚上刷手机刷到凌晨一点。第二天早上起不来，工作没精神，整个人都很疲惫。

他也知道熬夜不好，每次都下决心早点睡。结果到了晚上，还是忍不住拿起手机

这两个人很清楚这不对要改，他们甚至能够很清楚地告诉你，自己到底哪里做错了

但为什么知道了，还是改不了？

我们通常会认为，这是因为他们不够自律，意志力太差

可是，如果一个人已经重复犯了几十次同样的错误，难道真的只需要再下一次决心吗？

书里提出了一个很有意思的思考方式：把自己的人生，看成一部不断运行的机器

所以今天思考下如果一个人反复犯同样的错误，我们到底应该责怪这个人，还是检查让错误不断发生的那套机制



**不要只想着改变自己当下的行为，还要检查是什么机制，让自己不断重复这种行为。**

**与其每次都在错误发生时拼命克制，不如提前改变让错误更容易发生的条件。**

发现自己反复犯同样的错误，可以尝试下面四步：
**第一步：找出重复发生的问题**
**第二步：还原错误发生的过程**
**第三步：改变一个关键机制**
**第四步：观察结果，再继续调整**

**反复出现的错误，不要只靠决心解决，要检查背后的机制。**
当我发现自己一次又一次犯同样的错误时，不只责怪自己意志力不足，而是分析错误发生的条件、行为过程和即时回报，找到可以改变的环节，并通过行动验证新的方法。

**如果一个问题反复发生，就不要只把它当成一次失误，而要把它当成一个需要改进的系统。**
