# 《原则》｜第19天

为什么每天忙得要命，人生却始终没改变？



原则第19天思考



假设你想做自媒体。每天都很努力，早上研究拍摄设备，中午学剪辑，下午看别人分享运营经验，晚上有花几个小时研究平台算法



一个人过去了，感觉自己很充实。但你竟然一条视频都没发布。总觉得设备还不够好，剪辑技术不够成熟



与此同时，另一个人只有一部普通手机。他每天拍一条，发布以后看观众的反馈，再慢慢调整内容。一个月以后，他已经发布了三十条作品



虽然播放量不好，但至少知道了哪些内容有人喜欢，哪些表达方式需要改进



你做了很多事情，却始终没有真正接近自己的目标。他看起来准备的不够充分，却已经开始积累真实经验



为什么我们宁愿做十件容易的小事，也不愿意面对一件真正重要的事情？



书中强调遇到事情，需要分清优先级，集中精力解决那些真正影响目标的困难



今天大家想想一个人究竟怎样判断，哪些事情要优先解决，哪些事情只是让自己看起来很忙？





**真正重要的事情，通常不是你最喜欢做的事情，而是那个最能影响最终结果的事情。**



我们需要警惕一种状态：

**用忙碌逃避困难，用准备代替行动，用完成小事代替解决大问题。**



**不要把时间平均分配给所有事情。找到真正影响目标的关键问题，集中精力解决它。**

**人生的改变，不取决于你每天做了多少事情，而取决于你是否持续做那些真正重要的事情。**
