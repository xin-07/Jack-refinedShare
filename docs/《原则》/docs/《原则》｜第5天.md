# 《原则》｜第5天

当一件事情反复不顺利的时候，我们应该怎么办

原则第5天思考

假设你开了一家餐馆。刚开业的时候，生意很好，每天都有不少客人。但半年以后，客人越来越少，收入也开始下降

这时候，你会怎么办？

有些老板可能觉得是经济不好，大家都不愿意出来吃饭了。于是他开始降价、发优惠券，甚至花更多钱做广告。但生意依然没有明显改善

另一位老板却选择先研究为什么什么以前愿意来的客人，现在不来了？他开始查看顾客评价，发现最近很多人抱怨上菜太慢。继续调查才发现，餐馆换了一位厨师以后，厨房的工作流程发生了变化，导致平均出餐时间明显增加。

于是他重新调整厨房分工。几周以后，出餐速度提高了，顾客的评价也开始改善

两位老板都希望解决问题，也都付出了努力。但一个人急着寻找解决办法，另一个人先研究为什么会发生

生活中也是一样。大家想想最近的不顺利，是不是某个更深层原因表现出来的结果？尽量详细写下来



**解决问题最怕的不是没有行动，而是方向错了，却还在不断加大力度。**

**我们不能因为某件事情发生了，就直接认定自己找到原因了。**



**遇到反复出现的问题，先做这四步**

1. **描述问题**

   不要只说“最近很不顺”，尽可能用具体事实描述问题。

   例如：过去一个月，系统出现了 8 次同类型异常。

2. **寻找原因**

   从直接原因开始追问，找到背后的流程、习惯、判断或外部条件。

3. **寻找证据**

   查看数据、记录和实际情况，不要只依赖自己的猜测。

4. **改变关键因素**

   找到自己能够控制的因素，制定具体改进措施，再观察结果是否改善。



**当一件事情反复不顺利时，不要急着加大努力，先停下来看看，自己是不是一直在解决错误的问题。**

**不要只想着消除眼前的症状，要学会找到问题背后的原因。**
