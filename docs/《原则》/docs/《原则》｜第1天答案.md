# 《原则》｜第1天答案

如何看清现实

《原则》第1天答案

书里有个观点：拥抱现实，应对现实。听起来很简单，但怎么做到？因为我们每个人都希望世界世界按照自己想法运行。比如你觉得只要努力工作，收入就应该增加

但现实是，你做的工作市场需求不高，或者你的努力并没有创造更多价值

你觉得每天坚持运动，身体就一定会变好。但现实是你的训练方式不合理，休息不足，甚至长期积累了伤病

你觉得对别人好，别人就会对你好。但现实可能是，对方根本不需要你提供的帮助

很多时候，我们没有弄清楚事情真正的运行规律

分享一个思考方式，就是把现实当成一套有规律可循的系统。如果结果和预期不同，不要急着抱怨，也不要急着加倍努力，而是问问自己

一，想得到什么结果
二，现在采用的方法，为什么没有产生预期的效果
三，是否忽略某个重要的现实条件

我们要建立的第一条人生原则：当结果与预期不一致时，先尊重事实，寻找原因，再决定是继续坚持还是调整方法



我们经常把自己的期待，当成了现实应该遵循的规则。

**接受事实，不等于接受现状；看清限制，是为了找到真正可以改变的地方。**

人生原则 第1条
**先尊重事实，再决定行动。**
**当结果与预期不一致时，不急着抱怨、不急着否定自己，也不盲目增加努力。**
**先明确目标，检查实际结果，分析方法与现实条件之间的差距，再根据证据决定是继续坚持、调整方法，还是改变目标。**
行动提醒：下次遇到不顺利的事情，先问“我忽略了什么”，再问“我接下来能改变什么”。

**你不能要求现实按照自己的想法运行，但你可以通过理解现实，调整自己的行动。**
