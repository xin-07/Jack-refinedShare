# 《原则》｜第2天答案

不再犯错

《原则》第2天答案

中午讲了面对不理想的结果，先要尊重现实。晚上再往前一步

书里提出一个观点，把人生看成一部机器

就是你可以把每天的生活想象成一个不断运行的系统。你又目标，有行为，也有结果。如果结果不好，说明这个系统里存在可以改进的地方

比如熬夜。你告诉自己今天要早点睡。但手机就在枕边。晚上十点拿起来看一条消息。看完有刷几个视频。等反应过来已经凌晨一点

第二天早上，特别后悔。于是再告诉自己，今晚一定要早点睡

你有没有发现？你一直在改变自己的决心，却从来没有改变让自己熬夜的环境

如果换个方法呢。晚上十点后，把手机放在卧室外面。睡觉之前准备好第二天的事情。给自己安排固定的睡觉流程

这些方法不一定成功，但至少改变了原来不断导致熬夜的条件

这就是从改变意志，转向改变机制！

第二条人生原则：当同个错误反复出现时，不要依赖下一次决心，而要寻找共同原因，改变导致错误的机制



**改变机制，不是找到一个万能办法，而是找到真正影响自己行为的条件，再针对性地调整。**

**反复出现的错误，不要只靠决心解决，要检查背后的机制。**
当我发现自己一次又一次犯同样的错误时，我不只责怪自己意志力不足，而是分析错误发生的条件、行为过程和即时回报，找到可以改变的环节，并通过行动验证新的方法。

**不要只要求自己下一次做得更好，还要让下一次做得更好这件事，更容易发生。**
