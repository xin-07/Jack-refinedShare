# 《原则》｜第20天

为什么下过无数次决心，人生却始终没有改变



原则第20天思考



有两个人，都准备从明天开始锻炼



第一个人下决心：这次要坚持，每天至少运动一个小时



第一天，他运动了三个小时。第二天，浑身酸痛，但还是坚持完成了任务。第三天，工作突然变忙，他没有时间运动。第四天，他觉得特别累。到了第五天，他告诉自己等下周不忙了再重新开始。一个月以后，他已经完全回到了过去的生活



第二个人没有给自己定特别高的目标。他只要求自己每天运动二十分钟。而且他提前做好了安排。每天晚饭后固定运动，运动服放在门口，手机设置提醒。如果当天实在太忙，就做十分钟简单训练。一个月后，他没第一个人运动得那么激烈，但已经逐渐建立了稳定的习惯



第一个人明明更有激情，也有决心，为什么反而没有坚持下来？



大家有类似经历吗？



今天想想如果一个人总无法坚持某件事，究竟是因为他的意志力不够强，还是因为他没有建立合适的行动系统





**真正长期坚持的人，不一定从来没有中断过，而是他们知道中断以后如何重新开始。**



**不要总是试图改变自己，而要学会设计能够帮助自己改变的系统。**

决心让你开始，系统让你持续。

激情可以帮助你迈出第一步，但真正改变人生的，往往是那些看起来很普通、每天都能够重复的行动。

你不需要每天都成为一个特别自律、特别有激情的人。

你需要的是：即使今天很累、很忙、状态不好，依然能够做一点真正重要的事情。

**真正的进步，不是某一天突然变得特别努力，而是逐渐建立一套即使普通的自己，也能够持续执行的机制。**
