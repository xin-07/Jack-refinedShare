# 《原则》｜第15天答案

如何用概率看世界，选错都能带来收益

原则第15天答案

好的决定未必带来好结果，坏的决定也可能运气好而成功

为什么？因为现实世界存在不确定性。我们要理解概率，考虑不同结果发生的可能性

比如白天那两个投资者。第一个人认真分析却亏了，第二个人随便听朋友却赚了。如果只看结果，我们很容易认为第二个人更聪明。但事实完全相反

所以要学概率思维去看世界

假设一个选择有80%概率赚100元，20%概率亏100元

如果反复进行同类选择，平均每次预期收益就是60元，但即使这个选择长期有利，某一次仍然可能亏钱，而很多人就也第一次亏钱就出局了，失去了得到长期正收益的可能

所以总结三条，当你下次做决定时想想
一，掌握了哪些真实信息
二，列出所有可能性
三，用自己的概率模型算出结果

最后送给大家今天的原则

人生不是每次都要猜对结果，而是用认知建立一套即时猜错，也能长期受益、持续改进的决策系统
