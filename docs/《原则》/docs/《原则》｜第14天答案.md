# 《原则》｜第14天答案

这三步让你做出最佳决策

原则第14天答案 书中反复做决定时要分清重要信息和次要信息。

比如买房。有人每天研究利率、经济周期和专家预测，却始终不敢行动。但如果你买房是为了长期自住，那么家庭需求、财务承受能力、房屋质量可能比预测明年的房价更重要。

信息是否重要，取决于它能不能改变你的决定。有时候，我们不断收集信息，并不是因为真的缺少信息，而是害怕承担决策的风险，只要还在研究，就不用面对选择可能带来的结果。

那么，什么时候应该停止研究？

记住三点

一，哪些信息会真正改变我的决定？优先研究这些

二，继续研究还能带来多少价值？如果新增信息已经很难改善判断，就要马上行动

三，做错的代价有多大？容易撤销的小决定，快速尝试；涉及重大损失的决定，必须谨慎

最后送给大家今天的原则：好的决策不是等到什么都知道才行动，而是知道哪些必须弄清楚，哪些不确定性的可以接受🎁



**分析瘫痪（Analysis Paralysis）**
就是一个人不断分析、比较、收集信息，却迟迟无法采取行动。

**研究的目的不是让自己感觉安心，而是改善决策质量。**

**可逆决策（Reversible Decision）**
就是做出决定以后，如果发现不合适，还可以比较容易地改变。
**不可逆或难以撤销的决策（Irreversible Decision）**
就是一旦做出决定，想要改变可能需要付出很大的成本。

核心 takeaway：
**不要追求掌握所有信息，而要学会判断什么信息必须掌握。**
**好的决策不是等到完全确定才行动，而是在关键事实足够清楚、风险能够接受时，勇敢做出选择，并为后续调整留下空间。**
