# 《原则》｜第15天

为什么正确的决定也会得到不好的结果

原则第15天思考

假设有两个人，都拿十个玩。第一个人认真研究了公司财报、优势和估值，确认自己能接受所有结果，才决定买入。结果半年后，跌了30%

第二个人完全不懂投资，听朋友说某只股票会涨，就把十个全买了进去。结果运气好，三个月后涨了50%

第一个人亏了三万，第二个人赚了五万，谁做出了更好的决定？

如果只看结果，是第二个人。但如果让他们用同样的方法重复投资一百次，你还会这样判断吗？

生活中也一样。有人认真准备考试，最后却因为身体原因发挥失常。有人开车一路超速，最后平安到家。有人创业前做了充分调查，最后仍然失败

难道考试失利就说明努力没用？平安到家就证明超速是对的？创业失败就代表当初的判断不行？

我们究竟应该根据最终结果，还是根据做决定时掌握的信息和采用的方法，来评价一个决定的好坏？

晚上直播聊



**概率思维（Probabilistic Thinking）**
不要认为一个决定只有成功和失败两种确定结果，而要考虑不同结果发生的可能性。

**真正重要的是，把自己能够控制的部分做好，并且通过结果检验和改进自己的方法。**

核心 takeaway：
**不要因为一次好结果，就认为自己的方法一定正确；也不要因为一次坏结果，就否定当初所有合理的判断。**
**真正值得追求的，不是每次都赢，而是建立一套经得起重复检验、能够从错误中不断改进的决策系统。**
