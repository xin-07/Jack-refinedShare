# 《原则》｜第3天

你到底错了嘛

《原则》第3天思考

你和朋友讨论一只股票。你认为这家公司未来会发展得很好，于是买入了不少。半年以后，股价跌了40%

朋友提醒你，这家公司的经营情况已经变了，应该重新研究，但你第一反应不是去看财报，而是叫“你懂什么？这家公司我研究了很久，长期肯定涨

之后你开始寻找各种支持自己判断的信息。有人说公司前景不好，你觉得他不懂行业。有人说公司估值太高，你觉得他太保守。但只要看到有人预测股价即将反弹，你就特别愿意相信。

你有没有发现？原本我们买股票，是希望通过正确的判断获得收益。但到了后来，我们好像更在意证明自己当初没有看错

生活中夫妻吵架的时候，我们常急着解释自己为什么没错。教育孩子的时候，发现自己的方法不对，也不愿意轻易承认

今天大家想想为什么我们明明想得到正确答案，却总是忍不住维护自己原来的答案？如果有人提出与你完全相反的观点，你应该怎样判断自己是否真的错了?



**追求正确答案，和证明自己正确，是两件完全不同的事。**
前者关注事实，后者关注自我。

**一个人最难发现的错误，有时候不是自己不知道什么，而是自己以为已经知道了答案。**

**既不因为别人反对自己，就认为对方错了；也不因为别人反对自己，就立刻认为自己错了。要让证据决定判断。**

**追求正确，而不是证明自己正确。**
当别人提出与我不同的观点时，我不急着反驳，而是先理解对方的理由，检查支持自己观点的证据，并主动寻找可能推翻自己判断的信息。
如果事实证明我错了，我愿意修正判断；如果证据仍然支持我的观点，我也可以继续坚持，但要清楚自己为什么坚持。

**不要把改变观点当成失败，也不要把坚持观点当成能力。真正重要的是，你的判断是否经得起事实的检验。**
