# 《原则》｜第4天

逃避痛苦有代价吗

原则第4天思考

有两个孩子，都参加了一场游泳比赛。第一个孩子平时训练很认真，但比赛那天发挥不好，最后只拿到了第五名

他难过，回家以后告诉父母以后再也不想参加比赛了

父母心疼孩子，说没关系，以后不比赛了，省得你难受

第二个孩子也没有取得理想成绩。他很失望，甚至在回家的路上哭了。但父母没有急着安慰他说比赛不重要，而是等他情绪平静以后，陪他一起分析今天哪一段游得最好？哪一段没有好？下次训练可以改变什么？

几个月以后，两个孩子就不一样了

第一个孩子虽然避免了再次失败的风险，却也失去了一次挑战自己的机会

第二个孩子虽然经历了难过，却可能从中找到改进的方法

当然不是所有痛苦都有价值，也不是每次失败都能让人进步，但为什么同样经历失败，有些人能够从中获得成长，有些人却只是留下痛苦

大家觉得，痛苦和反思之间究竟是什么关系？

难道一个人要成长，就必须经历痛苦吗？



瑞·达利欧在《原则》中提出的一个重要观点有关：**痛苦 + 反思 = 进步。**

**痛苦只是经历，反思才可能让经历变成经验，而行动才能检验经验是否真的有用。**

**成长不要求我们主动追求痛苦，而是要求我们不要因为害怕痛苦，就拒绝一切有价值的反馈。**

**不要只想着逃离痛苦，要学会从经历中提取有价值的反馈。**
当我遇到失败、挫折或不理想的结果时，我允许自己有情绪，但不会急着否定自己，也不会为了逃避不舒服而放弃所有有价值的尝试。
我会在适当的时候复盘事实、分析原因，区分能够改变的因素与无法控制的条件，再决定下一步是继续尝试、调整方法，还是及时退出。
