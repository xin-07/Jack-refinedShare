# 《原则》｜第14天

为什么知道的越多越不敢做决定

原则第14天思考

假设两个人，都准备买房子。第一个人花了三个月研究。他每天查看房产网站，关注房价变化，阅读各种经济分析

他研究利率、通货膨胀、人口增长，甚至连美联储官员最近说了什么，都要认真分析。三个月以后，他掌握了大量信息。但每次准备买房，他会想房价会不会继续下跌？利率会不会下降？经济会不会进入衰退？是不是再等等会更划算？

于是，他始终无法做出决定。

第二个人也很认真。

但他先问自己我买这套房子是为了什么？准备住多少年？每个月能够承担多少费用？当地有没有更适合自己的选择？

研究清楚之后，他就开始行动。当然，第二个人买入以后，房价也可能下跌

到这里 大家想想，为什么第一个人掌握的信息更多，却不一定能做出更好的决定？

如果我们永远无法掌握全部信息，究竟应该在什么时候停止研究，开始做决定？

提醒大家，书中提过：好的决策需要分清不同信息的重要程度



我们要区分两个概念：
**决策质量**： 当时是否基于合理的目标、信息和分析做出了选择？
**决策结果**： 最后事情的发展是否符合预期？

**真正成熟的人，不是掌握了所有信息才行动，而是知道哪些信息重要，哪些风险可以接受，以及什么时候已经足够了。**

**不要为了追求掌握所有信息，而迟迟不做决定。**
**真正好的决策，不是建立在知道一切的基础上，而是建立在抓住关键事实、理解主要风险，并接受不确定性的基础上。**
