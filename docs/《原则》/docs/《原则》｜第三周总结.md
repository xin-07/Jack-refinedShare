# 《原则》｜第三周总结

原则第三周总结：真正改变命运的，是决策能力



这一周，我们的主题就是如何做出更好的决策？



第11天，区分事实和解释。同样看到一家餐馆营业额下降，有人建议涨价，有人建议降价。就看谁能找到事实证据



第12天，探讨为什么多数人的意见不一定正确。事实不是靠人多决定的，专业经验和可靠证据比人数更重要



第13天，识别真正的专家。不只看名气和自信，而要看实际结果，判断记录和推理依据



第14天，讨论信息过载。信息越多，决策未必越好，要学会抓住关键信息，不要让思考取代行动



第15天，学习区分决策质量和最终结果。一次赚钱不代表方法正确，一次亏钱也不代表判断不行



回顾这一周预期，预期收获是：好的决策，不保证每次成功，而是建立一套能够长期提高成功概率，控制失败代价的方法



下周，我们会研究：如何把失败变成进步的动力？为什么有些人失败一次就成长，有些人失败十次却毫无改变？





**不要把自己的第一反应当成事实。**

**真正的独立思考，不是为了反对多数人而反对，而是不因为多数人支持，就放弃自己对事实的判断。**

**不要只学习那些能够给你答案的人，而要学习那些能够告诉你答案从哪里来，以及答案可能在哪里出错的人。**



**风险管理（Risk Management）**

**好的决策不仅要寻找长期有利的机会，还要确保自己不会因为一次重大损失而退出游戏。**



**不要把观点当成事实**

**不要追求掌握所有信息，而要学会抓住关键问题**

**不要用一次结果评价一个人的全部决策能力**
