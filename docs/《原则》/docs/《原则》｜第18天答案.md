# 《原则》｜第18天答案

治标更要治本



原则第18天答案



比如白天餐馆的故事。服务员上错菜，经理批评服务员，重新上菜，事情暂时解决了。但如果真正的原因是点菜系统设计不合理，那么无论批评多少次，同样的错误都可能再次发生



批评服务员是在处理结果，改进点赞流程才是处理原因



生活中也是一样的。比如孩子每天早上起床迟到。父母每天催促，甚至发脾气。但如果真正的问题是孩子每天晚上睡得太晚，那么早上再怎么睡，也很难从根本上解决。



再比如一个人总是存不下钱。每个月都告诉自己下个月一定要节约。但如果没有记录支出，也没有建立自动储蓄的机制，那么仅仅依靠意志力，就很难坚持



所以要减少麻烦反复发生，需要改变产生麻烦的机制



那怎样找到根本原因？



试试以下三个方法



第一，先找到反复出现的现象。不要只说自己运气不好，而要认真观察：究竟是什么事情总在重复发生？



第二，连续追问为什么。比如：为什么总是迟到？因为早上起不来。为什么起不来？因为晚上睡得太晚。为什么睡得太晚？因为睡前一直玩手机



这时候原因就从早上起床，转移到了晚上的生活习惯。真正麻烦可能存在多个原因，不能仅靠连续追问就认定找到了答案，还需要观察和验证



第三，改变一个关键环节，再观察结果。比如睡前把手机放到另一个房间，连续尝试两周，看看早上迟到的次数有没有减少



如果有效，就把它变成长期规则。如果没有效果，就继续寻找其他原因



今天，我们建立第18条人生原则：当同一个麻烦反复出现时，不要只增加解决它的次数，而要寻找它的根本原因，并通过改变流程、环境或者规则，减少它再次发生的可能



最后送大家一句话：智慧就是尽可能减少掉进同一个坑里多次的概率🤫
