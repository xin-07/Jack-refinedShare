# 《原则》｜第12天答案

应该相信谁

原则第12天答案——观点的正确性，并不是由支持他的人数决定的

书中有个概念叫可信度加权决策，就是在做重要决定时，不应该只统计有多少人支持这个观点，还应该考虑这些人的知识、经验，以及过去判断的可靠程度

比如买房子的故事。九个朋友都觉得房子不错。只有一个结构工程师提醒你，地基可能不行。如果按照人数算，就是九比一，但工程师具有的相关经验，而且能够指出具体的异常现象，那么它的题型可能更重要

我们每天接触大量信息。有说怎样教育孩子。有聊怎样投资，或某个行业一定赚钱。如果每听到一种观点，我们都被对方的自信、名气或者支持人数影响，就很容易失去自己的判断

这里分享个方法。遇到重要分歧时，不要急着站队，先问自己

谁真正了解？判断依据是什么？有没有办法通过事实、数据或者小规模实验来验证？

送大家：真理不会因为赞成的人少而改变，也不会因为赞成的人多就自动成立，保护独立思考和验证的能力！



可信度加权决策，并不是说专家永远正确，而是说不同人的意见不应该被赋予完全相同的权重。

**观点的数量，不等于观点的质量。**

**真正值得信任的人，不是永远声称自己正确的人，而是能够根据事实修正自己判断的人。**

**不要把别人的观点当成自己的答案，要学会判断提出观点的人是否真正值得信任。**
