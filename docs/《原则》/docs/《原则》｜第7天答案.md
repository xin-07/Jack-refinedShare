原则第7天答案
有两种人，一种是正在做事情的人。另一种是站在旁边，观察这套做事方法是否有效的人

比如你经营一家公司。每天需要处理员工、客户、成本和收入。但作为观察者，你还应该定期问自己为什么我总是在某类事情上判断失误？为什么某些员工的表现始终没有达到预期？为什么过去有效的方法，现在越来越没有效果？

这两种角色关注的事情完全不同，做事的人关注眼前怎么完成任务，观察者关注自己做事的方式是否需要改变

所以今天我（Jack）希望大家尝试一个练习。回想最近一个比较重要的决定，投资、工作安排，或者一次教育孩子的选择，然后把自己当成一个旁观者，回答

一，如果是别人做出这个决定，我会怎样评价？
二，有没有受到情绪、面子或者过去经验的影响？
三，如果重新选择，我还会采用同样的方法吗？为什么？

当你理解为什么这样判断，就已经开始建立自己的决策系统了
跳出当事人的视角，想观察别人一样观察自己



有意思的心理现象：当我们身处一件事情之中时，很容易受到情绪和立场的影响

心理学中有一个相关概念叫作**自我距离（Self-Distancing）**。
简单来说，就是在思考自己的问题时，尝试从旁观者的角度观察自己，而不是完全沉浸在当时的情绪中。

**复盘不是为了证明过去做得不好，而是为了让下一次做得更好。**

**跳出当事人的视角，像观察别人一样观察自己。**

**不要只做一个努力把事情做对的人，还要做一个能够发现自己为什么做错，并不断改进的人。**
