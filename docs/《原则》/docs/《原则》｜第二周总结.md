# 《原则》｜第二周总结

真正认识自己就是进步的开始

原则第二周总结

这一周，我们围绕一个主题展开：如何认识真实的自己

第六天，我们讨论了认知盲点。为什么我们总能发现别人的不好，却很难发现自己？我经常把自己看到的那部分现实，当成了全部现实

第七天，我们讨论了如何跳出自己的视角。一个人不仅要学会做决定，还要学会观察自己为什么这样做决定。过去的成功经验 也可能成为未来判断的障碍

第八天，我们讨论了为什么人会本能的反驳。很多时候，别人只是指出我们某个行为存在不好，我们却把它理解成了对整个人的否定

第九天，我们讨论了承认不知道的价值。真正优秀的人，不是任何不对都有答案，而是清楚自己的知识边界，知道什么时候应该向更有经验的人学习

第十天，我们讨论了如何面对自己的弱点。一个人不需要什么都会，但应该知道哪些弱点必须改善，哪些可以通过合作、工具和机制来弥补

总结一句：有勇气发现自己的不足是真正的自信



**有勇气发现自己的不足，才是真正的自信。**
真正的自信，不是认为自己永远正确，而是即使发现自己错了，也有勇气面对、修正和继续成长。
不要把时间花在维护一个完美的自我形象上，而要把时间花在让真实的自己变得更好。
