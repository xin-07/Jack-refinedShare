# 《原则》｜第17天

为什么写日记如此的重要



原则第17天思考



假设有两个人，都在五年前买入了一只股票。五年以后，股价上涨了200%。第一个人非常高兴。说我早知道这家公司一定会成功，你看，我当年的判断多么准确



第二个人也很高兴。但他做了一件不一样的事情。他打开五年前写下的投资记录。上面清楚写着，当初买入这家公司的三个理由，以及他最担心的两个风险。结果他发现，自己当初预测的增长动力，其实并没有真正出现。公司股价上涨，主要来自另外一个他当年根本没有预料到的新业务



也就是说，两个人虽然都赚了钱，但第二个人发现一件非常重要的事情：自己当初的判断，并没有想象中那么准确



如果未来他们还要做十次投资，谁更有可能不断改善自己的判断能力？



大家还记得做完直播我（Jack）说过的关于口罩时期我写日记预测房价的走势的故事吗，你当时听了什么感受



今天大家想想。如果人的记忆会受到最终结果的影响，我们应该怎样客观评价自己过去的决定？





**不要相信自己记忆中的过去，要学会用过去真实留下的记录检验自己。**



写日记不是为了证明自己曾经多么聪明，也不是为了反复回忆自己犯过多少错误。

而是为了让未来的自己能够客观地评价过去的自己。



五年以后，你再回头看今天的记录，应该能够回答：

当初我是怎么想的？为什么这样决定？哪些判断正确？哪些地方错了？我究竟有没有进步？

**没有记录，经历容易变成记忆；有了记录，经历才有机会变成可以检验的经验。**
