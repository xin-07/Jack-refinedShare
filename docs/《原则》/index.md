# Jack带你读《原则》

《原则》（Principles）是瑞·达利欧（Ray Dalio）的代表作。他是全球知名投资机构桥水基金的创始人，把自己几十年来在投资、管理和生活中积累的经验，总结成了一套做事和决策的方法。

这本书最重要的不是提供标准答案，而是帮你建立一种能力：

- **研究原因**：不只经历事情，还要研究事情为什么发生
- **总结规律**：从每一次经历中提炼可复用的判断依据
- **修正行动**：让每一次经历都成为下一次行动的依据
- **面对现实**：原则不是束缚自己的教条，而是帮助自己更好地面对现实的工具

同样是投资亏钱，有人只会抱怨运气不好，有人却会认真分析自己当初为什么做出那个决定；同样是和别人发生争执，有人只想证明自己是对的，有人却会思考对方的观点有没有值得自己学习的地方。时间长了，这些不同的思考方式，会让人走向完全不同的人生。

我们还是白天一篇引发大家思考，晚上结合书中的观点和生活案例给出答案。这本书我想多做一步：每天帮大家总结一条属于自己的原则。这样 30 天结束，每个人都可以整理出一份自己的《人生原则手册》。

**不要让经历只是经历，要让每一次经历都成为下一次行动的依据。**
