# 《小岛经济学》｜第6天答案

第六天读小岛经济学：借 本身不可怕，关键看它有没有提高你的生产力



我(Jack)的理解，借不是绝对好，也不是绝对坏。关键看你借来的资源，用到了哪里。



如果小岛上的人借鱼只是为了多吃几顿，那鱼吃完以后，他还是原来的他，甚至还欠了💸。但如果他借鱼是为了撑过这几天，做出捕鱼工具，以后每天能抓到更多鱼，那这笔钱就可能变成改变命运的机会



生活里也是一样。借钱消费、炫耀、买没必要的东西，很危险。但如果借钱是为了学习技能、扩大生产、买入能产生现金流的资产，就有可能是好债务。



我做房产最大的感受就是：借不可怕，可怕的是没有现金流。只要资产本身能稳定创造收入，借就可能是工具；如果只幻想涨价，那压力会非常大。



所以判断一笔债，先问一句：



它是在让我变好，还是只是在提前透支未来？
