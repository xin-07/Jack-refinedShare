# 《小岛经济学》｜第19天

什么人能在危机中受益——读小岛经济学今日提问

昨天我们讲到，经济危机并不是突然发生，而是繁荣时期的过度借贷、盲目乐观和风险积累，最后一起爆发。

但危机来了以后，同样生活在一个小岛上，为什么有的人损失惨重，有的人却能买到更便宜的工具、房子和资产，甚至让自己更上一层楼？

是因为他们更聪明、更幸运，还是因为在繁荣的时候，他们做了不一样的准备？

仔细想想，因为很快 这样的机会就会来临🦌

<br />

这一篇让我明白：

**危机不会让所有人都失败，它只是放大了每个人之前的选择。**

有人在繁荣时期透支未来，所以危机来临时只能被动承受；有人在繁荣时期保持理性、积累现金、提升能力，所以当机会出现时，他们拥有更多选择。

这也是《小岛经济学》一直强调的长期思维：

**真正决定你能不能抓住机会的，不是危机来临的那一天，而是你在危机来临之前，做了怎样的准备。**
