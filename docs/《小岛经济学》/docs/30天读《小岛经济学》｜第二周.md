# 30天读《小岛经济学》｜第二周：从利息到通胀，开始读懂真实世界的经济运行

这周五期预告



这周我们会继续读《小岛经济学》，从小岛上的抓鱼故事，进入更接近现实社会的经济问题。



第一期，我们会聊：利息为什么存在？

为什么别人愿意把鱼借给你，不能只拿回原来的鱼？



第二期，我们会聊：分工为什么会让大家都变富？

为什么有人专门捕鱼，有人专门做工具，反而整个小岛效率更高？



第三期，我们会聊：贸易是不是一方占另一方便宜？

为什么两个人交换东西，可能不是谁吃亏，而是双方都变好了？



第四期，我们会聊：货币为什么会出现？

为什么小岛上的人后来不直接用鱼交换，而需要一个大家都认可的东西？



第五期，我们会聊：纸币为什么容易出问题？

当钱越来越多，但真正的鱼、工具、房子没有变多，生活会发生什么变化？



这周五期，会越来越接近我们今天的现实生活：借钱、利息、合作、交易、货币、通胀。
