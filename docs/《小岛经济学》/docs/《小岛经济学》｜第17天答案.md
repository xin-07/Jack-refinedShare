# 《小岛经济学》｜第17天答案

关于为什么会经济繁荣——读小岛经济学的思考



直接给我的答案：繁荣不是因为钱变多，而是因为每个人都变得更有效率！



经济真正繁荣的原因，从来不是印了更多钱，而是生产力提高了⚡



小岛上的人没有变多，但他们会储蓄、会做工具、会分工合作、会交换资源、甚至会和别的岛互换资源、会利用银行让资金流向更有效率的人。结果就是，同样一天，每个人都能创造更多财富。



这也是我为什么一直鼓励大家学习、健身、读书、做自媒体。



这些事情短期可能赚不到钱，但它们都在提高你的生产力。生产力提高以后，你未来创造价值的能力就会越来越强🎉



所以真正让一个集体、一个家庭、一个人越来越富有的，不是钱越来越多，而是每个人都在持续提高自己的生产力，并且让资源流向更有效率的地方。



这也是《小岛经济学》到目前为止，我觉得最重要的一句话🦌
