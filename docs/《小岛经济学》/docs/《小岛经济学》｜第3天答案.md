# 《小岛经济学》｜第3天答案

第3天关于工具的思考：

工具的本质，是放大人的能力



工具之所以重要，是因为它能让同样一个人，在同样的时间里，创造更多价值。



小岛上的人徒手抓鱼，一天只能抓一条；有了渔网，他可能一天抓三条。这个时候，他不是更努力了，而是生产力提高了。



这点放到今天也一样。AI工具，手机是工具，自媒体平台是工具，房子和股市等也是工具。工具用得好，普通人的能力就会被放大。



我(Jack)以前做房产，也是慢慢明白，房子不只是房子，它是一个现金流工具。你买得对、管理得好，它就可以持续帮你创造收入。



所以普通人不要只拼体力，更要学会升级工具。

你用什么工具，就决定你的时间能被放大多少倍。



好好想想 你现在使用了多少种工具🛠
