# 《小岛经济学》｜第5天

读小岛经济学第5天



小岛上的人省下一点鱼，花时间做捕鱼工具。这个过程其实很有意思，他没有把所有鱼都吃掉，也没有把多余的时间拿去享受，而是用今天的一点牺牲，换未来更强的捕鱼能力。



问题来了：如果他把省下来的鱼全部吃掉，这叫消费；如果他靠这条鱼撑过一天，做出一个以后能抓更多鱼的工具，这又是什么？



同样都是花掉资源，为什么有些花费会让人越来越轻松，有些花费却只会让人爽一下，然后继续回到原地？



今天的问题是：



投资和消费最大的区别是什么？普通人怎么判断一笔钱是在买快乐，还是在买未来？



大家可以先去书里找答案，也可以自己想一想、写一写，或者和AI聊聊。晚上我(Jack)发我的理解





我的看法：

我认为第五天的内容，是真正开始改变一个人消费观的一天。



前四天更多是在回答财富是怎么来的，而第五天开始回答一个更现实的问题：



为什么同样赚100块钱，有的人越来越富，有的人永远存不下钱？

关键不是收入，而是资源流向哪里。



我喜欢的一句话是：

消费满足今天，投资创造明天。



投资的本质，是把今天的资源，变成未来持续创造价值的能力。



总结：

消费让今天更舒服，投资让未来更轻松。
