# 《小岛经济学》｜第11天

关于钱变多的提问-读小岛经济学



前面我们讲到，货币最开始出现，是为了让交换更方便。小岛上大家不再每次都用鱼换工具、用工具换房子，而是用一种大家都认可的东西来做交换媒介。



但问题来了：如果这个“钱”本来代表的是背后真实存在的鱼、工具和劳动，后来有人发现，钱可以印出来，而且印起来比抓鱼、做工具、盖房子容易得多。



那小岛会发生什么？



如果钱变多了，但鱼没有变多，工具没有变多，房子没有变多，大家真的会更富吗？还是说，只是每个人手里的数字变大了，但能买到的东西反而变少了？
