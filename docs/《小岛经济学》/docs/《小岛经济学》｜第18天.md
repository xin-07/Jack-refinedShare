# 《小岛经济学》｜第18天

经济危机如何形成——30天读懂小岛经济学今日提问

前天我们讲到，泡沫的形成，是因为越来越多人开始相信：“价格一定还会继续上涨。”

但《小岛经济学》接下来提出了一个更重要的问题。

如果有一天，小岛上的人突然发现，未来命运自己想象得那么美好，借钱得人开始还不上债，买东西的人越来越少，大家都开始担心💣

原来一直上涨的价格，还会继续涨吗？

如果越来越多人同时想卖，却没有人愿意买，会发生什么？

今天的问题来了：

经济危机为什么会发生？

它真的事突然发生的吗？还是很多年前，就已经埋下了种子/

作为普通人该如何不陷入经济危机之中而无法自救呢？

晚上我会给出我的解药🦌

<br />

这一篇让我意识到：

经济危机往往不是从坏消息开始，而是从过度乐观开始。

真正危险的时候，不是大家都害怕，而是所有人都觉得"风险已经不存在了"的时候。

所以，无论面对AI、房地产，还是任何热门行业，都应该保持理性。

不要只看价格涨了多少，更要看：

它创造的真实价值有没有持续增长。
