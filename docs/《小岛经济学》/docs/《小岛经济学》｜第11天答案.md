# 《小岛经济学》｜第11天答案

关于钱变多的回答——纸币最大的问题，是它容易让人误以为钱就是财富



纸币本身不是问题，问题在于它太容易被创造出来。



小岛上真正的财富，是鱼、工具、房子和人的生产能力。但如果管理者不断增加纸币，真实财富却没有增加，那结果不是大家一起变富，而是价格上涨，钱的购买力下降。



这点放到生活里特别真实。你以为自己工资涨了，但房租、保险、食物、人工、维修也都涨了。最后你发现，数字变大了，但压力没有变小。



我(Jack)做房产也很明显。房价涨、地税涨、保险涨、维修人工涨，最后都要有人承担。



所以普通人一定要明白：钱只是符号，真正保护你的，是生产力、资产、现金流和看懂规律的能力。
