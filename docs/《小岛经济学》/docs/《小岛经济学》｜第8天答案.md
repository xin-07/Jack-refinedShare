# 《小岛经济学》｜第8天答案

第8天小岛经济学关于分工协作的思考：分工协作的出现让每个人把时间用在更擅长的地方🦌



我(Jack)的理解是分工不是让人变窄，而是让人的效率变高。



小岛上，如果每个人什么都自己做，时间会被大量浪费。但如果有人专门捕鱼，有人专门做工具，有人专门盖房子，大家互相交换，整个小岛能创造出来的东西就会变多👋



这点放到今天也一样。有人擅长拍视频，有人擅长剪辑，有人擅长销售，有人擅长管理。不是每个人都要什么都会，而是要找到自己最能创造价值的地方🛌



我自己二十多岁就知道 我最重要的能力之一就是把复杂的事情讲简单，把问题讲清楚，把人和人之间的想法连接起来，所以我找的工作都是这方面的🤫



任何人真的不一样，但不要总羡慕别人，先问自己：我在哪个位置上，最容易创造价值？
