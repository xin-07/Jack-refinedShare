# 《小岛经济学》｜第16天答案

如何看懂泡沫/读小岛经济学 答案

泡沫最可怕的，不是价格上涨，而是预期脱离了现实。



价格上涨本身不是泡沫。



如果小岛上的鱼越来越多、工具越来越先进、生产力越来越高，那么财富增加，价格上涨可能是合理的。



真正的泡沫，是大家开始相信：“以后一定还会涨。”



于是，买的人越来越多，不是因为它能创造更多价值，而是因为相信以后有人愿意出更高的价格接手💣



我（Jack）做房产这些年，最大的体会就是判断一套房子，不能只问以后能卖多少钱，更要问它今天能不能产生稳定现金流。



如果一顶资产脱离了它本身创造价值的能力，只剩下“一定会涨”这个理由，那就格外小心⚡️



所有当你投资时，问自己一句：



我买它，是因为它真的能持续创造价值，还是只是希望下一个用更高的价格买走？
