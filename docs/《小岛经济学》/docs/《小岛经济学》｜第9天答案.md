# 《小岛经济学》｜第9天答案

关于交易的思考 解答第9天小岛经济学



我(Jack)的理解是贸易的本质不是占便宜，而是交换彼此更需要的东西。



小岛上，会抓鱼的人鱼多，但缺工具；会做工具的人工具多，但缺鱼。他们交换以后，双方都拿到了自己更需要的东西，所以两个人都变好了。



这点在生活里特别常见。比如我做房产，我不可能所有事情都自己干。修水管、做电工、换屋顶、报税、法律文件，很多时候找专业的人做，表面看是花钱，实际上是用钱买效率、买专业、买时间。



自媒体也一样。有人会写，有人会剪辑，有人会运营，有人会直播。合作好了，不是互相占便宜，而是彼此放大。



所以普通人要懂贸易和合作：你要有别人需要的价值，也要学会用交换获得自己缺少的能力
