# 《小岛经济学》｜第19天答案

危机中的机会，属于繁荣是就留有余地的人——读小岛经济学启发



危机来了以后，真正稀缺的不是机会，而是现金、信用、判断力和承受波动的能力。



繁荣的时候，很多人会觉得钱放着浪费，于是借更多的钱，把资源全部押上去。等危机来了，他们为了还债，只能低价卖掉资产。



而另一些人平时不过度负债，保留现金流和安全垫，就能在别人被迫卖出的时候认真选择。



这也是我一直讲“六年之约”的原因。让大家存钱，不是让你永远不投资，而是先给自己积累选择权。



真正好的机会，往往不会在人声鼎沸的时候出现，而是在大家害怕、缺钱、想放弃的时候出现。



平时存下的钱，不只是存款，也是未来机会出现时，你手里的入场券



大家想买车 买手机 买电脑的时候 先再三思考一下🙏





在繁荣的时候保持克制，在平时积累现金、能力和判断力。这样，当机会真正来临时，你才能从容地抓住它，而不是因为没有准备，只能眼睁睁看着机会从身边溜走。
