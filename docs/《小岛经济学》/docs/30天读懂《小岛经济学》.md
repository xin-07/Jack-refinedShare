# 30天读懂《小岛经济学》：不直接给答案，带你重塑财富底层逻辑

孩子们，下周一开始，我们专属会员正式开启一个新的系列：30天读懂《小岛经济学》



这次我(Jack)不想用传统讲课的方式直接告诉大家答案。每天中午，我会从书里的内容提炼出一个问题。大家可以去书中找答案，也可以自己想一想🤔写一写，甚至可以和AI对话，把这个问题聊透。更好的方式是，直接拿起手机，把你的想法录下来。哪怕只有一分钟，也是在训练你的表达能力和思考能力。



晚上，我会再发一篇我的理解。不是标准答案，而是我结合自己的生活、房产、投资、现金流和这些年经历之后，对这个问题的真实看法。
