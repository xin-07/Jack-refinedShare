# 30天读《小岛经济学》｜第四周预告

30天读懂《小岛经济学》这周五篇预告



前三周我们已经把《小岛经济学》的基础逻辑搭起来了：生产力、储蓄、工具、借贷、利息、分工、贸易、通胀、银行……



明天开始，我们会进入这本书最精彩的一部分，也是和普通人生活最相关的一部分。



第一篇：为什么经济会越来越繁荣？

财富到底是怎么一点点积累起来的？



第二篇：泡沫是怎么形成的？

为什么很多人都觉得自己越来越有钱，最后却发现只是幻觉？



第三篇：经济危机为什么会发生？

危机真的是突然出现的吗，还是很多年前就已经埋下了种子？



第四篇：为什么有人总能在危机中抓住机会？

同样的环境，为什么有人越来越强，有人却越来越难？



第五篇：《小岛经济学》给普通人最大的启发是什么？

如果只能记住一本书里的几个观点，我希望大家记住哪些？



下周开始就解读新的一本书了。



大家有推荐的吗🎉





普通人在经济周期里，应该怎样思考、怎样准备自己。



很多人总想预测下一次机会什么时候来，但《小岛经济学》更想告诉我们的其实是：



机会往往属于那些在平时就提高生产力、保持储蓄、重视现金流、拥有长期思维的人。



如果说前三周是在学习经济学的“基础语法”，那么第四周就是开始真正“读懂现实世界”。



我也很期待这一周的内容，因为它不仅是在讲经济，更是在帮助我们理解：为什么有些人总能在变化中站稳脚跟，而有些人总是被环境推着走。
