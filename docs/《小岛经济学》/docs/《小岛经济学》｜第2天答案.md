# 《小岛经济学》｜第2天答案

读小岛经济学第二天答案：储蓄的本质，是给未来买时间



储蓄不是为了让钱躺着不动，而是为了让你有选择权🎊



小岛上的人如果每天抓一条吃一条，就永远没有时间做工具。他必须先省下一点鱼，才能腾出空间去改进生产力🦌普通人也是一样，如果每个月赚多少花多少，就永远只能被账单追着跑。



我自己做房产以后，对这一点感受特别深🤫维修、地税、保险、空置期，很多支出不会提前和你打招呼。如果没有现金储备，一点小问题都会变成巨大压力。



有机会和大家说说我sell put的策略，更是能体现平时的存款能如何在机会来临时创造巨大价值。



所以储蓄不是目的，储蓄是缓冲垫，是机会票，也是你人生的安全边际。



普通人想改变命运，第一步不是冲动投资，而是先让自己每个月能留下钱。



你敢不敢给自己一个承诺，一年内存下多少钱👍
