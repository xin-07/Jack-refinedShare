# 《小岛经济学》｜第10天

关于货币的产生/读懂小岛经济学第十天提问



小岛上的人开始分工以后，有人捕鱼，有人做工具，有人盖房子，大家也开始互相交换。



但问题来了：如果做工具的人想吃鱼，可捕鱼的人刚好不需要工具，那这笔交换是不是就很难发生？



鱼还会坏，工具又不能切成很小一份来换。交换越来越复杂以后，小岛上的人就需要一种大家都愿意接受、方便保存、方便计算价值的东西。



今天的问题是：



货币为什么会出现？钱最开始到底是为了让人变富，还是为了让交换变方便？



不知道这个问题大家以前认真想过吗





我看完之后的感受：

货币不是为了让人变富才出现的，而是为了解决“交换卡住”的问题。



以前总觉得钱就是财富，看完今天的内容才发现，钱本身并不是财富，而是一种帮助大家交换的工具。



如果没有货币，每次交易都要碰运气——我有你想要的东西，你也刚好有我需要的东西。一旦双方需求对不上，再有价值的东西也换不出去。货币的出现，就是为了降低交易成本，让交换变得更简单、更高效。



钱解决的是“交换问题”，但它并不能自动解决“价值创造问题”。真正让人变富的，还是你能提供什么别人需要的东西。
