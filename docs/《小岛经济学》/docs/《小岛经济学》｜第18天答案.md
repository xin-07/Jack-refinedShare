# 《小岛经济学》｜第18天答案

经济危机中如何存活——读小岛经济学思考



经济危机不是突然发生，而是长期积累后的结果，就像压垮骆驼的最后一根稻草。



真正的问题，是在繁荣的时候，大家借了太多的钱，承担了太大的风险，还相信未来一定会越来越好。



一旦有人开始还不上债，信心下降，借钱减少，消费减少，价格开始下跌，整个循环就会反过来运转。



我(Jack)做房产一直提醒自己一件事：赚钱的时候，更要留现金。



因为真正的机会，很多时候不是出现在所有人都乐观的时候，而是出现在别人没有现金、不得不卖资产的时候。



所以我一直和大家说“六年之约”。存钱不是因为悲观，而是因为我知道，经济一定有周期。
