# 《小岛经济学》｜第14天

欠款为什么会越滚越大的提问——30天读懂小岛经济学

前面我们讲到，管理者花钱大概有三种方式：收税、借钱、印钱。

今天我们继续想一个问题：如果小岛管理者今天想让大家过的更舒服，但又不想马上收税，他就可以先借鱼、借钱、借资源。

短期看，大家好像都没那么痛苦。但是，借来的东西未来要不要还？如果未来还不上，是不是又要继续借新的，去还旧的？

一开始只是借一点，后来利息越来越多，压力越来越大，最后整个小岛可能都被债务拖住。

今天的问题是：债务为什么会越滚越大？一个人、一个家庭、一个社会，什么时候最容易被债务困住？

<br />

这一篇让我明白：

债务并不会自动让人变穷，也不会自动让人变富。

真正决定债务好坏的，不是借了多少钱，而是借来的钱有没有创造未来更大的价值。

所以，不管是个人、家庭还是一个社会，都应该问自己一个问题：

今天借来的每一分钱，未来能不能帮助创造更多财富？

如果答案是可以，那么债务可能是一种推动成长的工具；如果答案是否定的，只是为了维持眼前的生活水平，那么债务就更容易变成越来越沉重的负担。这也是《小岛经济学》这一章最重要的启发
