# 《小岛经济学》｜第14天答案

关于债务越滚越大的思考- 读小岛经济学



债务本身不是问题，问题是你借来的资源有没有提高未来生产力。是否会把未来提前花掉？



如果小岛借鱼是为了做工具，未来能抓更多鱼，那债务可能是好事。但如果借鱼只是为了今天多吃一点、让大家暂时舒服一点，未来生产力没有提高，那还债的时候就会越来越痛苦。



一个家庭也是一样。如果贷款买能产生现金流的资产，可能是工具；如果借钱只是消费、面子、冲动购物，那就是提前透支未来。





我做房产感受很深：贷款不可怕，现金流断了才可怕。只要租金覆盖不了利息、地税、保险和维修，债务就会从工具变成枷锁。



所以记住一句话：债务能不能帮你变强，决定它是机会还是陷阱。



所有人留言： 生意里最重要的是：现金流！
