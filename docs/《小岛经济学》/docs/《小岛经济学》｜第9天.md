# 《小岛经济学》｜第9天

商业和交易是占便宜还是真的创造了价值/读懂小岛经济学第9天提问🙋

小岛上，有人特别会抓鱼，有人特别会做工具。后来他们开始交换：会抓鱼的人，用多出来的鱼换工具；会做工具的人，用工具去换鱼。

问题来了：这种交换是不是一定有一方吃亏？如果两个人都是自愿交换，为什么他们都可能觉得自己赚了？

再想一下，如果一个人什么都自己做，可能每天都很累，但效率很低。可如果大家把自己多出来的东西拿出来交换，整个小岛是不是反而能创造更多的财富？

咱们是农耕文明 很多人至今都不能理解交易的作用我(Jack)二十岁之前也一直以为只有生产才是有价值🤣

今天的问题是：

贸易到底是不是一方占另一方便宜？为什么自愿交换，可能会让双方都变得更好？

<br />

个人感受：

如果两个人都愿意交换，那说明一个很简单但很重要的事实：

你给我的东西，比我自己做/得到它的成本更低；我给你的东西，对你也是一样。

所以交易不是谁占谁便宜，而是：

👉 双方都用更低的成本，获得了更高的价值。

价值不是在生产那一刻产生的，而是在交换发生时被“确认”的。
