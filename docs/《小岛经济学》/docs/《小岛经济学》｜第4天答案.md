# 《小岛经济学》｜第4天答案

第4天答案：先答一下是为了以后不一直苦

真正改变命运的事情，刚开始大多都不舒服。



小岛上的人如果想做工具，就要先放弃一点眼前的安逸。普通人也是一样。你想存钱，就要少消费；你想健身，就要忍受训练；你想做自媒体，就要接受一开始没人看；你想学经济学，就要先逼自己思考。



我(Jack)以前做房产也一样。买房、维修、找租客、处理各种问题，前期都很麻烦。但如果系统搭起来，后面它就可以变成稳定现金流。



所以不要害怕短期不舒服。很多时候，今天主动吃一点苦，是为了未来少被生活逼着吃苦。



这个暑假 你准备让自己主动做什么 预期吃哪些苦😭
