# 《小岛经济学》｜第7天

读小岛经济学第7天

小岛上，如果一个人想做捕鱼工具，但手里没有多余的鱼，他可能会去想别人借鱼。

但问题来了：如果别人把鱼借给他，为什么不能只拿回原来那一条鱼？为什么借出去的人，通常会要求以后多还一点？

如果我今天把鱼借给你，我自己就会少一条鱼，也承担了你未来还不上的风险，还失去了用这条鱼做别的事情的机会。

所以今天的问题是：

利息为什么存在？它到底是剥削，还是时间、风险和机会的价格？

你在看这篇之前 你觉得利息是什么

<br />

个人理解

利息，本质上不是钱的价格。

而是时间、风险和机会成本的价格。

利息本身并不会让人变穷。真正让人越来越累的，是：

借的钱，没有创造新的价值。

所以：同样是利息。

有人把它当成工具、有人把它当成枷锁。

区别在于：借来的资源有没有提高生产力。

利息不是惩罚借钱的人，而是借用别人时间、承担别人风险所需要支付的价格
