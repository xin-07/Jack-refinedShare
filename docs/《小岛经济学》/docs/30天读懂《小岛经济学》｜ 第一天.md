# 30天读懂《小岛经济学》｜ 第一天

岛上有几个人，每天靠抓鱼生活。最开始，他们没有工具，只能用手抓鱼。一个人一天幸幸苦苦，只能抓到一条鱼，而这一条鱼刚好够他当天吃掉。



也就是说，他每天都在忙，但每天都只是勉强活下去。没有多余的鱼，也没有时间去做别的事情。



如果这个时候，突然有人给岛上的每个人发很多钱，大家是不是变富了？还是说，真正能改变他们生活的，不是钱，而是别的东西？
