# 30天读《小岛经济学》｜第三周预告

读懂小岛经济学这周五篇预告



上周我们讲到，货币为什么会出现。钱的本质不是财富，而是让交换更方便的工具。



这周我们会继续往下走，开始进入更接近现实生活的部分。



第一篇：纸币为什么容易出问题？

如果小岛上的钱可以随便变多，但真正的鱼、工具、房子没有变多，会发生什么？



第二篇：通胀到底是怎么来的？

为什么大家手里的钱变多了，反而可能觉得生活更贵、更难了？



第三篇：真弗花的钱从哪里来？

如果一个管理小岛的人想给大家发福利、修东西、解决问题，他的钱到底从哪里来？



第四篇：债为什么会越滚越大？

为什么一开始看起来只是借一点，最后可能变成越来越沉重的负担？



第五篇：阴行到底靠什么赚钱？

为什么音行看起来只是帮大家存钱、借钱，但它却能成为经济系统里非常重要的一环？



这周的内容会越来越接近我们今天的生活：纸币、通胀、真弗支出、寨务、阴行。
