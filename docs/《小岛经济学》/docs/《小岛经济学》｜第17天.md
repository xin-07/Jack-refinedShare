# 《小岛经济学》｜第17天

经济为什么会繁荣？读小岛经济学今日提问

前面我们讲了储蓄、工具、借款、利息、分工、贸易、货币、银行......

现在回头看，小岛上的生活是不是发生了很大的变化？

最开始，每个人只能徒手抓鱼，一天抓一条，刚好够自己吃。后来有人学会了储蓄，有人做出了工具，有人开始分工合作，有了贸易，有了货币，也有了银行。

神奇的是，小岛上的鱼越来越多，工具越来越先进，每个人的生活也越来越好。

今天的问题来了：

经济为什么会越来越繁荣？

到底是什么力量，让一个社会一年比一年富有？

是因为钱越来越多？还是因为有了其他更重要的东西？

<br />

这一篇让我明白：

经济繁荣，从来不是钱越来越多，而是创造财富的能力越来越强。

储蓄、工具、贸易、货币、银行，看似是不同的经济现象，其实都在服务同一个目标——提高整个社会的生产效率。

所以，无论是一个国家，还是一个普通人，真正值得长期投入的，不是追逐更多的钱，而是不断提升自己的生产力、创造力和解决问题的能力。

因为真正决定未来财富的，从来不是你拥有多少货币，而是你能够持续创造多少价值。
