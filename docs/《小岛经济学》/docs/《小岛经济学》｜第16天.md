# 《小岛经济学》｜第16天

泡沫怎么形成/读小岛经济学今日提问

小岛上的人越来越会捕鱼，也做出了越来越多工具，生活一天比一天好。

后来，大家开始相信：未来一定会越来越好。

于是，有人借更多鱼去投资，有人愿意出更高的价格买工具，也有人觉得，只要选择买下来，以后一定还能卖得更贵。

一开始，每个人都赚到了钱，大家越来越乐观，甚至觉得赚钱越来越容易。

今天的问题来了：

为什么当所有人都觉得未来一定会越来越好时，反而最容易产生泡沫？

泡沫到底是什么？

它是财富真的增加了，还是大家对未来的预期越来越高？

结合现在储存 光通信 AI等模块 思考下 晚上我给答案

<br />

我最大的感受

今天最大的启发不是告诉我们泡沫一定不好，而是提醒我们：

真正危险的时候，往往不是大家害怕，而是所有人都觉得"这次不一样"，赚钱已经变得很容易的时候。

市场最容易让人失去理性的，不是恐惧，而是过度乐观。

所以，无论面对AI、存储、光通信，还是未来任何热门行业，都应该回到一个最基本的问题：

它创造的真实价值，到底有没有跟上价格上涨的速度？
