# 《小岛经济学》｜第一天答案

第一天答案：钱不是财富，生产力才是财富



我的理解是，钱不是财富，钱只是交换财富的工具。



小岛上的人真正缺的不是钱，而是鱼、工具、房子、时间和生产能力。如果岛上的鱼没有变多，工具没有变好，大家只是手里的钱变多了，那生活不会真的变好，最后只会变成东西更贵。



这点我(Jack)做房产以后感受特别深。账户上的数字当然重要，但真正让我安心的，不是数字本身，而是房子能不能租出去，租客能不能按时付租金，扣掉地税、保险、水费、维修之后，还有没有稳定现金流。



一个人也是一样。你手里有多少钱，是结果；你能不能持续创造价值，才是源头。



所以第一天我想让大家记住一句话：



不要只追钱，要先提高自己的生产力。



你能解决问题，能创造价值，钱才会长期流向你。
