# 《小岛经济学》｜第8天

30天读懂小岛经济学第8天



小岛上，一开始每个人都要自己抓鱼、自己做工具、自己解决所有问题。看起来每个人都很独立，但效率其实很低



后来有人发现，自己特别会抓鱼；有人发现，自己特别会做捕鱼工具。如果一个人专门抓鱼，另一个人专门做工具，然后他们互相交换，整个小岛的效率是不是会提高？



问题来了：为什么每个人都只做自己最擅长的事，反而大家都可能过得很好？



今天的问题是：



分工为什么会让社会变富？普通人怎么找到自己最值得长期投入的分工位置？



好好想想 这个直接关系到你现代社会生产力提升的理解🎉





未来真正值钱的，不一定是最辛苦的人，而是最懂得发挥自己优势、善于利用工具、能够与别人高效协作的人。



所以，普通人最值得思考的问题，不是：

我还能做什么？



而是：

我最擅长什么？别人为什么愿意因为这一项能力来找我？
