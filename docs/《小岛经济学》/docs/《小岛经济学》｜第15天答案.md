# 《小岛经济学》｜第15天答案

银行到底怎么赚钱——读小岛经济学的思考



一句话：赚的是资金流中的差价和风险管理的钱银行最基础的赚钱方式，就是把存款人集中起来，再借给需要钱的人。



存钱的人希望安全和一点利息；借钱的人需要资源去买房、做生意、扩大生产。银行在中间承担筛选、管理和风险，所以它收的贷款利息，通常会高于给储户的存款利息，中间差额就是重要利润来源。



但银行也有风险。如果它把钱借给真正能提高生产力的人，经济会更活；如果它把钱大量借给还不起的人，或者大家都以为资产会永远涨，风险就会积累。



我(Jack)做房产特别懂这一点。贷款可以买资产，但前提是现金流能覆盖利息、地税、保险和维修。银行愿意借你钱，不代表这个项目一定安全。



所以普通人要记住：钱能放大机会，也能放大错误
