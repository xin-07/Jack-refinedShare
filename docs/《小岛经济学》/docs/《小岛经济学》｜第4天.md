# 《小岛经济学》｜第4天

读小岛经济学 第4天



小岛上，有个人想做捕鱼工具。但问题是，做工具需要时间。做工具的这一天，他可能就不能像以前一样去抓鱼。



也就是说，他必须先忍受一点短期的不舒服，才有机会换来长期的轻松。



如果他每天都只想着今天吃饱，永远不愿意停下来做工具，那他是不是一辈子都只能靠手抓鱼？



今天的问题是：为什么很多改变命运的事情，一开始都不会让你舒服？



大家可以先去书里找答案，也可以自己想一想、写一写，或者和AI聊聊。晚上我(Jack)发我的理解









把今天的内容总结成一句话就是：

改变命运的事情，往往都是先付费，后享受。



而普通人的本能恰恰相反：

先享受，再买单。



所以人与人的差距，很多时候不是智商差距，也不是资源差距。



而是：



谁更愿意为了未来的自己，忍受今天的不舒服。





如果让我给第4天再加一句收尾的话，我会写：

你今天为未来投资的痛苦，终将变成未来拥有选择权的自由。

因为自由从来不是突然得到的。

自由往往是无数个别人看不见的“不舒服”，一点一点换来的。

这也是为什么我觉得第4天，比前面三天更接近“改变命运”的本质。它讲的已经不是钱，而是在讲一个人的时间观、选择观和人生观。
