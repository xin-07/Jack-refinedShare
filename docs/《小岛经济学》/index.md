# Jack带你读《小岛经济学》

《小岛经济学》（How an Economy Grows and Why It Crashes）是彼得·希夫和安德鲁·希夫兄弟合著的一本经济学入门书。作者用一座小岛上从原始捕鱼到现代经济的演变故事，把储蓄、投资、借贷、通货膨胀、经济危机等抽象概念讲得通俗易懂。

这本书最大的特点是：不堆术语、不讲公式，而是通过一个不断发展的海岛寓言，让你自然而然地理解经济运行的底层逻辑。从一个人徒手抓鱼开始，到发明渔网、产生贸易、出现货币、银行信贷扩张，最终走向经济泡沫——整个过程就像一部迷你经济史。

无论你是经济学小白，还是想重新理解金钱和财富的关系，这本书都值得一读。
