直播有粉丝问如果让我（Jack）重读一次大学，我怎么做



刚好车在保养，等着，写一篇送给刚上大学的朋友



我认真想了一下，如果重新进入校园，我会做这五件事



一，大量阅读

不只读专业课

历史、经济、商业、科技、心理学、人物传记，我都会读

把自己的世界打开



见过的东西都不够多，怎么知道自己真实喜欢什么？

你想想，一个18岁的人和一个22岁读过两百本书的人，脑子里看到的世界可能已经完全不一样了



二，做一个长期项目

一个账号，健身，写文章，也可做一个小生意

有个要求，必须连续做四年



三，主动认识厉害的人

教授，学长，讲座社团比赛里的各种优秀人物

每个星期认识一个



四，开始赚钱

要理解到底是怎么来的，帮别人剪视频，做家教，写东西，卖产品都可以。要体验的知识和能力，是可以有人愿意付钱的



五，疯狂试错

年轻时犯错特别便宜，你有什么输不起的

千万不要想：我要完美的度过这四年！



加油吧 孩子们❤️勇敢做
