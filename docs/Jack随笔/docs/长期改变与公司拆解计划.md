看到大家真的开始系统性地练习“不抱怨”、主动夸奖别人，以及认真存钱，我(Jack)发自内心地为你们高兴。



这些看起来都是很小的事情，但其实都是在一点点重塑自己的性格、习惯和人生轨迹。



大家一定要有耐心。



不要指望做三天就脱胎换骨，也不要因为一周没变化就怀疑自己。



很多改变是看不见的。



就像种树一样，前几个月你看不到什么变化，但根正在地下悄悄生长。



也许要几个月以后，你才会发现自己情绪更稳定了，表达更好了，存款更多了，身边的人际关系也开始变得不一样。



不过我也在想，除了这些长期改变之外，我还想给大家一些能够马上看到提升的东西。



所以我计划从6月1日开始，每周或者每个月，带大家一起拆解一家优秀公司。



不是教大家炒股。



而是学习这个世界是如何运转的。



它靠什么赚钱？

为什么能做到行业第一？

它的护城河是什么？

它犯过什么错误？

普通人能从中学到什么？
