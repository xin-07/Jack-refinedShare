小时候，我（Jack）其实不知道自己以后会走到哪里



我出生在上海一个很普通的家庭

那时候身边大多数人的人生，看起来都有一条很清楚的轨道：读书，找一份稳定的工作，结婚，买房，养孩子，然后慢慢过完一生



我也曾经站在那条路上



只是后来，我一次又一次走到了岔口，第一次，是决定去美国



那时候我根本不知道，这个决定最后会把我带到哪里。

我只知道，如果一直待在熟悉的地方，也许会更安全，可我还是想去看看，一个更大的世界到底是什么样



所以我走了



后来还有很多次



别人上班的时候，我开始研究房子、投资、现金流。

别人觉得赚到钱以后就该享受的时候，我越来越想问自己赚钱到底是为了什么？



等我真的不再需要为了钱工作以后，我原本认为，人会突然变得很轻松



可真正发生的，是另一个问题出现了怎么



如果钱已经够了，我每天醒来，到底是为了什么？



于是我有走上了一条自己以前从来没想过的路





于是认识了你，感谢一路的陪伴
