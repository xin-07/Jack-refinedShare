昨天直播的时候我(Jack)突然意识到



在未来ai越来越发达时代



我(Jack)有义务帮助大家每天都练一件事：开口说话



你可以录口播，也可以对着镜子说，甚至你一个人在开车、洗澡、走路的时候自言自语都可以。实在不习惯，就找你身边的人，把今天看到的一件事，完整地讲给他听



说什么其实不重要，重要的是你每天都在练习把脑子里的东西，变成别人听得懂的话



很多人脑子里想得很明白，一开口就乱了。为什么？



就是两种能力



你每天开口逼自己思考：第一句话怎么让别人愿意听下去？一件事怎么用最简单地话讲清楚？别人可能会问什么？我能不能举个例子？哪些话其实都是废话？



这反而是好事，因为你终于发现自己表达地问题。



所以从今天开始，每天至少说五分钟。别追求完美也别想着一定要发出去



30天以后，回头听第一天的自己，你会发现说话不一样了，思考问题的方式也不一样了



表达不是思考的结果，表达本身就是在训练思考❤️
