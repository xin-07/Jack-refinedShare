很多人都听过Jack直播说的那个短信预测的故事



第一场，他发短信告诉十万人：“今晚主队赢。”



其实另外十万人收到的是：“今晚客队赢。”



比赛结束后，他只给收到正确答案的人继续发。第二场再筛选一次，第三场再筛一次......



连续五次以后，就会有一批人觉得：“这个人太牛了，已经连续对五场了！”于是开始相信他，甚至愿意付费。



这个故事真正可怕的是它让我想到了一件事。



如果把球赛换成股票，会不会也存在类似的筛选逻辑？



假设有很多人在不同方向发表观点。有人看好AI，有人看衰AI；有人看好新能源，有人看空新能源。市场总会轮动，总会有人连续踩中。于是，他们获得更多流量、更多关注、更多采访。而那些判断失误的人，则慢慢消失在大家的视野里。



大家务必用概率思维去判断，这也是我之后着重会讲的内容！
