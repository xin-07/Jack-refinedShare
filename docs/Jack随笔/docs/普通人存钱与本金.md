很多人第一次认识我（Jack），就理解到财务自由



第一反应就是：我要赚更多钱

但对普通人来说把钱留下来才是核心



假设你每个月赚一万，花一万，就算以后涨到两万，你很可能也会花到两万。收入增加并不会自动让你变富，收入和支出之间留下来的那部分，才是你未来真正的本金



所以我建议普通人存钱，不要用“月底剩多少存多少”的方式，而是反过来：工资一到账，先存，再花



比如每个月收入一万，先强制拿出两千，转到一个平时根本不动的账户。剩下八千，才是这个月真正可以花的钱



然后随着收入提高，别马上升级生活。工资从一万涨到一万五，生活费可以从八千涨到九千，但剩下的六千都存下



大家记住：存钱不是为了让你省钱，而是为了有一天，你可以不再为了钱做选择



财务自由的起点，就四个字：埋下种子——本金
