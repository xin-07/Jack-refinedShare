今天，一个曾经和我连线过两次的粉丝突然找到我。他告诉我，自己做了五年的投资，今天灰飞烟灭 500多没了



他踩了三个坑：第一，过度融资；第二，觉得自己买的是好公司，所以一定能穿越周期；第三，在不断盈利的时候，误以为只要还有利润，就可以继续放大风险



我看到后很感慨。因为他第二次和我连线时，问过我想去鲁国投资，却一直没有行动。我说过三句话：不要加杠杆；去土地肥沃的地方撒种子；让时间成为你的朋友



现在回头看，那次连线仿佛是老天提前给过他一次提醒，只是人在不断赚钱的时候，很难真正听进去



我也把这个真实故事送给所有专属会员。请永远记住：投资的第一目标不是赚得有多快，而是确保自己永远不会因为一次错误彻底离场



不加杠杆，分散播种，给时间足够的时间



很多道理，最好在付出代价之前就听懂，而我依旧会在专属会员不断度人，救一个是一个！
